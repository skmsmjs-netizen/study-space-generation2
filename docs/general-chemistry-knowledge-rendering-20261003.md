# 일반화학 연결도 · 실제 휴대전화 표시 결함 수정

사용자가 보낸 iPhone 사진 두 장에서 구조 보기의 같은 개념 상자 반복과 문장 보기의 떨어진 화살표를 확인했다. 기존 공통 `KnowledgeStructure`가 개념 목록을 그린 다음 모든 관계의 양끝을 별도 상자로 반복했고, 문장 보기는 같은 목록의 테두리만 제거했다. 일반화학 상세는 `선행 개념`과 `다시 쓰이는 연결`이라는 UI 역할을 내용 개념처럼 사용했다.

수정은 기존 Dagre와 React Flow, 공통 보기 보존·조작·명조 토큰을 재사용한다. 원문 개념 ID당 한 모듈과 작성된 관계별 한 선을 그린다. 관계의 방향과 설명을 유지하며 인과·동치·역방향을 추론하지 않는다. 실제 글자 높이와 관계 설명의 크기를 읽어 배치 공간을 확보한다. 작은 화면은 참조 모듈의 읽기 폭을 조정한다. 개인 Canvas 좌표·저장된 선·메모는 변경하지 않는다.

구조 보기의 전체 배율과 읽기 배율을 구별한다. 드래그·핀치·확대 버튼·방향키와 구조/문장 전환을 연결한다. 현재 시점과 배율은 기존 사용자·공간·질문별 `view-context`의 탭 세션 저장이다. 같은 탭 새로고침과 화면 재개에서 유지되지만 새 탭·다른 기기·서버 보존을 뜻하지 않는다. 닫기와 폭 변화는 내용·조절값·개인 배치를 초기화하지 않는다. 문장 보기는 같은 개념 정의와 같은 방향·관계 설명을 온전한 문장으로 표시한다. 확인되지 않은 연결 대상과 반복 관계·미작성 설명은 숨기지 않는다.

일반화학 197절 상세는 기존 개념 묶음 대응과 원문에 근거한 지도 관계를 재사용한다. 이 지도를 각 절의 모든 개별 법칙과 수식의 정밀 연결도로 확대하지 않는다. 조건과 새 내용은 해당 질문에서 계속 읽는다. 정적 설명과 실제 작성된 절차는 없는 선을 추가하지 않는다.

로컬 확인: 239 테스트 파일 통과, 하나 보류; 1398 검사 통과, 하나 보류. 프런트엔드 빌드·타입·디자인 토큰 확인 통과. 다섯 WebKit 모사 환경에서 구조/문장·닫기와 호출자 초점·보기 보존, 긴 원문·명조 정렬과 개인 Canvas 보존의 20 흐름을 통과했다. 여덟 지도 × 다섯 환경의 실제 글자·상자·관계 설명 겹침도 확인했으며, 전자 구조 지도의 교차 연결에서 드러난 실제 글꼴 높이 반영 오류를 수정해 다섯 전책 지도 흐름을 통과했다. 물리 기기에서 수정본을 재확인한 것은 아니다. 추가된 `chemistry-knowledge.pw.ts`와 기존 `knowledge-structure.pw.ts`가 실제 사용자 경로를 검증한다. 공개 배포와 공개 자산·흐름 확인은 Actions 결과 이후 별도 기록한다.

교재 모든 문장·수식·그림의 정독 및 개별 항목 전수 분석은 미완이다. 이 화면 수정이나 197절 대응을 전책 정독·전 관찰 구현·학습 효과의 증거로 처리하지 않는다. 원본 PDF와 전체 추출 본문은 공개 저장소와 배포 산출물에서 제외한다. 새 서버·DB 변경은 없다.
