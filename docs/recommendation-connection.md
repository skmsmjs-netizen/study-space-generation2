## 현재 연결

`src/App.tsx` 홈 → `src/ui/next-study.tsx` 입력·추천·원문 표시 → `src/data/recommendations.ts` 기존 자료 변환·소유자별 저장 → `src/domain/recommendation-kernel.mjs` 순수 판정으로 연결됩니다. 추천의 ‘주제 열고 시작하기’는 현재 주제와 공부 시작 안내·홈 복귀를 재사용합니다.

- 현재 학기·공부 범위의 살아 있는 주제 ID를 사용합니다. 목표나 평가가 없는 주제는 일반 시작 후보로 제시하고, 별도 근거 없이 특정 학습법이 더 효과적이라고 주장하지 않습니다.
- 확인할 내용·같은/새 문항 기준·개인 확인 기한은 선택 입력입니다. 기한 미정은 null이며 실제 시험 날짜·성적 비중으로 둔갑시키지 않습니다. 평소 체크와 자유 글에는 새 필수 입력을 추가하지 않습니다.
- 선택해서 남긴 학기 시작·종료일은 해당 학기를 보고 있을 때 주차·기간·재확인 시간 기준으로 사용합니다. 모든 공부·독립 공부·미지정에서는 학기 기간을 추정하지 않습니다. 날짜는 한국 달력 날짜로 해석하며 종료일 전체를 포함합니다.
- 기존 체크와 반복은 활동 근거로만 읽습니다. `updatedAt`을 실제 수행 시각으로 바꾸지 않고 날짜 exact/range/unknown과 원 기록 ID를 유지합니다. 결과 모름·도움 여부 미확인·새 문항 여부 미확인·도움 받은 성공은 독립 성공이 아닙니다.
- 지금 직접 남긴 수행은 자기 보고임을 표시합니다. 막힘 → 해당 실패에 연결한 교정 → 독립 재확인을 구별합니다. 새 문항 확인 목표는 같은 문항 성공으로 충족되지 않습니다. 학기 기간이 없으면 자동으로 임의의 재확인 주기를 만들지 않습니다.
- 보류는 추천 표시만 하루 멈춥니다. 최대 세 개를 고르기 전에 보류를 적용해 다음 후보가 들어올 수 있습니다. 확인 완료·지난 기한·추천에서 제외한 내용의 답변과 결과는 다시 열 수 있습니다. 제외/복귀는 원문·결과를 삭제하지 않습니다.

## 저장과 보존

기존 `study-space:demo:v1` 원장에 쓰지 않습니다. 추천의 확인 내용·수행 사건·초안·보류·학기 기간은 `study-space:{namespace}:recommendations:{userId}:v1`에 분리합니다. 소유자·namespace·버전·형식과 저장 직전 원문 일치를 확인하며, 저장을 확인한 뒤만 결과 사건을 반영합니다. 손상된 자료나 다른 창의 변경을 덮어쓰지 않습니다. 용량 실패 시 현재 입력을 유지하고 같은 입력의 재시도를 제공합니다. 기존 앱의 작성 창 Web Lock 안에서 실행되는 로컬 demo 저장입니다. 서버 권한·다기기 원자성·온라인 수신의 증거가 아닙니다.
