# UniV AI 학습 기능 대조와 현재 앱 연결

2026-10-01. 사용자 요청은 UniV AI의 자료 가져오기→요약/복습 자료→저장 흐름을 현재 앱에 연결하는 것이다. 비교 범위는 [공식 소개](https://univai.co.kr/)와 [공식 App Store 설명](https://apps.apple.com/kr/app/유니브-ai-강의-녹음-pdf-요약-퀴즈/id6754797367)의 공개된 학습 기능이다. 내부 알고리즘·모든 출시 버전·네이티브 운영체제 기능을 복제했다고 주장하지 않는다.

## 비용·권한·기본값

GPT 생성은 기존 OpenAI API 연결을 사용한다. ChatGPT/Gemini 유료 구독을 API 잔액으로 처리하지 않는다. 민석 소유자 계정만 생성/키/모델/사용량에 접근하며 서버에서 다시 인증한다. 키는 Vault에 보관하고 학습 자료/클라이언트 소스/보고서에 넣지 않는다.

월 2만 원 이내 요청에 맞춘 앱 기본 상한 US$10을 유지한다. 환율·세금에 따른 실제 원화 청구의 보장은 아니며, 앱 외부의 같은 키 사용량까지 막지는 않는다. 상한 초과 요청 거부, 출력 제한, 고정 저비용 모델, 비싼 모델 자동 전환/자동 재생성 없음은 유지한다. 새 자료는 카드·퀴즈 기본5개, 기존 선택/초안은 덮어쓰지 않는다. 요약/퀴즈/개념도 개별 작업도 선택할 수 있다.

## 이번 변경과 확인 범위

새 구현은 study-pack 작업/작업별 strict schema/출력 검증과 기존 네 결과 UI의 연결, TXT·MD 내보내기다. 공개된 도구를 다시 만들지 않고 기존 추출기·자료 계약·카드/퀴즈/개념도·저장 경로를 조합했다. 독립된 임의 생성의 네 번 호출 대신 한 묶음 요청으로 핵심 결과를 만든다. 튜터 질문은 사용자 후속 결정으로 제외하며 남은 작업이나 추가 API 연결로 요구하지 않는다.

관련 검사 결과·실제 API 호출 수·시험 namespace의 저장/재조회 결과는 [이번 작업 증거](../work/univ-complete-20261001/결과.md)를 기준으로 한다. 기기 모사/합성 원문 검사를 물리 기기·실제 강의의 정확성·학습 효과·장기 Sync의 증거로 바꾸지 않는다. YouTube 전용 기능은 사용자 후속 결정으로 제외됐으므로 남은 작업에 넣지 않는다. 녹음·전사는 사용자 결정에 따른 외부 경로이며 앱 내 구현의 미완 조건으로 다시 요구하지 않는다.
