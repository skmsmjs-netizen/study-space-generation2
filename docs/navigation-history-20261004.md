# 전 화면 뒤로가기·앞으로가기

2026-10-04 사용자 요청에 따라 공통 화면 이동 줄과 창 안의 이동 아이콘을 실제 앱에 연결했다. 담당 Linear: MAN-30.

기존 `IconButton`·디자인 토큰·hash route·읽기 위치/입력 커서 복원을 재사용한다. [MDN History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API/Working_with_the_History_API)의 브라우저 세션 기록과 `history.go`를 채택했고, API가 현재 기록의 양쪽 끝을 알려주지 않는 부분만 탭별 인덱스로 보완했다. 이 인덱스는 프로젝트 구현이며 별도 표준이 아니다.

- 공통 상단: 로딩·로그인·예시/개인 공부 공간·백업/복구·오류·등록된 모든 과업에 계속 표시한다. 44px 기존 터치 영역·한국어 이름/툴팁·키보드 조작을 재사용한다.
- 창: 공통 Modal/Sheet 헤더에도 두 아이콘을 두며 긴 창에서는 헤더가 남는다. 이동 전에 기존 초안/커서/읽기 위치를 캡처하고 창을 닫는다. 전체 화면으로 확대한 관찰 창도 공통 Modal을 재사용한다. 네이티브 Fullscreen API에는 같은 컨트롤을 portal로 연결한다.
- 동작: 실제 브라우저 기록을 한 칸 이동한다. 앱 진입 전 외부 페이지로 이동시키지 않는다. 양쪽 끝에서는 아이콘을 숨기지 않고 비활성화한다. 뒤로 간 뒤 새 화면을 열면 기존 앞으로 기록을 버리는 브라우저 동작과 일치한다.
- 보존: 새로고침 뒤에도 탭의 앞으로 기록을 복원한다. 기존 history state의 다른 필드는 병합한다. `sessionStorage`에는 임의 여정 ID/끝 인덱스만 보관하며 공부 글·계정 ID·인증정보를 넣지 않는다. 저장소 접근이 막히면 현재 실행의 메모리 상태로 이동한다. 반복 이동 때 기록 목록을 쌓지 않고 인덱스만 갱신한다.
- 범위: 화면 이동이다. 글/데이터 편집의 되돌리기·다시 실행은 기존 기능이 담당한다. 신규 서버/RPC/DB 변경과 개인 공부 자료 쓰기는 없다.

확인: 5개 관련 단위 파일의88검사, 타입/생산빌드/68CSS 토큰 오류0. 다섯 WebKit 환경에서 20검사(전 화면 표시+실제 기록/창/로그인·없는 항목)를 재시도·생략·실패 없이 통과했다. 마지막 실내 색상/창 헤더 고정 뒤 영향받는15검사를 다시 통과했다. 긴 공부 기록과 창의 이름 초안·브라우저 버튼과 혼용·새로고침·분기·스크롤 뒤 접근·320px 화면을 포함한다. 최초 작성 시험의 타입 옵션 오류는 수정했고 실패 로그와 이후 정상 결과를 구분한다.

필수 GitHub Pages CI와 공개 자산/공개 브라우저 확인은 이 문서 작성 시 진행 전이다. 최종 실행 ID와 결과는 로컬 인계/작업 증거/MAN-30에 연결한다. 물리 Safari·IME·서버/다기기 Sync·학습 효과의 확인으로 확대하지 않는다.

초기 CI 37136976314의 iPhone세로에서 적분 관찰의 기존 axe 검사가 페이지 banner 중복을 발견했다. 이동 줄은 기존 topbar의 페이지 머리말 역할을 반복하지 않도록 일반 컨테이너로 정정하고, 안쪽 nav의 이동 기록 의미/레이블은 유지한다. 아이콘·표시·이동·자료 계약은 동일하다. 해당 실패를 삭제하지 않고 관련 적분 검사와 이동 흐름을 다시 확인한다.

정정 뒤 생산 빌드와 다섯 환경의 기존 적분/axe5검사+이동15흐름, 총20검사를 재시도/생략/실패 없이 통과했다. 이동 단위4검사도 다시 통과했다. 필수 새 CI와 공개 결과를 이어 확인한다.

가로 화면에서 창의 별도 이동 줄이 필기 입력/확대 그래프를 가린 CI4실패를 확인했다. 제목을 남는 폭에 맞춰 줄바꿈하고 닫기/두 이동 아이콘을 같은 줄로 배치해 창 높이를 줄였다. 기존 필기/인식 원문/되돌리기·점 가까이 보기/시야 보존을 그대로 유지하며 해당 기존4검사 모두 통과했다. 최종 수정본의5WebKit25(등록30화면·이동15·적분5/axe)도 fail/retry/skip0이다. 35e0c07의 중간 후보 CI37138934107은 배치 정정이 빠져 이 대화에서만 취소했으며, 초기37136976314의 모든 실패 로그를 보존한다.
