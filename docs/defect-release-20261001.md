# 반복 결함 보수의 공개 배포 · 2026-10-01

현재 원격 main의 통합 기능을 유지한 별도 체크아웃에서 메모 메뉴 포인터 배치와 공개 CI의 현재 Clova 전사문 흐름 검사를 보수했다. 공유 개발 체크아웃의 미완성 기능/이력을 덮어쓰거나 자동 게시하지 않는다.

미리보기·기기 검사는 완성 빌드의 바이트 사본/manifest·별도 포트·결과 경로를 사용한다. 다시 빌드하는 동안 파일이 사라져 흰 화면/잘못된 검사 실패가 발생하는 로컬 경로를 차단한다. 혼합/누락 빌드는 시작하지 않는다. 실행 종료 뒤 큰 사본을 정리하며 보고/trace/manifest는 남긴다. 새 버전을 볼 때는 preview를 다시 시작한다.

메모의 휴지통 버튼은 native details의 펼침 내용 안에 배치해 포인터 영역과 일치시켰다. 기존 확인창/휴지통/복원·원문·ID·수정 이력·설정·민석 전용 AI 권한은 유지한다. 전사문 검사는 제거한 녹음 버튼 대신 원문 초안 보관→재접속 정확한 값과 마이크 미요청을 확인한다. 수동 자료 저장 검사는 서버 실패→재접속→재시도에서 원문/기존 음성/자료 버전 보존을 확인한다. 서버/스키마/키 설정/유료 AI 호출은 이번 변경에 없다.

기존 Vite preview와 Playwright webServer를 재사용하며 바이트 고정·보고 격리만 직접 추가했다. 공개 workflow의 단위/백엔드 번들/타입·빌드/다섯 환경 검사를 통과한 뒤 기존 Pages에 배포한다. 이미 진행 중인 공통 검사를 수동 취소하지 않는다. 근거 출처: [Vite API](https://vite.dev/guide/api-javascript#preview), [Playwright webServer](https://playwright.dev/docs/test-webserver). 브라우저 자동검사·실제 공개 화면·물리기기/OS IME/다기기Sync·학습효과는 서로 다른 증거다.

최종 배포 SHA·Actions·공개 확인은 로컬 담당 인계와 실행 결과에 남긴다. 계정·개인 공부 원문·키·로컬 작업 결과를 공개 코드/산출물에 넣지 않는다.
