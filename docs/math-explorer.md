## 선택한 기존 도구와 계산 기준

- [KaTeX](https://katex.org/docs/supported.html) 0.18.10: 계산용 식을 math.js `toTex()`로 변환해 HTML/MathML로 표시한다. 브라우저 수식 표시 도구이며 전체 TeX/TikZ 컴파일러로 취급하지 않는다. `trust:false`, 확장 횟수 제한을 적용한다.
- [math.js](https://mathjs.org/docs/expressions/parsing.html) 15.2.0: AST를 확인하고 수식의 계산 및 [기호 미분](https://mathjs.org/docs/reference/functions/derivative.html)을 사용한다. 허용된 수치 연산·함수와 x/t/a/b/pi/e만 허용한다. 대입·배열·프로퍼티 접근·임의 함수 호출을 실행하지 않는다.
- [Plotly.js](https://plotly.com/javascript/3d-line-plots/) 4.1.1: 2D scatter, 3D scatter3d/cone, 축·회전·확대·hover·반응형을 재사용한다. 앱·그래프를 지연 로딩하고 공식 배포 패키지를 번들에 포함한다. 수식이나 개인 메모를 외부 그래프 서비스에 전송하지 않는다.
- T·N·B·곡률은 [OpenStax Calculus Volume 3 §3.3](https://openstax.org/books/calculus-volume-3/pages/3-3-arc-length-and-curvature)의 매끄러운 곡선에 대한 정의를 따른다. T=r'/|r'|, B=(r'×r'')/|r'×r''|, N=B×T, κ=|r'×r''|/|r'|³. 0속도/0곡률/미분 비정의는 해당 벡터를 생략한다. abs 곡선은 비미분점 판별을 보장하지 않아 전체 프레임 계산을 생략하며 곡선·점은 표시한다. 거의 평행한 속도·가속도에는 상대 오차 기준을 적용한다.

TikZ/PGF·PGFPlots·tikz-3dplot·CircuitikZ는 정적 문서·기하·그래프·회로 출력 후보로 유지한다. 현재 요구의 슬라이더·회전에는 브라우저 그래프가 직접 대응하므로 TeX 재컴파일 경로를 새로 만들지 않았다. 직접 만든 부분은 앱 메뉴, 식과 슬라이더를 연결하는 상태, 허용 AST/계산 경계 및 기존 메모 저장 연결이다.

### 2026-10-01 t 조절과 표현 기준 보완

GeoGebra 3D도 공간 기하 참고 후보이지만 새 서비스 의존성을 도입하지 않았다.

## 2026-10-01 GeoGebra 로컬 연결과 비교

현재 기본 그래프는 GeoGebra Classic의 3D/2D 보기다. `그래프 도구`에서 Plotly로 전환해 같은 입력을 비교한다. [공식 임베딩](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_Embedding/)과 [앱 API](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_API/)를 재사용했다. GeoGebra는 도구이며 수학 전체의 공식 표준으로 취급하지 않는다. T·N·B 계산 정의와 math.js 계산은 위 기준을 유지한다.

- 공식 math apps bundle 5.4.930.2를 앱의 `public/vendor/GeoGebra/`에서 제공한다. `npm run prepare:math-tools`가 고정 다운로드와 SHA-256 확인 후 준비하며 dev/build에도 연결했다. 한국어와 공백이 있는 현재 작업 경로에서 실제 다운로드·검증·추출을 확인했다. 생성된 배포 파일은 Git에서 제외한다. 그래프를 열 때만 불러오므로 초기 파일 로딩 비용이 있다. 이 작업은 오프라인 최초 진입/PWA 검증을 포함하지 않는다.
- GeoGebra의 Curve/좌표축/회전/확대/3D 화살표를 사용한다. 슬라이더 갱신은 브라우저 계산으로 처리하며 외부 계산 API에 입력을 보내는 경로를 추가하지 않았다. 기존 수식 원문·메모·초안·저장 키를 유지한다.
- 허용된 math.js AST를 GeoGebra 식으로 옮긴다. 자연로그 `log(x)`는 `ln(x)`, `log(x,b)`는 `log(b,x)`로 바꾼다. 과학 표기 숫자는 괄호로 묶어 거듭제곱 우선순위를 보존한다. 곡선의 매개변수는 별도 지역변수 u로 옮긴다.
- GeoGebra는 대문자로 시작하는 좌표 객체를 점, 소문자로 시작하는 좌표 객체를 벡터로 해석한다. 실제 점을 자유점으로 생성하고, 갱신할 때 보호를 잠시 풀어 수치 API로 이동한 뒤 다시 보호한다. 작은 좌표의 산술 리터럴과 고정점 때문에 `setCoords`가 실패하는 경우를 실제 저장 XML 대조에서 찾아 수정했다. 숨겨진 벡터 끝점도 수치 API로 갱신한다.
- native XML을 선택적 필드로 저장한다. 이전 파일은 계속 읽으며, 보기 변경은 초안에 보관하고 저장/파일 출력/화면 이탈에서 현재 보기를 회수한다. t/a/b 변경은 회전·확대를 초기화하지 않는다. 저장한 탐색을 열 때는 해당 보기까지 다시 불러온다. 기본 수식/구간이 달라졌을 때만 구성과 초기 범위를 재생성한다.
- 좁은 화면의 이중 축소를 제거하고 직접 크기를 갱신한다. 390px 화면에서 페이지 폭 390px, 그래프 영역과 실제 GeoGebra 영역 폭 358px을 확인했다. 그래프 로딩/변환 실패에는 다시 열기와 Plotly 전환을 제공한다. 실제 실패 주입으로 복구 버튼을 전부 검증한 것은 아니다.
- [GeoGebra 라이선스](https://www.geogebra.org/license)의 제품 배포 조건과 상표 고지를 유지한다. 현재 비상업적 개인 공부의 로컬 연결이며 상업적 배포 권한을 확인한 것으로 확대하지 않는다. 화면에 Made with GeoGebra®와 라이선스 링크를 표시한다.

### 확인한 범위

## 2026-10-01 확대·축소와 숫자 표시

- 그래프 아래 공통 `＋ 확대`·`− 축소`·`보기 초기화`를 제공한다. 두 렌더러의 공간 곡선과 함수에서 사용하며 준비 전에는 확대·축소를 비활성화한다. 1회 배율은 1.2와 그 역수다. 회전과 수식·t·변수·자유 메모는 유지한다.
- t/a/b, 슬라이더 구간 표시, 좌표·단위벡터·곡률은 소수점 두 자리로 표시한다. `-0.00`은 `0.00`으로 표시한다. Plotly 축과 호버는 `.2f`, GeoGebra는 공식 `setRounding('2')`를 사용한다. 원문 수식/구간 편집·계산·슬라이더 원래 값·JSON 저장은 반올림하지 않는다. 표시가 `3.14`인 입력창에 단순히 포커스를 넣었다 빼도 π를 3.14로 덮어쓰지 않는다.
- 곡선/벡터 두께를 GeoGebra 2/3, Plotly 2/3으로 줄이고 점도 조금 줄였다. 그래프 기본 글자는 GeoGebra 14, Plotly 12로 조절했다. Plotly의 T/N/B 라벨은 서로 다른 화면 오프셋을 사용한다. 일반 입력/버튼의 글자·터치 영역과 사용자 서체 설정은 보존한다. 3D 투영 방향에 따른 모든 겹침이 사라진다고 보장하지 않는다.
- [GeoGebra 공식 API](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_API/)와 [Plotly 공식 이벤트](https://plotly.com/javascript/plotlyjs-events/)를 재사용했다. 현재 임베드에서 ZoomIn/SetActiveView가 거부되고 evalXML의 보기 조각 갱신도 배율에 반영되지 않는 것을 실제 확인했다. GeoGebra는 getXML로 현재 전체 구성을 회수한 뒤 coordSystem 배율만 바꾸어 setXML로 복원한다. 좌표·곡선·회전과 원문은 유지하며 새 구성을 즉석에서 다시 계산하지 않는다. Plotly는 공식 relayout와 이벤트로 현재 카메라/구간을 유지한다.
- 최종 수식 타입 검사와 Lint, 해당 CSS/토큰의 선택 검사(0오류), 도메인 7검사를 확인했다. 공용 node_modules의 postcss/로더 오류와 manifest/lock 불일치 때문에 공용 npm run build를 완료하지 못했다. 다른 작업의 패키지/잠금을 변경하지 않고 work/math-explorer-20261001/display/verify-runtime에 패키지를 별도로 설치하여 원래 src/public/index를 연결한 앱 번들을 생성했다. 전체 타입에서는 병행 commands.ts·quick-memos.test.tsx 오류가 남았다. 별도 환경 UI 단위 검사는 symlink setup 경로 해석 오류로 실행되지 않았으며 통과로 보고하지 않는다.
