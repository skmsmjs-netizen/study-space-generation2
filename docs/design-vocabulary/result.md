## 실제 반영 범위

기존 25페이지를 전수 읽고 페이지별 해설과 구조/원본/속성 연결에 교육 주석을 적용했다. 기존 파일 구조 정리 작업의 구획과 ID를 재사용하고, 새 `04 교육 · 구조·명명·어휘`를 페이지 순서 다섯 번째에 연결했다. 현재 전체 파일은 26페이지다. 새 교육 페이지는 4섹션, 수업 13보드(E00–E12), 사전 27보드로 구성되며 기존 Button 원본에 연결한 조작 실습 인스턴스가 있다.

사전 27분야·412항목의 원문 이름·정의·안정 ID를 모두 넣었다. 파일 타입 18종, 표현/배치/텍스트/변수/프로토타입 등 속성 키 104개를 사전에 연결했다. 이 104개는 교육에 쓰는 속성 대응 범위이며 Figma Plugin API의 모든 메서드/속성을 망라한 API 사전이라고 주장하지 않는다.

메인 원본 303개와 실제 편집 속성 186개 전부를 대조했다. 원본 설명의 한국어 역할명, 실제 속성키와 값/변형, 사전 ID를 연결했고 기존 실행 코드 부품 59개의 소스/API 연결을 재사용했다. `Input`을 “한 줄 입력 필드”, `BusyDots`를 “처리 중 점 표시”처럼 부를 수 있다. 의미를 추측해 영어 부분 문자열만 매칭하지 않도록 [59개 역할 대응](component-role-labels.json)을 별도로 고정했다. 장면·수식·시연 원본은 그 종류와 원본 식별자를 함께 부른다.

최종 기존 25페이지의 95,993노드는 페이지 해설 25개를 포함한 관측값이다. 적용 첫 조사 95,066노드와 적용 시점 95,818노드는 조사 시점이 다르며, 그 사이 병행 작업이 추가한 기준 운영/목차를 보존했다. 교육 주석은 구조·원본·속성 연결 및 확인한 그래프에 14,864개가 있다. 내부 수식 글리프 조각 모두에 독립된 수학 의미를 만들어 붙이지 않았으며 나머지 말단은 공통 타입/속성 색인과 상위 맥락에서 읽는다. 기존 25페이지의 포함 구조를 모두 다시 배치하거나 95,993개 이름을 일괄 변경한 작업이 아니다.

## 곡률을 어떤 이름으로 요청할 수 있는가

`탐구 작업대 → 수식 탐색의 곡률 관측 → 정밀 그래프와 현재 좌표 → 곡선 경로 / y = x² → 선 굵기`처럼 필요한 단위까지 지정한다.

실제 R09-B03은 `28:12793`, 그 안의 곡선 프레임은 `28:12803`이다. 정적인 y=x² 표현의 다섯 표시 조건에서 실제 벡터 경로 40개를 “곡선 경로”, “눈금선”, “세로축선”, “가로축선”으로 재명명했다. 경로/좌표/크기/선 속성의 전후 일치를 확인했다. Figma에 그려지지 않은 T/N/B나 실제 곡률 계산을 있다고 만들지 않았다. 수학적 곡률 κ와 UI 모서리 반경은 다른 대상이고, 실제 계산의 책임은 `src/domain/math-explorer.ts`, 표시/조작의 책임은 `src/ui/math-explorer.tsx`에서 읽는다.

## 확인 결과와 보존

- 원격 교육 본문에서 412개 이름·정의·ID의 원문 일치, 누락 0, 중복 0을 확인했다.
- 교육 40보드의 자동 배치 내부 겹침 0, 원격 대상에 대한 파일 내부 링크 미해결 0을 확인했다. 곡률 사례와 사전의 실제 렌더를 이미지로 읽었다.
- 기존 25페이지의 메타데이터 적용 시점에 원문/ID/이름/포함 관계/위치/크기/표시/프로토타입/변수 연결/컴포넌트 속성의 전후 지문 일치를 확인했다. 이후 확인한 그래프 40개만 의도적으로 이름을 변경했고 원본 내용·기하·선 속성을 보존했다.
- 303원본에 교육 설명이 빠진 대상 0, 편집 속성 186개를 최종 다시 읽었다. 처음 의미 대응이 빠졌던 63개 속성을 기본값으로 확인한 맥락 이름에 연결했고, 기존 10종도 본문/질문/현재 표시 값/상태 변형/닫기 레이블처럼 구체화했다. 보충 대응은 총29종이다.
- 로컬 색인의 용어 ID 참조와 분야별 전 항목 포함을 확인하고, 최신 계약을 읽는 페이지 실행 코드의 생성 경로를 확인했다. 이 생성 명령의 원격 쓰기는 0이다.
- 루트/웹앱 AGENTS.md, 용어사전 사용법, 활성 문서 안내를 담당 기준에 연결했다. 설계·UI뿐 아니라 도메인·저장/복구·서버·검증·인계에서도 같은 어휘를 사용한다.

이번 변경은 교육 구조·명명·설명·대응 문서와 Figma 적용이다. 웹앱 런타임·자료·저장 키·서버·배포를 변경하지 않았다. Figma의 정적 상태/그림은 실제 저장·계산·접근성 실행의 검증을 대신하지 않으며 교육 자료 제작을 학습 효과 확인으로 승격하지 않는다. 과거 소스 해시와 현재 소스가 다르면 과거 대응 스냅샷이라는 표시를 유지한다.

Linear에 작업 요약을 남기는 시도는 내부 프로젝트 정보와 파일 키/대화 식별자를 외부 목적지에 전송하는 구체적 승인이 없다는 이유로 자동 승인 검토에서 거절했다. 해당 전송은 수행하지 않았고 로컬 인계에 결과를 남겼다.
