# 천문대 내부의 창가 책상

2026-10-02 사용자 요청: 사용자가 천문대 내부의 책상에 앉아 창밖을 보는 UX. 실제 홈 `StudyLandscapes`와 같은 부품을 사용하는 상황/단계 비교 카드에 적용했다.

## 구성과 기존 기준

기존 최우선 디자인 기준의 위계·색 역할·조작 상태·반응형과 천문대의 SVG/픽셀·시간대 팔레트를 재사용했다. 카메라가 보는 바깥 풍경과 고정된 가까운 물체를 구분하는 전경 구성을 선택했다. 별도 그래픽 라이브러리·외부 이미지·필터·프레임 루프를 추가하지 않았다. 창틀의 구체적인 모양·비율은 이번 표현을 위한 미술 설계이며 표준이나 검증된 학습 효과가 아니다.

`ObservatoryRoom`은 기존 하늘 SVG를 그대로 감싸고, 960×400 좌표의 고정 SVG를 위에 겹친다. 깊이가 다른 나무 창틀, 모서리 황동 연결쇠와 나사, 두 가는 창살과 잠금쇠, 옅은 유리 반사, 창턱의 사선 면, 책상 결을 그린다. `ObservatoryDesk`는 왼쪽 별지도·연필과 오른쪽 황동 독서등·작은 책·컵이다. 소품33노드를 포함해 앞쪽 장식은 총57노드이며 애니메이션은 없다.

## 실제 조작과 반응

- 하늘의 머무름 확대·드래그·탐색 동안 창틀과 책상은 움직이지 않는다. 기존 하늘 SVG의 폭/높이/viewBox와 카메라 좌표 변환을 보존한다.
- 고정 SVG는 `pointer-events:none`이며 메뉴보다 낮은 층에 놓인다. 설정 팝업을 자를 수 있는 바깥 overflow 제한은 추가하지 않는다.
- 책상/창틀에서는 머무름 확대와 새 드래그를 시작하지 않는다. 실제 창이 열려 보이는 영역은 `OBSERVATORY_WINDOW_APERTURE`의 좌우32/928, 상하32/342 비율로 정한다. 창 밖으로 드래그한 채 놓으면 기존 감쇠 복귀를 따른다. 터치 스크롤과 정지/모션 감소 동작을 유지한다.
- 여섯 시간대의 기존 `light/wall/roof` 역할색이 창틀의 가장자리·창턱·종이에 반영된다. 수리엔진의 `response.activity`를 창턱의 광량 `0.12+0.2×activity`와 독서등의 금빛 혼합 `60+20×activity`%에 연결한다. 추가 입력/저장/점수는 없다.
- 모든 풍경 층을 끄면 방 장식도 함께 사라지고, 기존 ‘기본 풍경으로’로 돌아온다. 작은 상황 카드는 기존 지연 장착과 canvas0개 조건을 유지한다.

## 확인과 범위

실제 브라우저에서 노을/밤과 여섯 시간대의 실내 색, 상황 카드7개/방7개/canvas0개, 메뉴와 확대 시점을 확인한다. 기존 단위11개와 실제 홈의 저장/재접속/전체 숨김·복원/최대 단계 및 포인터 흐름을 다섯 WebKit 모사 환경에서 확인한다. 장식만을 위한 별도 전수 엔진 검사를 다시 만들지 않는다.

검사 결과·화면·빌드 근거는 `work/pixel-daily-20261001/interior/verification.json`에 기록한다. 개인 원장·ID·초안·설정 키·엔진 계산과 서버 계약은 변경하지 않는다. 로컬 구현/브라우저/기기 모사와 공개 배포·실물 기기 FPS·학습 효과는 구별한다.
