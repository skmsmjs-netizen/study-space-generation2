# 수학교재 실제 관찰 연결 — 현재 구현과 잔여 범위

2026-10-03. Riley/Hobson/Bence, *Mathematical Methods for Physics and Engineering*, 제3판(2006)의 기존 정리와 채택된 OS 기준을 실제 앱에 연결했다. 이 기록은 로컬 구현의 범위다. 전책 모든 관찰·서버 동기화·Figma 갱신·배포가 완료됐다는 뜻은 아니다.

## 확인된 자료와 전체 대응

원본 PDF1,363페이지의 기존 2026-10-01 순차 추출 독해 기록을 재사용했다. 이번에는 원문 목록·본문 시작 위치와 대표 수식의 원본을 대조했다. 전책 모든 페이지를 다시 시각 독해하거나 모든 정리를 독립 증명했다고 주장하지 않는다. 별도 해설서는 미첨부·미열람이다.

앞부분 PDF1–30의 목차 번호310개와 대조했다. 본문 주요 절248개, 연습문제31개, 힌트·답31개다. 본문248개 누락0·중복0이며 248개의 시작 페이지에서 해당 절 번호를 확인했다. 번호 존재 확인과 수식·도표의 시각 대조는 별개다. 문제를 자동으로 풀거나 공부 완료로 기록하지 않았다.

본문·색인은 PDF페이지=책 인쇄쪽+30이다. 앞부분의 로마자 쪽번호에 이 규칙을 적용하지 않는다. 시작 쪽은 기존 목록과 본문을 대조했지만, 종료 쪽은 다음 주요 절의 시작에서 유도한 추정이다. 같은 페이지에 이어지는 절·문항의 정확한 종결 위치로 사용하지 않는다.

기존 추출 목록에서 수식 제목의 줄바꿈 때문에 빠진 §26.8 δ·ϵ 텐서를 책941/PDF971에서 복구했다. 이 페이지와 Bayes 관계의 책1132/PDF1162를 원본 렌더링으로 확인했다. 확률 표기는 교재의 Pr와 여사건의 윗줄 표기를 사용한다. 연결도의 Potential/Inversion 등 복소해석 응용의 장 연결은 실제25장으로 수정했다.

## 실제 자리와 흐름

현재 로컬 실행은 http://127.0.0.1:5848/?space=demo&math=riley#/math 이다. 서쪽 자료 책장의 과목 목록에서 수학교재 관찰로 들어가며, 전체 도구는 기존 동쪽 수식 탐색 작업면을 사용한다. 독립 진입에도 실제 교재 목록·원문 경로가 있다. 새 방·개인 과목·개념 원장을 자동 생성하지 않는다.

기존4개 연결지도,49개 개념 묶음과61개 관계를 공통 KnowledgeStructure의 구조/문장 읽기에 연결했다. 원래 개념키·관계ID·설명을 재사용하고 개인Canvas의 배치를 변경하지 않았다. 지도에서 관련 장 목록으로, 절에서 원문·관찰로 이동한다.

248개 절 목록 → 선택한 절·발췌·장 맥락 → 실제 사례 관찰/크게 보기 → 원문 → 원래 관찰 → 목록의 실제 버튼·위치로 돌아간다. 자료 책장 호출자는 공통 navigation-context를 재사용한다. 장의 질문·조건을 선택한 절의 확정 질문·조건처럼 표시하지 않는다.

넓은 면은 위 질문/원식/조건, 왼쪽 중심 대상, 오른쪽 조절/현재 판단, 아래 설명/원문이다. 좁은 면은 의미와 읽기 순서를 유지하는 한 열이다. 긴 수식·원문·값 표는 별도 스크롤로 읽는다. 기존 상단 풍경·원본 위젯·바깥틀·천장 기능과 사용자의 테마·서체를 유지한다.

원문은 기존 파일을 읽는 루프백 전용 개발 연결이다. 앞/뒤 쪽·시작 위치·확대/축소/맞춤·로딩/실패를 제공한다. 원본을 수정하거나 공개 자산으로 복사·업로드하지 않았다. 생산 빌드에는 이 로컬 원문 API가 없으므로 생산 자료 접근이 연결됐다고 보고하지 않는다.

## 구현된 관찰17개

부분합/무한합, 복소수 직교·극 표현, 내적/외적, 행렬곱 순서, 고유방향/축퇴, 푸리에 부분합, 감쇠 ODE, 파동 모드, 확산 모드, 변분 경로족, δ/ϵ 성분, Newton 반복, 순환군, Bayes 관계, 이항분포, 평균/두 분산, 최소제곱 직선을 실제로 계산한다. 관련 주요 절24개에 연결했다.

관계는 교재에 근거하지만 구체적인 함수·고정 자료·범위·초기 상태는 제한된 설계 사례다. 이 예제를 교재가 직접 제시한 모든 사례·일반 해법으로 바꾸지 않는다. 식·변수·고정값·조건·단계·초기값 선정 이유는 [개별 사례 명세](../work/riley-observations-20261003/scene-specs.json)에 기록했다.

유한 부분합은 무한합 조건 위반에도 계산한다. Newton의 도함수0은 방정식의 근이 없다는 뜻으로 처리하지 않는다. 확률0인 분기의 조건부 확률은 해석·계산에서 제외하고, Pr(B)=0이면 사후 조건부 확률을 표시하지 않는다. 인공 자료의 두 분산은 계산하지만 표본 추출의 독립/동일 분포·유한 분산 가정은 확인 전으로 표시한다. 축퇴를 대각화 불가능과 혼동하지 않는다.

수치는 부동소수점 근사다. 공통 소수 두 자리 표시를 재사용하며 내부 계산·저장 입력값을 반올림하지 않는다. 작은 비영 값은 정확한0처럼 표시하지 않으며 등비급수의 꼬리가 표현 범위 아래로 내려가도 정확한0으로 판정하지 않는다. 유한 그림·표본을 일반 증명으로 취급하지 않는다.

그래프는 같은 축척이 필요한 공간 사례의 축척을 유지한다. 사각파의 점프를 경사진 선으로 이어 그리지 않으며, 관측 자료의 산점에 임의 보간선을 붙이지 않는다. 입력의 구조가 핵심인 δ/ϵ·군·확률은 구조/조건 대응을 사용한다. 모든 항목에 그래프·슬라이더를 강제하지 않는다.

## 남은 직접 조건

추가212절은 전체 대응 원장의 개별 ID·원문·장 맥락을 출발점으로, 관찰 질문/원식/조건/고정·변경값을 확정한 뒤 기존 허용 계산·구조·단계·조건 틀에 연결해야 한다. 구현된24절도 비대칭/복소 고유문제, 일반 푸리에 함수, 일반 초기·경계 자료 PDE, 전 함수공간 변분, 비가환군, 다사건 확률·추정/추론 등 해당 절의 전체 방법을 구현한 것은 아니다.
