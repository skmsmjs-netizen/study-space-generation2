## 수리엔진의 미세 출력과 연결

`q = evolution.position`, `g=q/11`, `a=recent[0]`, `d=recent[1]`, `r=recent[2]`, `c=abs(change[0])`이다. 기존 관측 사건/날짜/주제 의미는 바꾸지 않는다.

```text
광선 개수 = 6 + 36g + 6a       (최대48)
안내등 개수 = 2 + 8g + 2r      (최대12)
공간 크기 = 0.44 + 0.90g + 0.10d
광량 = 0.30 + 0.42g + 0.20a
호흡 주기 = 15 - 5a - 3g       (최소7초)
회전 주기 = 142 - 54g - 24a    (최소64초)
호흡 폭 = 1.025 + 0.065g + 0.04c
주황·다홍 혼합 비율 = 22 + 50g + 18a (%)
광륜 = smoothstep(clamp((q-0.5)/3))
역회전 조각 = smoothstep(clamp((q-2)/3))
나선 = smoothstep(clamp((q-4)/4))
파동 = smoothstep(clamp((q-7)/4))
```

개수의 소수 부분은 다음 입자의 투명도에 반영하며 단계 정수나100분위로 반올림하지 않는다. 계수는 실제 SVG/CSS 변수와 애니메이션 주기에 연결한다. 미세 변화는 DOM 속성과 다음 입자의 투명도까지 전달하되 모든 변화가 사람 눈에 구별된다는 뜻은 아니다. 정적 윤곽/배열은 모듈 수준에서 한 번 만들고, 입력이나 시각이 달라질 때만 파생 수치를 갱신한다.

지면 점등은 각 안내등에 호흡 주기의1/12씩 다른 위상을 부여한다. 원형 진행률·CLI 창·로딩 상태를 만들지 않는다. 원문·ID·초안·이력·owner 설정/저장 키와 서버 스키마는 유지한다. 추가 애니메이션은 기존 pause/숨김탭·화면 밖/OS 모션 감소의 공통 제어를 따른다.

## 비교 화면의 동시 재생과 반복 사용

넓은 화면에서 여러 비교 장면의 SVG 애니메이션이 동시에 실행되는 부담을 확인하여, 작은 카드에서는 커서가 올라가거나 키보드 초점이 있는 장면만 재생하도록 했다. 동시에 최대 두 카드(커서 하나+초점 하나)가 해당될 수 있다. 화면 밖 카드는 기존 관찰자가 정지시키고, 카드에서 크게 연 실제 커버는 전체 애니메이션을 제공한다. 터치에서는 카드 탭으로 큰 풍경을 연다. 이 변경은 합성 비교 화면의 CSS에 한정하며 실제 홈의 재생/정지 기본값이나 개인 설정을 변경하지 않는다. 레이어 윤곽과 최대 입자 수도 고정하여 기록 증가가 무제한 SVG 노드 증가로 이어지지 않게 한다.
