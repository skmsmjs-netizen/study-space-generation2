## 오류 경로 증거 경계

실제 브라우저에서 quota·Storage.setItem/removeItem 실패를 주입하지 않았습니다. 손상 초안 원문 보관, 저장 실패 RAM 복귀, 정리 양쪽 실패, 표 동일 opId/ID 재시도·응답 유실 중복 방지, 자유기록 정리 실패 이후 ID 연결은 자동검사로 검증했습니다. 이를 실제 디스크 고장이나 OS 강제 종료 복구 통과로 기록하지 않습니다.

이번 독립 코드 검토에서 새 자유기록 저장→초안 정리 실패→후속 수정→route 재진입 시 ID가 재생성되는 결함을 발견했습니다. 저장된 ID 경로로 이동하고 정리 오류는 Workspace에 남기며 초안에도 entityId를 보존하도록 수정했습니다. 기존 글과 복구 초안이 다른 경우 원문을 모두 유지하고 저장된 글을 확인할 수 있게 했습니다. 해당 재현 3개를 포함한 App 회귀검사를 통과했습니다.

공통 컴포넌트 전체 21종의 호출처와 상태는 `../component-matrix.md`의 최신 표에 연결합니다. 16종은 실제 App 또는 내부 호출처가 있고 5종은 현재 호출처가 없습니다. 조건부 호출 존재·자동검사·브라우저 실조작을 구별합니다. browser console error 조회는 빈 목록이었지만 전체 오류 부재의 증거는 아닙니다.
