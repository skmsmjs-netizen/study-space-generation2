# 천문대 드래그·머무름 확대 — 2026-10-01

사용자 “드래그 인터랙션이 심심하다”, “포인터를 가만히 두면 서서히 확대되고 상세한 애니메이션이 일렁이게” 요청을 실제 홈과 같은 StudyLandscapes에 연결했다. 기존16색 팔레트/12단계/6시간대/36상황/수리 표시/설정·저장 계약을 재사용한다.

## 채택 기준과 구현

[MDN requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)의 timestamp 기반 갱신과 취소, [MDN setPointerCapture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture)의 드래그 중 이벤트 유지, 기존 CSS transform/opacity·모션 감소 기준을 사용한다. 프레임마다 React 상태를 변경하거나 별도 모션 라이브러리를 추가하지 않는다. camera damping은 `1-exp(-dt/tau)`로 계산하고 dt를64ms로 제한한다. tau는 드래그95ms/접근210ms로 설정한 표시 계수이며 물리/학습 법칙이나 실측 최적값이 아니다.

- 하늘/망원경을 누르고 드래그하면 하늘 패닝·깊이 차·최대3도 회전·확대·관측 지점 파동과 별빛 잔상이 함께 반응한다. 포인터 capture로 영역 밖 드래그를 놓치지 않으며 놓기/취소 시 원래 시야로 복귀한다.
- 포인터의 마지막2단위 초과 이동 이후900ms 기다리고3500ms smoothstep으로 서서히 접근한다. 확대는1에서 `2+0.5*response` 사이이며 대상 지점이 확대의 원점이다. 다시 움직이면 확대 목표를 줄이고 새 위치에서 기다린다. 프레임 수에 비례해 속도를 증가시키지 않는다.
- 확대되는 동안0–1의 상세 노출값으로 가는 주황/민트 성운 실3개와 최대48개의 미세 별가루를 드러낸다. 별가루는 서로 다른 위상으로 밝기/1–2단위 이동을 계속하고 성운 실도 다른 주기로 일렁인다. 별가루 수 `6+36*position/11+6*recent[0]`는 같은 엔진의 소수 입자 투명도를 재사용하므로 초기에도 작은 움직임이 있고 발전할수록 촘촘해진다. 이것은 실제 천체 확대나 관측 결과가 아니다.
- 프레임 작업은 포인터가 있을 때만 예약하고 접근/카메라 수렴 후 종료한다. 상세 움직임은 CSS가 담당하며 원래 정지·OS/app 모션 감소 제어를 따른다. leave/cancel/blur/resize/scroll/숨김탭/화면 밖/컴포넌트 해제에서 프레임과 capture를 해제한다.
- 일시정지/모션 감소에서는 자동 확대와 드래그 운동이 없다. 터치 입력은 카메라를 초기화하고 페이지 스크롤을 유지한다. 임시 카메라 값은 공부 데이터·owner별 정지/층 설정·저장 키에 쓰지 않는다. 제어 버튼 위에서 풍경 조작을 시작하지 않는다.
