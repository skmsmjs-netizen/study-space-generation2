사용자 「배포해」에 따라 기존 공개 main 15feb28 위에 물리 전용 파일과 최소 자료/수식 탐색 진입을 연결한다. 공개 교재 관찰은 28장·167절·125개 한정 계산 관찰·167구조 읽기·1112원문 관계 연결이다. 35절 기존틀/126부분/6정적의 구현 범위를 보존하고 572그림의 독립 기하/축척/표식 대응은 판단 보류이다. 전책의 일반 계산 모형·모든 그림 검증 완료가 아니다.

원본은 1069쪽/SHA67f606ca1ec0bc93c593d2f90df2b0fc4a9e1159add89de6df0a11b12bc913b1/63,824,473바이트이다. 원본 PDF·전체 추출·쪽 이미지는 공개 코드/산출물에 넣지 않는다. 공개에는 검토한 한국어 해설·법칙·적용 조건·수식 관계·위치 메타데이터를 포함한다. 번호식1076출현과36선택된 번호없는 관계를 연결했으며 모든 번호없는 하위 항목의 수는 미확정이다. 전1069쪽 추출 글의 실제 읽기와12쪽 픽셀 확인을 구별한다.

자료 책장 `/materials/physics-principles`와 동쪽 `/math`의 「물리 교재 · 읽기와 관찰」에서 진입한다. 작은 관찰→전체→읽던 절/원문/초점 복귀, 기기별 확정값/raw 입력/메모/시야/읽기 위치의 owner-v1 저장을 유지한다. 공부 완료·정답·숙달은 기록하지 않는다. 종이 본문은 기존700/native95%/18·16/justify/start와 개인 설정을 재사용한다.

공개 원문은 사용자의 같은 판본 PDF를 직접 연결하고 PDF.js로 같은 쪽을 읽는다. 본문 모드에서는 기기에 연결한 PDF에서 글을 추출하고, 원본 모드에서는 같은 쪽의 실제 조판을 그린다. 추출 순서·복잡한 수식·그림의 한계를 구별한다. `physics-source-file`이 공통 자료 DB의 owner별 `files` 저장을 재사용한다. 공통50MB 첨부 한도를 바꾸지 않고 이 정확한 SHA/63,824,473바이트 교재만 별도 경로에 허용한다. 파일/바이트/판본/1069쪽을 확인하고 다른 파일이나 저장 실패에서 기존 원본을 유지한다. 원문 확대/쪽별 스크롤은 owner별 `physics-source-view:v1`로 기기에 보관하며 손상값을 덮어쓰지 않는다. 공개 원문 API/서버 업로드·다기기 동기화는 없다. 로컬 전용 원문 추출 서비스는 개발·루프백에서만 사용한다.

이번 배포는 원격 DB/RPC/RLS/Edge 적용을 포함하지 않는다. 배포 후보는 현재 공개 버전에서 별도 checkout으로 준비해 다른 과목·공유 Git index·개인 기록을 보존한다. 최신 CI/공개 산출물·브라우저/원문 확인은 로컬 정본 `work/physics-release-20261003/release-result.json`과 기존 MAN-12에 실제 완료 뒤 남긴다. 물리 기기·VoiceOver·장기 사용·학습 효과·572독립 그림/일반 계산 범위는 별도 잔여이다.
