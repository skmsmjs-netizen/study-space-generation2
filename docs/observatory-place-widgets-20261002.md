# 기능에 따라 바라보는 천문대 실내

> 이 문서는 최초 정적 구현 시점의 기록이다. 후속 전체 폭 커버·고급 움직임의 현재 구현은 [상단 커버 기록](observatory-cover-20261002.md)을 따른다.

2026-10-02 사용자 「다른 기능을 써서 자리를 회전하면 벽이나 책장 이런 위젯으로 바뀌어야겠지?」와 후속 「천장도 추가되었어」를 실제 앱에 연결했다.

## 채택 기준과 구현

[천문대 디자인 기준](observatory-design-standard.md)의 네 수평 자리와 위쪽 공통 자리, [기준값 원본](observatory-experience-baseline.json)의 실내·종이 재료 및 180ms 전환을 재사용한다. 해당 기준의 WCAG/공간 일관성 근거를 유지하며, 이번 맞춤 픽셀 소품 자체를 표준이나 검증된 학습 효과라고 부르지 않는다. 기존 SVG·Motion·React와 원래의 경로/복귀 부품으로 구현했으며 패키지를 추가하지 않았다. React 가이드의 SVG 바깥 wrapper 전환, 단순한 사용자별 저장 값, 기존 모션 구독 재사용을 적용했다.

| 시선 | 실제 표시와 연결 |
| --- | --- |
| 정면 | 홈의 원본 하늘·천문대 전체와 외부 창틀을 보존한다. 공부/기록 경로의 기존 본문은 유지한다. |
| 왼쪽 | 자료 책장: 서적·빈 라벨·묶은 종이·황동등. 과목/강의 자료/자료 카드/개념 전집으로 바로 이동한다. |
| 오른쪽 | 탐구 작업대: 열린 노트·계기·유리램프. 코딩 연습/수식 탐색으로 바로 이동한다. |
| 뒤쪽 | 기록·계획 벽: 날짜 없는 격자·고정핀·연결 종이. 통계/일정/Canvas/그래프/칸반으로 바로 이동한다. |
| 위쪽 | 천장 조명: 위로 모이는 목재 보·돔 리브·황동등. 찾기/도움말/백업·복원과 원래 자리 복귀를 연결한다. |

천장은 수평 자리 이력에 다섯 번째 방위를 추가하지 않는다. `useObservatoryJourney`가 원래 자리와 실제 과업을 보존하고, 공통 경로에서 표시하는 장면만 `ceiling`으로 바꾼다. 공통 화면을 연속 방문한 뒤의 ‘원래 자리로’는 유효한 마지막 비공통 경로를 찾는다. 삭제된 대상은 건너뛰고 직접 접속은 기존 자리의 안전한 기본 경로를 사용한다. 결과 선택은 해당 결과로 정상 이동한다. 계정·개인 설정·허용된 AI의 기존 조작과 권한은 유지하며, 존재하지 않는 `/account` 같은 새 화면을 만들어 연결하지 않았다. 모든 공통 설정을 새 천장 패널로 재배치한 완료를 뜻하지 않는다.

담당 부품은 `observatory-place-art.tsx/.css`, `observatory-place-scene.tsx/.css`이며 호출은 `ObservatoryNavigation` 한 곳이다. 본문을 장면 키로 감싸거나 다시 마운트하지 않는다. 원장·공부 엔진·하늘 렌더러·저장/인증·개인 배치를 변경하지 않는다.

## 반복 사용과 비용

새 그림은 960×260의 비례 SVG이다. 장면별 노드는 책장194/벽49/작업대82/천장32로, 자료 개수에 따라 증가하지 않는다. 원문처럼 읽힐 임의 제목·날짜·점수는 넣지 않았다. 새 프레임 루프·GPU·상시 빛 애니메이션은 없다. 시선이 달라질 때 그림 wrapper만 짧게 이동·밝기 전환하고, 같은 자리에서 메뉴/자료가 바뀌면 장면 전환을 반복하지 않는다. 동작 감소와 탭 가시성은 기존 공통 모션 경로를 따른다.

풍경 접기/펼치기는 `storagePrefix:view:observatory-room:encodedUserId:v1`의 기기별 단일 값으로 보존한다. 사용자/공간이 바뀌면 다시 읽고, 같은 사용자의 방향 전환/재접속에서는 선택을 유지한다. 브라우저 저장을 사용할 수 없으면 현재 세션 조작은 계속된다. 초안/기록 저장과 이 키는 별개다. 좁은 화면에서는 네 방향을 두 열, 천장을 그 아래 한 행으로 보여주며 실제 기능 링크를 숨기지 않는다.

## 확인한 결과

- 관련 경로/복귀 단위 검사 12개, 최종 타입·웹 빌드·선택 Biome·디자인 토큰 검사 통과.
- 고정 빌드 `work/device-runs/run-vPxJ8p`: iPhone 17 Pro 세로/가로, iPad Pro 13인치 세로/가로/좁은 창의 세 흐름씩 **15개 통과**, 실패/생략/재시도 통과 0. 자리별 그림·실제 기능 이동·천장 재접속/복귀·접기 보존·동작 감소·원장 불변과 자료 원문→곁 메모→도구→기록→복귀를 확인했다.
- 인앱 `http://127.0.0.1:5758/?space=demo#/subjects`에서 책장/벽/작업대/천장 표시와 벽→찾기→도움말→원래 벽을 직접 확인했다. 가로 넘침0, 새 탭 오류0. 화면은 `work/observatory-places-20261002/`의 네 PNG에 보존한다.
- 최초 로컬 서버의 sandbox listen 실패와 천장 아트가 아직 작성 중이던 타입 실패는 이전 로그로 남긴다. 최종 성공과 합산하지 않는다.

이번 완료는 코드와 로컬 확인이다. 공개 배포·운영 서버 변경·Figma 추가 편집·물리 기기/OS 입력 검증은 실행하지 않았다. 공유 체크아웃의 병행 프론트엔드 작업을 유지했다.
