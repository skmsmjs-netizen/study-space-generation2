### 실제 소비

- `ConceptReader`의 작성된 visual → `KnowledgeStructure`: 닫힌 모듈·같은 비교 조판·native dl/ol·명시적 연결어와 연결 대상·좁은 화면의 세로 관계. 비교에 순위를 붙이거나 없는 관계를 만들지 않는다. 수식은 기존 ConceptText/MathFormula를 사용한다. 기존 전문 SVG/과학 도형은 유지한다.
- 구조/문장 보기는 계정/자료/장면별 sessionStorage 단서이며 원문·읽기 위치·작성된 관계를 유지한다. 탭 내 재마운트/새로고침 유지와 새로운 탭/기기 공유를 구별한다. 저장 실패 시 현재 읽기를 유지한다.
- `StudyCanvas`: 실제 React Flow의 신규 공간에만 step 기본 선, 기존 설정/개인 좌표/연결/너비/되돌리기 유지. 자동 소속 선과 사용자가 작성한 방향/관계를 접어 읽는 범례에서 구별한다. 사각 경계는 기존 `--observatory-radius-panel`을 소비한다.
- 사용자 후속 「본문 글은 양쪽 정렬」: `metrics.paper.bodyAlignment` → 기존 `sync-observatory-ui.mjs` → 생성 CSS 변수 → 공통 본문/모듈/자유 글/메모 모달 입력. 양쪽 정렬·마지막 줄 start이며 제목/버튼/과학·코드 정렬과 원문/줄바꿈은 유지한다.

## 보존과 남은 조건

픽셀 하늘/원본 위젯 전체/바깥 창틀·네 방향과 공통 천장, 기존 전문 엔진/공부 의미·기록/초안·개인 배치·설정과 서버 책임은 유지했다. 실제 개인 기록 쓰기·commit/push·공개 배포·유료 API 호출0이다.

물리 iPhone/iPad·Pencil·OS 한글 IME·VoiceOver·교차 기기 동기화·장기 사용·실제 인출/기억 효과는 이번 모사 확인에 포함되지 않는다. 개인 저장 자료 모든 판본에 새로운 visual을 자동 생성하지 않았으며 모든111기능 상태를 실행한 것은 아니다. 추후 고급 기술과 실제 읽기/조작 결과에 따라 담당 값과 소비 경로를 함께 보정한다. 일반 전체 정적 파일을 포함한 패키징 지연은 배포 전에 별도로 해결하고 완성된 묶음으로 확인해야 한다.
