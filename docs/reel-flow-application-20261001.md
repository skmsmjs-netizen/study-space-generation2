통합 검색은 등록된 현재 자료의 읽기 전용 투영이다. 휴지통·이전 수정본·작성 중인 초안은 기존 보관함에서 관리한다. 다른 계정/공간과 삭제된 과목의 자료는 색인에서 제외한다. 과목 연결 없는 메모·코드는 ‘모든 공부’에서 찾는다. 여러 과목이 섞인 시험은 검색어와 실제 문항 소속이 함께 맞는 경우에만 선택 범위의 결과에 나타난다. 이전 일정 원본은 기존 읽기 어댑터로 검색하며 자동 이관·업로드하지 않는다.

보기 힌트의 수명은 **같은 탭의 화면 이동·새로고침**이다. 서버 동기화·다른 기기·브라우저 종료 후 장기 보존으로 확대하지 않는다. 원문과 작성 중인 내용의 기존 저장/초안 경로는 보기 힌트와 별개로 유지한다. 기존 저장 계약·민석 전용 AI 권한·입력 부담·수동 배치를 바꾸지 않는다.
