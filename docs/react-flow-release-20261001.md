# React Flow 공개 반영 범위 · 2026-10-01

사용자 “배포해야지”에 따라 기존 GitHub Pages 대상에 React Flow 개선을 반영합니다. 공개 main 1f3029901b249c1bb0dc60131b462d4ba6b8edb0을 기준으로 Canvas·그래프·자료 개념도와 해당 검사만 통합합니다. 공유 개발 폴더의 다른 미배포 작업은 포함하지 않습니다.

- 그래프의 실제 점 둘레와 선 끝을 맞추고 확대·축소 중 이름 간격을 유지합니다.
- 세 화면에 확대율·선 모양·격자·선택/이동·전체 위치 지도를 연결하고 계정별 기기 설정을 보존합니다.
- Canvas의 실측 배치·다중 선택/정렬·너비·동일 ID 재연결·세션 내 undo/redo·검증 후 JSON 가져오기와 SVG 내보내기를 연결합니다. 기존 원문/ID/수정 이력/저장 ACK/초안/사용자 좌표를 보존하며 재배치는 명시 조작에서만 실행합니다.
- 자료 개념도의 이름·관계·위치 수정과 최초본 복귀를 유지하고 상위 자료 화면에는 설정 소유자 연결만 추가합니다.
- 공식 React Flow12.12.0 API와 native 컴포넌트, 기존 D3 worker 및 Dagre3.1.1을 사용합니다. [전수 조사·적용 범위](react-flow-capabilities.md)의222개 색인과69개 예제 적용 판단은 구현된 기능 수와 구별합니다.
