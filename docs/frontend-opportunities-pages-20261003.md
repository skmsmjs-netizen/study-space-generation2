# A01–A10 프론트엔드 공개 반영 확인

2026-10-03 사용자 「배포해」에 따라 이 대화에서 구현한 열 가지 프론트엔드 기능의 실제 공개 상태를 확인하고, 기존 Pages 게시 과정의 중복 산출물 문제를 정리했다. 이 대화의 과거 commit/push/deploy 미수행 기록과, 이후 다른 병행 작업이 해당 기능을 통합 공개한 결과를 구별한다.

**요청한 A01–A10은 공개 앱 `15feb2835a0f7edad05d32bda76937fe3d699191`에 포함되어 있다.** [공개 앱](https://skmsmjs-netizen.github.io/study-space-generation2/?v=15feb283)에서 관련 핵심 흐름 16개를 실제 WebKit으로 실행했고, 검증된 CI 산출물의 JS/CSS/서체·index 134개가 공개 파일과 바이트/SHA-256이 모두 일치했다. 이 문서는 이후 병행 물리·모달 보완 후보의 배포까지 완료로 승격하지 않는다.

## 실제 근거

- [원 공개 실행](https://github.com/skmsmjs-netizen/study-space-generation2/actions/runs/37091693073)의 **attempt 1**은 success다. 빌드·타입·backend bundle 및 다섯 WebKit 환경의 성공을 현재 API에서 재확인했다. 단위 1,318통과/1기존 생략, 기기 1,087최초 통과/5재시도 통과/8조건 생략/최종 실패0은 기존 같은 빌드의 근거다. 이번에 그 전체를 재실행했다고 하지 않는다.
- 담당 핵심 소스 14개의 공유 파일과 공개 커밋이 byte 동일이다. `work/frontend-opportunities-deploy-20261003/source-parity.json`에 경로·SHA-256을 남겼다. 기존 App·수식·통계 호출도 공개 커밋에서 읽어 같은 증거 폴더에 보존했다.
- 공개 WebKit **iPhone 세로·iPad 가로의 8흐름×2=16개**: 실패/재시도/생략0. 격리 브라우저의 합성 자료만 사용했다. 원문·기존 기록·작업 구성·수식 장면·메모 보존, 저장 실패/재시도와 오래된 탭의 충돌 거부를 포함한다. `public-results.json`과 `public-tests.log`가 실제 근거다.
- `public-assets.json`: 공개 HTTP200 및 JS/CSS/서체/index **134개**, 바이트/SHA-256 불일치0. 이는 내려받은 Pages 산출물과 실제 공개 파일의 대조이며 공유 미공개 checkout 전체의 일치를 뜻하지 않는다.

## 게시 복구와 병행 범위

원 공개 실행의 attempt 2는 같은 이름 `github-pages`가 2개 있어 게시에 실패했다. [GitHub 공식 deploy-pages 구현](https://github.com/actions/deploy-pages/blob/v4/src/internal/api-client.js)과 [공식 job 재실행 절차](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/re-run-workflows-and-jobs)를 확인했다. 두 임시 산출물 ZIP을 내려받아 CRC·SHA-256과 실패 로그를 보존한 뒤 중복 ID11262842003/11267027635만 정리하고 게시 job을 attempt 3으로 재실행했다. 이 재실행은 병행 후보 전환 과정에서 cancelled되어 새 게시 성공으로 보고하지 않는다. 기존 실제 공개 파일은 유지됐으며 위 134개·16흐름으로 확인했다.

병행 공개에는 물리 화면과 모달 초점 보완이 추가됐다. 작성 시점 후보 `71fef95eee32a75b480fbc918e1fa0a8f7478f52`의 [Pages 실행37105323970](https://github.com/skmsmjs-netizen/study-space-generation2/actions/runs/37105323970)은 진행 중이다. 오래된 중복 실행37104869901/37105218650을 정리해 최신 후보가 이어 실행되도록 했다. 이 후속 후보의 실제 게시 성공·새 자산/브라우저 결과는 해당 배포 작업의 완료 근거로 별도 갱신한다. A01–A10의 확인된 공개 반영과 신규 후속 후보의 미완료 상태를 섞지 않는다.

공유 HEAD/index·병행 소스·개인 자료와 운영 backend는 이 대화에서 변경하지 않았다. `study-deploy`를 사용했고, Figma·전체 UX 경로 문서는 기존 대응을 유지했다. 물리 기기/IME/VoiceOver·개인 계정 서버 왕복/다기기 Sync/장기 사용/학습 효과는 이번 공개 확인으로 완료가 되지 않는다. Linear MAN-19 전체는 기존 In Progress를 유지한다.
