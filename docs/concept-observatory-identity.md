# 개념 전집 · 자료 책장의 도감

**개념 전집은 ManSeekSong OS의 서쪽 자료 책장에서 궁금한 개념을 꺼내 펼쳐 이해하는 도감이다.** 목차에서 이름을 찾고, 종이 작업면에서 구체적인 사례·관계·조건과 이유를 읽으며, 닫으면 실제 꺼냈던 목록으로 돌아온다. 읽은 사실을 숙달이나 공부 완료로 환산하지 않는다.

2026-10-02 전체 보수의 실제 증거는 [작업 결과](../../outputs/20261002-concept-os-repair/결과.md)가 담당한다. 이전 첫 디자인7개념/16장면과 이번 전체1,168개/1,851장면 대응을 구별한다. 이전 정체성·종이 보수 증거는 `outputs/20261002-concept-identity/`와 `outputs/20261002-concept-paper/`에 보존한다.

## 화면과 내용의 역할

| 부분 | 실제 구성과 목적 |
| --- | --- |
| 자료 책장 | 검색·유형·결과 수·쪽과 개념 이름을 함께 놓는다. 대표 과업 P02와 목록·상세 패턴 L045를 사용한다. |
| 펼친 종이 | 개념 이름 → 질문 → 사례·도해·본문 → 조건과 요점으로 연결한다. 따뜻한 종이와 선명한 잉크를 쓰며 글자 아래 빛·흐림·질감을 넣지 않는다. |
| 내용에 맞는 조작 | 정의·원리·절차·구별·구조·과정·관점의 일곱 유형을 유지한다. 한 화면583개, 선택368개, 단계217개이며 모든 설명을 단계식으로 바꾸지 않는다. |
| 장면 전환 | 같은 개념 안에서는 장면 높이를 유지한다. 조작의 현재 위치를 표시하고 짧은 전환과 모션 감소 설정을 따른다. |
| 목록 복귀 | 검색·유형·쪽·읽던 장면·목록 위치와 초점을 연결한다. 앱의 탭 상태와 재접속 후 저장되는 읽기 상태의 범위는 구별한다. |
| 근거와 이력 | 원문·출처·조건·미확인·개념/장면 ID·수정 이력을 보존한다. 읽기 화면에 제작 근거를 상시 나열하지 않는다. |

설명 본문을 천문대 비유로 치환하지 않는다. 천문대 정체성은 장소·재료·읽기와 복귀에 적용하며, 개념마다 필요한 논리와 예외는 그대로 설명한다.

## 채택 기준과 실제 적용

[유형별 설계 기준](concept-interaction-design.md)과 [기계 판독용 틀](concept-interaction-templates.json)을 재사용한다. PhET은 일관된 표현·의미 있는 초기 상태·조작의 묶음, DeFT는 여러 표현의 역할과 대응, NCTM은 수학 표현 사이의 연결, WCAG/APG는 키보드·초점·라벨·색 외 단서에 적용한다. 일곱 유형은 프로젝트의 편집 분류이며 학습 효과가 검증된 보편 분류라고 표현하지 않는다.

공간·재료는 [천문대 기준](observatory-design-standard.md), 현재 실행 값은 [baseline](observatory-experience-baseline.json), 구조·명명은 [설계 어휘](design-vocabulary/README.md), 화면 패턴은 [레이아웃 기준](layout-standard.md)을 따른다. 설명을 쉽게 고치는 작업에서도 조건·예외와 원문을 지우지 않는다.

## 현재 실행판의 종이 조판

- 종이는 기본768px, 본문은648px 열이다. 개념명을 표제로, 설명 제목을20px 리드로 연결한다. 본문은 개인 `--font-reading`을 따르며 기본18px이다.
- 현재 실행 중인 `metrics.paper.bodyTypography`·`bodyAlignment`를 소비한다. 굵기500, 넓은 본문 행간2/자간−0.05em, 실제 본문40rem 이하에서는1.85/−0.025em, 양쪽 정렬/마지막 줄 시작 정렬이다. 창 폭만으로 좁은 본문을 판정하지 않는다.
- 명시적인 줄바꿈은 문단으로 연결하며 사이 간격을 둔다. 같은 도입·도해 설명의 중복 노출을 줄이고, 요점은 본문 뒤 정상 흐름에 놓는다. 수식·코드에는 본문 자간을 퍼뜨리지 않는다.
- 수식·변수·단위는 공통 `ConceptText`/KaTeX/MathML로 표시한다. SVG 기하와 값은 유지하고 수식 표지는 실제 브라우저에 맞춰 배치한다. 확대 창에도 수식 표시와 키보드 복귀를 연결한다.

소비 파일은 `src/ui/concept-library.tsx/css`, `concept-text.tsx`, `concept-figure.tsx/css`와 자체 실행 읽기 파일의 `reader.tsx/css`이다. 줄바꿈·수식·개인 설정·좌표를 보존하며 가로 scaleX로 작업면 전체를 줄이지 않는다.

**후속 승인된 나눔명조700·장평95%는 앱 적용 대기 상태이다.** [후속 글자 계약](paper-typography-standard/contract.json)의 `paused-by-user`를 유지한다. 이번 읽기 파일과 Figma 전체 대응판은 현재 실행 값500/100%에 해당한다. 후속 디자인 [기준 보드](https://www.figma.com/design/YHmD1PpWWfR9JGTEs77JsX?node-id=241-202)와 이 실행판을 구별하며 앱 적용을 임의로 재개하지 않는다.

## 확인 범위

전체 내용은 작성 담당과 다른 검토 담당이 현재 해시에 묶어 대조했다. 최종 자체 실행 HTML은5개 WebKit 모사 환경에서 각각1,168개·1,851개 장면을 읽고 조작했으며, 별도 흐름 검사와4개 조판 조건을 연결했다. 실제 앱의 개인 저장 경로에서는 전체2파일 반입·재접속·재반입·기존 합성 공부 기록 보존을 확인했다. 해시와 실패 후 재확인 기록은 작업 결과 원장에 남긴다.

이는 별도 AI 검토와 브라우저 모사 결과이다. 실제 중학생 이해, 물리 iPhone/iPad, VoiceOver, 학습 효과, 실제 계정/서버 및 새 공개 배포를 완료로 보고하지 않는다. 이전 검증의 범위와 원문 미확인도 유지한다.
