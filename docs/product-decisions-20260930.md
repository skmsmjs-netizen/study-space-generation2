사용자 원문: “3은 A지. 뭔가 공부하다가 잡생각떨치기나 심심풀이로 해볼 수 있는 놀이항목처럼 ㅋㅋ. 꼭 필요할까 싶긴해. 그러므로 사고 도구만.”

선택형 사고 도구만 채택합니다. 공부 중 잠깐 환기하거나 심심풀이로 열어 보는 놀이 성격을 유지합니다. 기본 공부 절차·필수 입력·해야 할 일·매일 사용 목표로 만들지 않습니다. 필요성에 대한 유보도 보존합니다. 상태 입력·생활 동역학 계산·점수·예측은 이번 채택 범위에 포함하지 않습니다. 개별 도구의 종류와 배치는 아직 지정되지 않았으며 기존 후보를 모두 필수 출시 조건으로 해석하지 않습니다.

## 4. 삭제 — 휴지통·복원까지

사용자 원문: “4는 A”

이번 완성 범위는 휴지통·복원까지입니다. 일반 영구삭제 UI는 제공하지 않으며 영구삭제 구현·정책 결정을 이번 출시의 선행조건으로 삼지 않습니다. 휴지통은 같은 ID로 복원하고 기록·본문·이력을 보존합니다. 향후 영구삭제를 새로 요청하면 그때 삭제 범위·백업·첨부·다기기 처리 정책을 결정합니다.

## 5. 입력 부담 없는 기록 표시

사용자는 ‘너무 입력 피로가 생기는, 좀 오버인 기능들은 빼’라고 정정한 뒤, 아래 두 가지로 줄인 제안에 ‘어 그렇게 적용해’라고 지시했습니다.

- 홈의 기존 주제 카드에 해당 주제의 최근 글을 한 줄로 표시합니다. 등록 시각 기준으로 가장 최근의 비어 있지 않은 공부 기록 본문을 사용하고 글이 없으면 생략합니다. 한 줄 표시는 원문·줄바꿈·공백을 변경하지 않으며 기존 주제 상세에서 원문을 엽니다. 멈춘 지점·다음 행동의 별도 입력을 추가하지 않습니다.
- 기존 목차의 주제에 ‘기록 있음’을 작게 표시합니다. 공부함 체크뿐 아니라 글만 남겼거나 일부만 체크한 저장 기록도 포함하고, 휴지통에 있는 기록은 제외합니다. 기존 공부함 횟수는 유지하며 기록 여부를 이해·목표 달성으로 환산하지 않습니다. 별도 주간 보고·기간 설정을 추가하지 않습니다.

이번 추가 추천에서는 의문 표시·관리, 확신 선택·결과 비교, 두 기록의 전용 비교 화면을 제외합니다. 이는 기존 메모·추천 확인 결과·서술·이력 기능을 삭제하는 지시가 아닙니다. 비교 대상 선정이 미정인 ‘헷갈리는 둘’도 채택하지 않습니다.

## 2026-10-01 녹음 대신 클로바노트 전사문 사용

앱의 녹음 시작·음성 파일 가져오기·Whisper/브라우저 받아쓰기·음성 자동 생성 흐름을 제거합니다. 클로바노트 전사문 붙여넣기 또는 전사문 파일 가져오기를 통해 선택한 글만 GPT 자료 생성에 사용합니다. 기존 원음·원문·초안·결과·ID/이력은 읽기/다운로드 호환으로 보존하며 이전 정리 예약만으로 자동 삭제하지 않습니다. 구체적인 흐름·한도·기기/검증 범위는 [클로바노트 전사문 계약](clovanote-transcripts-20261001.md)을 따릅니다. 민석 전용 AI를 유지하며 이번 변경만으로 키 등록·결제·실제 유료 호출의 권한을 추가하지 않습니다.
