# ManSeekSong OS — 본 작업 마무리 체크리스트

기준 정정: 2026-10-02. **현재 다른 채팅 「웹앱 구현 진행」의 통합 구현이 아직 시작되지 않았다고 가정한다.** 그 작업에서 새로 적용한 레이아웃 소비·본문700/95%·통합 빌드 결과는 이 기준표의 완료에 포함하지 않는다. 그 이전에 독립적으로 구현·확인한 앱·API·서버·자료·목업은 유지한다. 실제 소스를 되돌리거나 진행 중인 채팅을 중단하는 요청으로 해석하지 않는다.

이전의 ‘웹앱 구현이 끝날 때’ 기준표를 대체한다. 사용자는 **웹앱 구현이 끝난 뒤 이 체크리스트를 한 번 더 검증**하기로 했다. 후속 검증에서는 실제 구현판·운영판·공개판의 버전과 증거를 대조하여 체크를 갱신한다. 자동 예약·다른 채팅 메시지는 실행하지 않는다.

## 일정과 제외 범위

리셋쿠폰은 다음 화요일2026-10-06까지 사용하지 않으며 이후에도 자동 사용하지 않는다. API 호출 비용과 계정 사용량 리셋쿠폰은 구별한다. 새 물리/수학/화학 개념/관측틀 생성은 ‘화요일 이후’에 진행하며 그 전에는 준비된 웹앱의 구동을 우선한다. 토·일·월 과제 일정을 존중한다. 화요일/이후의 실제 재개일을 여기서 임의 확정하지 않는다.

다음은 본 작업의 필수 미완으로 다시 추가하지 않는다.

- 결제/청구·외부 문의 접수/회신.
- 전용 YouTube 가져오기·제외된 AI 튜터·앱 마이크/유료 전사·기기 OCR.
- 종료한 Obsidian/Vault 구현·설치/기기 Sync.
- 미승인 LMS/외부 캘린더 양방향 연동·미래24분류 전부의 신규 기능화.
- 무한 규모/모든 외부 예제 구현·학습 효과/충성도 연구.

기존 원문/과거 튜터 결과/도움말·일반 문서·자막/클로바노트 전사문은 보존한다. 외부 알림 발송·개인 자료 업로드·새 운영 배포·실제 계정 삭제는 해당 작업의 기존 권한/승인과 별도로 다룬다.
