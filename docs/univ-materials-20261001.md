# 문서·사진·자막 가져오기와 UniV 학습 흐름 구현

2026-10-01. 사용자 요청 ‘남은 작업 다해’의 범위는 강의 자료의 비녹음 입력, 자료에 근거한 퀴즈·다회차 질문 답변·수정 가능한 개념도, 기존 Canvas 연결, 비공개 원본 보관이다. 추가 유료 API·Gemini·GPT 크레딧 구매나 재설정은 사용하지 않았다. 기존 기록·원문·수정 전 문장·ID·초안·결과 이력과 병행 변경을 보존했다.

## 현재 사용 흐름

로컬 실제 앱 `http://127.0.0.1:5491/#/materials/new`에서 과목을 고르고 **문서·사진·자막 가져오기**로 파일을 선택한다. 파일별 원문을 펼쳐 수정하거나 복원하고, 사용할 쪽·슬라이드·구간을 선택한다. **GPT 작업**에서 요약과 카드, 객관식 퀴즈, 자료에 질문, 개념도 만들기 등을 선택한다. 생성 결과와 원문 근거를 대조하고 **자료 저장**을 누른다. 가져오기만으로 GPT를 호출하거나 공부·정답·숙달 기록을 만들지 않는다.

| 입력 | 실제 연결한 처리 | 조건 |
|---|---|---|
| PDF | PDF.js 쪽별 텍스트, 쪽 범위 선택, 글 없는 쪽의 한국어·영어 OCR | 암호/손상 문서는 원본을 보관하고 오류·재시도 표시 |
| DOCX | Mammoth 원문 추출 | 옛 DOC는 DOCX로 변환 필요 |
| PPTX | 슬라이드 관계 순서와 발표자 노트 추출 | 옛 PPT는 PPTX로 변환 필요 |
| 사진 | Tesseract.js 한국어·영어 OCR, 원본 사진 확인, 원문 수정/복원 | 손글씨·수식·띄어쓰기 정확성 보장 없음 |
| TXT·MD·CSV | 원문 보관과 구간 분할 | 원문을 몰래 자르지 않음 |
| VTT·SRT | 시간 구간을 유지한 자막 | 원래 음성 파일이 없으면 자막만 보관 |
| YouTube | 공개 영상의 한국어/영어 자막을 로컬 도구로 가져오기, 수동 자막 파일 대안 | 자막 없는 영상·로그인/제한 영상은 자동 가져오기 불가, 영상 다운로드 안 함 |

자료는 최대20개·파일50MiB·원문 합계100만 문자로 제한한다. PDF는 한 번에500쪽 이내, 사진/OCR은2천만 픽셀 이내로 처리한다. 압축 문서의 확장 크기·XML 외부 선언·URL 형식을 확인한다. 긴 문서는 전체 원본을 남기고 처음 사용할 범위를 선택하며 한 GPT 요청은 선택 원문과 추가 입력15만 문자 이내로 검사한다. 구간 선택/해제·취소·손상 파일 재시도·초안 재접속을 제공한다. OCR 엔진·한국어/영어 모델은 같은 origin에서 읽어 브라우저 안에서 처리한다. PDF/DOCX/PPTX/사진 원본을 추출 서비스로 업로드하지 않는다.

## 학습 결과와 반복 사용

- 객관식 퀴즈는 제출 전 답을 숨긴다. 오답과 미응답을 구별하고 원문 근거·해설을 보인다. 다시 풀기는 새 시도로 남기며 제출한 이전 답/문항을 바꾸지 않는다. 최대100시도이며 시험 점수나 숙달에 자동 합산하지 않는다.
- 자료 질문은 질문 초안과 이전 대화를 저장한다. 같은 원문을 사용한 최근6대화만 다음 요청의 대화 맥락으로 전달한다. 질문·이전 AI 답 자체를 자료 근거로 승격하지 않는다. 원문이 달라져도 지난 대화는 삭제하지 않는다.
- 개념도는 기존 React Flow와 Canvas를 재사용한다. 개념/관계 이름·원문 근거·위치 수정, 숫자로 위치 지정, 최초 생성 관계도 복원을 제공한다. **Canvas에 추가**로 기존 배치 오른쪽에 개념 메모와 관계를 연결하고 기존 메모·편집·화면 위치를 보존한다. 같은 결과의 재추가로 메모/연결을 중복 생성하지 않는다.
- 각 생성은 사용한 선택 원문·파일 해시·쪽/슬라이드/시간·결과 ID를 보관한다. 서버는 실제 원문 구간의 근거 ID와 출력 구조를 검증하며 원문을 AI의 재작성으로 대체하지 않는다. 형식/출처 검증은 설명의 사실성이나 학습 효과 검증과 구별한다.

## 비공개 원본 보관과 서버 적용

원본은 먼저 계정/공간별 IndexedDB에 보관한다. **자료 저장할 때 원본 파일도 비공개 서버에 보관**을 직접 선택하면 현재 로그인 계정의 `study-material-originals` private bucket에 올린다. 공개 URL을 사용하지 않으며 기기에 파일이 없을 때 본인 인증으로 내려받아 SHA256/크기를 확인한 뒤 기기에 보관한다. 부분 업로드 성공 정보는 초안에 남겨 재시도하고, 중복 업로드의 응답 누락도 원본 해시를 읽어 확인한다.

기존 Supabase에 `20261001070035_material_originals.sql`을 적용했다. 본인 경로·personal/test 공간·현재 승인·실제 Auth 세션을 검사하는 SELECT/INSERT, 음성의 본인 명시 정리만 허용하는 DELETE, immutable 파일,50MiB 파일 및500MiB 버킷 총량 안전 상한을 둔다. 문서 삭제/교체를 자동으로 허용하지 않는다. 계정 전체 탈퇴 시 클라우드 원본 일괄 삭제는 이번 검증 범위에 포함하지 않았다.

운영 `study-command`의 기존 source를 읽어 자료 계약 모듈과 해당 저장 전이만 바꾼 v22를 적용하고 내려받은 소스 일치를 확인했다. 문서·퀴즈 시도·튜터 초안·원본 경로의 저장 검증을 연결했다. 다른 도메인·공부 원장·로그인·운영 전체 코드를 공유 checkout에서 일괄 재배포하지 않았다. 이후 다른 작업의 GPT 계약 보완과 서버 버전은 별도로 확인해야 한다.

현재 승인된 실제 계정의 **test 공간**에서85bytes 합성 파일로 실제 업로드→다운로드→SHA 일치→중복 업로드 복구→익명 공개 접근 거부(HTTP400)→정리를 확인했다. SQL로 잔여 test/audio 파일0개를 확인했다. 개인 강의 파일·공부 기록을 이 시험에 쓰지 않았으며 GPT 호출0회다. 이 결과를 물리 iPhone/iPad 간 전달·Sync 확인으로 확대하지 않는다.

## 도구 선택과 확인 범위

이미 구현된 GPT 구독 연결·무료 전사 도구를 유지하고 공식 [PDF.js](https://mozilla.github.io/pdf.js/), [Mammoth](https://github.com/mwilliamson/mammoth.js), [Tesseract.js](https://github.com/naptha/tesseract.js), [fflate](https://github.com/101arrowz/fflate), [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api), [Supabase private Storage](https://supabase.com/docs/guides/storage/security/access-control)을 목적별로 재사용했다. GPT 구독의 Files/음성 제약을 피하려고 원본을 로컬에서 텍스트로 읽고 선택 원문만 기존 구독 연결로 전달한다. 이들 도구의 널리 쓰임을 OCR 정확성·학습 효과의 보장으로 표현하지 않는다. 자체 구현은 자료 계약·선택/수정/복원·출처 추적·학습 UI·저장 연결이다.

실제 인앱 브라우저의 격리 origin62656에서 두 쪽 PDF, 한국어 DOCX, 실제 순서/노트가 있는 PPTX, 한국어 사진 OCR, 시간 자막,23만8천 문자 텍스트, 손상 PDF의 오류/재시도를 확인했다. OCR의 수식/띄어쓰기 오류를 원본과 비교해 직접 수정하고 수정 전 내용을 보존했다. 긴 텍스트는30구간 전체를 남기고15구간을 선택했다. 파일 선택 이벤트와 계정/GPT 응답은 합성, PDF/Word/PPT/OCR 추출기는 실제다.

동일 브라우저에서 GPT가 반환한다고 가정한 결과로 퀴즈의 오답1/미응답1→다시 풀기→저장/재접속, 두 차례 튜터와 이전 대화 전달, 개념 이름/관계 수정→Canvas3메모/2관계→중복 추가 방지와 공부 기록0을 확인했다. 제품의 실제 HTTP 클라이언트·로컬 서버 검증·도메인 명령·원본 IndexedDB를 사용했다. 격리 시험의 workspace 저장 acknowledgment는 합성이다. 이후 현재 승인 계정의 빈 test 공간에서 실제 study-command HTTP 저장과 재조회도 수행했다. 문서 원문·수정 전 원문·제출된 퀴즈 답·질문 초안이 유지됐고 공부 기록0/GPT 호출0을 확인했다. 시험 workspace는 sequence2와 정확한 두 operation ID를 확인한 뒤 정리했고 SQL로 workspace/operation/시험 음성 잔여0을 확인했다. personal 공간은 바꾸지 않았다. 물리 기기나 민석의 실제 강의 자료 확인과 구별한다.

최종 사본의 타입·디자인 토큰·production build를 확인했다. 첫 회귀15파일55검사에서51개 통과, 기존 GPT 근거 예제1개와 UI3개가 실패했다. 근거 예제는 병행 작업의 실제 원문을 함께 인용하는 수정으로 맞췄다. 초안 보관을 기다리는 동안 중단한 경우 호출을 시작하지 않도록, 결과를 받은 직후 중단된 경우 결과를 붙이지 않도록 AbortSignal 확인을 추가했다. 공유 기기의 동시 검사 지연을 고려해 UI 비동기 대기10초/검사30초·한 worker로 재확인해2파일13개를 모두 통과했다. 최초의 나머지13파일42개와 합쳐 관련15파일55개가 통과했다. 보완 후 production build도 통과했다. 정확한 수치는 `work/univ-materials-20261001/verification.json`과 검사 로그를 기준으로 한다.

공유 checkout의 PostCSS/CJS 의존 오류를 다른 작업의 패키지 삭제/덮어쓰기로 고치지 않았다. 정상 의존성으로 설치한 확인 사본을 사용했다. 경로는 `work/univ-materials-20261001/check-path.txt`, 실제 앱 포트5491이다. 확인 사본의 변경과 이후 공유 파일 변경을 해시로 구별한다. 일반 사용 UI에 시험 표식을 넣지 않았으며 격리 시험 표식은 시험용 origin에만 있다.

## 실행할 수 없었던 확인

- 조회한 GPT 포함 사용량100%/일반 사용 불가로 실제 모델 생성·정답/설명 품질 검증은 수행하지 않았다. 무료 재설정·추가 크레딧·유료 API·Gemini 전환을 하지 않았다.
- 원격 GPT 사용은 공식 서비스 접근 신청/승인과 보호된 서버 실행 환경이 필요하다. 승인 전 임의 터널·기존 Codex 토큰 공유로 우회하지 않는다. 현재 기능 구현을 iPhone/iPad 원격 GPT 완료로 보고하지 않는다.
- 이번 새 화면의 공개 frontend 배포, 물리 기기·실제 한글 IME/VoiceOver·장기 강의 OCR/전사 품질은 확인하지 않았다.

GPT 한도가 다시 허용될 때 실제 연결의 새 결과1회와 실제 자료의 품질을 확인한다. 원격 승인 전까지 로컬 GPT 연결 범위를 유지한다. 새 기능 metadata의 실제 서버 저장/재조회는 위 격리 자료로 확인했다.
