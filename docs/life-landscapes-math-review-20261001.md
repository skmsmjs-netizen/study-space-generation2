# 생활점수 수리 검토와 픽셀 풍경 적용

2026-10-01 사용자 요청: 생활점수의 수리적 부분을 먼저 검토하고, 필요한 만큼 서로 다른 픽셀아트 위젯을 실제 웹앱에 만든다. 숫자 점수와 개발용 해설을 일반 풍경 화면에 노출하지 않는다.

## 검토 범위와 결론

활성 참고자료 `../../docs/reference/learning-life-dynamics-v2.0-provisional/학습생활_통합이론명세_v2.0_잠정.md`의 0~22절, 식(1)~(62), 같은 폴더의 검토기록을 읽었다. 종료한 앱·보관본은 조사하지 않았다. 원문은 수정하지 않았다. 원문 SHA-256: `54a39d041e751ec2d5f2e1c8858702f383ab30b43f4f7ce0b0e73efc2d9af4ac`.

계산 규칙이 성립하는 것과 인간의 생활 상태를 타당하게 측정하는 것은 다르다. 연속 상태의 지수해·범위 보존·시간구간 합집합·결측 구분은 재사용 가능한 수학이다. 25점씩의 생활 합산, 기상 배점의 수면 문턱, 임의 피로계수·준비도·이탈률은 개인의 검증된 생활점수로 채택할 근거가 없다. 현재 공부 데이터만으로 원점수 D를 계산하는 것도 불가능하다. 숨긴 숫자라도 실제 생활 상태처럼 사용하면 같은 문제가 남는다.

이번 구현은 생활을 연상시키는 그림에 **공부 기록에서 관측되는 별도의 세 가지 사실**을 연결한다. 수면·식사 설문, 포인트 원장, 상태 예측, 개인 계수 학습은 도입하지 않는다. 기존 참고자료 전체의 채택 확정으로 읽지 않는다.

## 기존 기준과 도구 선택

- [OECD/JRC 합성지표 안내서](https://www.oecd.org/content/dam/oecd/en/publications/reports/2008/08/handbook-on-constructing-composite-indicators-methodology-and-user-guide_g1gh9301/9789264043466-en.pdf)의 변수·결측·가중·대체 가능성·민감도 검토 관점을 사용했다. 이 문서는 국가 비교 지표의 방법 안내이며 개인 건강점수 인증이 아니다. p31의 동일 가중치도 판단이라는 설명, p32와 p103의 합산에 따른 다른 영역의 상쇄가 이번 판단과 직접 관련된다.
- [Borbély & Achermann 원 논문](https://journals.sagepub.com/doi/pdf/10.1177/074873099129000894)의 부록 p566에 18.2시간/4.2시간 상수가 실제로 있다. 이것은 수면압 시나리오의 문헌 출처이고, 원명세의 한국 시각 위상·F·R·개인 종료 확률을 검증하지 않는다.
- [Calm Technology](https://calmtech.com/papers/designing-calm-technology)의 주변 시야에 두는 표현, [ambient information systems 분류](https://courses.ischool.berkeley.edu/i262/f13/readings_pdf/taxonomy_for_ambient_media_pousman.pdf)의 표현·알림 강도 구분을 참고했다. 이번 풍경의 효용이 실증됐다는 뜻은 아니다.
- [WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)의 자동 움직임 정지·숨김, [2.3.3](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)의 비필수 모션 해제를 적용한다. 전체 접근성 준수 판정은 별개다.
- 기존 React·SVG·CSS steps·공통 Button/Checkbox·색상 토큰을 재사용한다. 신규 라이브러리는 필요하지 않다. 외부 공룡/Notion 이미지를 복제하지 않고 직접 그린 벡터를 픽셀 격자에 맞춘다. 그래프·수치 읽기가 목적이 아니므로 차트 라이브러리를 추가하지 않는다.

### 점수에서 실제로 드러나는 문제

수면 목표480분·기상 기준 만족이라면, 479.999분일 때 수면 배점은 약19.99996이고 480분에서는25다. 극한 차이5점은 수면의 순간적 개선을 측정한 값이 아니라 **기상 보상을 켜는 정책의 불연속**이다. 향후 원점수를 채택한다면 시간의 정밀도·정정 비용·문턱 인센티브를 먼저 정해야 한다. 연속으로 바꾸려면 `k_w=q_s q_w` 같은 후보가 있지만, 이는 ‘수면 미달일 때 기상 보상0’ 계약을 바꾸므로 이번에 원문을 몰래 수정하지 않았다.

수면360분이고 다른 세 영역이 완전히 채워지면 D=90이다. 수면480분·식사 만족이고 자기관리/공부가0이면 D=50이다. 이것은 규정된 합산 결과이지 첫 날의 생활이 더 건강하다는 근거가 아니다. 다른 영역의 점수를 더 받으면 결핍 영역을 상쇄하는 특성이 합산 자체에 있다. 그러므로 총점 하나로 화창함·시듦·캐릭터 활력을 결정하지 않는다.

원명세 예제 D=58.75, 미확인 구간 추가 후 D=null/E 유지, 확인 후60.833333과 차액2.083333, 휴무75/75와 공부일100/100, 수면 주기 고정점, R=44.58208094, 블록23.6127838분, 위험의 기본률 변경에 따른3.7771%~45.9923%를 재현했다. 마지막 범위는 가정 변경의 민감도이지 관측된 확률의 오차범위가 아니다.

## 현재 앱 데이터와 연결하는 수학

활성 소유 계정/namespace와 선택 공부 범위의 기록만 읽는다. 최신 버전을 선택한 뒤 삭제 여부를 확인하고, 삭제된 부모 과목·공부 사건을 제외한다. 본문·항목 메모·체크 중 실제로 남긴 활동이 있는 기록을 사용한다. 빈 미체크 행은 활동으로 세지 않는다. 글의 길이와 정답 여부에 배점을 주지 않는다.

`T = 기록이 남은 (과목ID, 대상ID) 집합`, `V(t) = 대상 t가 기록된 서로 다른 공부사건ID 집합`, `B = 유효한 정확 날짜 집합`이다. 같은 사건의 같은 대상 여러 행·재저장은 추가 방문이 아니다. 다시 찾은 대상은 `|V(t)| > 1`로만 정의한다. 선택 TRACE의 반복 수나 날짜 미정 기록을 특정 날짜의 방문으로 자동 변환하지 않는다.

| ------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 작은 뜰 | T의 안정된 ID 해시로 식물 형태를 선택  | 최대12식물, 크기·종류는 해시로 정함. 공부량·능력 성장 곡선 없음                                                 |
| 물가    | B의 최근12개 기록 날짜 사이의 간격     | 간격 `min(4,max(1,날짜차))`. 날짜 미정/기간은 별도의 강가 흔적으로 남김. 오늘부터의 미기록 기간은 계산하지 않음 |
| 산책길  | 서로 다른 공부 사건에서 다시 찾은 대상 | 최대8길표식. 걷는 속도는 고정된 미술 설정이며 성취/피로 추정이 아님                                             |

세 값을 합쳐 D나 숨은 총점을 만들지 않는다. 그림 선택은 원기록과 ID에서 매번 재구성하여 재접속·수신순서 변경·중복 저장에 불변이다. 현재 시각이나 무작위 호출로 상태를 초기화하지 않는다. 수정·삭제·복원 후 현재 기록을 다시 읽어 반영하고 원문/이력에 새 점수를 쓰지 않는다. 그림의 최대 개수와 CSS 움직임의 시간은 **이번에 직접 정한 표시 정책**이다. 생활동역학의 검증된 계수로 표현하지 않는다.

별도 생리 ODE를 장식에 덧붙이지 않았다. CSS steps의 고정 주기 움직임에 관측된 그림 구성을 연결한다. 이는 사용자가 원한 느슨한 의미의 실시간 풍경이며 데이터 갱신 즉시 그림에 반영된다. 움직임의 재접속 시 프레임은 다시 시작되지만 기록 기반의 구성·사용자 선택은 보존된다.

## 반복 사용과 보존

- 홈의 기존 공부 입력·메모 흐름 다음에 세 풍경을 배치한다. 각 풍경을 숨기고 복원하며 전체 움직임을 멈출 수 있다. 숫자 점수·범례·목표·연속 출석 의무를 붙이지 않는다.
- 선택·정지는 계정/namespace를 구별한 기기 표시 설정에 저장한다. 공부 데이터/서버 스키마를 변경하지 않는다. 다른 기기로 동기화되는 설정은 아니다. 저장 실패 시 현재 선택을 유지하고 재시도 경로를 표시한다.
- 새로고침으로 설정과 그림 구성을 복원한다. 그림 구성만 원기록에서 유도한다. 다른 탭의 표시 설정 변경을 수신한다.
- OS 움직임 감소가 켜지면 정적 그림을 사용한다. 화면 밖·백그라운드에서는 애니메이션을 정지하고 다시 보일 때 이어간다. 소리·번쩍임·자동 포커스 이동은 없다.
- SVG는 장식으로 처리하고 세 풍경 이름과 조작을 접근 가능한 글로 둔다. 좁은 화면에서는 세로로 흐르며 고정 논리 격자192×96을 확대한다. 밝음/어두움의 기존 토큰을 따른다.
- 자동 검사의 누적 조건은 합성10,000기록이다. 무제한 데이터나 실제 장기 사용/물리 기기/학습 효과를 검증한 것으로 확대하지 않는다.

프로덕션 소스와 이번 두 테스트의 타입 검사: `npx tsc --project work/pixel-landscapes-20261001/tsconfig.app.json --noEmit` 통과. 공유 전체 타입 검사에서 다른 일정 테스트17개 오류가 확인됐으며 해당 파일은 변경하지 않았다. Vite 앱 빌드와 디자인 토큰 검사 통과. 전체 `npm run build` 결과 및 브라우저 최종 증거는 같은 work의 `verification.md`에 이어 기록한다.

실제 조작 증거는 개인 기록을 사용하지 않는 별도 localhost origin에서 현재 앱의 예시 자료 저장 경로를 사용한다. 운영 서버 저장·공개 배포·사용자 실계정·물리 iPad/iPhone·장기 효용은 이번 완료 범위에 포함하지 않는다.
