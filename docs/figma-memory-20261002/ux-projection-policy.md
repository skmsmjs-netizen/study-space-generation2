# Figma UX 원장의 경량 투영

2026-10-02 메모리 문제 보수. Figma에는 화면의 역할·진입·복귀·대표 조건과 조작을 짧게 보여주고, 전체 조건·이벤트·핸들러 분기는 기존 로컬 문서와 실제 코드에서 관리합니다. 복잡한 위젯의 내부 실행·렌더링은 앱 구현에 연결합니다. 전체 정보와 실제 앱 기능은 유지합니다.

현재 캡처의 조작 1,462개·표면 121개·개요 2개는 동일 ID·제목·소스 경로를 유지합니다. 표시본문은 2,640,037자에서 529,230자로 79.95% 줄였으며, 카드의 최장 본문은 650자입니다. 조작의 공유 핸들러 전체를 카드마다 반복하던 출력과 표면의 모든 조작 이름을 반복하던 출력을 없앴습니다. 전체 표면-조작 참조 6,182개와 조작-핸들러 참조 3,399개는 `references`에 보존합니다. Figma에 이미 있는 별도 색인 4개는 이 입력 집합에 포함되지 않습니다.

원문 담당 파일은 `docs/ux-paths-20261002/source-actions.json`, `manifest.json`, `전체경로.md`, `paths/*.md`, `actions/*.md`, `handlers/*.md`입니다. 요약의 긴 조건이 생략 부호로 끝나면 반드시 연결한 원문을 따라갑니다. 요약에서 보이지 않는 조건·원문·ID를 지우거나 성공·실패·보존 사실을 새로 추정하지 않습니다. Figma의 짧은 표시가 모든 실행 경우를 설명한다고 주장하지 않습니다.

`compact-ux-cards.json`은 이번 경량 입력이고 `compact-ux-summary.json`은 입력 원문과 전체 소스의 SHA-256·길이를 보존한 준비 기록입니다. 현재 `ux-paths-20261002/figma-inputs`와 이전 원격 검증은 당시 전체본문의 근거로 유지합니다. 같은 파일의 과거 통과를 새 요약의 원격 통과로 승격하지 않습니다. `verify.cjs`도 기존 전체본문 증거와 이번 투영 상태를 구별합니다.

생성기는 기본적으로 `summary-reference-v1`만 Figma에 출력합니다. `render-docs.cjs`는 전체 Markdown·JSON을 계속 같은 경로에 만들며, Figma용 출력에서는 모든 공유 분기·호출을 반복하지 않습니다. `build-figma-paths.js`는 예전 긴 입력을 받더라도 쓰기 전에 요약하고, 명시적 전체본문 모드를 거부합니다. 기존 짧은 입력은 호환됩니다. 한 카드의 표시본문을 한 TextNode로 만들고 카드마다 반복하던 검증 안내를 덜어냅니다. 전체본문을 Figma에 기본 재생성하는 옛 절차를 사용하지 않습니다.

현재 입력의 캡처 시각은 `2026-10-02T03:27:44.072Z`이며 이후 실제 소스 변경은 별도로 남습니다. 이 보수는 원래 문서의 ID·범위를 보존하기 위해 소스를 재캡처하지 않았습니다. 새 소스 대응 작업이 필요한 경우 기존 캡처와 원격 근거를 보존하고 새 캡처의 증분을 따로 비교합니다.

현재 전체 원문·이전 입력을 바꾸지 않고 요약을 준비하고 확인하는 명령은 다음과 같습니다.

```sh
node docs/figma-memory-20261002/compact-ux.cjs
node docs/figma-memory-20261002/verify-compact-ux.cjs
node docs/ux-paths-20261002/verify.cjs
```

`compactItem(item, createContext(source, manifest))`를 다른 변경 작업에서 재사용할 수 있습니다. Figma 파일의 전체본문을 줄이기 위해 별도 표준을 만든 것이 아니라 기존 고유 조작 정규화와 원문 참조 구조에 표시 어댑터를 붙인 것입니다. 원격 기존 TextNode의 ID·프로토타입·목표 링크를 유지하는 실제 적용과 readback은 부모 작업의 별도 근거로 판단합니다.

격리된 `/tmp` 생성에서 전체경로·공통 상태·소유 매핑 및 `paths/actions/handlers` 326개 파일의 바이트를 현재 원문과 전수 대조했습니다. 새 기본 입력은 모든 1,585개 ID·본문·참조가 독립 요약 함수의 결과와 같았습니다. 당시 반환된 326개 검사 결과는 [원문 보존 증거](../../work/figma-memory-20261002/full-documents-preservation.json)에 회수해 보존했습니다. `compact-ux-verification.json`은 후속 기본 호출로 갱신되어 `fullDocumentsCompared:0`인 별도 투영 재검사 결과입니다. 원래 파일/로그가 그대로 남았다는 뜻은 아니며 회수 출처와 격리 폴더를 증거에 명시했습니다. 두 결과 모두 실제 Figma 메모리 수치·앱 실행·저장·물리 기기의 통과 증거는 아닙니다.
