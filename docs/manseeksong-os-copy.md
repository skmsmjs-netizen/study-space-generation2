저장·권한·오류·복구에서는 ‘일정 저장’, ‘닫고 초안 보관’, ‘주차 생성 되돌리기’처럼 실제 동작을 먼저 말한다. 기록 수나 출석·공부함 체크에서 이해·숙달·학습 효과를 만들어내지 않는다.

[Apple WWDC24 UX writing](https://developer.apple.com/videos/play/wwdc2024/10140/)의 일관된 목소리와 상황별 표현, 기존 [브랜드와 반복 사용 경험 지침](manseeksong-brand.md)의 약속을 재사용한다. 제품 설명·처음 방문·복귀·월간 회고에서는 개성을 드러내고, 입력·저장·실패 안내는 명료한 행동명을 유지한다. 이번 문장은 제품을 위한 카피이며 학습 효과나 사용자의 감정을 설명하는 연구 결론이 아니다.

코드 원본은 `src/domain/brand.ts`이다. 홈·로그인·공통 브랜드는 이 값을 사용하고, 일정·월간 기록은 각각 실제 기능과 함께 표시한다. 기존 기능명과 원문·기록·저장 키는 유지한다.

2026-10-02 천문대 정체성 개선: 중심 문구는 마침표 없이 명조체로 표시하고 제품명은 독립 벡터 워드마크를 쓴다. 영문은 정돈된 도구의 명판, 한글은 종이 작업면의 문장 역할이다. 영문 Inter name weight470/광학크기32/자간-.012em, OS weight520/크기76%/자간.065em/앞간격.30em는 이번 프로젝트의 디자인 선택이며 공인 표준값이 아니다. 한글 문구는 Noto Serif KR400·15px/행간1.8/자간.025em이며 기기 안에서 같은 글자로 보이도록29,136byte WOFF2와 OFL을 앱에 포함한다. 일반 본문·사용자 서체와 분리하며 좁은 상단에서는 제품명만 표시한다. 로그인에는 제품명과 문구를 한 묶음으로 배치한다.

기존 Inter/FontTools 생성기와 천문대 재료색·공통 토큰을 재사용했다. 로고의 벡터 윤곽선과 일반 카피의 텍스트 표현을 구별하는 근거는 [W3C Images of Text](https://www.w3.org/WAI/WCAG22/Understanding/images-of-text.html), 글자 확대·간격 조정 확인은 [W3C Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)이다. [Google Fonts 공식 text 최적화](https://developers.google.com/fonts/docs/css2#optimizing_for_latency_and_file_size)로 고정 문구 글리프만 받아 로컬 WOFF2로 변환했다. 런타임의 Google 글꼴 요청이나 개인 글 전송은 없다. 출처/해시/라이선스는 `assets/brand/promise-font-source.json`·`public/fonts/brand/OFL-NotoSerifKR.txt`, 확인 결과는 `work/brand-identity-20261002/결과.md`에서 관리한다.
