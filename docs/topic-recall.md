# 주제 카드로 설명하기

홈의 ‘주제 카드로 설명하기’ 또는 주 메뉴의 ‘주제 카드’에서 시작합니다. 등록된 주제만 사용하며 화면 상단 학기 범위 안에서 과목·단원을 고를 수 있습니다. 한 바퀴 동안 중복 없이 무작위로 보여주고, 다음 바퀴의 첫 주제는 가능한 경우 직전 주제와 다르게 고릅니다. 바퀴 수는 주제를 지나간 횟수이며 학습 완료·정답·숙달을 뜻하지 않습니다.

카드 바로 아래에 설명 입력창을 둡니다. 입력 중에는 주제를 바꾸지 않습니다. ‘메모 저장 후 다음 주제’는 원문·공백·줄바꿈을 그대로 보존해 해당 주제에 연결된 새 메모를 만듭니다. 같은 주제를 다시 설명해도 이전 메모를 덮어쓰지 않습니다. 이전 메모는 접힌 영역에서 열거나 메모 화면에서 편집할 수 있습니다. 공부 기록·세션·체크를 자동 생성하지 않습니다.

‘건너뛰기’, 과목·단원 변경, 화면 이동, 새로고침 때 작성 중인 글은 주제별 초안으로 유지합니다. 한글 조합 중에는 범위 변경·저장·건너뛰기를 비활성화합니다. 입력창의 Enter는 줄바꿈이며 저장·전환 단축키가 아닙니다.

새 답변의 메모 ID는 초안에 미리 저장합니다. 메모 저장 성공 뒤 초안 정리만 실패하면 동일한 ID·본문으로 재시도해 메모가 중복 생성되지 않습니다. 그동안 메모가 수정됐다면 기존 메모와 초안을 보존하고 별도 메모 저장을 제공합니다. 읽을 수 없는 카드 초안은 덮어쓰지 않으며 다시 읽기를 제공합니다. 저장 실패는 화면에 표시하고 해당 전환을 멈춥니다. 기존 초안 구조·메모 원장·schema 1·저장 키를 변경하지 않습니다.

현재 저장 범위는 기존 demo/localStorage입니다. 온라인 개인 저장·다기기 Sync·OS 데이터 삭제 복구·물리 iPad 한글 입력의 완료로 표현하지 않습니다. 1세대 Anki에서는 주제·정의/조건 서술·저장 후 다음 주제의 흐름을 참고했습니다. 이번에는 평가 버튼과 간격 스케줄을 강제하지 않습니다.

검증: 카드 선택·주제 범위·원문 보존·초안 복귀·메모 저장 실패·저장 후 초안 정리 실패의 재시도·회차별 메모 보존·한글 composition 이벤트·손상 초안 비파괴 읽기 관련8개 통과. 전체 자동301개 통과/opt-in성능1개 미실행, TypeScript/Pages base빌드 통과. 실제 브라우저의 직접 경로·하단 입력·저장 후 전환·메모 열기·건너뛰기 초안·새로고침 복원·넓은 화면과390px 화면을 확인합니다. 물리기기·실제 OS IME·서버 수신은 별도입니다.
