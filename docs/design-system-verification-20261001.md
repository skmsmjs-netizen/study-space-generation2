## 대조 범위와 선정 방법

기존 공통 토큰, Button/Input/Checkbox/Card/NavigationBar 등의 구현과 컴포넌트 계약을 재사용했습니다. `study-review`, `study-fix-issue`, 여러 TSX 변경에 대한 React 검토 스킬을 적용했습니다. 소스는 기존 Babel JSX 파서로 구조를 읽고, CSS는 기존 토큰 검사기, 부품은 Storybook의 실제 등록 목록, 화면/조작은 Playwright와 axe로 확인했습니다. 별도 UI 라이브러리나 디자인 시스템을 새로 만들지 않았습니다.

- 화면 소스: 첫 고정 사본의 App 및 production UI TSX 81개, 마지막 현재 소스86개를 구조 대조했습니다. 처음 대조에서 공통 부품 참조851곳·native 입력/버튼 정의25곳을 확인했습니다. 이후 개념 검토 체크1곳도 공통 Checkbox로 연결했습니다.
- 기초 스타일: 첫 CSS32개와 마지막 현재 CSS34개. 색/글자/간격/경계 역할, 오타와 직접 값, 기존 예외를 확인했습니다.
- 화면: 주 메뉴18개와 백업·보관함·휴지통·예약 복습·상세/기록 등 추가12개 경로, 합계30개. 밝게/어둡게 × 다섯 모사 환경으로 총300회 대조했습니다.
- 부품: 등록된 Storybook 예시16개 전부, 밝게/어둡게와320px에서 Chromium/WebKit으로 확인했습니다. 기존 입력·제출·Escape/초점 복귀·탭 방향키 검사도 포함했습니다.
- 기능: 전체 기기 검사 첫290개와 병행 변경을 반영한 재검사310개를 실행하고, 실패한 경로와 마지막 변경은 별도로 재검사했습니다. 모든 가능한 데이터/URL 매개변수/펼침 상태의 조합을 전수 확인했다는 뜻은 아닙니다.

다섯 환경은 iPhone17Pro 세로/가로, iPadPro13 세로/가로/반창의 WebKit 모사입니다. 실제 기기/IME/VoiceOver/장기 사용이나 운영 서버의 확인으로 확대하지 않습니다. 개인 원문·원장·계정에 시험 데이터를 넣지 않고 격리된 예시 자료를 사용했습니다.

## 실제 수정

1. Touch/Monaco 코드 편집기의 체크와 문법 오류 안내·재검사/진단 이동 버튼을 공통 부품으로 연결했습니다. Touch 도구 여섯 개도 공통 Button을 사용하며 기존 command·readOnly·선택/초점·Undo/Redo를 유지했습니다. 중복 버튼 CSS를 제거했습니다.
2. 밝은 목차의 단원/주제 역할 글자는 배경에 대해4.31:1로 검출됐습니다. 해당 기본 역할 토큰만 더 진하게 조정했습니다. 어두운 수식의 B 설명은4.43:1로 검출되어 기존 info 팔레트의 밝은 변형을 사용했습니다. 출제 의미색, 개인 설정과 계산·TNB 성분·좌표를 변경하지 않았습니다. 일반 글자는4.5:1 기준으로 판단했습니다. [W3C 대비 해설](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
3. 가로 화면의 필기 viewport에 이름·region·Tab 초점을 연결해 키보드 스크롤을 가능하게 했습니다. 공통 focus-visible 스타일을 재사용하며 필기 좌표/쪽/이력을 유지했습니다. 조작/요약/미리보기 구역의 접근성 역할과 진전 표시 이름도 보완했습니다. 폼이 아닌 그룹/스크롤 viewport에 대한 정적 검사기의 선택 권고 예외는 이유를 해당 선언에 남겼습니다. [W3C 키보드 해설](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html)
4. 개념 검토 체크를 공통 Checkbox로 바꾸되 기존 초안 저장·검토 의미를 유지했습니다. 통계/월간 타일·메모 미리보기의 native 버튼은 type을 명시했습니다.
5. 화면 목록을 한 파일에서 공유하고 빠졌던 백업·예약 복습을 추가했습니다. 부품 검사는 실제 Storybook 등록 목록을 순회합니다. 코드 실행 검사는 HTTP batch 방식과 터미널 방식을 구별하도록 수정했습니다. 백업 검사는 실제 download 파일·왕복 바이트 검증을 유지하고 바뀐 사실 안내 문구에 맞췄습니다.

## 버전과 남은 범위

검사한 고정 작업 사본은 `/private/tmp/manseeksong-design-audit-te2_pzhj`입니다. 앱/fixture 서버와 결과를 작업별로 격리해 다른 작업의 dist/원문을 덮어쓰지 않았습니다. 부품 검사 두 실행의 trace 출력 경로가 겹친 중간 실패는 경로를 나누어 재실행했고 최종16검사는 통과했습니다.

검사 중 다른 작업도 진행되어 마지막 소스 대조에서27파일의 후속 차이가 확인됐습니다. 이 시점의 목록은 `source-drift.json`에 있으며 저장/자료/통계/개념/수식 등의 후속 변경입니다. 이번 수정은 현재 프로젝트에 남아 있고 다른 작업을 되돌리지 않았습니다. 검증한 고정 사본과 그 뒤의 병행 변경을 같은 버전의 전체 검증으로 합치지 않습니다.

운영 서버 연결·새 공개 배포·실제 계정/물리 기기·장기 효과는 이번 작업의 실행 결과가 아닙니다. 기존 허용과 보존 계약을 유지합니다. 마지막 현재 CSS에서 새로 생긴 미정의 사진 입력 색/서체 참조는 기존 역할 토큰으로 연결하고, 수식의1em/1.08em·행간1은 같은 값의 공통 수식 글자 토큰으로 옮겼습니다. 수식 치수를 반올림하지 않았으며 당시 병행 작업이 보완한 캡션 선택도 유지했습니다. 앞으로 관련 UI 변경은 담당 디자인 시스템과 이 대조 결과의 실패/보류를 확인하고, 실제 바뀐 부품·화면·저장/복귀를 검사합니다. 종료한 앱/보관본은 읽지 않았습니다.
