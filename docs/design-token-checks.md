# 디자인 토큰 검사 사용

기준은 [디자인 시스템](design-system.md#2026-10-01-토큰-준수-검사와-기존-표현-보존)입니다. 화면 CSS 변경은 공통 토큰을 재사용하고, 해당 부품의 상태와 실제 화면도 필요한 범위에서 확인합니다.

- `npm run check:design`: src CSS의 토큰 위반을 읽기 전용으로 확인합니다. dev·build·lint에 연결했습니다.
- `npm run test:design`: 의도적인 위반과 정당한 예외 27사례를 확인합니다. npm test의 선행 명령입니다.
- 기존 Pages CI의 npm test와 npm run build가 위 두 확인을 자동 실행합니다.
- 숫자 0, 데이터/도형 치수, 반응형 조건 등은 일괄 오류로 처리하지 않습니다. 선언별 예외의 이유·범위와 검사 한계는 디자인 시스템에 있습니다.

검사 성공은 공통 Component 선택·State의 의미·접근성 전체·실제 저장·물리기기 확인을 대신하지 않습니다. 테마·사용자 글꼴·출제 의미색·원문·ID·초안·개인 배치는 유지합니다.
