# 천문대 UX·UI·디자인 확정 기준

**2026-10-03 Figma 후속:** [39페이지 검토 기록](figma-guideline-review-20261003/README.md)에 OS28페이지·개념11페이지의 최종 원격 재조회, 편집 가능한 나눔명조700 기반95% 본문, 공통36창의 SWAP/CLOSE·좁은 폭 보완을 연결한다. 기존 픽셀 하늘·네 자리/천장·종이·전체 위젯/바깥틀을 유지했다. 공통 본문 부품의 Fill1건은 로컬 편집 연결 오류로 미적용이며 전체 UI 완료로 보고하지 않는다. 기준/보존 계약을 낮추지 않고 속성 확인·대표 렌더·실제 조작·앱/배포를 구별한다.

**2026-10-02 최종 레이아웃 채택:** [OS 레이아웃 확정 기준](layout-standard.md)·[선택 계약](layout-standard-contract.json)이 공통 외곽/과업별 배치와 현재·미래 요소의 등록 패턴 선택·크기/증가·전환/복귀를 소유한다. 웹앱은 최종 통합 파일의 등록 패턴에서 선택하며 Figma의 편집 가능한 기준은 [실제 결과](layout-standard/README.md)에 연결한다. 이 문서는 정체성/공간/재료/색·글자·빛·모션 값과 기술 적응을 계속 소유하며, 개인 배치·위젯 전체/바깥틀·자료/설정 보존을 유지한다.

**2026-10-02 지식 표현 철학 채택:** [지식 표현과 천문대 경험 기준](knowledge-structure-standard.md)을 이 정체성의 지식 구성/읽기/연결/인출/수정 원칙으로 연결한다. 같은 장소에서 질문을 잡고 전체→모듈·뜻 있는 관계·실제 순서→조건·예외·원문으로 읽고 돌아온다. 닫힌 네모·직선·화살표는 종이 작업면의 지식 문법이며 픽셀 창밖·실내/종이·네 자리/천장과 함께 사용한다. 공간/재료/기존 토큰은 이 문서가, 새 지식 표현 문구·신규 Canvas 선 기본값은 [소비 계약](knowledge-structure-contract.json)이 소유한다. 개인 배치·설정·원문과 위젯 전체/바깥틀을 보존하고 고급 기술과 실제 적용에 따라 값을 보정한다. 단순 도형을 학습효과의 증거로 쓰지 않는다.

**버전 2.0.0 · 2026-10-02 채택.** 사용자 「여기까지, ux, ui, 디자인 기준으로 값을 정해둬라」에 따라, 이 대화에서 정한 실내·창문·픽셀·종이·기능의 자리·문구를 현재와 앞으로의 ManSeekSong OS 기준으로 확정한다. 색과 치수의 원본은 [기준값 JSON](observatory-experience-baseline.json)이다. 이 문서는 그 값의 역할·적용 조건을 설명한다. 앞선 연구 문서의 ‘후보’ 지위와 충돌하면 이 기준이 우선한다.

**기술 구현에 따른 조정 가능성 — 2026-10-02 사용자 정정:** 여기서 채택한 값은 현재의 공통 기본값이며, 앞으로 적용할 고급 렌더링·조명·애니메이션·상호작용 기술의 가능성을 제한하는 고정 규격이나 상한이 아니다. 기술 구현과 실제 사용 결과에 따라 색·치수·간격·픽셀 표현·재료·그림자·움직임 시간·전환·배치 방식 등을 조정할 수 있다. 새로운 기술을 기존 수치에 억지로 맞추거나 이전 값과 다르다는 이유만으로 배제하지 않는다. 구현을 통해 더 적합한 값을 찾으면 담당 원본에 변경 이유·적용 범위·확인 결과를 남기고 공통 부품/실제 소비 경로와 함께 갱신한다. 기존 수치 전체를 다시 승인받는 절차를 추가하지 않으며 허용된 작업 범위 안에서 조정한다. 천문대 정체성, 원본 위젯 전체 보존과 바깥 테두리, 읽기/조작 가능성, 학습 의미와 자료/개인 설정 보존이라는 사용자 요구는 계속 충족한다.

**사용자는 어두운 천문대 안의 책상에 앉아, 창밖의 픽셀 하늘을 두고, 앞에 펼친 종이를 읽고 쓰며 공부한다.** 다른 기능은 같은 방의 일정한 자리에 있다. 이 정체성은 기능 이름을 꾸미는 데 그치지 않고 공통 부품·재료·움직임·복귀까지 연결한다. Stardew Valley에서 참고하는 것은 픽셀 재료와 사물의 일관성, 생활 공간의 감각이며 게임 자산이나 화면을 그대로 복제하지 않는다.

**2026-10-02 시점·프레임 정정:** 사용자 「동료 천문대를 보는 느낌」 → 「그 동료가 사실 나」에 따라, 안쪽에는 지금 공부하는 내가 있고 창밖의 천문대에는 그 나를 동료처럼 바라보는 관점을 둔다. 같은 나의 공부를 가까이 수행하고 조금 떨어져 바라보는 상징적 이중 시점이다. 자기 건물이 보인다는 이유로 공간 오류로 판단하거나 기존 천문대를 제거하지 않는다. 실제 다른 사용자·AI 동료·성과 비교를 뜻하지 않는다. 이어진 「위젯을 자르면 안돼. 위젯 바깥에 테두리」에 따라 **원본 위젯 전체를 보존하고 바깥에 창틀 공간을 더한다.** [사용자 참고 사진](../work/observatory-baseline-20261002/self-companion-reference.jpg)은 이 해석의 참고이며 이미지 속 안쪽 프레임의 덮임까지 채택한 것은 아니다.

범위는 OS 공통 화면·현재 웹앱 기능·위젯·수식/통계의 표현과 관련 문서/도해/유지보수이다. 원문·ID·이력·초안·개인 테마/서체/배치·학습 의미·저장/권한은 유지한다. 기준 채택, 소비 코드 연결, 실제 화면 확인, 공개 배포는 각각 기록한다.

**2026-10-02 기능별 정체성·디자인·UX·UI 채택:** 사용자 「OS에 따른 각각의 정체성 정의, 그리고 정의에 따른 디자인, UX, UI를 본 문서에서 정의해내라. 그리고 그 정의에 따라 수정하라」에 따라 [기능별 정체성 정본](observatory-feature-identities.md)과 [소비용 JSON v1.0.0](observatory-feature-identities.json)을 이 확정 기준의 기능별 세부 정의로 채택한다. 기존 41경로·29모달·41보조면111개를 25개 실질적 기능 역할에 중복 없이 연결하고 A01–A10·천장 조명도 해당 역할의 보조 행동으로 연결한다. 실제 기능명은 유지하며 관측일지·관측판·관계 배치도·외부 연산 연결대 등의 보조 정체성에 따라 정보 우선순서·화면 구성·주요 조작·상태·복귀·반복 사용 조건을 적용한다. 이름이나 설명만 추가한 것을 적용 완료로 판단하지 않는다. 이 문서/기준값은 공통 공간·재료·수치를, 새 정본은 기능별 의미·구성·동작 경계를 소유한다. 기존 저장/권한/원문/개인 배치·설정과 통계/학습 의미는 보존하며 Figma 요약·앱 소비·실제 조작·배포는 각각 확인한다.

**2026-10-02 상단 커버 정정:** 사용자 「위젯은 위쪽 상단을 다 차지…노션 배경처럼」에 따라 천문대 풍경은 앱의 첫 행에서 사이드바와 작업면 전체 폭을 차지한다. 자리 이동과 과업 UI는 그 아래에 둔다. 정면 창문·자료 책장·탐구 작업대·기록 벽·위쪽 천장 조명이 같은 커버 자리에서 교체된다. 원본을 자르지 않고 전체 비율에 따라 높이가 정해지며, 명시적인 탐색 확대만 내부 시야를 움직인다. 접기·정지 선택과 원래 과업 복귀를 보존한다. 정본의 `spatialWorkspace.cover`와 [구현·검증 기록](observatory-cover-20261002.md)을 따른다. 고급 표현은 기존 엔진 연속값·카메라·LOD를 재사용하고, 작업면 글자와 학습 의미는 변경하지 않는다.

## 2. 색: 실내·종이·하늘

각 기능이 자기 색을 갖는 방식보다 **같은 재료가 같은 색 역할을 갖는 방식**을 사용한다. 실내는 저채도 먹색·짙은 회갈색, 종이는 따뜻한 크림과 잉크색, 하늘은 현재 천문대의 남색·푸른빛·주황·흰빛·보라 역할을 사용한다.

| 역할 | 실내 `materials.interior` | 종이 `materials.paper` |
| --- | --- | --- |
| 바탕 | `#1F1E1B` | `#E4DCCD` |
| 표면 | `#282722` | `#E4DCCD` |
| 보조/선택 면 | `#33312D` | `#D7CBB4` |
| 본문/선택 글자 | `#E8E3D7` | `#34312B` |
| 보조 글자 | `#B7B0A2` | `#5B5448` |
| 장식 경계·구분선 | `#514A42` | `#B4A891` |
| 조작에 필요한 경계 | `#8B8071` | `#796D5D` |
| 키보드 초점 | `#D7B477` | `#725425` |
| 주요 버튼 기본 | `#D7B477` | `#554530` |
| 주요 버튼 hover | `#E5C890` | `#473924` |
| 주요 버튼 pressed | `#C2A062` | `#3B3022` |
| 주요 버튼 글자 | `#1F1E1B` | `#E4DCCD` |

종이 보조색은 앞선 시안의 `#60594D`에서 `#5B5448`로, 조작 경계는 검토값 `#817565`에서 `#796D5D`로 조정했다. 선택 면에서도 일반 글자 4.5:1·필수 경계 3:1을 확보하기 위한 변경이다. 첨부 사진에서 정밀 추출한 색이나 Claude의 공식 팔레트라는 뜻은 아니다.

하늘은 [장면 색 원본](observatory-palette.json)을 참조한다. 현재 연결은 깊은 하늘 `night-950`, 남색 `night-800`, 차가운 대기 `night-450`, 푸른 별빛 `cool-500`, 주황 발광 `warm-500`, 금빛 `warm-250`, 흰 중심광 `star-050`, 보랏빛 성운 `cool-400`이다. JSON의 `sceneColors.roleReferences`가 이 역할을 연결한다. 현재 확장 강조색의 옅은 보라 `#A995D6`와 등불 `#E7CE84`는 장면/장식 역할이다. 초신성·폭발·성운의 연출은 현재 장면의 사건/반응 조건을 따르며 새 효과의 자동 발동을 이 기준으로 추가하지 않는다.

- 텍스트·버튼·초점은 **현재 놓인 재료의 색**을 사용한다. 실내의 금빛 글자를 밝은 종이로 그대로 가져오지 않는다.
- 선택 배경만으로 선택을 알리지 않는다. 현재 표시·체크·뚜렷한 경계를 함께 쓴다. 초점과 선택은 별도 상태이다.
- 장식선은 유일한 입력 경계나 상태 표시로 사용하지 않는다. 금빛 버튼의 금빛 초점은 표면색 간격 3px로 분리한다.
- 출제 가능성=주황·출제 확정=빨강, 그래프/수식/계층/상태 의미색과 사용자색은 기존 담당 원본을 유지한다. 새 재료에서 대비를 확인하고 필요하면 기존 읽기 가능한 상태 면과 글자/기호를 함께 제공한다.
- 저장된 사용자 테마·서체·움직임 설정과 기존 OS 따르기를 보존한다. 천문대의 기본 구도는 어두운 실내+종이이며 사용자 선택을 덮어쓰는 테마 강제가 아니다. 어두운 읽기를 선택한 경우 종이의 조판을 유지하고 선택된 읽기 면의 색을 사용한다. 시간대는 하늘의 빛만 바꾸며 본문색·종이색·테마를 자동 전환하지 않는다.

## 4. 창문 아래의 종이 작업면

창문은 풍경 위젯의 **바깥에 더하는 실내 창틀과 창턱**이다. 창틀 기본 8px·좁은 면 4px, 계단 2px, 창턱 깊이 8px·좁은 면 4px, 창 아래 작업면까지 24px·좁은 면 16px를 공통 크롬 기준으로 삼는다. 이 두께는 위젯 콘텐츠 영역 밖에 별도 공간으로 확보한다. 위젯 안으로 그린 두꺼운 inset 경계·그림자·장식 오버레이로 가장자리를 덮지 않는다. 기존 상세 SVG의 좌표/비율·카메라/조작 영역은 그대로 보존한다.

**장식에 의한 잘림은 허용하지 않고, 가림은 0px**로 한다. 위젯 원래의 하늘·천문대·애니메이션·조작부와 전체 종횡비/viewBox를 유지한다. 좁은 화면에서는 전체 위젯을 비례 조정하고 외부 프레임을 얇게 한다. 창에 맞추는 cover crop·가장자리 clipping·장식 때문에 확대/재구성하기·안쪽 aperture로 시야/조작 영역 줄이기를 하지 않는다. 기존 사용자의 탐색/확대 조작은 유지한다. 바깥 창틀/책상은 고정되어 하늘 탐색 중 움직이지 않으며 메뉴·초점·터치·스크롤도 가리지 않는다. 창밖의 천문대는 동료처럼 바라보는 나 자신이라는 상징을 유지한다.

종이는 불투명도 **1**, 회전 **0°**, 글자 밑 질감 불투명도 **0**, 글자 glow/blur **0px**, 경계 **1px**이다. 그림자는 x **2px**, y **2px**, blur **0px**, `#00000033`; 기본 가짜 종이 적층은 **0장**이다. 종이 느낌은 크림 면·잉크 글자·여백·정렬·얇은 선으로 만든다. 낡은 얼룩·구겨진 배경·비스듬한 문단·강제 손글씨를 기본으로 넣지 않는다.

기록·문제·조건·수식·그래프·설명은 한 과업의 종이 안에서 관계가 드러나게 배치한다. 모든 줄을 작은 카드로 만들거나 수식 뒤까지 줄노트를 깔지 않는다. 긴 글은 실제 읽기 면에서 이어지며 입력/설명을 종이 높이에 맞춰 잘라내지 않는다. 정밀 그래프는 축·단위·값·범례·실제 조작을 유지하고 색면이나 픽셀 질감으로 계산을 흐리지 않는다.

참고 사진은 [로컬 보존본](../work/observatory-spatial-20261002/paper-reference.jpg)이다. 사용자 표현대로 일부 맞는 예시로만 채택했다. 사진 바깥의 검은 여백·닫기/저장 아이콘은 뷰어이며 제품 요구가 아니다. 사진의 전체 배치와 작은 수식 내용을 그대로 승인한 것으로 처리하지 않는다.

**2026-10-02 사용자 「공통은 위 천장 조명을 바라보는 곳으로 하자」 결정:** 공통 기능의 공간적 자리를 천장 조명으로 정한다. 북쪽 공부 책상·서쪽 자료 책장·동쪽 탐구 작업대·남쪽 기록·계획 벽 위에서 **공부 공간 전체를 비추고 조율하는 자리**이다. 네 수평 방향에 위쪽 공통 시선을 더하며, 이전의 ‘방향 없음’ 분류를 이 위치로 구체화한다. 새 수평 방위나 별도 방으로 취급하지 않는다.

- 어느 방향에서든 ‘천장 조명 · 공통 도구’ 또는 기존 바로가기로 연다. 실제로 고개를 들거나 기기를 기울이는 입력을 요구하지 않으며 터치·키보드로 같은 기능에 접근한다. 작은 조명 그림만 유일한 진입점으로 삼지 않는다.
- 조명 아래 공통 도구를 열 때 진입 직전의 방향·과업·초안·스크롤/시점·포커스를 보존한다. 닫기/취소하면 그 자리로 돌아가며 북쪽으로 초기화하지 않는다. 검색 결과 등 명시적으로 선택한 대상은 해당 기능의 정상 목적지로 이동한다.
- 저장 실패·미전송처럼 지금 필요한 상태와 복구 행동은 현재 과업에도 표시한다. 이를 확인하려고 매번 천장으로 이동하게 하지 않는다. 자료 곁의 작은 보조 조작도 기존 과업 맥락을 유지한다.
- 천장 조명을 선택하는 동작은 공통 도구 진입이다. 방의 실제 조명·밝기·테마 변경, AI 생성/호출과 구별한다. 설정 변경은 명시적 조작을 따르며 AI 권한은 기존 민석 전용 범위를 유지한다.
- 공통 도구의 면·초점·모션은 기존 실내 역할과 전환/움직임 감소 기준을 재사용한다. 조명 모양·빛·위를 보는 표현은 고급 기술 구현에 따라 조정 가능하며, 기존 원본 위젯을 자르거나 덮지 않는다.

정면을 기준으로 장소 이름과 좌표를 고정한다. 현재 방향에서 왼쪽/오른쪽으로 도는 행동과 고정 목적지의 이름을 혼동하지 않는다. **기능의 보관 장소와 지금 사용하는 장소는 구별한다.** 자료는 책장에서 골라 책상에 펼치고, 짧은 메모·작은 보조 계산은 하던 과업 옆에서 끝낸다. 전체 수식 도구나 통계 정리로 명시 이동할 때 해당 자리로 전환한다.

현재 메뉴 18개·보조 경로 23개·비경로 기능 23묶음의 대응은 [경로 대응 원본](../work/observatory-spatial-20261002/route-map.json)과 [읽기용 표](../work/observatory-spatial-20261002/route-map.md)에서 관리한다. 내부 버튼의 전수 인벤토리라는 뜻은 아니다. 새 기능은 이 원본의 `homePlace`·현재 과업에서 쓰는 방식·닫기/복귀를 함께 정한다.

- 기존 기능명과 직접 이동을 유지한다. 아바타 걷기나 첫 방 방문이 기능 사용의 조건이 되지 않는다. 스크롤·창 가장자리 머무름으로 방을 자동 전환하지 않는다.
- 브라우저 ‘뒤로’는 실제 탐색 이력이다. ‘뒤쪽 기록·계획 벽’은 고정 목적지이다. 검색/딥링크로 들어오면 대상을 바로 열고 이전 출발지를 만들어내지 않는다.
- 보조면 닫기는 실제 호출한 과업과 버튼/편집기로 돌아간다. 전체 목록 버튼은 본래 위치로 간다. 호출자가 없거나 사라졌으면 실제 사용 가능한 해당 목록으로 돌아간다.
- 지원되는 초안·커서·대상·필터·스크롤/시점·개인 배치는 담당 저장 계약으로 유지한다. 한글 조합 중·입력 중·긴급 행동에서는 카메라 연출을 하지 않는다. 저장 실패가 원문을 버리는 전환으로 이어지지 않게 한다.
- 방 이동은 공부 사건이 아니다. 자료가 늘어도 장소의 의미를 바꾸거나 개인 Canvas를 재배치하지 않는다. 임시 시점과 재접속 후 남는 설정을 구별한다.
- 좁은 화면에서도 장소 이름과 바로가기를 유지하고 읽기/조작을 한 열로 재배치한다. 핵심 기능을 풍경 속 작은 핫스폿에만 숨기지 않는다.

## 6. 움직임·문구·수리엔진

공통 피드백 **120ms**, 명시적 자리 전환 **180ms**, easing **ease-out**, 눌림 **y 1px**이다. 동작 감소에서는 해당 전환 **0ms**로 상태를 즉시 바꾼다. 90°/180°는 장소의 관계이며 그만큼 화면을 실제 3D 회전시킬 의무가 아니다. 입력을 전환 완료까지 기다리게 하지 않는다.

작업면의 반복 장식·타자 효과·자동저장 축하·강제 입장 연출은 기본 **0회**이다. 소리는 기본 **꺼짐**이며 명시적으로 켠 경우에만 사용하고, 독립 음소거와 선택 보존을 제공한다. 하늘 애니메이션의 속도/장면/반응은 확장 중인 현재 소스가 소유한다. 사용자가 멈춘 연출을 자동 재개하거나 떠난 동안의 장식 반응을 줄 세워 재생하지 않는다.

문구는 **실제 기능과 행동이 먼저**, 공간감은 짧은 보조 문장으로 둔다. 활성 과업의 제목/빈 상태에서 분위기를 보태는 문장은 최대 한 줄을 기본으로 하며 매 행·저장 알림마다 반복하지 않는다.

저장·삭제·오류·시험·동기화를 모호한 우주 용어로 바꾸지 않는다. 상태별 실제 원인/복구/보존 사실이 위 예시보다 우선한다. 자세한 디테일과 출처는 [디테일 조사](observatory-presence-details-20261002.md)에 둔다.

수리엔진과 위젯은 **기존 관측/계산 → 그 의미에 맞는 표현 → 실제 피드백**을 따른다. 공부 시도/반응은 기존 빛·사물 반응에 연결하고 숙달·정답·목표 달성으로 바꾸지 않는다. 별이 지식을 표현할 때 실제 개념 ID·관계가 연결됐는지를 구별한다. 장식 별을 실제 지식망처럼 설명하지 않는다. 수식·통계는 수치·축·단위·불확실성·실제 조작을 유지하며, 모양을 맞추려고 엔진 계산/정규화/임계값을 바꾸지 않는다. 대응 소스와 조건은 JSON의 `enginePresentation`에 둔다.
