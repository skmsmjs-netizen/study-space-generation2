## 검사와 결과의 정본

`e2e/devices/ux-complete.pw.ts`는 현재 App의 메뉴에서 경로를 읽고 상세·보관함·도움 경로를 추가한다. 다섯 환경마다 정상 글자 크기의 밝은/어두운 WCAG 자동 검사와 200% 문서 재배치를 수행한다. 로그인/가입은 테마 전환이 완료된 상태에서 각각 검사한다. axe incomplete와 물리 증거는 자동 통과와 구별한다.

누적 검사는 격리된 브라우저의 합성 자료만 사용한다. 1만 기록·1만 이력·1만 공부 사건·880 목차·80과목·8학기에 고유 검색·9,020자 원문 저장·재접속을 실행하고 기존 1만 기록의 전체 행을 대조한다. 시간은 브라우저 자동 조작/실험 환경이며 실제 INP나 사용자 75백분위가 아니다. 원기록 대조 비용도 재접속 시간에 합산하지 않는다.

중간 실패·취소한 통합 실행·설치 경로 오류·한글 조합/기기 미확인을 삭제하지 않는다. 초기 200% 검사의 글자 스타일 제거 누락을 수정해 정상/확대 상태를 분리했고, 즉시 테마 전환 중의 색 검사 실패는 전환 완료를 기다리는 검증으로 분리했다. 적용 뒤 전체 검사·배포·공개 자산 결과의 정본은 `work/ux-complete-review-20261001/verification.json`과 `report.md`에 남긴다. 필수 CI 성공 전에는 이번 변경의 배포 완료를 보고하지 않는다.
