## 실제 동작

기본 전집은 원장 쓰기 없이 열리며 이름/ID 검색, 일곱 유형 선택, 30개씩 목록, 장면/목록 복귀를 기존 화면에서 사용한다. 같은 원문을 가진 개인 `published` 설명은 기본 설명보다 먼저 읽는다. 개인의 미등록 초안을 검토 완료로 추정하지 않는다.

설명 만들기 → 선택한 개념 → 「내 설명으로 가져와 수정」은 선택한 하나만 개인 초안으로 만든다. 원문이 이미 있으면 기존 원장을 그대로 재사용하고, 개인 수정본이 있으면 새 판본으로 덮지 않는다. 새 초안의 여섯 검토 항목은 모두 해제하며 등록은 기존 검토·판본 규칙을 따른다. 같은 SHA의 다른 raw는 쓰기 전에 거부한다. 개인 저장 연결의 원문 반입/설명 저장 capability도 각각 확인한다.

읽기로 돌아오면 같은 전집의 기본 설명과 개인 등록 설명을 함께 사용한다. 편집 전용 「보류/미분류」 필터만 해제하고 일반 유형·검색은 유지한다. 원문 내보내기는 읽기만 가능한 상태에서도 접근한다. 저장·되돌리기의 `flush()`가 resolve되더라도 서버 저장 상태가 미확인/대기/충돌이면 성공 문구로 확정하지 않고 복구용 초안을 보존한다.

## OS 표현과 도구 선택

현재 승인된 [본문 기준](paper-typography-standard/README.md)과 실제 공통 CSS를 소비한다. 한글/영문은 명조 Bold 700·native 95% 글자 폭·양쪽 정렬/마지막 줄 시작 정렬을 따르고 개인 설정과 수식 표현을 보존한다. 과거 별도 HTML/Figma의 500/100% 검증을 이 화면의 최신 서체 검증으로 승격하지 않는다.

기존 Vite 플러그인 API의 [가상 모듈](https://vite.dev/guide/api-plugin.html#importing-a-virtual-file)을 재사용했다. 직접 추가한 부분은 선택적인 로컬 읽기 자료 로딩과 공개 빌드 제외 규칙이다. 자료는 Git에서 제외되며 `CI` 또는 `PAGES_BASE` 환경에서는 존재하더라도 `null` 모듈만 반환한다. 이 웹앱 연결은 개인 전집의 공개 배포·서버 업로드를 뜻하지 않는다.

또한 공식 [의존성 탐색 시작점](https://vite.dev/config/dep-optimization-options.html#optimizedeps-entries)을 `index.html`로 지정해 과거 검증용 HTML과 저장된 도구 복사본을 앱 시작점으로 함께 탐색하지 않게 했다. 통상 개발 화면/배포 동작과 이번 로컬 확인을 구별한다.
