## 원본과 실제 실행에 남는 경계

소스 인벤토리는 현재 대상의 생산 TSX104개, 실제 호출 경로103개를 기록하며 호출 가능한 모듈의 미대응은0개이다. `src/ui/material-transcription.tsx`1개는 호출되지 않는 모듈로 구별한다. 제작 manifest의 스냅샷과 현재 소스가 달라진 `src/App.tsx`와 `src/ui/quick-memos.tsx`는 제작 담당이 읽기 전용으로 다시 대조했다. App의 TSX104개·메뉴18개·모달 범위는 유지되고, 자료 곁 메모 누락은 `R23-B02`로 보완했다. quick-memos는 MouseEvent import와 두 곳의 `focus({preventScroll:true})`만 차이가 있으며, 그 변경만 메모리에서 되돌린 비교 해시가 원래 값과 정확히 일치했다. 기존 O24 복귀 계약 안의 변경이고 새 엔터티는 없다. 결과는 [소스 범위 재대조](figma-state.json)의 `sourceDriftReview`에 남겼다. 과거 snapshotMatches:false를 소급해서 true로 바꾸지 않았으며, 이번 범위 재대조와 실제 브라우저 입력 동작 검증은 구별한다.

채택한 Instagram 자료는 기존 확인·미확인 범위를 보존했다. L16·L25·L27은 제목만 확인한 상태에서 영상·음성·캡션 확인이 남아 있고, L14의 작은 본문 판독과 L01 이외의 캡션 확인도 기존 잔여로 남는다. 이번 Figma 대응을 그 원문을 새로 전부 확인했다는 뜻으로 사용하지 않는다. 출처121의 조건부43개는 설치·유료 도입·개인자료 전송 권한으로 승격하지 않았다.

현재 Pro 환경의 Code Connect 게시 제약 때문에 원격 게시하지 않았다. 로컬 소스–Figma 대응과 네이티브 부품 생성은 유지하며 Code Connect 게시 완료로 표시하지 않는다.

Figma 파일·편집 가능한 상태·참조·프로토타입 연결은 실제 웹앱의 코드 적용, 브라우저 입력과 IME, 키보드·VoiceOver, 물리 iPhone/iPad, 저장·오프라인·동기화·복원, 서버 RLS·민석 전용 AI 권한, 배포·장기 사용·학습 효과를 대신하지 않는다. 실제 기록과 원문·ID·초안·이력·개인 설정·배치·권한은 보존 대상이다. 천문대 기준값은 현재 공통 기본값이며 새 기술과 실제 사용 결과에 따라 조정할 수 있다.
