## 현재 구현과 설계의 경계

조사 중 병행 구현으로 ObservatoryNavigation과 ObservatoryTaskReturn이 App에 연결됐다. 네 고정 장소, 현재 자리, 그 자리의 기능, 실제 과업 복귀를 코드에서 확인했다. 주제는 공부 책상·단원은 자료 책장, 기존 자료 상세는 책상·새 자료는 책장, 자료 휴지통은 공통, 내 생각은 기록·계획 벽이다. 기록 저장은 현재 주제/자료 출발지로 돌아가며 출발지가 없으면 오늘로 간다. 이 사실은 실제 브라우저나 배포 완료의 증거가 아니다.

강의 자료의 현재 입력은 클로바노트 전사문 붙여넣기·파일 가져오기다. 앱 내 새 녹음 UI를 만들지 않는다. 이전 음성 재생·내려받기·중단 복구를 보존한다. 장식 별과 실제 개념 관계, 공부함과 독립 수행, 자기 평가와 객관 결과, 기기 초안과 서버 저장을 구별한다.

## 제작 입력과 검증 경계

[prepare-screen-calls.cjs](scripts/prepare-screen-calls.cjs)는 routes를 빌더의 screens로 정규화하고, 중복 표면은 coverageLinks로 실제 모달/블록에 연결한다. 주 화면 18개는 5개 환경으로, 보조 독립 표면은 넓은 환경으로 제작한다. 기본 생성 계획은 독립 화면 83개, 주 화면 프레임 90개+보조 65개=155개이며 상태/공통부품 페이지는 별도 작업과 연결한다. 이는 실제 생성·readback된 수가 아니다.

기기 가용 영역은 iPhone 세로 402×681·가로 756×352, iPad 세로 1032×1376·가로 1376×1032·좁은 창 517×1200이다. 물리 iOS 키보드·VoiceOver·Pencil·Sync의 증거로 확대하지 않는다.

여러 배치를 같은 페이지에 만들 때 INPUT.startY 또는 기존 형제 프레임 아래 위치를 적용해야 겹치지 않는다. 빌더의 타입 판정은 필터·설정·도구 모음을 그래프나 코드 본문으로 오인하면 안 된다. 출처 설명을 실제 개인 내용으로 채우거나 빈 데이터를 가짜 성과 그래프로 대체하지 않는다.

확인: JSON 파싱·ID 유일성·소스 경로 존재·생산 TSX 대응 누락 0·29모달 근거·스크립트 문법·26개 호출 포장의 50,000자 이하를 확인했다. Figma 조회/편집과 최종 스크린샷은 상위 작업의 별도 증거를 따른다.
