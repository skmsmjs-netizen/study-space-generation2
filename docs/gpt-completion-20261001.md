# GPT 후속 구현과 검증 · 2026-10-01

최신 실제 API 평가: [생성·저장 평가](gpt-api-evaluation-20261001.md)에서 기존21개 사례·복습 묶음·v6 재시험의 실제 응답25개와 저장/재접속을 확인했습니다. 아래 최초 사용량 소진·잠금·미평가 항목은 당시 기록입니다. 현재 API 설정과 실제 확인 범위를 최신 평가에서 구별합니다.

후속 갱신: 같은 날 [실제 개인 저장·공용 빌드 보수](gpt-real-flow-20261001.md)에서 당시 열린 실제 저장·공용 빌드 항목을 확인했습니다. 아래 내용은 최초 확인 시점의 기록이며 최신 GPT 사용 범위는 Mac 로컬입니다. 실제 GPT 응답 품질은 사용량 소진으로 아직 미검증입니다.

사용자 ‘남은 작업 다해’에 따라 GPT 학습 작업의 실제 입력 연결, 매 요청 공통 프롬프트, 생성 출처 보관, 반복 입력·재접속과 평가 준비를 보완했습니다. 사용량 재설정 없이 구현·검증부터 진행한다는 결정을 유지합니다. 이번 결과는 로컬 소스와 격리 검증이며 공개 앱 전체·실제 GPT 응답·운영 저장·학습 효과의 완료가 아닙니다.

## 실제 변경

- 강의 자료의 **기존 기록 가져오기**: 현재 과목의 공부 기록·주제 자유 글·자료, 미지정 메모와 코드를 명시적으로 선택합니다. 첫 30개 표시/추가 30개, 전체 후보 검색, 최대 20개 선택, 필요할 때 원문 펼치기, 기존 필기에 그대로 추가, 마지막 가져오기 취소를 제공합니다. 사용자 후속 편집이 있으면 되돌리기가 덮어쓰지 않습니다. 가져오기 자체는 GPT를 실행하지 않습니다.
- 입력 의미와 원문 보존: 소유자·namespace·과목·휴지통 범위를 검사하고 다른 계정의 자료를 포함하지 않습니다. 원문 공백/줄바꿈·ID/수정 버전·실제 날짜 근거·행동별 입력을 남깁니다. 기록 체크는 시도이며 숙달이 아닙니다. 수정일을 공부일로 환산하지 않고, 현재 코드와 과거 실행 당시 코드를 구별합니다. 문서는 선택한 구간과 추출 경고를 전달합니다.
- 작업 추가: **설명·논리 검토**, **코드·실행 검토**를 실제 선택·생성 경로에 연결합니다. 자료 질문은 병행 연결된 `tutor`를 재사용했습니다. 전체 자료 작업은 기존 14개와 이번 2개, 병행 퀴즈/튜터/개념도 3개를 합친 19개입니다. 입력에 없는 숙달·오류 원인·새 실행을 확정하지 않습니다.
- 공통 프롬프트 v3: 자료 생성과 목차 출제에서 매 요청 `instructions`와 실제 `input`을 분리합니다. 서버가 새 결과에 `promptVersion`을 기록하고 목차 카드 등록에도 생성 출처로 남깁니다. 과거 결과의 선택 필드는 유지하며 자동 재생성·원문 덮어쓰기·저장 이관을 하지 않습니다.
- 평가 준비: 19개 작업, 지시 공격, 목차 출제를 합친 21개 합성 사례와 확인 기준을 준비했습니다. 현재 앱의 실제 생성 함수를 통과한 요청을 로컬 JSONL로 출력합니다. 실제 공급자 호출과 내용 평가는 미실행으로 기록합니다.

## 기준과 선택

기존 React 구성요소·디자인 토큰·자료 초안/명령/버전 충돌 계약, 기존 공식 로컬 구독 연결을 재사용했습니다. React best practices의 파생 값 메모화·검색 지연·조건부 원문 마운트와 제한 표시를 현재 입력에 맞춰 적용했습니다. 별도 UI/가상화 라이브러리나 AI SDK를 추가하지 않았습니다.

[OpenAI 프롬프트 지침](https://developers.openai.com/api/docs/guides/prompt-engineering)의 매 요청 지침·데이터 분리와 버전 관리, [평가 지침](https://developers.openai.com/api/docs/guides/evaluation-best-practices)의 작업별 기준·경계/공격 사례·사람의 내용 판단을 적용했습니다. 학습 체크·불확실·원문 보존은 프로젝트 제품 결정이며 외부 표준이나 검증된 학습 효과로 표현하지 않습니다. 외부 평가 서비스·유료 API·개인자료 업로드를 수행하지 않았습니다.

## 확인한 범위

- 변경 관련 10개 파일 **39개 검사 통과**: 소유자·과목·삭제 범위, 120개 자료 후보/최대 선택/길이 실패, 필기·CRLF 원문·이력 보존, 안전한 취소, 실제 19개 생성 함수의 공통 프롬프트, 연속 목차 출제와 등록 출처, 공식 Responses 요청 직렬화, 로컬 요청 거부/한도 경로. 가짜 provider/fetch만 사용합니다.
- 인앱 브라우저: 합성 메모 65개와 코드 1개, 첫 목록/추가 표시/전체 검색, m64 선택·취소·다시 가져오기, 수식 표시·자료 저장·재접속 후 제목/필기/작업/결과 유지. 원자료 파일의 CRLF 보존은 자동 검사로 확인하며 textarea 표시의 브라우저 줄바꿈 정규화와 구별합니다.
- 다섯 WebKit 모사 환경: iPhone 17 Pro 세로/가로, iPad Pro 13인치 세로/가로/517px 창에서 같은 핵심 흐름을 확인합니다. 후속 편집을 덮어쓰지 않는 취소, 원문·저장 버전·수식의 재접속 보존, 가로 넘침 0, 앱 오류 0, 외부 HTTP 요청 0과 재접속에서 합성 GPT 호출 수 증가 없음도 검사합니다. 실제 GPT·운영 계정/토큰은 사용하지 않습니다. 최초 실패는 새 자료의 버튼 이름을 기존 결과 화면 이름으로 지정한 시험 오류였으며 실제 UI 이름으로 수정했습니다.
- 최신 격리 사본의 타입 검사·앱 번들·서버 빌드 통과, 디자인 26 CSS/오류 0/기존 예외 1. 공용 `npm run build`는 PostCSS 의존성 오류로 실패했습니다. 격리 빌드에서는 기존 정상 의존 환경, 실제 프로덕션 React 설정/현재 public 파일, CodeMirror가 선언한 누락 의존성 한 개를 별도 작업 폴더에 설치해 사용했습니다. 개발 전용 서버 플러그인은 빌드 설정에서 제외했습니다. 공용 패키지·잠금파일·다른 개발 서버는 변경하지 않았습니다. 격리 번들 통과를 공용 CI 재현성·공개 배포 완료로 확대하지 않습니다.
- 21개 평가 요청 오프라인 준비. `node scripts/prepare-study-gpt-eval.mjs --out 새경로.jsonl`로 현재 요청을 재생성합니다. 이미 존재하는 파일을 덮어쓰지 않습니다.

합성 저장소의 `flush`/저장 성공 응답은 시험용이며 실제 개인 서버의 저장 확인으로 보고하지 않습니다. 물리 iPhone/iPad·한글 IME·Pencil·VoiceOver·다기기 Sync·장기 학습 효과는 이번 검증 범위 밖입니다.

## 실제 사용에서 남은 조건

1. **실제 GPT 응답 평가**: 실제 공부앱5491의 연결 화면에서 ‘ChatGPT 연결됨’과 모델 목록을 읽기 전용 확인했습니다. 계정 조회는 공유 포함 사용량 소진/일반 사용 불가였습니다. 무료 재설정·크레딧 소비·실제 추론·자동 재시도를 하지 않았습니다. 포함 사용량이 돌아오면 준비된 사례 중 필요한 대표 입력의 실제 응답을 확인해야 합니다.
2. **실제 개인 공간 조작·운영 저장**:5491 개인 공간은 다른 창의 사용 잠금 상태입니다. 현재 연결을 해제하거나 창/잠금/초안을 강제로 제거하지 않았습니다. 선택 기록 가져오기와 새 결과 버전의 실제 개인 서버 저장 왕복은 활성 개인 창에서 따로 확인해야 합니다. 서버 codec/명령 계약의 합성 검사는 통과했습니다.
3. **원격/iPad 직접 GPT 연결**: 원격 SIWC 접근 승인·앱 등록·허용 callback·보호된 실행 환경이 아직 필요합니다. 연락 이메일·이름 영문 표기·실제 회사/소속 정보는 사용자에게 요청했고 꾸며 넣지 않았습니다. [신청 초안](chatgpt-remote-access-draft-20261001.md)이 있으며 아직 제출/승인을 완료하지 않았습니다. 기기 받아쓰기 구현·모사 화면 통과만으로 원격 생성이 가능하다고 보고하지 않습니다.
4. **배포/기기 검증**: 이 작업에서 공개 Pages나 운영 AI 서버를 새로 배포하지 않았습니다. 현재 소스 구현·기존 연결·공개 반영·운영 저장·물리 기기를 각각 구별합니다.

증거는 `work/gpt-completion-20261001/verification.json`, 관련 검사 로그, 기기 JSON/로그와 현재 요청 JSONL에 있습니다. 기존 다른 작업의 변경·인계·보존 조건을 유지합니다.
