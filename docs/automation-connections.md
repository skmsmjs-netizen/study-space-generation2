# 2026-10-01 학습 자동화 연결

사용자 요청의 네 연결을 기존 원장·학습 규칙에 연결했습니다. 브라우저가 기존 기록과 FSRS·일정을 계산하며 개인 원장은 기존 Supabase 인증·승인·소유자 저장을 사용합니다.

## 실제 사용 경로

1. 시험 연습의 지난 메모 또는 암기시험의 저장 답안 → ‘이 답안으로 수행 결과 남기기’ → 확인할 기준·결과·도움·새로움 선택 → 기존 다음 공부·통계의 원문 근거. 미확인이 기본이며 암기시험의 맞음 표시를 독립 수행으로 자동 환산하지 않습니다.
2. 오늘 → 복습 시기·기한이 있는 일정·자유롭게 고르는 공부. 복습은 기존 FSRS 예약을 열고 일정은 해당 계획을 펼쳐 초점과 위치를 옮깁니다. 제안을 완료로 바꾸지 않습니다.
3. 자료 카드 → 검색·원자료/질문/답 비교 → 확인 선택·주제 선택 → 암기 항목 등록 → 암기시험 재사용. 기존에 저장된 자료 카드만 사용하며 외부 AI 호출이나 새 공급자 연결을 추가하지 않습니다.
4. 코딩 예제 → 선택적 공부 주제 연결 → 주제 상세에서 같은 예제 열기. 코드·입력·설명·실행 이력과 별도로 연결을 저장합니다. 실행은 정답·숙달 판정이 아닙니다.

## 반복 사용과 보존

- 답안 ID/버전과 원문·그림·문항/기준 답안을 함께 보존합니다. 수정/휴지통 이후에도 해당 저장 버전으로 근거를 읽습니다. 결과 판정은 같은 사건 ID의 revision으로 남고 여러 기준의 근거는 유지하되 통계는 같은 물리 답안을 한 번 셉니다. 실제 수행 시각이 확인되지 않은 시험 메모는 최초 결과 연결 시각을 사용하며 이후 판정 수정으로 날짜를 옮기지 않습니다.
- 결과 선택 초안은 사용자·namespace·탭·원문 버전별로 보존하고 손상 원문은 보관 후 초기화합니다. 저장 CAS/명령 멱등성·소유권·원문 검사가 오래된 화면의 덮어쓰기와 다른 사용자 자료 연결을 막습니다.
- 자료 카드 목록은 검색·20개 단위 표시·선택한 카드만 펼치기를 사용합니다. 800카드 검색/펼침을 합성 검사했습니다. 같은 자료 카드를 다시 등록해도 기존 수정본을 덮어쓰거나 휴지통 항목을 자동 복원하지 않습니다. 원자료 버전은 카드 편집 뒤에도 남습니다.
- 수행 근거는 최신 판정별 20개씩 표시하고 원문/이전 판정은 필요할 때 엽니다. 80사건과 판정 revision을 검사했습니다. 예약 복습으로 이동할 때 미저장 답변·저장 재시도·평가 되돌리기 상태를 보존합니다.

## 기존 기준과 적용 범위

기존 recommendation-kernel과 ts-fsrs를 재사용했습니다. [ADL xAPI 데이터 모델](https://github.com/adlnet/xAPI-Spec/blob/master/xAPI-Data.md)의 사건/결과/맥락 구분과 [W3C PROV-O](https://www.w3.org/TR/prov-o/)의 원자료/파생 결과/수정 관계를 보존 설계에 참고했습니다. 이 구현은 해당 표준의 직렬화·LRS·RDF 준수 구현으로 인증한 것이 아닙니다. 이미 저장된 주제/답안/계획만 연결하므로 문제별 개념·혼동 관계를 새로 입력시키거나 추정하지 않습니다.

## 확인과 한계

격리 배포본에서 최신 공개 변경을 합친 최종 배포본의 전체522검사 통과·성능1미실행, 디자인 검사27개 통과 및 CSS20파일 위반0, 타입/Pages build/backend bundle 통과입니다. 날짜/다중 기준 회귀를 포함한 관련14검사도 통과했습니다. 실제 브라우저의 합성 자료로 복습 이동, 시험 연습 답안→결과→재열기, 암기시험 원문 비교→결과 초안 복원→저장→reload 근거/통계2건, 자료 카드→시험, 코드 주제 연결→reload→역방향 링크를 확인했습니다. 운영 API의 별도 시험 계정/test namespace에서 10번의 정상 저장, 원문 수정 뒤 과거 답안 보존, 동일 요청 멱등성, 위조 원문 거부, 오래된 sequence 거부, 타인 명령403, 미인증401과 재조회을 확인했습니다. 시험 계정2개/원장/operation을 정확한 UUID로 정리하고 잔여0을 확인했습니다.

공유 작업공간의 병행 GPT 생성·수리 도구·그래프·보드 UI는 이 배포에 임의 포함하지 않습니다. 기존 공개 기능과 studyBoards 메타데이터는 유지합니다. 물리 iPad/Pencil·한글 IME·다른 실제 기기 수신·민석 본인 계정의 조작·학습 효과·전체 학습 동역학 모형 완료는 이 결과의 증거 범위 밖입니다. 음성 다기기, 알림, WHY/HOW/WHAT, 반응/부담 입력, 공식 성적 등 전체 잔여는 기존 요구에서 유지됩니다.
