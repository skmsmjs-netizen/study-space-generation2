## 공용 빌드와 반복 실행 보수

이번 시점의 공용 환경에서는 이전 PostCSS 로딩 실패가 재현되지 않았습니다. 실제 빌드 실패는 CSS 토큰 검사3곳이었으며 기존 공통 토큰으로 수정했습니다. `app.css`의 숨김 라벨 여백은 `calc(-1 * var(--border-width))`, 브랜드 화면의 없는 토큰은 기존 `--control-height`와 `--layout-reading`을 사용합니다. 병행 작업의 `source-qa` 호환 타입 보완은 그대로 유지했습니다.

빌드와 dev를 동시에 준비할 때 FSRS vendor 복사가 같은 파일을 지워 `ENOENT`로 실패하는 현상도 재현했습니다. 기존 설치된 `proper-lockfile`의 디렉터리 잠금을 재사용해 해당 파일의 복사·worker 경로 수정만 직렬화했습니다. 잠금은 정상 종료와 실패 모두에서 해제하고 오류를 숨기지 않습니다. 계정·학습 데이터·패키지 잠금파일과 무관합니다. 선정 근거는 설치된 라이브러리의 README/API와 기존 프로젝트 사용입니다. 임의 잠금 알고리즘이나 별도 의존성을 추가하지 않았습니다.

