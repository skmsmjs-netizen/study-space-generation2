# 급수의 수렴 판단 · 적분판정법

수식 탐색에서 **탐색할 내용 → 급수의 수렴 판단**으로 연다. 정리의 조건 목록 앞에 구하려는 것, 항의 극한, 판정법 선택을 연결한 실제 React 화면이다. 특정 예제를 읽고 조작하는 도구이며 임의의 급수를 자동 증명하는 계산기는 아니다.

## 채택한 기준과 연결

- 수학적 근거는 [OpenStax Calculus Volume 2 5.3](https://openstax.org/books/calculus-volume-2/pages/5-3-the-divergence-and-integral-tests)의 발산판정법·적분판정법과 [5.6](https://openstax.org/books/calculus-volume-2/pages/5-6-ratio-and-root-tests)의 판정법 선택 전략이다. 항의 극한은 수렴의 필요조건이고, 양수·연속·감소는 선택한 적분판정법의 적용 조건이다. 다른 정리로 수렴을 보일 수 있으므로 세 조건을 모든 수렴 급수의 필요조건으로 가르치지 않는다.
- 판정법 후보를 비교하고 되돌아가는 배치는 이 앱을 위한 설계이다. 유일한 최적 판정법이나 모든 급수에 통하는 결정 알고리즘이라고 주장하지 않는다.
- 기존 공통 버튼·선택·체크박스·디자인 토큰, KaTeX의 HTML+MathML 렌더링을 재사용한다. 블록 수식은 키보드로 가로 스크롤할 수 있고 각각 구별되는 이름을 갖는다. 한글 개념명과 영어 이름을 함께 표시한다. 설명 축약은 사용자가 선택하며 숙달을 추정해 자동으로 줄이지 않는다.
- 정밀 넓이 도해는 코드로 만든 SVG이다. 감소 곡선, 왼쪽·오른쪽 직사각형 합, 유한 구간 적분값을 같은 값에서 계산한다. 그래프를 몇 점 확인한 사실을 무한 범위의 증명으로 바꾸지 않는다.

## 확인할 경로

| 예제·갈림길 | 올바른 판단 |
| --- | --- |
| 로그가 제곱인 양항급수 | 양수·연속·감소 확인, 로그 치환, 유한한 이상적분, 급수 수렴 |
| 로그가 한 번인 양항급수 | 조건은 충족하지만 이상적분이 발산하므로 급수 발산 |
| 부호가 번갈아 바뀌는 급수 | 원래 급수에 직접 적용 불가. 절댓값 급수로 대상을 바꾸면 절대수렴 확인 |
| 처음에는 증가하는 로그/역수 급수 | 세 번째 항부터 조건 확인, 앞의 유한한 항 유지, 원래 급수 발산 |
| 익숙한 등비급수 | 공비로 바로 수렴·합 확인 가능. 적분판정법만 강제하지 않음 |
| 항이 0으로 가지 않는 급수 | 수렴의 필요조건 위반으로 발산. 불필요한 뒤 단계 제거 |
| 비율 극한이 1 | 그 판정법으로는 결론을 내리지 못함. 발산으로 변환하지 않음 |
| 정수 사이에서 값을 바꾼 불연속함수 | 정수에서 같은 항을 갖는다는 사실만으로 연속성을 보장할 수 없음. 적절한 함수로 복귀 |
| 아직 확인하지 못한 조건 | 거짓으로 처리하지 않고 판정 보류. 근거 확인 뒤 재개 |

급수와 적분의 수렴 여부가 같다는 관계와 값 자체를 구별한다. 두 값이 모두 무한대로 발산하는 경우에 서로 다르다는 부등식을 표시하지 않는다. 유한하게 수렴하는 이 예제들에서만 급수의 합과 적분값이 다름을 표시한다.

## 저장과 복귀

data/integral-reasoning-view.ts가 계정·공간별 :integral-reasoning:view:v1 키를 담당한다. 예제, 읽던 단계, 판정법 후보, 절댓값·시작점 변경, 미확인 조건, 설명 축약, 그림의 구간 값은 예제별로 유지된다. 원래 급수·조건으로 돌아가는 경로를 제공한다.

이 상태는 기기 안의 읽기 위치이다. 서버 공부 기록·독립 답변·정답·숙달을 생성하지 않는다. 기존 그래프의 수식·메모·GeoGebra 보기를 화면 전환 전에 보관하고 그래프를 유지한다. 계정이 바뀌면 기존 App의 계정별 key로 다시 마운트된다. 저장 실패는 현재 상태를 남기고 재시도·파일 보관을 제공한다. 읽을 수 없는 기존 값은 자동 덮어쓰지 않는다.

## 검증과 남은 경계

분기 보호·수식 파싱·예제별 위치 복원·원문 보존 검사와 기존 그래프 회귀 검사를 실행한다. 다섯 공통 WebKit 모사 환경에서 조건 실패/보류/복귀, 계산·결론, 구간 조작, 재접속, 그래프 전환, 페이지 넘침과 axe 접근성을 확인한다. 실제 실행 결과는 work/integral-reasoning-20261001/의 로그와 결과 JSON에 남긴다. 검사 코드의 존재를 통과로 표현하지 않는다.

교재 PDF가 아직 제공되지 않았다. 특정 교재의 빠짐없는 개념 추출·페이지 연결·수식 OCR 정확도·생성 결과의 학습 효과는 이번 작업으로 입증하지 않는다. 실제 교재 한 절의 대조와 설명을 줄여도 독립적으로 판단할 수 있는지의 관찰은 별도 연구이다. 공개 배포·실물 기기·서버 Sync 검증과도 구별한다.
