## OS의 실제 진입·배치·복귀

서쪽 자료 책장 → 강의 자료 → 벡터 미적분 자료와 관찰 → 개념 버튼에서 자료 곁의 작은 관찰을 연다. 기본/기존 확장은 보존하며 「다른 식과 조건의 관계 관찰 열기」에서 일반 관찰을 펼친다. 「크게 보기」와 「탐구 작업대에서 열기」는 기존 동쪽 수식 탐색으로 연결된다. 새로운 과목 방을 만들지 않았다. 실제 호출자가 없는 재접속은 실제 자료 목록의 현재 개념으로 닫기/초점을 돌린다.
