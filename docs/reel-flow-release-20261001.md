# 작은 과업·검색·목록 복귀의 공개 적용 · 2026-10-01

사용자의 배포 요청에 따라 현재 공개 main의 기존 기능을 유지하고 마지막 검색/목록 복귀 수정만 연결합니다. 공개에 이미 반영된 원문 검색·자료/코드/카드 연결·공통 빈 상태/오류 경계·Storybook 상태를 재사용합니다.

- 이전 일정 색인은 현재 계정/공간이 일치할 때만 읽습니다. 원문·이력·ID·학습 사건은 변경하지 않습니다.
- 선택 보기 힌트는 같은 탭의 계정/공간/화면/활성·휴지통별로 분리하며 저장 실패는 원문 편집을 막지 않습니다. 메모의 검색과 표시 개수도 같은 경로에 연결합니다.
- 재시도는 보관된 검색 원본을 다시 읽으며, 화면 파일 실패의 실제 다시 시도 조작은 기존 오류 경계에 연결됩니다.
- 합성 필기85개에서 첫40개/더 보기80개 표시와 마지막 원문 검색·원본 불변을 검사합니다.

배포 후보의 관련9파일72개 시험, 타입을 포함한 Pages base 전체 빌드, 서버 번들, 새 모듈6개 lint, 같은 다섯 WebKit 모사 환경의 자료 저장→원문 검색→범위 복구→다시 열기/복귀 및 화면 실패/재시도10개를 확인했습니다. 이전 소스의 초기 실패를 현재 결과와 섞지 않습니다.

배포 대상은 기존 GitHub Pages입니다. 실제 commit/Actions 결과와 공개 파일 일치·공개 주소에서의 조작 결과는 배포 후 인계/실행 기록으로 별도 확인합니다. 로컬 시험만으로 운영 배포 성공을 주장하지 않습니다. 운영 AI 옵션/자격·서버DB·실제 개인 계정·물리기기·OS IME·기기 간 Sync·학습 효과를 변경하거나 새로 검증한 것으로 표현하지 않습니다.
