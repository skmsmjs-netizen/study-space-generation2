# 기기 환경 검증

2026-10-01 사용자 결정: 지금까지 구현한 기능과 이후 앱 변경을 다음 다섯 환경에서 확인한다. 실제 기기를 연결하는 대신 Playwright의 WebKit·터치 모사를 사용한다. 프로필은 `e2e/devices/environments.ts`, 앱 검사는 `playwright.devices.config.ts` 한 곳에서 관리한다.

| 환경 | 사용 가능한 화면 | 배율 | 확인할 변화 |
|---|---:|---:|---|
| iPhone 17 Pro 세로 | 402×681 | 3 | 좁은 입력·긴 한국어·메뉴·주요 버튼 |
| iPhone 17 Pro 가로 | 756×352 | 3 | 낮은 높이·대화상자 스크롤·편집 복귀 |
| iPad Pro 13인치 세로 | 1032×1376 | 2 | 여러 주제·도구·상세 정보 |
| iPad Pro 13인치 가로 | 1376×1032 | 2 | 넓은 그래프·패널·목록 |
| iPad Pro 13인치 좁은 창 | 517×1200 | 2 | 좁은 창의 정보·조작·원문 보존 |

iPhone의 논리 화면은 402×874, 가로 874×402이며 위 값은 브라우저 도구를 고려한 가용 영역이다. 등록된 iPhone 16 Pro와 iPad Pro 11 프리셋의 WebKit·터치 설정에 목표 화면/배율을 적용한다. iPad 좁은 창은 대표 검증값이며 모든 창 크기를 대표한다고 주장하지 않는다. 물리 safe area·가상 키보드·Pencil·실제 iOS 버전 전체를 복제하지 않는다.

## 실행과 미래 변경

```sh
npm run build && npm run test:devices
```

이미 빌드한 공개 경로를 검증할 때는 빌드와 검사 모두 동일한 `PAGES_BASE`를 지정한다. 검사는 새 격리 브라우저 프로필과 합성 기록을 사용한다. 개인 로그인·실제 자료·기존 브라우저 저장소를 읽거나 변경하지 않는다. JSON, HTML 보고서와 실패 화면/trace는 `work/device-*`에 남긴다. 동시에 별도 검사를 실행할 때는 `DEVICE_REPORT_ROOT`로 결과 경로를 분리한다. 로컬 기본 작업자는 1개, CI는 독립된 브라우저/합성 자료로 2개를 사용한다. [Playwright 공식 병렬 실행](https://playwright.dev/docs/test-parallel)에 따른 설정이며 검사 범위와 실패 기준은 유지한다.

- 현재 버전의 App 메뉴에서 기본 화면 목록을 읽으므로 새 메뉴 화면도 기본 진입·로딩 완료·가로 넘침·입력창 폭 검사에 자동 포함한다. 제목만 표시되고 내용이 아직 로딩 중인 상태를 통과로 삼지 않는다. 보관본·휴지통·자유 기록·과목/주제/기록 상세도 확인한다.
- `learning.pw.ts`: 자료 수동 입력/저장, 실제 Plotly·수식 메모, 암기시험 답 숨김/응답/비교/저장, 칸반 카드, Canvas 개념/그래프 목록, 시험 연습 중단/복귀, 과목/검색, 메모의 터치 표시·파일 내보내기, 주제 카드 등록/자기 평가/되돌리기를 확인한다.
- `schedules.pw.ts`: 홈의 두 일정 진입, 초점·터치 크기, 긴 이름/메모, 회전, 닫기/새로고침/수정/저장을 확인한다.
- `records.pw.ts`: 공부 범위와 검색의 빈 상태, 두 주제의 긴 원문/체크·미체크 구분, 메뉴 이동·재접속·공부 사건 보존을 확인한다.
- `capabilities.pw.ts`: 현재 전사문 입력 흐름에서 마이크가 거부된 환경도 원문 입력·재접속·파일 가져오기를 사용할 수 있고, 마이크 요청을 발생시키지 않는지 확인한다. 앱 내 녹음 대신 클로바노트에서 만든 전사문을 붙여넣는 현재 공개 구현을 따른다.
- `screens.pw.ts`: 전체 화면과 코드 터치 입력/실제 JavaScript 실행/복원, 마이크 API 미지원과 알림 API 미지원의 대안을 확인한다.
- 화면 이름을 기기 권한으로 해석하지 않는다. 핵심 조작이나 저장·제한 경로를 바꾸면 해당 검사에 반영하고 다섯 환경 모두 실행한다. 자료 증가·긴 글·회전·중단/실패 중 관련 조건을 추가한다. CI의 Pages artifact 업로드 전에 같은 명령을 실행하여 실패한 버전은 배포하지 않는다. PR UI workflow에도 같은 환경 작업을 연결한다.
- 예전 공개 버전에 아직 없는 자료/수식/알림 화면의 전용 검사는 명시적으로 제외하고 이유를 보고한다. 실제 존재하는 기능의 실패는 제외하지 않는다. 최신 개발 원본에 존재하는 경로는 모두 실행한다. 자료 기능이 존재하면 `test:devices`가 기존 합성 GPT 화면을 로컬 전용 서버에 자동 준비한다. `STUDY_AI_FIXTURE_URL`은 이미 준비된 격리 화면을 명시적으로 재사용할 때만 지정한다. `e2e/fixtures`는 운영 번들에 포함하지 않으며 실제 로그인·유료 호출·개인 기록을 쓰지 않는다.

## 환경 제한과 실제 앱의 대안

| 조건 | 앱 동작·대안 | 보존 |
|---|---|---|
| 터치가 주 입력인 코드 편집 | 모바일을 지원하는 기존 CodeMirror 6 편집기 사용, 로딩 중 기본 입력 제공, 화면 회전 중 편집기 유지 | 코드·제목·설명·실행 결과·문법 오류 목록 |
| 마이크 API 미지원/권한 거부 | 현재 자료 입력은 마이크를 요청하지 않으며 클로바노트 전사문 붙여넣기·문서 파일 가져오기를 제공 | 기존 음성의 다운로드/중단 복구·필기·초안 |
| 알림 API 미지원/권한 차단 | 켜기 버튼 비활성화, 홈 화면 추가·설정·목록/캘린더 경로 안내 | 일정·기한 미정·준비/제출 상태 |
| 음성 decoding/Worker/WASM 미지원 | 받아쓰기 버튼 비활성화, 수동 필기·지원 브라우저 안내 | 원본 음성·완료 사본 |
| 끌기 어려운 Canvas·그래프·칸반 | 항목 목록, 카드 위치 버튼, 열 선택/순서 이동의 기존 경로 유지 | 개인 좌표·연결·카드 순서·원문 |
| 원격 실시간 코드 터미널 연결 없음 | 입력값을 미리 적는 방식 및 코드·설명 보관의 기존 경로 | 코드를 일반 기록으로 보관, 실패를 수행 성공으로 바꾸지 않음 |
| 일반 계정 | AI 연결/생성 미제공. 공부·자료·수동 입력 유지, 서버 소유자 확인 | 승인/관리자 역할로 AI 권한을 추가하지 않음 |
| 원격 ChatGPT 연결 승인 미충족 | 현재 서버의 실제 연결 상태와 수동 기록/파일 경로 제공 | 연결/추론/사용량 차감을 완료로 주장하지 않음 |

## 채택 기준과 한계

[WCAG 2.2 Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)의 좁은 화면 기준을 적용한다. 그래프/Canvas의 2차원 작업 영역 예외를 주변 버튼·설명·입력창에 확대하지 않는다. 기존 디자인 토큰의 주요 버튼 48px/아이콘 44px과 최소 16px 입력 글자를 유지한다. [MDN feature detection](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Testing/Feature_detection)에 따라 실제 API·권한·서버 상태를 확인한다.

[Monaco 공식 지원 범위](https://github.com/microsoft/monaco-editor#faq)는 모바일 브라우저를 제외하므로 현재 앱의 [CodeMirror 6 모바일 편집](https://discuss.codemirror.net/t/codemirror-v6-cross-platform-support/9313)을 재사용했다. 선택 근거와 기존 지원 범위는 `docs/code-mobile.md`를 따른다. [Apple/WebKit Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)의 홈 화면 조건은 OS 제한이며 CSS로 해제하지 않는다. [Playwright 모사](https://playwright.dev/docs/emulation)는 개발 회귀에 사용하며 물리기기의 iOS 키보드·VoiceOver·Pencil·OS 알림·기기간 수신·실제 AI 결과/학습 효과를 증명하지 않는다.

정확한 실행 수·버전·배포 상태는 최신 인계와 이번 검증 결과에서 기록한다. 이전 전체 검사나 프로필 정의를 이번 실행의 성공으로 재사용하지 않는다.
