| 검색·초안 보관·휴지통·복원 | 실제 검색/복귀, 관련 자동검사·화면 | 모든 자료 유형 찾기·전체 첨부 포함 복원 |
| 선택적 공부 도구·시작 안내·표시/모션·작은 풍경 | 현재 코드와 최근 인계에서 적용 범위 확인 | 모든 선택 도구의 과업 적합성·병행 변경 이후 실제 상태 |

자료→카드 검토 전환, 코드 예제의 주제 연결, FSRS/일정 기반 다음 공부 연결은 현재 코드에 있으므로 과거 조사 문서의 ‘없음’을 재사용하지 않았습니다. 위 표는 주요 요구 묶음을 검사 범위에 포함했다는 기록이며 개별 하위 기능 전체의 완료표가 아닙니다.

## 수정 가능한 결함과 보완 과제

1. **좁은 화면의 공부 범위 선택란 이름 손실 — Q03/Q13, P2.** [app.css 617행](../src/app.css#L617)의 `display:none`이 연결된 label을 접근성 트리에서도 숨깁니다. 320px의 20경로에서 axe `select-name`이 검출됐고 현재 CSS도 같습니다. 사용자에게 읽히는 선택란 이름을 보존하는 visually-hidden 처리나 명시적 accessible name으로 연결해야 합니다. 보이는 간격은 유지하고 키보드/보조기술 이름을 확인합니다.
2. **통계 차트의 이미지 안 버튼 역할 — Q03/Q05/Q13, P2.** [statistics.tsx 41행](../src/ui/statistics.tsx#L41)은 `svg role=img` 안에 focus 가능한 `g role=button`을 둡니다. 홈과 통계에서 두 폭 모두 axe `nested-interactive`를 검출했고 현재 코드도 같습니다. 그래프 설명과 실제 근거 열기 조작이 함께 표현되는 역할 또는 별도 접근 가능한 조작 구조가 필요합니다. 근거 열기 기능은 보존합니다.
3. **전체 자료 백업·복원 범위 부족 — Q12, 보완 필요.** [personal-repository.ts 212행](../src/data/personal-repository.ts#L212)의 `exportPreserved`는 repository envelope와 deviceRecovery만 JSON으로 만듭니다. [material-files.ts](../src/data/material-files.ts)의 별도 IndexedDB 파일/녹음 bytes 및 기능별 별도 초안/기기 설정을 수집하지 않습니다. 데이터 계약 INV20과 현재 다운로드 범위를 구별해야 합니다. 전체 백업 묶음과 검증·중복 방지·첨부 hash를 포함한 새 환경 복원 왕복이 미구현입니다. 현재 내려받기가 원자료를 삭제한다는 증거는 없으며, 새 material-cloud는 전체 복원을 대신하지 않습니다.
4. **관계 그래프 라이브러리 표시의 낮은 대비 — Q13, P2.** axe가 ReactFlow attribution의 10px 글자 대비 2.84:1을 검출했습니다. 라이선스 표시는 유지하며 프로젝트 토큰으로 충분한 대비를 제공해야 합니다. 해당 그래프 소스는 사본과 현재가 일치합니다.
5. **누적 자료의 단일 편집 비용 — Q10, 원인 측정 필요.** 합성 19.4MB 상태의 단일 본문 명령은 3회 중앙값 약 776ms였습니다. 검증 중앙값은 약207ms이며 첫 실행은1,088ms입니다. 1만 기록이 사용자의 확정 규모라거나 실제 입력이 그만큼 지연됐다고 주장하지 않습니다. 같은 규모의 브라우저 입력/저장·프로파일을 확인하고 전체 복제/검증/직렬화 경로에서 실제 병목을 좁혀야 합니다. 코드 JS gzip 약861kB·수학 plot 약1,413kB도 관련 진입 비용의 관찰 대상이며 chunk 경고만으로 성능 실패를 확정하지 않습니다.
6. **통합 검사와 공유 도구의 불안정 — Q15, 출시 전 통합 조건.** 최초 정식 빌드는 서버 검사 mock 타입 때문에 실패했고 이후 병행 수정됐습니다. 뒤의 공유 타입 검사는 다른 펜 검사 factory 타입 때문에 실패했습니다. 종료 타입 재확인은 통과했습니다. 검사 중에도 소스가 바뀌므로 한 번 고정한 소스·정상 의존성에서 정식 build/필수 회귀를 함께 확인해야 합니다. 공유 Playwright CLI 오류와 Vitest worker 시작 지연도 재현 가능한 개발 환경의 문제로 남깁니다.
7. **자동 발견 뒤 판정이 더 필요한 항목 — Q13.** Canvas의 zoom 뒤 작은 링크/attribution target-size, 수학 라이브러리 이미지 alt와 스크롤 영역 focus를 별도로 남깁니다. 동일 행동 대안·2차원 본질 예외·장식 이미지 여부를 확인하지 않은 채 WCAG 위반으로 확정하지 않습니다. Canvas/수학은 사본 이후 바뀌었으므로 현재 해당 상태도 다시 확인해야 합니다.
8. **제품 결함과 구별한 검사 보수 — Q15.** 일정 초점 기대값 5건은 새 버튼을 반영하도록 기존 회귀를 보수해야 합니다. 자동검사 3건은 분리 실행에서 재현되지 않아 안정적인 대기/시간 조건을 확인해야 합니다. ResizeObserver 1건은 화면·전환·반복 조건을 특정한 뒤 영향에 따라 처리합니다.

## 남은 일의 종류와 순서

- **미구현:** 첨부 원본·필요한 초안/설정/이력/배치를 포함한 전체 백업과 검증 가능한 전체 재가져오기. 기존 Anki/자료 가져오기와 휴지통 복원은 이미 있으므로 별개로 취급합니다.
- **부분 구현:** 전체 자료 유형의 찾기 경로, 전체 자료의 휴대성, 누적 성능의 실제 사용자 조건 측정, 공유 실행 환경의 재현성. 개별 설정/저장/검색 기능이 있다는 사실만으로 이 범위가 끝나지 않습니다.
- **구현됐으나 검증 잔여:** 실제 서버의 중복 없는 재시도·계정 거부·동시 편집/충돌/권한 전환, 오래 열린 탭/이전 자료 업데이트, 모든 편집기의 한글 조합/펜, 이후 변경된 Canvas/수학/자료/풍경 통합. 기존 인계의 해당 검증은 과거 시점 증거로 유지합니다.
- **제외·보류:** 종료한 구현, 실제 판매·결제/가격/기업 조달 기능, 사용자 개인정보 외부 전송·새 공개 배포. 물리 기기 연결은 이번 합의한 모사 검사의 선행조건이 아닙니다. 장기 사용 만족/학습 효과는 이번 코드·브라우저 검사로 확정할 수 없습니다.

우선순위는 **공유 소스/도구를 고정한 정식 통합 확인 → 확정 접근성 결함 수정 → 전체 백업/복원 → 누적 브라우저 성능 → 서버/동시 편집의 잔여 검증**입니다. 원문 손실·소유권 오류·중복 기록이 발견되면 이 순서보다 먼저 처리합니다. 이번 검사는 제품 코드를 일괄 개편하거나 서버/배포를 변경하지 않았으며, 발견한 대상과 완료 조건을 다음 보완에 바로 사용할 수 있게 남겼습니다.
