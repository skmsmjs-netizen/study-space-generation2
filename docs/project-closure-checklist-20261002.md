## 남은 실행 우선순위와 당장 할 수 없는 조건

1. 이미 마련된 웹앱 구동·저장·복원의 직접 위험부터 보수하고 관련 반복검사/증거를 마감한다. 이번 실행 범위다.
2. Figma는 다른 채팅이 복구한 로컬 플러그인으로 실패26root 상태 확인/공백 사례를 진행 중이다. 남은 조판/재사용 본문/안내/최종 판정의 실제 종료 기록을 통합한다. MCP 경로의 오류와 로컬 복구를 구별하며 새 배치부터 덮어쓰지 않는다.
3. 모바일3문제/고급UX모션/물리·화학·벡터 확장과 최신공개 후보는 현재 다른 채팅의 진행 범위다. 완료 보고/정본/CI/실제 공개를 받은 뒤 해당 항목만 갱신한다.
4. 새 과목별 생성은 이 대화의 화요일 이후 조건을 지킨다. 기존 교재별 부분/정적/추가 범위를 실제 수강 범위에 맞추고 필요한 지원을 마감한다.
5. 실제 학기 자료의 과목/강의/과제/시험·일정과 API 생성→검토/편집→풀이/도움/오답→복습→학기말 전체 백업을 완성한다. 없는 날짜·정답·출석·학습 결과를 만들지 않는다.
6. 민석의 실제 기기/공부 관찰로 입력 부담·저장/교대·IME/Pencil/보조기술을 확인한 뒤 필수 결함을 보수하고 최종 후보를 확정해 종료한다.

접근 차단이나 민석의 실제 기기/공부가 필요한 항목을 백그라운드에서 계속 실행 중이라고 보고하지 않는다. 다음 화요일2026-10-06까지 리셋쿠폰을 사용하지 않으며 이후에도 자동 사용하지 않는다. 이번에는 새 과목 개념/유료 API 호출/개인 자료 변경/운영 쓰기/새 공개 배포를 하지 않았다.
