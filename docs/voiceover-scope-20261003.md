# VoiceOver 제외 결정

2026-10-03 사용자 「보이스오버는 웹앱의 모든기능에서 빼」 결정이다. ManSeekSong OS의 모든 현재 기능과 이후 변경에서 VoiceOver 전용 지원·구현·시험·QA 체크·완료 및 배포 조건을 제외한다. 이전 문서의 VoiceOver 미검증·잔여 조건은 현재 작업의 차단 조건으로 사용하지 않는다. 당시 실행 결과와 과거 기록은 그대로 보존한다.

이 결정은 VoiceOver 전용 범위에 적용한다. 일반 버튼·입력·선택·터치·키보드·초점·레이블·저장·원문 이동·복귀 기능은 유지한다. 웹앱이 기기의 VoiceOver 자체를 끄는 기능을 제공한다는 뜻은 아니다.

현재 `src/`, `e2e/`, `scripts/`, `.github/`에는 VoiceOver/보이스오버 이름의 전용 코드·시험·배포 단계가 없다. 이 문서와 AGENTS.md, 기기 검증 안내, QA 목록이 모든 기능의 공통 적용 범위를 소유한다. 일반 접근성 검사와 화면 조작 검사는 해당 변경에 필요한 범위에서 계속 사용한다.
