## 사용할 흐름

`강의 자료 → 자료 추가 → 과목 선택 → 녹음 파일 가져오기 또는 녹음 시작 → 요약과 카드 만들기 → 원문 근거 확인·카드 수정 → 자료 저장` 순서입니다. 주제 연결은 선택입니다. 소유자 계정에서는 ‘녹음을 가져오거나 마친 뒤 자동 정리’를 기본 선택합니다. 원본 음성을 보관하지 못하면 자동 정리를 시작하지 않습니다. 필기만 붙여 넣어서 정리할 수도 있습니다.

요약·받아쓴 원문·카드를 따로 봅니다. 카드의 답은 `답 보기` 전까지 숨기며, 각 요약과 카드의 근거 버튼은 받아쓴 구간으로 이동합니다. 음성 구간 시간이 있는 경우 원본 재생 위치도 이동합니다. 받아쓰기와 구간 시간은 AI 추정이며 원본 대조가 필요합니다. 텍스트만 넣은 경우 근거 구간은 서버가 입력을 그대로 분할하고 AI가 원문을 다시 쓰지 않습니다.

질문/답과 받아쓰기를 수정하면 수정 전 문장을 남깁니다. 카드 제외/복원, 여러 생성 결과 선택, JSON 내보내기, 자료 휴지통/복원을 제공합니다. 기존 결과와 생성 당시 입력을 유지하며 입력이 바뀌면 이전 원문 기준 결과라는 사실을 알립니다. 생성·카드 열기·수정·저장은 공부 횟수·정답·숙달로 환산하지 않습니다. 현재 카드 열람에는 FSRS 일정·자기 평가 저장이 연결되지 않았습니다.

## 기존 기록 가져오기

민석 계정에서는 ‘기존 기록 가져오기’로 현재 과목의 공부 기록·자유 글·자료와 과목 미지정 메모·코드를 고를 수 있습니다. 검색은 전체 후보에서 하고 처음 30개씩 표시하며 한 번에 최대 20개를 가져옵니다. 가져올 원문을 펼쳐 확인할 수 있고 원래 필기에 그대로 덧붙입니다. 원본 저장 자료를 바꾸거나 가져오기만으로 GPT를 실행하지 않습니다.

공부 날짜의 미확인 상태·기록 체크의 시도 의미·행동별 입력·원문 ID/버전과 문서 추출 경고를 보존합니다. 코드는 현재 코드와 이전 실제 실행 당시 코드를 구별합니다. 최대 15만 문자보다 길면 자르지 않고 선택을 줄이도록 안내합니다. 마지막 가져오기는 같은 화면에서 취소할 수 있으며 이후 필기를 수정했다면 그 편집을 유지합니다. 가져온 필기는 기존 초안 보관을 거쳐 저장·재접속에 연결됩니다.

공통 프롬프트 v3와 설명·논리 검토/코드·실행 검토를 연결했습니다. 새 GPT 결과에는 서버가 프롬프트 버전을 저장합니다. 기존 결과는 자동 재생성하지 않습니다. 상세 증거와 실제 모델 미검증은 [이번 후속 작업 결과](gpt-completion-20261001.md)를 확인합니다.

## 자료와 저장

- 선택적 `studyMaterials`에는 제목·과목/선택 주제·원문·음성 메타데이터·생성 당시 입력·받아쓰기/요약/카드·version/revision을 저장합니다. `saveStudyMaterial`, `trashStudyMaterial`, `restoreStudyMaterial` 명령이 브라우저와 서버에서 같은 계약을 사용합니다.
- 실제 음성 bytes는 IndexedDB `study-space-material-files`에 user/namespace별로 보관합니다. 파일 SHA256과 metadata를 연결하며 원본을 압축하거나 변환하지 않습니다. **음성 파일의 다기기/서버 저장은 아직 구현하지 않았습니다.** 다른 기기에서 원본이 없으면 사실대로 표시하고 같은 파일을 다시 가져올 수 있습니다.
- 직접 녹음은 MediaRecorder를 사용하고 5초 구간을 먼저 보관합니다. 중단된 녹음은 초안의 recordingId로 복구합니다. 브라우저/기기의 MediaRecorder 지원에 따라 직접 녹음이 불가하면 기기 녹음 앱에서 만든 파일을 가져옵니다.
- 초안은 원래 baseVersion과 함께 보관합니다. 서버/다른 곳의 최신 버전과 다르면 자동 덮어쓰지 않습니다. 전송/AI/저장 오류가 나도 원본·초안을 유지합니다. 본인 탈퇴의 기기 정리는 해당 계정의 자료 보관소만 지웁니다.
- 최대 음성50MiB, 입력15만 문자, 생성당 카드1~30개, 보관 결과30회입니다. 큰 강의는 나누어 가져와야 할 수 있습니다. 모델이 전체 내용을 처리했다는 학습/정확성 보장은 하지 않습니다.

## AI 연결과 권한

[현재 AI 소유자 정책](product-decisions-20260930.md#2026-10-01-gptai-연동은-민석-계정-전용)을 유지합니다. 확인된 민석 계정과 personal 공간을 서버 인증으로 확인한 뒤 승인 상태를 검사합니다. 다른 승인 사용자/관리자·시연 공간·위조 userId는 AI 설정·상태·생성 전에 거부하며 provider 호출/사용량 예약을 하지 않습니다. 일반 사용자의 수동 자료 보관·기존 결과 열기는 유지합니다.

로컬 실행은 `npm run setup:gpt-local`로 Mac 키체인 도구와 무료 받아쓰기 모델을 준비한 뒤 `npm run dev -- --port 5218 --strictPort`를 실행합니다. 설치 스크립트의 Python은 3.10 이상이어야 하며 `STUDY_TRANSCRIPTION_PYTHON`으로 경로를 지정할 수 있습니다. 현재 Mac에는 번들 Python3.12 기반 전용 venv와 faster-whisper1.2.1/PyAV16.1.0, Whisper small을 설치했습니다. 모델은 `.local/`에 두어 Git·브라우저 번들에 포함하지 않습니다. PyAV19와 첫 실행 호환 문제가 있어 실제 동작을 확인하는 버전을 고정합니다.

개인 공간 → 강의 자료 → GPT 연결 → ChatGPT 연결 시작 → Continue with ChatGPT → 로그인·구독 사용 동의 → 연결 확인 → 계정에서 조회한 GPT 모델 선택 → ChatGPT 사용량 설정에서 추가 크레딧 사용 허용 꺼짐 확인 → 생성 설정 적용 순서입니다. 모델 선택은 프로필별 비공개 파일에 보관하며 재접속 뒤 현재 계정의 모델 목록에 있는 경우 복원합니다. 없는 모델을 임의로 호출하지 않고 현재 목록의 첫 모델을 선택합니다. 손상된 설정 파일은 덮어쓰지 않습니다. 크레딧 확인은 연결 프로필에 묶어 한 시간 유지하며 연결 변경/해제/서버 재시작 후 다시 확인합니다. 이 확인은 사용자의 확인이며 앱이 계정 설정을 조회하거나 추가 크레딧 소비를 프로그램으로 강제 차단했다는 보장은 아닙니다. 포함 사용량·크레딧 제어 원칙은 [Plus 연결 설계](chatgpt-plus-design.md)를 유지합니다.

[공식 OpenAI DevKit](https://github.com/openai/sign-in-with-chatgpt-devkit)의 로컬 SDK를 고정 commit으로 재사용합니다. npm 공개 패키지가 아닌 저장소 workspace여서 `scripts/vendor/siwc-local/`에 source·라이선스·출처·수정 내역을 함께 보관했습니다. PKCE/state/nonce, ID-token 서명/issuer/audience/만료 검증, 승인된 scope 확인, 회전 토큰 갱신, 계정별 보호 저장, 모델 조회와 `response.completed` 스트리밍 판정을 이 SDK가 담당합니다. 추가한 훅은 OAuth callback의 코드 교환과 토큰 저장 전에 시작한 앱 소유자 세션과 최신 이용 승인을 재확인합니다. 구독 연결과 앱 로그인은 별도이며 기존 Codex/ChatGPT 토큰을 읽거나 공유하지 않습니다.

토큰은 이 앱 전용 Mac 키체인의 암호화 키와 AES256-GCM으로 암호화해 `~/.config/study-space-chatgpt/`에 보관합니다. 공식 SDK의 owner-only 권한·원자적 파일 교체·잠금을 사용하며 브라우저 저장소/원장/로그에는 토큰이 들어가지 않습니다. 이 Mac의127.0.0.1 같은 origin, 서버가 검증한 민석 계정과 승인 상태에만 상태/로그인/모델/설정/생성을 제공합니다. 원격 웹주소를 로컬 중계에 임의로 연결하지 않습니다.

[구독 경로의 공식 제약](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)에 따라 음성·Files 업로드·받아쓰기 API를 호출하지 않습니다. 음성은 로컬 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)로 한국어 받아쓰기와 초 단위 구간을 생성하고, 그 구간 및 필기만 GPT에 보냅니다. 원본 음성은 변경하지 않고 임시 처리 파일은 성공/실패 뒤 제거합니다. 모델은 local_files_only로 실행하며 API 비용이 발생하지 않습니다. 긴 녹음 처리 시간과 전문용어·수식의 정확성은 강의 내용/기기 성능에 따라 달라집니다. 필기와 받아쓰기의 원문/시간/id는 GPT의 응답으로 교체하지 않습니다. 모든 요약·카드 근거 id와 개수를 검증하며 내용의 사실성은 원자료 대조가 필요합니다.

GPT는 계정별 모델 목록의 slug와 공식 `https://api.openai.com/v1/responses`, `store:false`, `stream:true`만 사용합니다. 유료 API 키·추가 크레딧 구매·다른 provider 전환·자동 추론 재시도는 없습니다. 현재 앱 상한은 로컬 시간20회/동시1개이며 실제 포함 사용량을 보장하는 횟수가 아닙니다. 미연결/크레딧 확인 전/권한 거부는 원문 처리·provider 호출/사용량 예약 전에 중단합니다. 한도·중단·불완전 스트림은 생성 완료로 저장하지 않습니다. 정리 중단 버튼과 화면 이탈은 처리 취소 신호를 로컬 받아쓰기와 GPT에 전달하며 원본·초안·기존 완료 결과를 보존합니다. 중단 직전 이미 처리된 구독 사용량의 반환은 보장하지 않습니다. 부분 스트림 본문을 앱 초안에 보관하는 기능은 이번 자료 경로에 연결하지 않았습니다.

[공식 Cookbook의 적용 조건](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)에 따라 현재 개인 로컬 실행에서만 연결합니다. 원격 GitHub Pages 앱의 접근 승인은 미확인입니다. 클라이언트는 원격 호출을 시작하지 않으며 Supabase study-ai도 인증·소유자/승인 확인 후 body 처리/사용량 예약 전에 연결 필요 오류로 끝냅니다. 기존 Gemini secret을 사용하지 않습니다. 자료 metadata의 서버 저장은 별도 study-command capability/migration 적용이 필요하며 이번 GPT 변경은 그 배포를 수행하지 않았습니다.

## 이번 검증의 경계

격리된 합성 자료로 원문 UTF-16·ID/이력·소유권·버전/멱등·휴지통/복원, 음성 bytes/계정별 정리·녹음 구간 복구, AI 형식/거부/한도/provider 파일 정리, 생성 성공/실패 초안 보존, 카드 조작·저장/재열기와 녹음 API 흐름을 검사합니다. 녹음 UI 검사는 합성 MediaRecorder이며 실제 마이크 녹음을 실행하지 않았습니다. 실제 브라우저에서는 합성 WAV 가져오기·원문 저장·reload·원본 음성 재연결을 확인합니다.

실제 GPT 응답·실제 강의 한국어/수식 받아쓰기 품질·민석 로그인 서버 왕복·물리 iPad/IME/Sync는 미확인입니다. PDF/슬라이드 입력, 자료 질의응답, 객관식 퀴즈, Anki 덱 내보내기, 음성 요약 생성은 이번 첫 범위에 포함하지 않았습니다.
