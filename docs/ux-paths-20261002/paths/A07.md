# A07 · 검색 워커·최신 요청 보호

범위: extension. 정적 경로 문서이며 실행 검증 완료가 아니다.

- 원본: [src/data/workspace-search-client.ts](../../../src/data/workspace-search-client.ts), [src/data/workspace-search.worker.ts](../../../src/data/workspace-search.worker.ts), [src/data/workspace-search-engine.ts](../../../src/data/workspace-search-engine.ts), [src/domain/workspace-search.ts](../../../src/domain/workspace-search.ts)
- 진입: R18 / A03
- 복귀: 원래 호출자·현재 소스가 지정한 경로. 고정 목적지를 임의 만들지 않는다.
- 상태 계약: 확장/표면에 별도 지정 없음
- 소스 상태군: 별도 이름 없음

구체적 경우와 경로:

1. 검색 자료 갱신 → owner/revision에 따른 초기화 또는 upsert/remove/order 패치. 같은 자료·순서면 불필요한 갱신 생략.
2. 검색 요청 → 앞 대기 요청 취소(null) → 요청 번호 증가 → worker 전송. worker 없음/생성 실패/메시지 오류/10초 시간 초과 → 같은 로컬 검색 엔진으로 전환.
3. 응답의 owner/revision/request가 현재와 일치할 때만 결과 수락. 늦은 응답과 다른 소유자의 응답은 적용하지 않는다.
4. 해제 → 대기 취소·worker 종료·색인 비움. 색인은 저장 원장·계정 권한 원본이 아니며 UI 조작은 A03에서 출발한다. 이 항목에는 별도 버튼을 만들지 않는다.

이 범위가 새 버튼을 직접 만들지는 않는다. 표현 전용/엔진 계약은 진입하는 상위 UI·수동 경우의 경로와 연결한다. 조작이 없는 것과 구현 누락을 같은 상태로 세지 않는다.

중단·복귀 대조: lifecycle effect 0개, 상태 변수 0개. 아래 effect는 mount/의존성 변경/cleanup 경로이며, 브라우저를 닫은 뒤의 영구 보존을 자동 보장하지 않는다.
