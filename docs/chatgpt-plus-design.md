# ChatGPT Plus 포함 사용량으로 공부 기록 생성

2026-10-01 사용자 결정: “어, plus 기준으로 설계할거야 과금 없이.”

기존 Plus 구독료 외 추가 AI 비용 없이, 앱의 입력 기록을 바탕으로 내용을 생성하는 설계입니다. 이 문서는 제품 요구와 구현 순서를 확정하며, 계정 연결·GPT 호출·저장·배포가 완료됐다는 증거는 아닙니다. 기존 기록·응답·초안·ID·개인 설정과 병행 변경을 보존합니다.

## 2026-10-01 매 요청에 적용하는 앱 공통 프롬프트

앱 GPT의 전용 지침은 [공통 GPT 프롬프트](study-gpt-prompt.md)와 `src/server/study-gpt-prompt.ts`에서 관리합니다. 현재 버전은 `study-gpt-2026-10-01-v3`입니다. 자료 보조 19개 작업과 목차 기반 암기항목의 실제 생성 요청마다 공통 지침·선택 작업·근거 범위·출력 계약을 `instructions`에 넣고 원문과 보조 입력은 별도 `input`으로 전달합니다. Codex의 AGENTS.md나 개인 ChatGPT 대화 지침이 자동으로 앱에 전해진다고 가정하지 않습니다.

원문 보존·불확실성·학습 의미·정답 분리의 공통 기준을 유지하면서 자료 기반 질문과 목차 기반 일반 지식 출제의 근거 범위를 구별합니다. 저장·권한·사용량·출력 검사는 앱 코드가 담당합니다. 지침 전달과 합성 회귀 확인을 실제 모델의 응답 품질·수식 정확성·지시 공격 방어 완료로 보고하지 않습니다. 새 자료·목차 생성 결과와 등록한 목차 카드의 출처에 서버가 프롬프트 버전을 남깁니다. 이전 결과의 선택 필드는 유지하며 새 프롬프트로 자동 재생성하지 않습니다. 선택한 기존 기록의 가져오기, 관련 확인과 남은 외부 조건은 [GPT 후속 구현 결과](gpt-completion-20261001.md)에 정리했습니다.

## 2026-10-01 민석 계정만 연결·생성

현재 제품의 GPT 기능 사용자는 민석 한 명입니다. 승인된 회원·추가 관리자도 ChatGPT 연결·토큰 설정·생성·자동 실행·한도 조회를 사용할 수 없습니다. 앱은 기존 확인된 민석 계정 ID로 화면을 제한하며, 보호된 실행 환경은 매 요청마다 서버가 검증한 앱 신원·현재 이용 승인·민석 ID를 확인해야 합니다. 요청 본문 userId/이메일/이름/관리자 표시는 권한의 근거가 아닙니다. 비소유자 요청은 OAuth 시작·콜백/토큰 저장·사용량 조회·생성 원문 전송·한도 차감 전에 거부합니다. OAuth state/PKCE와 callback은 민석의 시작 세션에 묶고 다른 앱 계정으로 연결 결과를 넘기지 않습니다.

공용/시연 공간에 민석의 자격증명·사용량·결과를 제공하지 않으며, 일반 계정의 기록·복습·수동 자료 저장은 유지합니다. 중지·탈퇴 후에는 기존 토큰으로도 실행하지 못하게 현재 앱 계정을 확인합니다. 같은 이메일의 새 계정이나 다른 관리자에게 자동 승계하지 않습니다. 현재 공통 소유자 제한은 src/domain/ai-access.ts 및 AI 핸들러/개발 서버/화면에 반영하며, 실제 ChatGPT OAuth·Plus 연결·GPT 호출 완료는 별도 검증 대상입니다.

## 2026-10-01 전사한 녹음의 보관 정정

사용자 정정에 따라 전사문을 확인해 필기에 추가하고 자료의 서버 저장이 성공한 뒤에는 앱의 녹음 사본을 기본적으로 정리합니다. 전사·저장 실패, 다른 자료/초안의 참조, 사용자의 명시적 보관 선택에서는 원음을 남깁니다. 자세한 처리·정리 재시도·실제 확인 범위는 [모바일 처리](mobile-gpt-20261001.md#2026-10-01-정정-전사문-저장-후-녹음-정리)에 둡니다. 250MB는 모델 다운로드 용량이고 녹음의 현재 별도 제한은 50MiB/20분입니다. 월간 Plus 사용 조건은 유지하며 별도 요금제 가입으로 설명하지 않습니다.

## 비용과 연결 원칙

- 연결은 공식 Sign in with ChatGPT의 요금제 사용 권한을 기준으로 합니다. 별도 유료 API 키, 운영자 비용 대납, 추가 크레딧 구매, Pro 업그레이드, 다른 유료 모델/서비스로의 자동 전환은 제공하지 않습니다.
- Plus 포함 사용량을 다른 Codex/ChatGPT Work 이용과 공유합니다. 고정 요청 횟수나 매일 생성 가능량을 보장하지 않으며, 앱별 상한은 ChatGPT 설정의 공식 기능을 사용합니다.
- 최초 연결에서 ChatGPT 설정의 **한도 초과 후 다른 앱의 크레딧 사용 허용을 끈 상태**를 확인해야 합니다. 기존 크레딧 잔액이 있어도 이 앱은 사용하지 않는 기준입니다. 앱이 추가 구매를 하지 않는 것만으로 기존 크레딧 소비를 막았다고 보고하지 않습니다.
- 확인한 문서에서 요청별 ‘포함 사용량만 사용’ 스위치나 위 계정 설정의 자동 조회/변경 방법은 확보하지 못했습니다. 구현에서 이런 기능을 임의로 가정하지 않습니다. 확인 가능한 공식 제어와 계정 설정 확인을 연결하고, 추가 비용 없는 호출 조건을 확인하지 못하면 생성을 시작하지 않습니다. 사용자 설정 확인과 프로그램이 강제한 보장을 구분합니다.
- 사용 한도·요금제 권한 없음·연결 실패에서는 새 생성만 중단합니다. 유료 경로로 재시도하거나 계정을 자동 전환하지 않습니다. 한도 해제 뒤 사용자가 다시 요청하며, 대기 중인 생성 요청을 자동으로 몰아서 실행하지 않습니다.

## 실제 앱에 연결하는 경계

### 2026-10-01 iPhone·iPad 단독 사용 조건

사용자 정정: 사용 기기는 Mac일 수도 있지만 iPhone·iPad일 수도 있습니다. 기본 사용 흐름은 iPhone·iPad에서 공부 공간에 로그인해 생성 요청과 결과 저장·재열기까지 마치는 것입니다. Mac 설치·상시 실행·같은 네트워크 접속을 일반 사용의 필수 조건으로 확정하지 않습니다. GPT 모델의 OpenAI 서버 실행과 앱의 인증 중계·받아쓰기 실행 위치를 구분합니다.

Mac의 개발용 GPT 연결은 Vite loopback·Mac 키체인에 의존합니다. 이번 모바일 구현은 브라우저 받아쓰기와 보호된 원격 연결 상태 조회를 추가했습니다. 원격 GPT 생성은 OpenAI의 접근 승인 전 차단합니다. 따라서 Mac 연결이나 브라우저 받아쓰기 구현만으로 iPhone·iPad의 GPT 연결·생성 완료로 보고할 수 없습니다. `127.0.0.1`은 접속한 기기 자신이므로 Mac의 로컬 주소를 모바일 사용 주소로 안내하지 않습니다.

모바일 처리 경로는 원격 웹앱의 공식 요금제 접근 권한을 먼저 확인해 연결합니다. 공식 사용자 소유 VM 절차는 별도 후보이며 보호된 자격증명 이전·갱신, 소유자 인증, HTTPS 접근, 호스팅 비용·운영 조건을 확인해야 합니다. 문서에 VM 절차가 있다는 사실을 현재 운영 웹앱의 권한·추가 비용 없음·모바일 로그인 지원 증거로 쓰지 않습니다. 별도 유료 API로 자동 전환하지 않습니다.

공식 요금제 연결은 현재 음성/영상 입력 및 transcription API를 지원하지 않습니다. 녹음을 글로 바꾸는 경로는 Transformers.js 4.3.0의 WASM·Whisper small q8 브라우저 실행으로 구현했습니다. Mac 브라우저의 합성 음성 실행을 확인했으며, 실제 강의 품질·물리 iPhone/iPad 메모리·백그라운드 지속은 미검증입니다. 자세한 모델 버전·보존·확인 범위는 [모바일 GPT 연결과 받아쓰기](mobile-gpt-20261001.md)에 남깁니다. 처리 중 화면 잠금·앱 전환·통신 중단·재접속에서도 원본·초안·받은 결과를 보존하고, 저장 실패만으로 생성 요청을 다시 실행하지 않는 조건을 적용합니다.

현재 확인은 소스·공식 문서·실제 Mac 브라우저의 받아쓰기/정정/필기 추가/재접속과 기존 Supabase의 연결 상태 경로 적용입니다. 원격 GPT OAuth·생성은 접근 승인 전 미연결이고, 물리 iPhone·iPad 연결·녹음·생성·재접속은 미검증입니다.

현재 앱은 GitHub Pages에서 화면을 제공하고 별도 인증·저장 서버와 연결됩니다. 공식 문서는 오픈소스·로컬 실행 앱의 요금제 사용 경로를 제공하고, 원격 호스팅/유료 앱에는 별도 신청 경로를 안내합니다. 공개 코드 저장소가 있다는 사실만으로 현재 원격 웹앱에 요금제 사용 권한이 있다고 판단하지 않습니다.

구현 전에 현재 배포 형태에 허용되는 연결 경로를 확인합니다. 원격 웹앱에 해당 권한이 성립하면 그 경로를 연결합니다. 성립하지 않으면 개인 컴퓨터 또는 사용자 소유 실행 환경에서 생성 처리를 맡는 경로를 검토하되, 설치·컴퓨터 상시 실행·iPad 접근·인증·운영 부담을 확인한 뒤 결정합니다. 로컬 중계는 설계 후보이며 새 제품 형태로 확정하거나 원격 앱의 권한 조건을 우회하는 수단으로 삼지 않습니다. 확인되지 않은 원격 권한 때문에 별도 과금 방식으로 요구를 바꾸지 않습니다.

앱의 공부 공간 로그인과 ChatGPT 생성 권한 연결은 구분합니다. 같은 이메일만으로 소유자를 연결하지 않으며, 생성 요청과 결과도 기존 사용자 소유권을 유지합니다. OAuth 토큰은 브라우저 저장소·학습 원장·소스·로그에 넣지 않고 허용된 실행 환경의 보호된 저장소에 둡니다. ChatGPT의 기존 대화·메모리 접근을 전제로 하지 않습니다.

## 사용 흐름과 생성 범위

1. 앱에서 ChatGPT를 연결하고 Plus 포함 사용량 및 크레딧 설정을 확인합니다.
2. 첫 연결 대상은 기존 공부 기록과 연결 주제의 **기록 요약·다음 공부 제안**입니다. 추가 설명 입력은 필수로 만들지 않습니다. 확인 질문은 기록/자료에 내용 근거가 있을 때만 생성합니다.
3. 사용자가 생성을 요청하면 대상 주제와 필요한 기록만 선택합니다. 무관한 개인 자료·휴지통·다른 사용자의 자료를 전달하지 않습니다. 입력 중 키 입력·화면 열기·새로고침·일반 기록 저장이 자동 생성 호출을 일으키지 않습니다.
4. 요청 하나로 필요한 결과를 함께 생성합니다. 같은 사용자·입력 버전·생성 목적의 완료 결과는 다시 보여 주고, 중복 클릭은 하나의 진행 요청으로 처리합니다. 새 생성/재생성은 명시적 조작으로 시작합니다.
5. 결과는 요약, 근거 기록 ID, 해석, 다음 행동, 남은 불확실성을 구분해 표시합니다. 생성 결과를 읽었다는 이유로 수행/정답/숙달 기록을 만들지 않습니다.
6. 원문을 덮어쓰지 않고 별도 생성 결과로 저장합니다. 요청 ID·입력 기록 ID와 버전·생성 시각·모델·생성 기준 버전을 유지합니다. 원기록 수정 후에는 이전 결과가 어느 입력을 바탕으로 만들어졌는지 알 수 있게 하고 조용히 재호출하지 않습니다.

수치 집계·날짜·공부 횟수·목표/복습 계산은 기존 검증된 프로그램 규칙이 담당합니다. GPT는 글의 문맥에 따른 요약과 제안을 맡습니다. 체크는 시도 근거이며 완전 이해·독립 수행으로 환산하지 않습니다. 정보가 없으면 실패·0점·능력 추정으로 채우지 않습니다. GPT의 결과 형식 검증과 내용의 사실 확인을 구분합니다.

## 중단·실패·저장 처리

| 상태 | 처리 |
| --- | --- |
| 연결/크레딧 설정 확인 전 | 새 호출을 시작하지 않고 필요한 연결 행동을 안내합니다. 일반 공부 기록은 사용합니다. |
| 생성 중 | 기존 화면·글을 유지하고 같은 요청의 중복 실행을 막습니다. 취소해도 이미 처리된 사용량이 반환된다고 보장하지 않습니다. |
| 사용 한도 도달 | 새 생성과 자동 재시도를 멈추고 ChatGPT 사용량 설정으로 연결합니다. 확인된 재개 시점만 안내합니다. |
| 연결 만료·권한 취소 | 생성을 멈추고 다시 연결합니다. 기존 공부 기록과 생성 결과는 보존합니다. |

| 생성 완료·결과 저장 실패 | 받은 결과를 재시도 가능한 상태로 보존하고 저장만 다시 시도합니다. 저장 실패 때문에 GPT를 다시 호출하지 않습니다. |

공식 요금제 경로의 모델 목록은 연결 계정에서 조회합니다. HTTP 생성은 공식 Responses 엔드포인트와 `store:false`, `stream:true` 조건을 사용하고, `response.completed` 이후 결과 검증을 통과해야 생성 완료로 처리합니다. 스트리밍 중에도 한도 오류가 올 수 있으므로 첫 글자 수신을 성공으로 판단하지 않습니다. 생성 호출·앱 저장 성공·서버 저장·다시 열기를 각각 확인합니다.

## 구현 순서와 직접 완료 기준

1. **배포 형태·요금제 권한·추가 크레딧 차단 조건 확인.** 사용자 계정의 실제 허용 여부는 로그인 뒤 확인하며, 문서 열람만으로 연결 완료를 보고하지 않습니다.
2. **공식 로그인과 한 가지 생성 흐름 연결.** 합성 기록으로 요약·다음 행동을 생성하고 완료 응답, 별도 결과 저장, 다시 열기를 확인합니다. 실제 개인 자료 전송은 연결 권한과 대상 범위를 확정한 뒤 진행합니다.
3. **관련 실패 확인.** 사용 한도/크레딧 조건 미확인에서 호출 중단, 유료 경로 없음, 중복 요청 억제, 저장 재시도 시 재생성 없음, 원문·ID·미응답 의미 보존을 확인합니다. 계정 설정의 크레딧 차단과 실제 사용량 반영 확인을 모의 응답 검사와 구분합니다.

현재 이번 작업의 완료 범위는 Plus·추가 과금 없음의 설계 및 제품 결정 반영과 로그인한 계정의 사용량·크레딧 설정 직접 확인입니다. 실제 앱 OAuth 연결, 생성 호출, 결과 저장·재열기, 공개 배포는 미실행입니다.

## 확인한 공식 근거

### 2026-10-01 실제 연결 조건 확인 결과

- 현재 공개 앱 URL의 HTTP 200과 GitHub Pages 제공을 확인했습니다. GitHub의 공개 저장소 메타데이터는 `private:false`, `license:null`입니다. 공개 코드만으로 오픈소스 자격이나 원격 앱의 요금제 사용 허가를 확인했다고 판단하지 않습니다. 라이선스는 임의로 추가하지 않았습니다.
- 최초 연결 조건 조사에서는 `src/`, `scripts/`, 환경변수 예시와 Pages 설정에서 실제 ChatGPT 로그인·요금제 사용 연결을 찾지 못했습니다. 후속 소유자 제한 구현과 실제 OAuth 등록·연결 완료는 구분합니다. 이 앱의 원격 호스팅 접근 승인은 확인하지 못했습니다.
- 공식 Cookbook의 Usage policy and terms는 오픈소스 도구와 로컬 개인 프로젝트에 연결 경로를 제공하고 **원격 호스팅 앱은 사용 제공 전 접근 신청**을 안내합니다. 현재 웹앱을 그대로 유지하는 경로에는 해당 권한 확인과 보호된 생성 실행 환경이 필요합니다. 등록 페이지의 공식 신청 양식도 확인했으며 신청을 전송하지 않았습니다.
- 로컬 공식 등록은 사용자 컴퓨터의 `127.0.0.1` 콜백, 앱 이름, 고정 호스트 ID, PKCE와 사용자 동의를 사용합니다. 별도 partner API 키/secret 없이 등록할 수 있는 절차는 확인했지만, 실제 계정 등록·요금제 권한·호출은 미검증입니다. iPad에서 기존 웹 주소만 여는 경험과 동일하다고 보고하지 않습니다.
- 사용자 소유 VM의 공식 절차도 존재합니다. 로컬 OAuth 완료 후 보호된 자격증명 이전·토큰 갱신·호스트 운영을 요구하므로 무료·즉시 연결 또는 기존 웹앱의 원격 제공 권한 대체로 확정하지 않습니다.
- 최초 조사에서는 앱 내 브라우저가 로그아웃 상태여서 로그인 화면을 준비했습니다. 이후 사용자 “어 로그인했어”에 따라 같은 브라우저의 로그인된 계정과 사용량 설정을 직접 확인했습니다. 비밀번호·토큰·계정 저장소를 읽지 않았습니다.

### 2026-10-01 로그인 후 계정 설정 직접 확인

- 프로필 메뉴에는 민석·Pro로 표시됩니다. 실제 로그인 계정 표시를 Plus라고 보고하지 않으며, 제품의 최소 설계 기준은 사용자가 정한 Plus·추가 과금 없음으로 유지합니다. 이 표시만으로 웹앱의 민석 계정 ID와 OAuth 계정을 연결하지 않습니다.
- 설정 → 사용량에서 **“사용량 한도에 도달한 후 다른 앱에서 크레딧 사용 허용”이 꺼짐**을 DOM과 실제 화면으로 확인했습니다. **자동 충전도 꺼짐**입니다. 기존 크레딧 잔액은 있지만 잔액 유무와 외부 앱의 소비 허용을 구별합니다. 설정을 변경하거나 크레딧을 구매하지 않았습니다. 이번 시점의 직접 관측이며 향후 사용자가 변경할 가능성까지 프로그램이 막았다는 뜻은 아닙니다.
- 공유 주간 플랜 사용량은 **0% 남음**, 화면의 초기화 안내는 **5일 7시간 남음**입니다. Codex 사용량 조회도 주간 포함 사용량 소진을 보고했습니다. 이 화면은 Codex·Work 등이 공유하는 사용량이며 일반 Chat 대화는 포함되지 않는다고 안내합니다. 현재 포함 사용량만 쓰는 새 생성은 한도 복원 전까지 실행하지 않습니다. 사용 가능한 초기화 1개도 이번에 사용하지 않았습니다.
- 앱 사용 한도 목록에는 Vercel만 표시되고 학습 웹앱은 나타나지 않습니다. 보안 및 로그인 → ChatGPT로 로그인의 연결 목록(Vercel·Canva·Apple Intelligence·Codex CLI)에도 학습 웹앱이 없습니다. ChatGPT 사이트 로그인 성공과 학습 웹앱의 실제 OAuth 연결·추론 권한·생성 성공을 구분합니다.

따라서 현재 판정은 **Plus 포함 사용량을 쓰는 공식 방식은 있음 / 현재 원격 웹앱의 직접 사용 권한은 미확인·접근 신청 경로 필요 / 로그인 계정의 외부 앱 크레딧 사용 허용은 꺼짐·현재 주간 포함 사용량은 소진 / 실제 앱 연결·생성 호출은 미실행**입니다. 웹앱을 유지하는 신청 경로와 로컬 실행 경로를 구분하며, 사용자 동의 없이 신청 전송·라이선스 변경·유료 API 전환·새 배포를 실행하지 않습니다.

## 2026-10-01 강의 자료의 GPT 로컬 구현 반영

사용자의 “gpt용으로 수정해야지 그러면”에 따라 강의 자료의 새 요약/카드 생성 경로를 GPT로 교체했습니다. 공식 DevKit을 로컬 Vite 실행 환경에 연결하고 민석 앱 인증/현재 승인/콜백 재검사, 키체인 암호화 저장, 계정 모델 조회, 크레딧 꺼짐 사용자 확인, 완료 스트림 검증을 구현했습니다. 구독 경로에 음성 입력/받아쓰기 API가 없어 무료 로컬 Whisper로 받아쓴 텍스트만 전달합니다. 설치·합성 자동검사·실제 브라우저 저장/재열기·키체인 왕복·한국어 합성 음성 받아쓰기를 확인했습니다.

이번 구현의 연결은 개인 로컬 실행에 한합니다. 기존 웹앱의 원격 접근 승인·실제 민석 계정 OAuth·GPT 추론 성공·개인 자료 서버 저장·공개 배포는 실행하지 않았습니다. 현재 앱 브라우저는 공부 공간 로그인 화면이어서 로그인 뒤 강의 자료/GPT 연결에서 사용자가 공식 동의를 진행해야 합니다. 앞 절의 계정 요금제/사용량 관측을 현재 앱 연결 성공으로 승격하지 않습니다. 세부 경로와 확인 범위는 [강의 자료 계약](ai-materials.md)을 따릅니다.

모델 선택은 프로필별로 재접속 뒤 복원하며 크레딧 설정 확인은 서버 재시작/연결 변경 뒤 다시 받습니다. 정리 중단은 받아쓰기/GPT 처리에 취소를 전달하고 원문·초안·기존 결과를 보존합니다. 최종 관련9파일34개와 빌드를 확인했습니다. 이 확인을 실제 계정의 OAuth·생성·비용 차단 보장으로 확대하지 않습니다.
