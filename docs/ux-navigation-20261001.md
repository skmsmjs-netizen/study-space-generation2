# 홈 이동과 일정 열기 — 2026-10-01

- 홈의 독립된 이동 링크와 추천 카드의 일정 이동 링크를 기존 조작 토큰(높이 48px, 최소 너비 44px)에 맞췄다. 긴 글은 줄바꿈한다. 본문 속 링크에 일괄 적용하지 않는다.
- 일정 이동은 브라우저 기본 details를 열고 summary로 키보드 초점을 옮긴 뒤 해당 위치로 이동한다. 다시 접었다가 이동해도 열린다.
- 일정 열기는 화면 상태만 바꾸며 원문, 일정, 기록, 저장 키와 수정 이력은 변경하지 않는다. 재접속 시 기본 접힌 상태는 유지한다.
- 기존 UI와 디자인 토큰, 네이티브 details를 재사용했다. WCAG 2.2 Target Size (Enhanced)의 44×44 기준과 WAI-ARIA APG Disclosure 패턴을 판단 기준으로 참고했다. 이 변경만으로 전체 접근성 준수를 판정하지 않는다.
- 근거: https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html , https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/
- 회귀 검사는 닫힌 일정 열기, 초점, 위치 이동, 반복 이동, 저장 원문 보존, 재접속 후 일정 보존을 확인한다. 모바일 브라우저 화면 폭 검증과 물리 기기 검증은 구별한다.
- 현재 공개 코드의 추천 카드 경로에 적용한다. 다른 작업의 미배포 기능과 저장·서버 변경은 포함하지 않는다.
