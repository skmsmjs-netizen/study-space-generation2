# 전체 백업·복원과 접근성 보수 — 2026-10-01

사용자의 실제 입력·보수 요청에 이어 통합 실행본, 확인된 접근성 결함, 전체 백업·복원을 구현했습니다. 공유 작업본의 병행 변경을 보존하고 `/tmp/study-full-backup-20261001`의 분리된 실행본에서 확인합니다. 공개 배포·서버 자료 변경은 이번 작업 범위에 포함하지 않습니다.

## 구현한 동작

- 사이드바의 백업·복원에서 현재 계정·공간의 공부 원장, 수정 이력, 그래프/Canvas 배치·보기, 첨부 원본, 녹음 조각, 작성 중인 초안, 기기 설정을 ZIP 한 파일로 내려받습니다. 로그인·토큰·다른 계정 자료를 포함하지 않습니다.
- 백업을 고르면 내용·계정·크기·SHA-256 지문·원장과 첨부 참조를 검사하고, 명시 확인을 받은 뒤 복원 요청을 보관합니다. 다른 공부 창을 마치고 다시 열 때 기존 자료의 ZIP 사본을 먼저 만든 뒤 복원합니다. 사본도 화면에서 내려받아 되돌릴 수 있습니다.
- 공부 원장은 백업 시점으로 돌아갑니다. 별도 첨부·초안 중 백업에 없는 키는 유지하며 기록을 임의 합치지 않습니다. 다른 창의 초안 원문은 보관하고 입력창에 자동 적용하지 않습니다.
- 여러 저장소의 적용 중 실패하면 복원 전 값을 돌려놓습니다. 강제 중단으로 복구가 남으면 앱 저장소를 시작하기 전에 복구를 재개합니다. 다른 작성 창의 잠금을 확보하지 못하면 자료를 변경하지 않습니다.
- 개인 공간의 복원 자료가 실제 서버 자료와 다르면 양쪽을 유지하고 기존 충돌 선택으로 연결합니다. 캐시를 먼저 읽었더라도 복원 자료를 서버 자료로 바꾸거나 자동 전송하지 않습니다.
- 기기 화면 위치 갱신을 공부 자료 변경으로 오인하던 다운로드 실패를 직접 재현하고 수정했습니다. 화면 위치는 백업 시점의 값으로 담으며 공부 원장·첨부·초안은 보관 중 변경을 계속 검사합니다.
- WebKit의 Blob 저장 정지 조건에 맞춰 병행 도입된 바이너리 저장 형식(타입+ArrayBuffer)을 백업/복원과 연결했습니다. 기존 Blob 자료도 읽습니다.

## 접근성 보수

좁은 화면에서 공부 범위 선택의 접근 가능한 이름을 유지하도록 라벨을 시각적으로만 숨깁니다. 통계 SVG를 group 역할로 표시해 내부 근거 버튼을 키보드로 계속 열 수 있게 합니다. 그래프 제공자 표기의 바탕·글자색을 기존 토큰으로 지정해 대비를 확보하고 표기는 유지합니다. 이 세 조건의 검사이며 앱 전체 WCAG 준수 판정은 아닙니다.

## 채택한 기준·도구

기존 `fflate` ZIP, Web Crypto SHA-256, IndexedDB transaction·기존 저장소 경계와 잠금, Playwright·axe 검사를 재사용합니다. [WCAG Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html)를 선택/근거 버튼의 이름과 역할에 연결하고, ZIP은 [fflate 공식 문서](https://github.com/101arrowz/fflate)를 확인했습니다. 병행 PDF 경로의 타입 오류는 [PDF.js LoadingTask](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib-PDFDocumentLoadingTask.html)의 해제 경로와 [pdf-lib 공식 문서](https://pdf-lib.js.org/)에 맞춰 보수했습니다. 복원 전 사본·재시작 복구는 현재 데이터 계약에 맞춘 프로젝트 구현이며 외부의 인증된 표준이라고 표현하지 않습니다.

## 실제 한계

백업·해제 크기는 512MiB, 보관 항목은 20,000개까지입니다. ZIP을 메모리에 구성하므로 이 상한까지 모든 모바일에서 원활하다고 검증하지 않았습니다. 서버에만 있고 이 기기에 없는 참조 원본은 누락된 백업을 만들지 않고 오류로 안내합니다. 먼저 강의 자료에서 원본을 열어 기기에 받은 뒤 재시도해야 합니다. 서버 전용 계정/인증/운영 데이터 전체를 보관하는 관리자 백업은 아닙니다. 개인 계정의 실제 서버 복원·실물 기기·VoiceOver·장기 누적 성능은 이번 합성/브라우저 확인으로 확대하지 않습니다.
