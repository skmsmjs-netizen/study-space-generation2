# 좌측 사이드바의 분류형 탐색 · 2026-10-03

사용자 사진의 분류 제목·하위 목록·들여쓰기·구분선 방식을 실제 주 탐색에 적용하고 공개 배포한다. 기존 NavigationBar, OBSERVATORY_MENU, 고정 장소, hash 경로와 이동/복귀 계약을 재사용한다. 과업 화면의 주 패턴은 유지하고 탐색 구역에 등록 L065 Side Navigation, 내부 L068 Accordion을 조합한다. 좁은 화면은 기존 L066 빠른 이동을 유지하며 L068 펼침형 전체 메뉴를 추가한다. 새 미등록 화면 패턴을 도입하지 않는다.

선정 근거: [NN/g 세로 탐색](https://www.nngroup.com/articles/vertical-nav/)의 분류/성장/공간 제약과 [W3C APG 펼침형 탐색](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)의 링크/펼침 상태/키보드 지침. NN/g의 UX 권고와 W3C 구현 지침을 구별하며 학습 효과를 주장하지 않는다.

## 구성과 보존

- 공부 / 자료 / 탐구 / 기록·계획 / 공통 도구 다섯 분류, 기존 주 메뉴18개와 보조 목적지6개를 연결한다. 주제 카드·칸반보드 등 기존 실제 기능명을 유지한다.
- 굵은 분류 제목과 접기/펼치기, 얇은 구분선, 하위 목록 들여쓰기, 현재 항목 배경/왼쪽 표식과 현재 분류 밑줄을 연결한다. 행은 기존 control-height와 글자/간격/색 토큰을 재사용한다.
- 접힘은 초기 모두 펼침. `${storagePrefix}:sidebar-groups:v1`에 기기별 표시 선호만 저장한다. namespace/소유자별 분리, 손상 값은 기본값으로 복귀, 저장 실패는 현재 세션의 조작을 유지한다. 기존 개인 공부 내용이나 기존 저장 키를 덮어쓰지 않는다.
- 메뉴 스크롤은 데스크톱 `${storagePrefix}:sidebar-scroll:v1`, 좁은 메뉴 `${storagePrefix}:mobile-sidebar-scroll:v1`의 탭별 sessionStorage이다. 같은 탭의 재열기/새로고침과 기기별 접기 선호를 구별한다.
- 기존40rem 경계를 재사용한다. 넓은 면은 좌측 메뉴, 좁은 면은 상단 ‘전체 메뉴’를 열어 같은 분류/순서로 접근한다. 선택하면 닫고 목적지 본문에 초점을 이동한다. Escape는 닫고 열기 제어로 초점을 돌린다. modifier-click은 원래 링크 동작을 유지한다.
- 백업·휴지통·초안·도움말·소개는 공통 도구에 직접 노출하고 내 생각 다시 보기는 기록·계획으로 이동했다. 기존 화면 설정과 계정 제어를 유지한다. 개인자료/초안/ID/학습 의미/Canvas/권한과 병행 소스를 보존한다. 운영 DB/RPC/Edge 변경은 없다.

## 확인과 공개 근거

변경 관련 타입·토큰·생산 빌드, 단위/이동 통합 검사, 다섯 WebKit 환경에서 메뉴 이동·현재 항목·키보드·접힘/스크롤 복원·검색 맥락·입력 초안·선호 저장 실패·원자료 불변을 확인한다. 스크롤 이벤트 직후 새로고침에도 위치가 남도록 pagehide에서 한 번 더 보관한다. 목차 이름 수정 단위 검사의 text selector가 닫힘 전환 중 창 제목까지 찾는 문제를 실제 menuitem 역할로 좁혔다. 원래 검사의 저장 실패/재시도/항목별 초안 요구는 유지한다.
