## 명칭 적용과 확인

`manseeksong os`를 현재 프로젝트·앱의 표시 이름으로 정했습니다. 앱의 두 브랜드 요소, 브라우저 제목, 웹앱 설치 name/short_name, 공통/웹앱 AGENTS와 README 및 제품 결정에 반영합니다. 패키지/폴더/저장 키·형식/ID·원문/초안/이력/개인 설정/배치·서버/인증·공개 주소·PWA 시작 주소/범위/아이콘 주소는 유지합니다. 명칭 변경으로 학습 이외의 생활 전반의 추가 기능을 확정하지 않습니다.
