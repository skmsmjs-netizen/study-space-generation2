# 목차 기반 암기항목 실제 생성 확인 · 2026-10-01

사용자 ‘너가 한번 시험삼아서 해봐’에 따라 5491 개인 앱의 기존 API 연결을 사용했다. 기존 대학수학 과목은 수정하지 않고 ‘암기 생성 확인용’ 과목과 ‘옴의 법칙: 전압·전류·저항과 적용 조건’ 합성 주제를 별도로 등록했다. 공부 수행·사용자 응답·숙달 자료로 해석하지 않는다.

실제 화면에서 기본 3개와 짧은 출제 초점을 넣어 생성했다. 첫 요청은 API_BUSY로 공급자 호출 전 차단됐다. 운영 예약 메타데이터를 읽기 전용으로 확인하여 이전 요청들이 정산되고 미확인 예약이 없는 것을 확인한 뒤 직접 다시 생성했다. 자동 재시도·예약 삭제·사용량 초기화·키 변경은 하지 않았다. 두 번째 요청에서 공식과 단위, 일정한 저항에서 전압/전류 비례, 온도/비옴성 소자의 적용 조건에 관한 질문·답안 3개를 받았다. 답안의 내용은 수동 검토했다. 클라이언트의 10초 시간 제한 오류 없이 결과를 받았지만 정확한 응답 시간은 독립 측정하지 않았다.

준이 세 항목을 검토해 등록했다. 서버 저장 표시와 동일 브라우저 새로고침 후 3개 보존을 확인했다. 쪽지시험을 열어 1/3 문항, 글·스케치 답안 입력, 기준 답안 미노출을 확인했고 응답·채점은 입력하지 않았다. 사용자가 확인할 수 있도록 시험 첫 문항을 열어 두었다. 다른 기기 수신·실제 학습 효과는 확인 범위 밖이다.

병행 API 사용이 있어 계정 집계 차이를 이번 시험 비용으로 환산하지 않는다. 코드 수정·서버 재배포·공개 배포는 필요하지 않았다. 확인용 과목/주제/3항목은 결과 확인을 위해 보존했다.
