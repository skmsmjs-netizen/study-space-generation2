## 선정과 실제 연결

공식 [API 요금](https://developers.openai.com/api/docs/pricing)과 [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [Spend limits](https://developers.openai.com/api/docs/guides/spend-limits), [키 보호](https://developers.openai.com/api/docs/guides/production-best-practices), [Supabase Vault](https://supabase.com/docs/guides/database/vault)를 확인했습니다. 기존 Supabase·소유자 인증·자료 생성 계약을 재사용하고 유료 서버나 외부 자동화 서비스를 새로 구매하지 않았습니다. 공식 API 키 등록 전용 도구는 현재 세션에서 찾지 못해, 앱에서 직접 입력하고 승인된 소유자 세션으로 서버에 전송하는 연결 화면을 구현했습니다.

기본 모델은 GPT-6 Luna입니다. Standard 입력 US$0.10/백만 토큰, 출력 US$0.50/백만 토큰으로 확인했습니다. 입력 20,000/출력 5,000 토큰의 가정 작업은 US$0.0045, 달러당 1,400원을 가정하면 약 6.3원입니다. 실제 자료의 토큰 수·추론 출력·재생성 횟수와 세금/환율은 별도이며 모델의 한국어 강의/수식 품질은 실제 호출 전까지 미검증입니다. 비싼 모델로 자동 전환하지 않습니다.

새 계정은 [공식 선충전 안내](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing)에 따라 최소 US$5 충전이 필요하며 구매 잔액은 1년 뒤 만료됩니다. 충전 화면의 기본 자동 충전은 사용자가 꺼야 합니다. 앱은 결제·잔액 충전·자동 충전 설정을 수행하지 않습니다. Plus 구독과 API 결제는 별개입니다.

## 비용과 키 보관

- 앱의 기본 월 상한은 US$10, 선택 US$1/2/3/6/10이며 서버에 보존합니다. 사용자는 결제 화면과 앱에서 필요한 한도를 선택합니다. 앱 상한은 UTC 월 기준이며 다른 앱의 키 사용·세금·환율과 기존 Supabase 비용은 포함하지 않습니다.
- 소유자 personal 계정, 승인 상태, 현재 Auth 세션을 서버에서 반복 확인합니다. 일반 회원/관리자 역할이나 demo/test 공간은 AI 권한이 아닙니다. RPC와 테이블은 일반 클라이언트에서 사용할 수 없습니다.
- 키는 서버 Vault에 암호화하고 클라이언트 응답·localStorage·IndexedDB·학습 자료/백업·소스에 넣지 않습니다. 화면은 password 입력만 제공하고 성공/실패 후 입력을 지웁니다. 등록만으로 실제 API 권한·잔액 확인을 성공이라고 표시하지 않습니다.
- 키 교체/일시 중지/해제는 사용 집계를 초기화하지 않습니다. 키 삭제는 Vault만 삭제하며 기록을 보존합니다. 계정 삭제의 settings cascade는 Vault 키도 삭제합니다.
- 실제 호출 직전에 DB advisory lock과 행 잠금으로 예상 최대 비용을 확보합니다. 진행 중/최근 응답 미확인 예약은 동시 호출을 막고, 오래된 미확인 예약도 월 합계에 남습니다. 요청 UUID 중복도 거부합니다.
- 입력 UTF-8 바이트+4,096 여유를 토큰 상한으로 보고 출력은 8,000 토큰으로 제한합니다. 표준 장문/캐시 쓰기까지 보수적으로 덮도록 입력 US$0.25/백만, 출력 US$0.75/백만으로 예약·집계합니다. 이는 실제 청구서가 아니며 일찍 상한에 도달할 수 있습니다. 요금표 변경 시 이 계수를 다시 확인해야 합니다.
- 응답 usage의 추론 포함 출력으로 보수 집계하고, 응답 단절·중단·usage 미확인·정산 실패는 예약을 풀지 않습니다. 반환된 일부 결과/형식 실패도 생성 비용을 없던 것으로 취급하지 않습니다. 공급자 호출은 1회이며 자동 재호출·고가 모델 fallback·검색/파일 저장/음성 API를 쓰지 않습니다. `store:false`는 사용하지만 OpenAI의 전체 데이터 보존 정책을 바꾸는 설정이라고 주장하지 않습니다.
- 파일 추출/OCR/전사문 가져오기는 API를 호출하지 않습니다. 현재 화면의 녹음·전사 입력은 병행 작업에서 채택한 클로바노트 전사문/파일 흐름을 보존했습니다. 외부 전사 서비스 자체의 가격이나 정확성을 무료·완료라고 보장하지 않습니다.

## 확인 범위

`work/openai-api-20261001/verification.json`이 이번 작업의 실행 결과 정본입니다. 관련 자료/생성/키 패널 33검사와 클라이언트 3검사, 낮은 상한 선택 1검사, 예산 SQL 16조건, 타입/프런트 빌드/전용 백엔드 번들을 확인했습니다. 초기 병렬 검사의 9실패를 숨기지 않고, 패널 matcher 2건 수정 및 바쁜 공유 머신의 기존 자료 검사 timeout을 한 worker/30초로 재검증했습니다. SQL의 정규식 반복 제한과 Vault 열 이름 충돌도 적용 전에 수정했습니다.

실제 Supabase에는 `openai_api_budget` 및 `openai_api_default_budget` 마이그레이션과 `study-openai-api` v1을 적용했습니다. 실제 Vault에서 합성 키 암호화/키 없는 상태 조회/진행 중 차단/상한 초과/사용 집계 불변/세션 거부/키 삭제를 트랜잭션으로 검사하고 rollback했습니다. 무인증·무효 토큰의 status 401, 실제 로그인한 5491 화면의 키 미등록/US$10/US$0을 확인했습니다. 학습 자료와 실제 API 키는 시험에 사용하지 않았습니다.

다섯 WebKit 기기 모사에서 합성 인증/서버 응답으로 키 입력·비용 확인·상한 선택·저장·키 입력 지움·중지/재개·reload·저장 실패·원문 보존·가로 넘침 없음·유료 호출 0을 확인했습니다. 이는 실제 iPhone/iPad와 실제 OpenAI 결과의 증거가 아닙니다. 공유 저장소 전체가 계속 변경되므로 검증 사본·실제 5491에 적용한 API 클라이언트/패널/관련 문구와 공유 최신 전체를 구별합니다.
