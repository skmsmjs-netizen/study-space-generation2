# 작은 도구를 바로 쓸 수 있는 개인 공부 공간

채택일: 2026-10-01. 사용자 「본 프로젝트에 지침화하고 반영해」에 따라 [위젯 라운지](https://minseok-widget-lounge.bobmanseek.chatgpt.site)에서 확인한 표현과 흐름을 ManSeekSong OS에 적용합니다. 사용자가 ‘좋았다’고 밝힌 사실과 준이 제안한 이유의 해석을 구별합니다. 이번 요청은 아래 설계 방향의 채택이며 과거의 개인 감정·사용 효과가 증명됐다는 뜻은 아닙니다.

## 적용할 다섯 기준

1. **차분한 바탕에서 중요한 값과 행동을 먼저 보이게 합니다.** 중성 면·얇은 경계·여백·글자 위계를 사용합니다. 시각이나 실제 기록 값은 읽을 크기로, 설명은 바로 옆의 짧은 문장으로 둡니다. 기존 의미색·서체·테마·터치 영역·포커스 대비를 유지합니다. 모든 목록의 카드화·새 장식을 강제하지 않습니다.
2. **하나만 사용해도 과업을 끝낼 수 있게 합니다.** 기록·자유 글·주제 설명·메모는 전체 생활/공부 체계 등록을 선행조건으로 삼지 않습니다. 목적·필요한 입력·핵심 행동을 같은 영역에 두고 기존 저장·취소·복귀로 연결합니다. 날짜·공부법·상세 설명을 새 필수 입력으로 만들지 않습니다.
3. **생활과 공부의 순간에 맞는 이름을 씁니다.** ‘공부한 뒤’, ‘생각이 떠오르면’, ‘하나를 설명해 보면’처럼 진입 상황을 말하고 버튼에는 실제 행동을 씁니다. 이는 사용자가 고르는 길잡이이며 감정·피로·의도·숙달을 자동 추정하는 기능이 아닙니다. 기존 과목·일정·자료의 이름과 원문은 보존합니다.
4. **입력 전에도 현재 위치를 알 수 있는 쓸모를 제공합니다.** 날짜·시각은 입력 없이 보이고 남긴 기록의 변화·일정은 기존 근거와 단위로 표시합니다. 시계는 한국 시간임을 명시합니다. 시간의 경과와 공부량·성취를 구별하며 임의의 하루 시작/끝을 진척률처럼 제시하지 않습니다. 계속 움직이는 장식이나 초 단위 갱신을 강제하지 않습니다.
5. **작고 구체적인 말로 돕고 확인하지 못한 것은 평가하지 않습니다.** 바로 할 수 있는 행동을 짧은 존댓말로 안내합니다. 미기록·부분 수행·불확실과 실패를 구별합니다. 체크나 시계·습관 기록을 이해·독립 해결·학습 효과로 환산하지 않으며 오류/저장 상태를 사실대로 유지합니다.

## 반복 사용과 자료 누적

- 홈의 기본 도구는 세 가지 진입으로 유지하고 기록 수에 따라 버튼을 늘리지 않습니다. 전체 기능은 기존 메뉴에서 찾습니다. 메모/최근 주제/기록은 제한된 요약과 전체 보기 경로를 유지합니다.
- 긴 최근 기록은 홈에서 세 줄 미리보기로 제한하고 ‘기록 열기’에서 전체 원문을 제공합니다. 원문·공백·ID·수정 이력은 저장 단계에서 자르지 않습니다. 카드 배치는 가용 폭에 따라 자동 줄바꿈하며 좁은 창·확대 글자에서도 행동을 유지합니다.
- 시계는 독립 컴포넌트에서 분 경계에만 갱신합니다. 배경에서는 갱신을 멈추고 다시 보이거나 창에 돌아오면 현재 시각/날짜를 다시 읽습니다. 누적 타이머로 시간을 더하지 않고 화면 읽기 도구의 반복 알림을 발생시키지 않습니다.
- 시계 갱신으로 에디터·초안·커서·포커스·개인 배치를 다시 만들지 않습니다. 시계에 별도 저장 키/설정/서버 명령을 추가하지 않고 기존 기록·AI 권한을 유지합니다.

## 기존 기준과 도구

[Nielsen의 사용성 원칙](https://www.nngroup.com/articles/ten-usability-heuristics/) 중 익숙한 언어·기억보다 화면에서 확인하기·핵심 정보에 집중하기를 재사용했습니다. 이는 일반적인 사용성 휴리스틱이며 개인 선호·학습 효과를 보장하는 법칙은 아닙니다. 기존 [Notion 중심 기준](../../docs/Notion%20중심%20UI%20UX와%20벡터%20도해%20기준.md)·[디자인 시스템](design-system.md)의 토큰·Card·Button과 기존 기록/자유 글/주제 카드/메모 저장 경로를 사용합니다. 시각 표시는 브라우저 Intl.DateTimeFormat을 사용하고 맞춤 구현은 독립 시계와 홈의 과업 묶음에 한정합니다. 별도 라이브러리·외부 전송·로그인을 추가하지 않습니다.
