# 학습자 입력을 바탕으로 GPT가 할 수 있는 작업 조사

조사일: 2026-10-01. 요청: “gpt가 학습자가 입력한 데이터를 바탕으로 할 수 있는 작업들을 조사해봐.”

## 판단과 범위

GPT의 활용 범위는 기록의 표현 보조, 자료의 재구성, 질문·힌트·피드백, 기록 간 변화 해석까지 확장할 수 있습니다. 다만 필요한 입력이 서로 다릅니다. 주제 이름과 체크만으로 특정 오개념·문제별 오류·독립 수행 능력을 알아낼 수는 없습니다. 아래 20개는 연구·공식 문서에서 확인한 작업 유형을 현재 앱에 맞게 풀어 쓴 후보이며, 전부의 구현·학습 효과·제품 채택을 뜻하지 않습니다.

현재 평소 입력은 주제 단위의 기록·체크·선택 메모입니다. 학습 내용이 담긴 자유 글이 있는 경우와 없는 경우를 구분합니다. 문제 본문·번호·모범답안·개념별 혼동 관계가 이미 수집됐다고 가정하지 않습니다. 실제 답변이나 자료가 선택적으로 제공된 경우에만 그 내용을 근거로 확장합니다.

이번 읽기에서는 `src/domain/model.ts`의 기록·메모/펜 흔적·복습 참고 설명·평가 이력·코드/실행 결과 계약과 `src/domain/study-material.ts`의 원문·원문 구간·요약·카드 근거 계약을 확인했습니다. 자료형의 존재를 실제 개인 자료가 채워져 있다는 증거로 쓰지 않습니다. 최신 인계에 강의 자료 입력/정리의 별도 개발 작업이 있으므로 해당 작업을 새 GPT 기능이 완성됐다는 증거로 쓰거나 덮어쓰지 않습니다.

제품 조건은 [GPT 연결 설계](chatgpt-plus-design.md)의 Plus 기준·추가 크레딧/유료 API 자동 전환 없음·민석 전용을 유지합니다. 연구에서 다른 모델이나 API를 사용했더라도 해당 비용·제공 경로를 제품에 자동 채택하지 않습니다. 개인 기록을 외부로 보내거나 생성 실험을 실행하지 않았습니다.

## 조사에 적용한 기존 방법과 기준

학습 방법의 판단에는 [Dunlosky 등의 학습 기법 연구 종합](https://journals.sagepub.com/doi/10.1177/1529100612453266)을 참고했습니다. 이 연구는 연습 시험/능동인출과 분산 연습에 비교적 넓은 효과 근거를, 자기 설명에는 조건부 근거를 제시합니다. GPT가 자동으로 요약한 글을 읽는 효과를 검증한 연구는 아닙니다. 따라서 요약은 기록을 다시 찾고 읽는 편의에, 인출 질문은 학습자가 답을 떠올리는 연습에, 풀이 검토는 자신의 이유를 설명하고 확인하는 데 연결합니다. 복습 간격은 앱의 기존 계산을 재사용합니다.

GPT 작업의 가능성에는 공식 입력·출력·요금제 문서를, 문항과 피드백의 품질에는 원 연구를, 학습 효과에는 대조군이 있는 교육 실험을 각각 사용했습니다. 공식 지원 범위·연구의 조건부 결과·이 앱을 위한 설계 제안을 구별합니다. 현재 사용한 OpenAI 문서 스킬과 웹 검색은 근거 확인 도구이며, 아래 20개 묶음은 공인 표준이나 효과가 검증된 일괄 패키지가 아닙니다.

## 1. 기록하고 다시 읽는 일을 돕는 후보

대상은 현재 열어 둔 메모/기록의 선택한 부분을 기본값으로 합니다. 모든 주제를 별도로 등록하거나 특별한 표식을 입력하도록 요구하지 않습니다.

| --- | --- | --- | --- | --- |
| T01 | 말로 쓴 식·부분 수식을 완성하여 수식 입력 부담 줄이기 | 선택한 글, 명시한 개념, 주변 조건·기호; 필요하면 원자료 | 편집 가능한 수식 후보·기호 뜻·성립 조건 → 메모의 보완안 | 수식 불편은 사용자가 언급한 필요입니다. 표현 변환과 새로운 지식 보충을 표시하고, 여러 식이 가능하면 짧게 확인합니다. 입력 불편으로 비운 부분을 지식 부족으로 판정하지 않습니다. |

| T04 | 메모 안의 의문·이유·예외·다음 행동을 나누기 | 자유 글에서 해당 내용이 실제로 나타나는 부분 | 원문 위치가 붙은 분류 후보 → 메모의 찾아보기 | 추출과 실행을 구분합니다. “다음에 해 보기”를 확정 일정/의무로 만들거나 질문을 이미 해결한 것으로 바꾸지 않습니다. |
| T05 | 용어 풀이·번역·개인 용어집 만들기 | 실제 기록 속 용어와 문맥; 교재의 정의가 있으면 함께 | 원어·풀이·분야별 뜻 → 별도 참고 설명 | 동음이의어·교수의 특수 정의를 일반 정의로 덮어쓰지 않습니다. 원자료 설명과 모델의 보충 설명을 구별합니다. |
| T06 | 선택 기록의 근거 있는 요약·남은 의문 정리 | 주제의 선택한 기록/필기/메모와 실제 날짜·버전 | 시도한 내용·남긴 의문·근거 ID → 별도 요약 | 글이 없으면 활동 사실까지만 요약합니다. 공부 체크를 이해·독립 해결·성공으로 환산하지 않습니다. |

T02의 기술적 가능성과 한계는 [OpenAI 이미지 이해 문서](https://developers.openai.com/api/docs/guides/images-vision)에서 확인했습니다. 자유 글을 일정한 구조로 추출하는 기술적 근거는 [구조화 출력 문서](https://developers.openai.com/api/docs/guides/structured-outputs)에 있습니다. 두 문서는 입력 판독이나 출력 형식의 지원을 설명하며, 수식의 정확성·학습 효과를 보장하지 않습니다.

## 2. 입력한 내용을 이해·연습에 쓰는 후보

대상은 내용이 있는 메모 또는 사용자가 제공한 교재/강의 자료 구간입니다. 실제 문제·답안이 필요한 작업은 요청하는 순간에만 해당 내용을 제공합니다. 평소 공부 기록에 문제 번호·전체 풀이를 필수로 추가하지 않습니다.

| ID | 작업과 쓰일 상황 | 필요한 입력 | 결과와 저장 위치 | 추가 부담·판단 한계 |
| --- | --- | --- | --- | --- |
| T07 | 같은 내용을 다른 말·예시·표현으로 설명 | 내용이 있는 기록/자료 구간, 사용자가 원하는 설명 방식 | 쉬운 설명·수식↔문장·수치 예 → 별도 참고 설명 | 단순화하면서 원문의 조건을 없애지 않습니다. 학습 스타일·수준을 자동 확정하지 않고 요청한 방식만 조정합니다. |

| T15 | 답안 피드백·오류 위치와 이유 후보 제시 | 문제·실제 답안·조건·모범답안/채점 기준 또는 검증 도구 결과 | 근거 문장·오류 후보·빠진 설명·고쳐 볼 질문 → 원답안 옆 검토안 | 계산·단위·방법·설명 누락을 구별합니다. 오개념의 원인은 가설이며 확정하려면 후속 응답이 필요합니다. 정답 근거가 없으면 공식 점수/자동 합격 판정을 하지 않습니다. |

| T17 | 코드·실행 결과를 바탕으로 설명·수정·연습 제안 | 실제 코드·입력값·컴파일/실행 결과·사용자 설명 | 오류 위치·제어 흐름·개선 후보·다른 입력 테스트 → 코드 옆 설명 | GPT의 코드 예측과 실제 실행 결과를 구분합니다. 실행과 격리는 기존 실행기가 담당하고 성공을 공부 완료나 독립 작성 능력으로 처리하지 않습니다. |

자료를 설명·개념도·여러 표현·연습으로 변환한 사례는 [Learn Your Way의 저자 연구보고서](https://arxiv.org/html/2509.13348v1)에 있습니다. 이 보고서는 Gemini로 구현한 복합 시스템의 연구이며, 개별 기능마다 독립 효과가 증명됐거나 현재 GPT 연결에서 같은 기능이 제공된다는 뜻은 아닙니다.

문항 생성은 [Scaria 등의 교육 질문 생성 연구](https://arxiv.org/abs/2408.04394)에서 검토했습니다. 충분한 맥락을 제공했을 때 유용한 문항을 생성할 수 있지만 모델별 차이가 있었고 자동 평가와 전문가 평가가 일치하지 않았습니다. 오래된 연구 모델의 수치를 현재 연결 계정 모델의 품질로 재사용하지 않습니다.

답안 검토는 [Gohr 등의 학부 수학 피드백 연구](https://aclanthology.org/2026.bea-1.55/)에서 참고했습니다. 채점 기준을 제공하는 구성은 전문가 점수와의 상관을 개선했습니다. 다만 65개의 한 기관·한 과목의 저자 작성 통제 문항이며, 평가 일부를 LLM이 수행했고 실제 학습 효과는 측정하지 않았습니다. 이 연구만으로 학습자 오류의 원인이나 자동 채점의 신뢰성을 보장할 수 없습니다.

## 3. 쌓인 기록을 돌아보는 후보

선택한 주제·기간의 기록을 앱이 먼저 가져오고, GPT는 그 안의 실제 글을 비교합니다. 주제별 세부 설명이나 자기 반성 글을 매일 새로 쓰게 하는 기능으로 만들지 않습니다.

| ID | 작업과 쓰일 상황 | 필요한 입력 | 결과와 저장 위치 | 추가 부담·판단 한계 |
| --- | --- | --- | --- | --- |
| T18 | 시간에 따른 질문·설명·자기 정정의 변화 정리 | 같은 주제에 연결된 여러 실제 기록·원문·날짜 근거·버전 | 이전 표현↔새 표현·반복한 질문·근거 위치 → 주제 회고 | “이렇게 썼다”는 변화만 확인합니다. 질문을 다시 언급하지 않은 것을 해결로 처리하지 않으며, 글이 길어진 것을 실력 상승으로 환산하지 않습니다. |
| T19 | 다음 공부의 작은 행동·회고 질문 제안 | 실제 막힘/의문/사용자 목표·예정 작업·앱의 기존 복습 후보; 계획 조정에는 사용자가 제공한 시간/부담 | 근거 있는 작은 행동과 선택적 계획 조정안 → 기존 다음 공부/계획의 제안 영역 | 미기록을 실패로 만들지 않고 제안을 밀린 의무로 쌓지 않습니다. 실제 연결된 자료만 열게 하며 총량·복습 날짜·횟수는 기존 계산 규칙이 맡습니다. 감정·생활 상태는 사용자가 쓴 범위를 넘어서 추론하지 않습니다. |
| T20 | 음성으로 남긴 생각을 기록·복습용 글로 재구성 | 사용자가 제공한 받아쓴 텍스트; 원음은 별도 지원/권한 확인 시에만 | 발표/설명 원문의 정리·질문·요약 → 원문과 연결된 메모/자료 | 현재 Plus 연결 경로는 음성·영상 입력과 받아쓰기 API를 지원하지 않습니다. 이미 받아쓴 글을 GPT가 정리하는 작업과 원음을 전사하는 작업을 구분합니다. 다른 구독/서비스의 권한과 비용을 Plus에 포함됐다고 하지 않습니다. |

T18·T19는 현재 데이터 계약과 사용자 보존 요구를 바탕으로 도출한 적용 후보입니다. 이 앱에서 개인별 추천 정확성이나 장기 학습 효과를 검증한 것은 아닙니다. T20의 경로 제한은 [공식 요금제 연결 제한](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)에서 확인했습니다.

## 4. 연구에서 확인한 중요한 갈림길

### 설명·피드백이 도움이 될 수 있지만 구조가 필요합니다

[Kestin 등의 2025년 연구](https://www.nature.com/articles/s41598-025-97652-6)는 대학 기초 물리의 194명을 대상으로 두 수업 주제를 비교한 무작위 교차 실험입니다. 교사가 준비한 문제별 해설·단계별 진행·응답 피드백을 갖춘 AI 튜터에서 더 높은 단기 평가 결과가 나왔습니다. 범용 채팅의 사용 효과, 전 과목·장기 기억·우리 앱의 효과로 확대하지 않습니다.

우리 앱에 대한 판단은 문제·풀이·기준 없이 일반 챗봇에게 평가를 맡기기보다, 실제 원문과 확인된 해설을 전달하고 사용자가 어느 단계에서 도움을 받았는지 구분하는 편이 타당하다는 것입니다. 이는 연구에서 도출한 설계 해석입니다.

### 쉽게 완성한 결과가 혼자 할 수 있는 능력을 뜻하지 않습니다

[Bastani 등의 2025년 PNAS 연구의 저자 제공 원문](https://hamsabastani.github.io/education_llm.pdf)은 터키 고교 수학에서 AI 도움을 받는 연습과 이후 도움 없는 시험을 구분했습니다. 일반형 GPT 사용군은 도움 없는 평가에서 불리한 결과를 보였고, 교사의 해설·힌트를 활용하는 구성은 그 부정적 결과를 크게 줄였습니다. 모든 GPT 사용이 해롭다는 주장이나 장기 효과의 증거로 쓰지 않습니다.

따라서 수식 입력 보조와 능동인출을 같은 동작으로 묶지 않습니다. 원래 아는 식을 입력하기 편하게 옮기는 경우에는 바로 후보를 보여줄 수 있지만, 기억해서 쓰는 연습에서는 먼저 학습자의 시도를 받고 답을 뒤에 제공합니다. 빈칸을 보고 그 목적을 자동 추정하지 않습니다.

## 5. 현재 앱에서의 선정과 사용 흐름

### 먼저 검토할 세 가지

1. **수식 표현 보조(T01).** 사용자가 직접 언급한 입력 불편을 해결합니다. 현재 메모의 선택 글 → 수식 후보·조건 미리보기 → 선택 반영·되돌리기를 연결합니다. 사진 인식(T02)은 사진/손글씨 이용 필요와 연결 경로가 확인되면 붙입니다.
2. **현재 기록의 요약·의문 정리(T04·T06).** 기존 채택 역할을 구체화합니다. 현재 주제 또는 선택 기록을 읽고 원문으로 돌아갈 수 있는 요약을 별도 저장합니다. 내용이 없는 체크 기록은 활동 요약까지만 제공합니다.
3. **실제 자료의 인출 질문(T13).** 자료나 내용이 있는 참고 설명이 있을 때의 조건부 후보입니다. 이미 진행 중인 강의 자료 카드 구조를 재사용할 수 있는지 확인합니다. 새 등록 부담이 필요한데 기존 주제 카드로 충분하다면 확장하지 않습니다.

이 순서는 수식 불편이라는 확인된 필요, 이미 채택한 기록 정리 목적, 조건부 확장을 구별한 판단입니다. 모든 후보를 우선 구현하거나 학습 효과가 큰 순서로 주장하지 않습니다. 기존 다음 공부 제안(T19) 합의는 유지하되 단순 기록 횟수나 제목으로 새로운 학습 진단을 만들지 않습니다.

### 사용자 흐름 후보

- **메모에서:** 현재 글의 선택 부분 → 원하는 보조 작업 선택 → 원문 옆 후보/근거 → 넣기·수정·취소 → 원문과 적용 이력 보존. 모든 메모에 표시나 입력을 추가하지 않습니다.
- **자료에서:** 사용자가 제공한 구간과 실제 원문 위치 → 요약/설명/질문 후보 → 답 숨김·시도·근거 보기 → 선택한 결과만 별도 저장. 원문 자료는 그대로 둡니다.
- **풀이에서:** 해당 문제와 실제 시도 → 사용자가 요청한 힌트 또는 검토 → 근거·고쳐 볼 부분 → 답안 수정과 도움받은 결과를 구분해 보존. 평소 기록에 풀이 입력을 필수로 넣지 않습니다.
- **주제에서:** 선택한 기간/기록 → 앱이 해당 원문과 계산된 사실만 전달 → 변화 요약/작은 다음 행동 → 기존 제안 영역에 선택 저장. 없는 자료·등록하지 않은 문제로 이동시키지 않습니다.

## 6. Plus 조건에서 기술적으로 구별할 일

[공식 연결 경로의 제한](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)은 선택 모델이 받는 텍스트·이미지·파일 입력을 허용하지만, 음성/영상 입력·Files 업로드 API·전사 API는 허용하지 않습니다. 이미지 생성·호스팅 File Search·Code Interpreter 등도 이 경로에서 지원하지 않습니다. 따라서 일반 ChatGPT 화면이나 유료 API에서 가능한 일을 이 앱의 Plus 연결에서도 그대로 할 수 있다고 확정하지 않습니다.

- 그림을 **읽는 것**과 새 이미지를 **생성하는 것**을 구분합니다. 관계/절차 설명을 텍스트로 받고 앱이 편집 가능한 벡터로 그리는 후보는 별도로 검토할 수 있습니다.
- 내 자료 검색은 앱이 소유자·선택 범위·원문 위치를 확인해 관련 내용을 가져오는 방식으로 설계할 수 있습니다. 호스팅 File Search 지원을 전제로 하지 않습니다. 새 유료 임베딩/외부 검색 서비스를 자동 도입하지 않습니다.
- 수식의 계산·차원·특정 수치 검증 및 코드 실행은 별도의 검증 가능한 프로그램 결과를 사용합니다. GPT가 옳다고 재평가했다는 이유만으로 검증 통과로 처리하지 않습니다.
- 전사된 텍스트의 정리는 텍스트 작업입니다. 녹음 원음 전사·음성 출력은 별도 제공 경로·사용 권한·추가 비용 유무가 확인돼야 합니다.
- 출력 형식이 올바른 것과 내용이 올바른 것은 다릅니다. [구조화 출력 문서](https://developers.openai.com/api/docs/guides/structured-outputs)도 형식에 맞는 출력에 내용 오류가 남을 수 있다고 설명합니다. 현재 계정/모델 경로의 실제 지원을 확인한 뒤, 앱에서 근거 ID·원문 버전·형식·완료 응답을 검증합니다.
- 생성은 사용자 요청으로 시작하고 필요한 입력만 보냅니다. 한 번 받은 결과를 다시 열거나 저장 재시도할 때 GPT를 다시 호출하지 않습니다. 한도에서는 새 생성만 중단하고 원문·기존 결과·일반 공부 흐름을 유지합니다.

개인 자료·토큰을 다른 계정에 전달하지 않으며 서버의 민석 소유자 확인은 모든 작업에 적용합니다. 이 조사에서는 OAuth·실제 생성·배포·연구 실험을 실행하지 않았습니다.
