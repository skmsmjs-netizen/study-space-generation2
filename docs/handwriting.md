# 공통 필기 동작과 보존 계약

2026-10-01 사용자가 필기 보완과 참고할 기준을 요청하고 적용을 승인했다. 기존 메모·주제 카드의 인출 답안·암기시험 기준/응답에 같은 `MemoInkPad`를 연결한다. 전체 화면의 Notion 중심 미감과 공통 UI/토큰은 유지한다.

## 채택한 기존 기준과 적용 범위

| 종류 | 채택 이유와 실제 연결 | 한계 |

기존 공통 UI와 원문 저장 경로를 재사용한다. 라이브러리가 제공하지 않는 페이지 메타데이터, 부분 지우기, 선택, 기기 설정과 수정 이력만 필요한 범위에서 구현했다. 필기를 이미지로 변환하거나 원문 점을 간소화하지 않는다.

## 저장과 호환

- `MemoStroke`의 기존 `id/ink/width/points`를 유지한다. 선택 속성 `page`는 0부터 시작하며 없는 값은 첫 쪽이다. 각 쪽의 좌표는 기존 900×600이다. 새 쪽·확대·화면 크기 변경이 기존 점/필압을 재계산하지 않는다.
- 선택 속성 `pressureSensitive`는 표시 방식이다. 필압 원문은 켜짐과 무관하게 보존한다. 기존 선에 옵션을 소급 적용하지 않는다. 잘못된 페이지/필압/좌표는 기존 도메인 오류로 거부한다.
- 새 쪽에 실제 작성한 선은 기존 메모/답안 JSON과 서버 원장에 저장된다. 기기별 빈 쪽 수·현재 쪽·확대와 최근 수정 이력은 해당 문서의 `:ink-workspace:v1`에 저장한다. 빈 쪽 수·보기/펜 설정·빠른 되돌리기 이력의 서버 동기화는 이번 범위에 없다.
- 펜 색·굵기·손가락·필압 선택은 사용자/namespace별 `:ink-preferences:v1`에 저장한다. 문서 보기만 저장할 때 다른 열린 편집기의 새 펜 설정을 덮어쓰지 않는다. 지우개 모드와 도구 선택은 해당 편집기에서 유지된다.
- 최근 50개 편집 동작을 변경된 선의 이전/다음 값으로 보관한다. 전체 그림 50벌을 저장하지 않는다. 50은 이 프로젝트의 기기 저장 부담을 제한하는 기본값이며 외부 표준 수치가 아니다. 저장된 필기·원장 수정 이력의 보존 기간을 줄이지 않는다.
- 현재 필기와 수정 이력의 지문이 다르면 오래된 되돌리기를 자동 적용하지 않고 원문 사본을 보관한다. 읽기 실패도 원문을 자동 덮어쓰지 않는다. 저장 실패 시 현재 입력과 재시도 경로를 유지한다. 지문은 암호학적 검증이나 서버 인증이 아니다.
- 부분 지우기는 선을 여러 조각으로 나눈다. 첫 조각은 원래 ID, 추가 조각은 새 ID이며 경계의 필압을 보간한다. 되돌리기는 정확한 원래 점과 순서를 복원한다. 선택 복사만 새 ID를 만든다. 다른 쪽은 보존한다.
- 메모·Canvas·시험 결과·수행 근거의 읽기 화면도 쪽별 표시를 사용한다. 카드 목록은 첫 쪽 미리보기와 쪽 수를 표시한다. 새 페이지 메타데이터를 읽지 않는 구버전 화면은 여러 쪽을 겹쳐 표시할 수 있으므로 배포 시 프론트엔드 버전을 맞추고 이전 열린 탭을 갱신해야 한다. 기존 JSON 필드를 유지하므로 SQL 스키마 이관은 추가하지 않았다.

## 반복 사용과 완료 근거

목록은 처음 40개, 더 보기마다 40개를 표시하고 검색은 전체 메모의 글·과목/주제 이름에 적용한다. 편집기는 현재 쪽만 표시하며 기존 선의 표시를 재사용하고 입력 중 화면 갱신을 애니메이션 프레임으로 묶는다. 이 정책은 무제한 자료 성능을 보증하지 않는다.

검증 자료는 `work/ink-goodnotes-20261001/`에 있다. 합성 65개 메모의 숨겨진 원문 검색/더 보기, 20쪽·2,000개 선의 현재 쪽 표시/다른 쪽 보존, 부분 지우기/되돌리기/설정 실패/취소/재접속, 로컬 PostgreSQL JSON 왕복과 중복 재시도를 확인한다. 실제 Browser에서는 두 쪽 작성·부분 지우기·선택 이동·정확한 선 복원·저장/재접속·390px 확대와 가로 넘침을 확인한다. WebKit 다섯 환경의 변경 관련 검사는 `npm run test:devices -- --grep 'ink pages|memo text'`로 반복한다.

검사 수·실행 결과와 공유 의존성/병행 변경의 상태는 이번 작업의 `work/ink-goodnotes-20261001/README.md`와 최신 인계에 남긴다. 로컬 서버 합성 저장을 운영 서버·개인 계정·다기기 수신의 증거로 쓰지 않는다. 공개 배포와 물리 iPad/Pencil은 이번에 실행하지 않았다.
