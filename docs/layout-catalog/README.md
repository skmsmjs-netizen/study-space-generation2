## 검토에서 달라진 점

원본은 **화면 구조, 정렬 기준, 구도, 간격, Figma 도구, 구현 방식, 실패 조언을 함께 담은 사전**이다. 이 범위를 유지하면서 선택 축을 명확히 했다. Figma의 Fixed/Hug/Fill이나 8pt를 고르는 것으로 실제 화면 레이아웃을 정했다고 처리할 수 없게 구별했다.

원본의 Layout Guide·Grid Auto Layout·Auto spacing은 공식 문서로 확인했다. 4/8/12열, 70/30, 황금비, 버튼 고정 높이, 본문680–800px 같은 예시는 강제값으로 승격하지 않았다. Responsive/Adaptive의 설명, 음수 Gap과 CSS 대응, 일반 Auto Layout 자식의 Constraints, 표의 카드 전환, 말줄임과 모달의 복귀 조건을 보정했다. 공식 제품 설명·특정 디자인 시스템·관행·연구 관찰·CSS 초안·프로젝트 제안을 구별했다.

추가187–198은 기존 패턴을 구체화한 작업 패턴이다. 폭 조절 분할면, 도킹 작업면, 계층/상세, 원자료/주석, 곁면, 짧은 명령면, 질문/내 답/설명, 조절/그림/근거, 여러 그래프/원기록, 관계 지도/상세, 일정/선택 과업, 변경/실행/복구이다. 모두 새 엔진이나 새 기능 구현을 요구하는 뜻은 아니다.

## 천문대와 연결한 범위

- 창밖 픽셀 위젯은 전체 장면·비율·조작을 보존하고 테두리는 바깥에 더한다.
- 어두운 실내와 아래 종이 면을 구별하며 본문 기본 양쪽 정렬·마지막 줄 시작 정렬을 유지한다.
- 북쪽 공부 책상·서쪽 자료 책장·동쪽 탐구 작업대·남쪽 기록/계획 벽·위쪽 천장 조명의 기능 역할을 유지한다. 기존 JSON의 공통 자리 식별자 `global`은 변경하지 않고 천장 조명으로 설명한다.
- 채택된 닫힌 지식 모듈·뜻 있는 선/화살표·실제 순서를 과업에 연결한다. 시각적 대칭과 지식의 재구성 대응을 구별한다.
- 현재25역할/111엔터티 모두에 배치 후보를 연결했고, 앞으로 놓일 요소24종에도 적용 구조와 증가 조건을 정리했다.
- 색/치수 원본은 기존 baseline을 참조한다. 새로운 고급 기술과 실제 사용에 맞춰 조정할 수 있도록 기본값·내용 성장·전환·수동 설정·복귀·확인 조건을 함께 기록한다.

‘이 파일에 있는 레이아웃 중 하나’라는 요구는 **각 화면의 대표 패턴을 사전에서 선택하고 등록된 내부 패턴/전환형을 조합한다**는 해석으로 제안했다. 문서의 종류 분류와 후보는 이번 검토를 위한 편집 분류이다. 다음 OS 기준 작업에서 이 선택 규칙과 화면별 적용을 정본에 연결해야 한다.

## 확인과 한계

원본은 61,833바이트·3,688줄·36장·도입0번+본 항목1–186번이다. 보존본과 통합본 안의 원문이 첨부와 일치함을 확인했다. 추가 항목187–198의 번호 중복/누락, 패턴 참조, 현재25역할/111개 고유 엔터티의 대응도 확인했다.

이번에는 문서 파일만 생성했다. 웹앱/원격 Figma/배포를 변경하거나 111엔터티의 실제 렌더링을 전수 검증하지 않았다. 후보 배치의 실제 적합성은 대표 실자료·긴 글·자료 누적·좁은 화면·중단/복귀로 확인해야 한다. 특정 CSS masonry 버전, 구도와 도형의 학습 효과, 실제 기기·장기 사용은 이번 검토의 확인 범위 밖이다.

## 갱신 방법

```sh
python3 generation2/docs/layout-catalog/scripts/build_catalog.py
```

보존 원문에서 색인/통합본을 만들고 현재 기능 정체성 JSON에서 후보 표와111개 연결을 다시 생성한다. 기존 원문과 다른 첨부를 넘기면 덮어쓰지 않고 중단한다. `expansion.md`의 검토/패턴 본문은 사람이 수정하는 원본이고 역할 표만 표시된 경계 안에서 재생성한다. 자동 생성 자체가 제안 채택이나 실제 제품 동작을 뜻하지 않는다.
