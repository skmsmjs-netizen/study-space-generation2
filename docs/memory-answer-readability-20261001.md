# 암기 답안 수식 조판과 읽기 개선 · 2026-10-01

사용자 첨부 화면에서 암기시험의 기준 답안이 `\\(V=IR\\)`를 그대로 표시하고 비교 결과·질문·답안 구역이 잘 구별되지 않았다. 기존 KaTeX 표시 컴포넌트를 암기 항목/시험/비교, 자료 카드 보관함, 자료 퀴즈의 질문·보기·기준 답안, 목차 생성 초안 미리보기에 연결했다. 실제 사용자 원문·ID·그림·비교 판단·초안·저장 계약은 수정하지 않았다.

Q02/Q03/Q04/Q09/Q10/Q12/Q13 관련 범위에 기존 디자인 토큰·공통 입력과 KaTeX 공식 구분자/옵션을 재사용했다. [KaTeX 옵션](https://katex.org/docs/options)의 MathML 출력, 비신뢰 입력, 확장/크기 한도를 유지한다. 새 UI는 문항 번호/질문/주제를 구분하고 실제 구역 폭에 따라 두 답안을 나란히 또는 위아래로 배치한다. 비교 결과는 라벨과 숫자를 붙여 줄 바꿈하고 판정 입력은 필요한 폭만 사용한다. 생성/수정 원문은 편집 가능하게 유지하고 조판 미리보기를 함께 제공한다.

공통 API 프롬프트 v7은 모든 작업의 수학 기호/식을 인라인 또는 별도 행 LaTeX로 쓰고 직접 답/핵심 식/기호·단위/조건을 필요한 단락과 실제 줄바꿈으로 구분한다. 기존 한 번의 요청 품질·10초 대기/자동 재호출 없음·민석 전용 권한/예산은 유지한다. 기존 답안을 다시 생성하지 않고 표시를 고친다.

검증: 관련 단위 25건, 타입/앱 빌드, 디자인 토큰 0오류. iPhone 세로/가로·iPad 세로/가로/반쪽 창 다섯 WebKit에서 긴 수식의 가로 이동/키보드 초점·페이지 폭·답안 배치·접근성 axe 0위반·원문 공백/줄바꿈 저장 후 재열기를 통과했다. 최초 WebKit 기본 화살표 이동 미작동을 발견해 수식 영역에 명시적인 좌우 이동을 연결하고 최종 다섯 환경을 재검사했다. 생성 HTML은 문자로 유지하고 비신뢰 LaTeX 링크/그림은 실행하지 않는다. 기기 프로필을 물리 Pencil/IME/VoiceOver·실제 Sync 확인으로 확대하지 않는다.
