## 수정한 실제 동작

1. **Modal/Sheet:** 배경 pointerdown에서 닫던 것을 완료 click으로 변경했습니다. 취소·드래그·본문에서 시작/끝난 포인터는 닫지 않고 명시적 닫기/Escape·원문 초안 정책을 유지합니다. 진입/복귀 초점은 preventScroll을 사용합니다.
2. **useRoute/LoadingState:** 지연 화면이 준비될 때 원래 조작·스크롤을 복원합니다. 임시 로딩 화면에서 잘린 위치가 저장된 힌트를 덮어쓰지 않고, 빠른 이동 또는 사용자의 새 입력/휠/터치 조작 뒤 늦은 복원을 적용하지 않습니다. pointerdown의 읽던 위치는 실제 탐색 click 때만 반영합니다. 로딩 중 취소한 이동이 실제 전환으로 이어지지 않아도 본문 준비 후 위치 저장이 다시 가능해집니다. 가로 메뉴 초점은 메뉴의 scrollLeft만 조정해 본문을 유지합니다.
3. **ScreenBoundary/Workspace:** 지연 모듈 또는 화면 렌더 실패가 전체 앱을 흰 화면으로 만들지 않게 합니다. 본문 오류 안내·재시도와 본문 밖 기존 메뉴를 유지하며 다른 route에서는 정상 내용을 다시 표시합니다. 재시도는 페이지를 다시 열고 저장된 기록/초안을 삭제하지 않습니다. 아직 저장하지 않은 모든 값의 자동 복구를 보장하는 기능은 아닙니다.
4. **공통 CSS:** 스크롤바 공간을 안정적으로 확보합니다. 기존 버튼 색상·의미·크기와 병행 색 토큰 변경은 보존했습니다.
5. **수식 화면:** ResizeObserver에서 프레임마다 현재 폭·높이를 함께 relayout하고 종료 시 프레임을 취소합니다. 수식은 useLayoutEffect에서 삽입해 탐색 복귀 후 브라우저 scroll anchoring이 화면을 밀지 않게 합니다. 함수·메모·카메라/개인 저장 의미를 변경하지 않습니다.
