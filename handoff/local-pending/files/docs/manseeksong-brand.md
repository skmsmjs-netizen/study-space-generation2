## 3. 대표 과업: 이어가기

실제로 방문한 공부 대상과 자료·원문·초안을 연결한다. 홈에서 남은 작업으로 한 번에 돌아가며 읽던 위치·초점·커서를 가능한 범위에서 복원한다. 사용자가 명시적으로 남긴 다음 행동과 자동 제안은 구별한다. 삭제·소속 변경·다른 사용자·잘못된 저장 내용을 검증하고 연결할 수 없는 대상은 현재 과목 선택으로 복귀시킨다. 계정·namespace별로 분리하고 미기록을 미완·실패로 만들지 않는다. 기기별 보기 힌트와 서버의 공부 자료를 구별한다.

## 4. 지속 사용의 필수 세부 동작

한글 조합 중 저장/갱신으로 글자·커서를 끊지 않는다. 자료 열기/닫기와 재접속에 원문·초안·선택을 유지한다. 새 자료나 업데이트가 읽던 위치·개인 Canvas·수동 배치를 흔들지 않는다. 기기 저장/서버 반영/다른 기기 수신을 구별하고 두 편집본을 조용히 덮어쓰지 않는다. 수정·삭제에는 가까운 되돌리기와 이력을 제공한다. 누적 자료는 검색·과목·최근 사용으로 찾고 긴 글·모바일에서도 원문 확인/편집/복귀를 유지한다. 새 기능 소개가 기존 작업 복귀를 강제 차단하지 않는다. 완료는 관련 실제 결과로 판정한다.

## 5. 감각과 조작

현재 중립색/사용자 테마·서체·의미색을 유지한다. 글과 관계·여백이 중심이며 강조색은 필요한 선택/행동에 집중한다. 공통 토큰·UI·접근성 기준을 재사용한다. 문구→판단→버튼의 순서와 동사를 맞춘다. 모션은 변화의 위치/이유만 전달하고 실제 저장 지연을 숨기지 않는다. reduced-motion을 존중한다. 소리·진동·배경음은 기본 활성화하지 않으며 필요·환경·제어 가능성이 확인된 경우 선택 기능으로만 검토한다.

## 6. 개인화와 통제

과목·서체·읽기 폭·수동 배치·테마·알림 선호를 기존 계약에 따라 보존하고 수정/초기화/복귀를 제공한다. 평소 공부에 설계 화면을 강제하지 않으며 자세한 옵션은 필요할 때 펼친다. 예외·자유 입력·원문·이력은 삭제하지 않는다. 추천의 근거/대상/조건을 확인하고 바꾸거나 숨길 수 있게 한다. 현재 입력에 없는 문제 번호·개념·감정을 가정하지 않는다. 민석 전용 AI를 일반 사용자 혜택으로 승격하지 않는다.

## 8. 누적 기록의 재사용

현재 주제와 직접 연결된 과거 질문·원문·수정을 찾고 열 수 있게 한다. 수동 연결과 앱의 제안을 구별하고 제안을 숨기거나 수정한다. 현재 입력이 주제 단위라는 계약을 유지한다. 단어 유사성만으로 많은 기록을 강제로 노출하지 않는다. 과거 글을 현재의 정답으로 취급하지 않으며 원문/수정 이력을 함께 확인한다. 재사용은 실제 열기·가져오기 등 관측된 동작으로 기록하며 학습 성공을 추정하지 않는다.

## 9. 확인 가능한 진전

기록/재사용/복귀/수정과 독립 설명/정확성/숙달을 분리한다. 시간을 오래 쓰거나 체크를 많이 했다고 성장을 주장하지 않는다. 앱 밖 공부와 미기록을 구별한다. 연속 접속 끊김·밀린 의무·강제 보상을 만들지 않는다. 비교는 원문과 확인된 수행 근거가 있을 때만 제공한다.

## 10. 회사의 책임과 도움 요청

사용자가 같은 문제를 여러 번 설명하지 않도록 문의 내용·식별 번호·상태를 보존하고 내보낼 수 있게 한다. 2026-10-01 사용자 결정으로 문의 접수·회신 서비스는 제외한다. 도움말에서는 문제 상황을 기기에 메모하고 내보내는 기능만 유지하며 기존 문의 원문·ID·이력을 보존한다. 개인 글은 사용자가 포함 범위를 확인한 경우에만 첨부한다. 문의 접수·회신·응답 시간·SLA를 제공하거나 그 설정을 요청하지 않는다. 업데이트는 확인한 사용자 장면과 수정 결과로 설명하며 보고의 미확인 상태를 보존한다.

## 11. 결제 제외와 자료 접근

2026-10-01 사용자 결정으로 결제·유료 구독·청구·갱신·해지·유료 권한과 요금 안내 화면을 요구 범위에서 제외한다. 가격·결제 사업자·지원 회신 정보를 추가로 요구하지 않는다. 기존 계정·탈퇴의 삭제 범위와 자료 내보내기는 유지한다. 예전 이용 정보 주소는 저장·복구 도움말로 연결한다.

## 12. 사용자의 내용이 중심인 공유

처음 질문·수정·현재 설명 중 사용자가 고른 것만 미리보기 후 내보낸다. 이름/민감한 글/다른 자료를 자동 포함하지 않는다. 브랜드 표시는 작게 두며 원문·출처·버전 의미를 유지한다. 공유 버튼은 학습 성공이나 공개 게시를 의미하지 않는다. 다운로드와 외부 공유를 구별한다.

## 13. 연결된 과업 검증

첫 자료→입력→중단→재접속→다른 환경→이전 글 수정→오류 복구의 흐름을 필요한 범위에서 확인한다. 약속/복귀/보존/명료함/선택/감각/일관성의 일곱 축을 모두 관리한다. 코드/합성/브라우저/운영 서버/물리 기기/장기 고객 관찰은 별도 증거다. 이번 변경은 합의한 다섯 기기 모사 환경과 빌드/타입/디자인/관련 회귀를 확인한다.

## 14. 실제 재선택으로 검증

2–4주 실험의 대표 과업은 이어가기다. 실제 복귀 후 다음 행동·기록 재사용·공부 시작 부담·오해를 관찰한다. 로고를 가린 일관성 평가와 사용자의 자발적 브랜드 설명을 확인한다. 실제 재선택/추천과 말로 표현한 의향을 분리한다. 측정은 최소한의 내용 없는 이벤트로, 사용자 동의와 열람/내보내기/중단/삭제를 제공한다. 개인 글/키/비밀번호를 수집하지 않는다. 로컬 이벤트만으로 장기 효과나 충성도 확보를 주장하지 않는다. 실험 방법은 프로젝트 제안이며 검증된 효과로 표현하지 않는다.

## 적용 원칙

14절을 관리하되 사용자 결정으로 결제와 문의 접수·회신은 제외한다. 기존 구현 재사용, 새 구현, 외부 운영 정보 의존, 실제 관찰 대기를 각 항목별로 기록한다. 미검증 항목은 누락시키거나 완료로 승격하지 않는다. 판매·문의 외부 전송·공개 배포는 실제 권한/정보와 별도로 수행한다. 이번 채택만으로 다른 기능/서버/개인 배치/저장 키를 변경하지 않는다.
