## 현재 적용 범위 — 웹앱만 작업

종료한 구현의 보관본·지침·설치·원본 비교·호환 검사는 앞으로 읽거나 실행하지 않습니다. 과거 지침으로 돌아가는 링크와 이전 비교 미완을 후속 작업의 조건으로 삼지 않습니다. 현재 웹앱의 계약·코드·요청을 기준으로 진행합니다.

# 화면·기능·조작 QA Inventory

**2026-09-30 작업 순서 정정:** [작업 진행과 검증 정책](../../docs/작업%20진행과%20검증%20정책.md)을 따릅니다. 초안을 먼저 제시하고 검사는 변경·위험·실사용 단계에 맞게 선택합니다. 이 문서의 검사·완료 항목은 모든 초안의 선행조건이 아닙니다.

이 목록은 발굴 기능을 구현·검증에 연결하는 **예정 Inventory**입니다. 버튼이 존재하거나 동작한다고 확인한 목록이 아닙니다. 실제 DOM/화면과 연결하고 조작 artifact를 남긴 뒤 상태를 갱신합니다. 현재 웹앱의 관련 흐름만 검사하며 종료한 앱과의 비교 검사는 수행하지 않습니다.

2026-10-03: 모든 기능에서 VoiceOver 전용 지원·QA·완료 조건을 제외한다. [공통 적용 범위](voiceover-scope-20261003.md)를 따른다.

## 검증 기준

이 Inventory는 후속 검사 후보입니다. 이번 변경에 관련된 항목만 고르며 전체 목록·모든 Phase 완료를 새 초안의 입장 조건으로 만들지 않습니다.



- Hick: 기본 기록에서 불필요한 판단·반복 선택을 줄이되 필요한 기능·예외·자유서술은 보존합니다.
- Fitts: 자주 누르는 조작의 터치 영역·위치·거리와 키보드 가림을 확인합니다. CSS 크기 확인과 실제 엄지 조작은 별도입니다.
- Jakob: 뒤로·닫기·취소·최근 복귀가 브라우저/iOS 관습과 일치하고 맥락을 보존해야 합니다.
- Proximity: 대상·소속·설명·편집/삭제 조작이 같은 단위로 읽혀야 합니다.
- Von Restorff: 한 화면의 핵심 행동과 경고·시험 의미 색을 구별합니다. 모든 조작을 같은 강조로 만들지 않습니다.
- 정상 화면 외 Empty/Loading/Success/Partial success/Error/Offline/Syncing/Conflict/Disabled/Large-data를 필요에 따라 확인합니다. 내부 JSON·개발 버튼·불필요한 복구 컨트롤은 홈의 정상 상태에 노출하지 않습니다.

## A–G 조작 횟수 관찰표

시작 상태를 고정하고 click/tap 각각 한 번을 1회로 셉니다. 타이핑은 클릭 수에 합치지 않고 필드·문자 수를 별도로 기록합니다. 펼침·선택·저장·취소·복귀도 동작으로 셉니다. 화면 이동과 overlay 열기는 분리하고 최근 맥락이 있는 경우/없는 경우를 별도 측정합니다. 최소 흐름과 상세 선택 흐름도 합치지 않습니다. 이전 앱의 실측값이 없으면 ‘개선’ 또는 ‘악화 없음’을 주장하지 않습니다.

## 한 학기 E2E의 연결 범위

시험 namespace에서 학기 생성→여러 과목→깊이·동명·긴 제목의 목차→추가/수정/이동/정렬/삭제/복원→한 주제/복수 주제 공부→내용 없는 기록/부분/막힘/장문/중단·복귀/몰아쓰기→일정/할 일/과제/온라인 강의의 등록·변경·완료·취소·기한 미정/변경→검색·현황·Canvas→학기 중반 누적→시험 전후→학기 종료→다음 학기→이전 학기 조회를 연결합니다. 각 단계의 데이터 snapshot과 UI 증거를 남기며 시뮬레이션을 실제 한 학기 장기 사용 또는 학습효과로 표현하지 않습니다.
