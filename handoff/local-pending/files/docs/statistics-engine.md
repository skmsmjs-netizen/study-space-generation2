## 볼 수 있는 곳

홈에 최근 14일 공부 회차 그래프가 있습니다. 주 메뉴 `#/statistics`에서 날짜·과목·단원·주제 범위, 현재 지표·이전 같은 길이의 기간, 그래프·대체 목록, 확대, 막대/전체 근거·고정을 사용합니다. 고정한 근거는 당시 원문 사본을 표시합니다.

현재 자료에서 계산하는 지표는 다음 여덟 가지입니다. 이 구현을 흥미·능력·성적 추정 모형의 완성이나 과거 여덟 지표의 의미 대조 완료로 보고하지 않습니다.

| 지표 | 근거와 단위 |
| --- | --- |
| 공부를 남긴 회차 | 공부함/활동/반복이 있는 고유 session ID. 여러 주제·과목도 한 사건은 한 번 |
| 기록이 닿은 주제 | 현재 목차의 고유 topic ID / 현재 주제 수. 글만 남긴 기록도 포함 |
| 표시한 공부 활동 | checked 상태의 record ID + 활동 ID |
| 따로 남긴 반복 | 추가 반복 ID. exact는 확정, minimum은 하한, unknown은 미확정 |
| 글을 남긴 기록 | 비어 있지 않은 공부 기록 본문 ID |
| 도움 없이 확인한 수행 | 독립 pass/fail을 직접 남긴 고유 수행 사건 ID. 자기 보고 |
| 도움 없이 기준을 충족한 수행 | 도움 없음·pass의 수행 사건 ID. 새로운 문항·지연 조건 충족과 별개 |
| 다시 정리한 기록 | 실패와 연결된 교정 사건 ID. 교정 자체는 재확인 성공이 아님 |

날짜 exact/range/unknown을 원문 그대로 읽습니다. range가 기간에 모두 들어오면 확정 포함, 일부 겹치면 상한에만 포함하고 날짜 미정은 기간에 배정하지 않습니다. 그래프에는 exact 기록만 표시합니다. 반복 날짜를 기록 날짜에서 자동 추론하지 않습니다. 빈 기간·미응답을 실제 실패·0점으로 바꾸지 않습니다. 수행 이벤트는 최신 revision/knownAt/occurredAt 기준으로 계산합니다. 같은 이름·다른 ID는 합치지 않습니다.

시험 제외 표식·문제 최초 독립 해결·성적/흥미 추정 등 현재 모델에 없는 입력의 통계와 과거 지표 전체의 대응은 이 여덟 숫자로 대체하지 않습니다. 입체 막대와 시간순 구간 강조 재생, 직접 다음 구간 이동을 제공합니다. 재생에서도 계산값은 변하지 않으며 동작 줄이기 설정에서는 자동 재생을 비활성화합니다. 평면·키보드 조작·대체 목록을 함께 제공합니다.

## 일정·수행과 추천

홈 다음 공부의 `일정·선행 관계·추천 근거`를 펼칩니다.

- 시험/퀴즈: 과목·실제 주제 범위·날짜·선택 비중·원문을 저장합니다. 기존 확인 목표를 주제 ID로 연결하며 기준이 없는 범위는 표시합니다.
- 과제: 준비/제출을 독립적인 unknown/not-done/done 상태로 남깁니다.
- 온라인 강의: 재생/학습/출석 확인을 서로 독립적으로 남깁니다. 마감의 의미는 시험·제출·출석·개인·미정으로 구별합니다.
- 선행 관계/자료: 직접 고른 관계만 적용하고 순환·다른 과목 관계를 거부합니다. 목차 구조를 선행 공부로 환산하지 않습니다.
- 지연 확인: 목표에 필요한 일수와 수행 시 실제 지난 일수·확인을 각각 남깁니다. 같은 문항·도움 받은 성공·간격 미확인은 새 문항/지연 확인 기준 충족이 아닙니다.
- 방법 비교: 결과 확인 이전에 기준·방법·이전 점수·미래 확인일을 등록합니다. 독립 채점/같은 기준/귀속 조건이 확인되고 수행·기한 조건을 갖춘 비교만 사용합니다. 결측은 가능한 변화 구간에 남고 표본/관측/결측 조건이 부족하면 기본 추천을 유지합니다. 두 방법 이상의 충분한 비교에서 구간이 분리될 때만 방법 후보를 표시합니다. 관찰 자료이며 인과 효과·개인 능력 점수가 아닙니다.
- 추천 이력: 의미 있는 목표/수행/일정/관계 변경 시 당시 정책·모델·사건·기록 버전·결과를 자동 보존합니다. 명시적인 현재 추천 보관도 제공합니다. 초안의 한 글자마다 추천 이력을 만들지는 않습니다.

## 저장과 적용 상태

추천/일정은 선택적인 `learningPlans` 엔터티와 `saveLearningPlan` 공통 명령으로 연결합니다. 같은 버전 검사·operation 재시도·수정 이력·서버 소유권을 따릅니다. 기존 demo 추천 키는 첫 명시적 편집에서 복사하되 원본을 남깁니다. 개인 공간의 이전 로컬 추천은 별도로 읽고 사용자가 가져오기를 선택하기 전 자동 업로드하지 않습니다. 일정 편집 초안은 사용자/namespace/일정별 로컬 키에서 보존합니다.

서버는 `supportedCommands`에 `saveLearningPlan`을 응답해야 개인 공간의 새 일정 저장이 활성화됩니다. 서버 기능이 적용되지 않았으면 해당 조작을 잠그고 실제 상태를 안내하며 기존 공부 입력/통계를 유지합니다. 저장 성공과 서버 승인/전송 대기를 공통 저장소가 구별합니다.

서버용 코드·번들과 추가 마이그레이션 `202610010002_learning_plans.sql`을 준비했습니다. Supabase CLI가 `AccessTokenRequiredError`를 반환했으므로 실제 서비스 함수/SQL 적용·실제 서버 왕복은 아직 확인하지 못했습니다. 이 시점의 준비·로컬 PostgreSQL 검사를 실제 서버 적용으로 보고하지 않습니다.
