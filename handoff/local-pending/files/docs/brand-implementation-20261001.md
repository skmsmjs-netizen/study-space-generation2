## 기존 4절 세부표와 확인 범위

한글 조합/커서: 기존 공통 입력과 editing context를 재사용한다. 자료↔글 전환/중단: 기존 원문·exact draft를 보존하고 다음 행동/문의에도 연결했다. 다음 행동 교체/표시 해제: 이전 원문을 보관하고 홈에서 다시 표시한다. 문의 수정: 식별 번호를 유지하고 이전 원문/시각/수정 ID를 보관한다. 읽기 위치: 원래 좌표·초점 복귀를 유지하며 기록의 stable reading anchor를 추가했다. 원문/충돌: 서버 상태/충돌·revision·보관함을 바꾸지 않는다. 새 기기: 서버가 저장한 학습 자료와 기기별 힌트는 분리한다. 삭제/되돌리기: 기존 학습 명령을 유지한다. 누적: 기존 검색/메모40개/보드/자료 경로와 관련 기록 펼치기·공유40개·문의 검색/40개를 사용한다. 공유 검색/선택/이전 수정본 포함 여부는 현재 탭의 재접속·이동에 보존하며 전체 기기 공유 설정으로 설명하지 않는다. 업데이트: 브랜드 소개에서 확인된 기능을 설명하며 작업 복귀에 강제 안내를 끼우지 않는다.
