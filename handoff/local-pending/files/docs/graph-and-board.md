# 그래프뷰와 칸반보드

## 2026-10-03 원형 그래프 기본 배치

사용자 요청에 따라 기본 `auto`를 ‘원형으로 모으기’로 표시한다. 병행 읽기 보수 대화에서 사용자가 확정한 ‘처음에는 읽기 크기, 전체 보기 버튼으로 원형 개요’ 선택을 유지한다. 점 선택/읽기 크기로 보기에서 확대하며, 명시적인 목차 배치와 기존 수동 도구는 유지한다. 원형은 연결끼리 모이고 전체가 둥근 분포를 이루는 힘 기반 배치다.

[Obsidian 공식 Graph view](https://obsidian.md/help/plugins/graph)의 원형 노드/연결선과 중심 인력의 역할, [D3 공식 Position forces](https://d3js.org/d3-force/position)의 축별 인력을 참고했다. 기존 D3/React Flow를 재사용하고 화면 비율에 따른 x/y 인력 차이를 제거한다. 누적 시 중심 인력이 너무 약해져 타원으로 늘어나는 것을 막기 위해 기존 밀도 적응식을 `clamp(0.13 / (1 + density * crowding * 0.35), 0.045, 0.085)`로 보정했다. 이 수치는 이 앱의 선택값이며 공인 표준/Obsidian 내부 수치로 표현하지 않는다.

탐색 상태는 배치 버전2로 구별하여 새 원형 기본값을 적용한다. 유효한 수동 고정점은 유지하고 Canvas 좌표/원문/ID/연결/학습 기록을 쓰지 않는다. 같은 탭의 원문 왕복에서는 위치/시야/선택을 복원하며 ‘배치 다시 맞추기’는 고정을 해제한 원형 전체 보기로 돌아간다. 실제 관계와 수동 고정을 보존하므로 완전한 기하학적 원을 강제하지 않는다.

검증 결과와 최초 311항목 타원 실패, 자원 경합 시 단위 검사 시간 초과는 `work/graph-circular-20261003/`에 보존한다. 최종 결과는 해당 폴더의 결과.md에 연결한다. 새 공개 배포/운영 서버 쓰기/물리 기기 검증은 이번 범위에 포함하지 않는다.

[읽기 초기 화면·전체/주변 보기와 원문 복귀 보수](graph-readable-20261003.md)에 실제2% 재현,60% 읽기 시야, 작은 지도 크기·점 조작 영역·보존과 검증 근거를 연결합니다.

2026-10-01 사용자 요청의 핵심 흐름을 실제 웹앱 `#/graph`와 `#/board`에 연결했습니다.

그래프뷰는 기존 과목·목차·주제·QuickMemo·Narrative·개념 카드와 Canvas 연결을 읽습니다. 전체 범위/과목, 글 검색, 목차+직접 연결/직접 연결만, 설명·메모 표시, 선택한 항목 주변 1~3단계, 확대·이동, 항목 목록 및 원문 열기를 제공합니다. 소속 없는 자유 글·메모도 연결 없는 점으로 표시하며 추정 관계를 만들지 않습니다. 화살표는 저장된 방향과 설명을 따릅니다. 그래프에서 끈 위치는 개인 Canvas와 분리된 탐색 배치입니다. 2026-10-03 보수 이후 같은 탭에서 원문 왕복·새로고침하면 유효한 선택/주변/시야/탐색 배치를 복원하고, 자료·배치 조건이 달라지면 다시 계산합니다. 기존 Canvas 좌표·연결·원문·기록을 변경하지 않습니다.

칸반보드는 하나의 `board:main`에서 ‘할 일/하고 있음/마침’을 기본으로 제공합니다. 자유 카드에 제목·선택 글·선택 주제 연결을 남기고, 열 추가/이름 변경/빈 열 지우기, 마우스 끌기 또는 선택 메뉴로 열 이동, 위/아래 순서 변경, 검색, 카드 보관·복원, 기존 수정 이력을 통한 되돌리기를 제공합니다. 보관한 카드도 원문·ID·열·순서를 유지합니다. 카드가 있는 열은 지우지 않습니다. 보드의 마침은 공부함·TRACE·실제 제출·정답·숙달을 생성하지 않습니다. 여러 보드, 열 순서 편집, 기한/우선순위, Obsidian Markdown 보드 가져오기는 현재 구현 범위에 없습니다.

## 2026-10-01 자동 배치 보완

기본 ‘자동으로 맞추기’는 항목 수·유효한 고유 연결 수·연결 차수·이름의 예상 표시 폭·실제 그래프 영역 크기를 읽어 연결 거리/강도, 반발력, 중심으로 모으는 힘, 충돌 반경과 점 크기를 고릅니다. D3의 [연결 힘](https://d3js.org/d3-force/link), [반발력](https://d3js.org/d3-force/many-body), [충돌 방지](https://d3js.org/d3-force/collide)를 재사용하며 선택 공식은 이 앱의 가독성 조정 기준입니다. 보편적 최적 배치 법칙으로 주장하지 않습니다. 연결 없는 항목도 표시하며 저장된 방향/이름/연결을 계산용 사본으로 보호합니다. 중복/역방향 연결은 힘을 중복 계산하지 않지만 원래 선은 보존합니다.

배치 계산은 로컬 Worker에서 수행합니다. 자료의 구조/이름, 필터, 보기 영역 또는 간격이 달라졌을 때 새 계산을 요청하고 이전 요청은 종료하여 오래된 결과가 새 범위를 덮지 않습니다. 내용만 바뀌고 점/연결/이름이 같으면 배치를 다시 계산하지 않습니다. 기존 좌표를 새 계산의 시작점으로 사용하며, 직접 끌어 옮긴 점은 해당 화면 방문에서 고정하여 새 자료/좁은 화면에서도 유지합니다. ‘배치 다시 맞추기’는 현재 방문의 고정을 해제합니다. 그래프 좌표/힘 옵션은 원장이나 Canvas 배치에 저장하지 않습니다. 다시 열면 자동값으로 시작합니다.

‘조금 가깝게/조금 넓게’도 자동값을 상대적으로 조정합니다. 연결이 많은 점은 조금 크게 표시하며 축소해도 점이 너무 작아지지 않도록 보정합니다. 이름 미리보기의 화면 글자 크기를 유지하고, 선택/이웃/연결 수 순으로 화면에서 겹치지 않는 이름을 표시합니다. 선택 상세/항목 목록에는 전체 이름을 유지합니다. 긴 이름 미리보기의 말줄임·겹침 숨김은 원문을 변경하지 않습니다. 이름 미리보기는 포인터를 가로채지 않아 뒤의 점 조작을 방해하지 않습니다. 많은 항목의 전체 보기는 개요이며 자세한 관계는 확대/주변 보기/검색으로 확인합니다. 임의의 모든 대규모 그래프에서 최적 가독성을 보장하지 않습니다.

합성 긴 한글 30→100→300개 추가(기존 11개 포함)의 실제 Browser에서 자동 재배치/화면 맞춤과 표시된 이름 간 겹침0, 점의 영역 밖 이탈0을 확인했습니다. 수정 후 실제 점을 끌어 옮기고 30→100개 증가 및390px 화면에서 지정 좌표 유지, 정확한 점 선택/전체 이름 확인, 다시 맞추기 고정 해제, 가로 넘침0을 확인했습니다. 자동 수치 선택·사본 보존·중복 연결·유한/분리 좌표·지정 좌표·글자 겹침 회귀12개 통과, 새5파일 Biome와 공통 CSS 검사 통과. 결과는 `work/graph-auto-20261001/`입니다. 운영 배포/개인 계정 자료/물리 iPad 확인은 이 작업에서 실행하지 않았습니다.

## 설정 복원·누적 자료·서버 연결 보완

간격, 과목 필터, 검색어, 표시할 연결, 설명/메모 표시와 주변 단계 설정은 계정/공간별 `:graph-view:v1`에 이 기기의 보기 설정으로 저장합니다. 화면 재진입과 새로고침에서 복원하며, 현재 범위에 없는 과목은 현재 범위 전체로 보여 주고 저장된 과목 선택을 덮지 않습니다. 직접 옮긴 점은 현재 방문에서만 고정합니다. 보기 설정 초기화와 배치 다시 맞추기는 각각 설정/현재 방문의 고정을 다룹니다. 손상된 설정은 덮어쓰지 않고 명시적인 초기화에서 사본을 먼저 보관합니다. 저장 실패 시 현재 값을 보존하고 다시 저장할 수 있습니다. 이 설정은 서버 원장에 포함되지 않으며 기기 간 공유를 약속하지 않습니다.

칸반은 열 안에서 세로 스크롤하고 열 제목/추가 버튼은 목록 밖에 둡니다. 각 열의 첫40개 카드를 표시하고 필요하면40개씩 추가로 펼칩니다. 검색은 아직 펼치지 않은 카드의 제목/원문도 찾으며 숨겨진 카드를 삭제하거나 순서를 다시 매기지 않습니다. 긴 제목과 글은3줄 미리보기로 접고 제목/글 전체 보기에서 원문을 엽니다. 열이 많을 때 열로 이동 선택으로 해당 열을 보여 줍니다. 키보드가 이름 있는 스크롤 영역에도 접근할 수 있습니다.

이 기기 저장과 서버 전송/오류 상태를 구별합니다. 서버 저장 실패의 다시 시도는 기존 개인 원장의 동일한 대기 명령을 재전송합니다. 계정 승인, 인증, 소유권, 예상 버전, operation ID와 원문 UTF-16 보존 경계는 유지합니다.
