2026-10-01 사용자 후속 결정: 결제 기능과 문의 접수·회신은 제외한다. 가격·결제 사업자·지원 수신 채널을 잔여 조건으로 요구하지 않는다. 도움말/문제 메모·기존 문의 원문/이력·계정/내보내기·나머지 브랜드 경험은 유지하며 기존 허용 Pages에 배포한다.


## 수학 인터랙티브 기준 연결

2026-10-02 공통 관찰틀은 [위치·조작·보존 기준](docs/observation-frames.md)을 따른다. 수식 도구·개념 탐구실·개념 전집의 질문/관찰/조절/현재값/근거/참고 역할, 좁은 화면 순서, 초기화 범위와 개념별 복원을 실제 소비 경로에 연결한다. 대표 과업의 검증과 전체 원문 전수 대응을 구별한다.

2026-10-01 [수학 인터랙티브 설계·검증 기준](../docs/수학%20인터랙티브%20설계·검증%20기준.md)의 네 근거와 MI01–MI12를 필수 적용합니다. 수식 탐색·정밀 도해·공통 틀·개념별 구성의 변경에서 관련 규칙과 실제 호출/계산/저장/접근성/복귀를 연결하고 실행 근거 없는 완료를 보고하지 않습니다. 새 틀/큰 변경은 전체 적용 여부와 이유를 남기고, 작은 수정은 영향받는 규칙과 연결된 기존 과업을 선택합니다. 종료한 작업·전수 QA·새 공개 배포를 이 지침으로 자동 재개하지 않습니다.

## 2026-10-03 VoiceOver 제외

사용자 결정으로 웹앱의 모든 기능과 이후 변경에서 VoiceOver 전용 지원·구현·검증·QA·완료 및 배포 조건을 제외한다. 이전 문서의 VoiceOver 잔여 항목을 현재 작업의 차단 조건으로 사용하지 않는다. 일반 터치·키보드·초점·레이블·저장·원문 이동·복귀는 유지한다. [적용 범위](docs/voiceover-scope-20261003.md)를 따른다. 과거 실행 기록은 보존한다.
