# 데이터베이스와 Supabase

[웹앱 지침](../AGENTS.md)을 상속합니다. [서버 지침](../src/server/AGENTS.md)의 권한·API 계약을 이 경로에도 적용합니다.

- 스키마·RLS·함수·마이그레이션은 재현 가능한 파일로 관리합니다. 이미 적용한 이력을 고쳐 새 마이그레이션인 것처럼 만들지 않습니다.
- DB 적용은 현재 사용자 허용과 대상 프로젝트·namespace를 확인한 범위에서 수행합니다. 지침 정리는 DB 실행·실제 기록 이관의 권한을 추가하지 않습니다. 이미 허용된 적용을 다시 승인받지는 않습니다.
- 변경한 소유권·권한 거부·version·원자성·중복 요청 조건을 격리된 자료에서 확인한 후 실제 적용 결과와 구별해 보고합니다.
