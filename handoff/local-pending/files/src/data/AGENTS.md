# 저장과 복구

[코드 지침](../AGENTS.md)을 상속합니다.

- [데이터 계약](../../docs/data-contract.md)과 [책임 분리](../../docs/architecture.md#프론트엔드백엔드-책임-분리)의 해당 저장·오류 계약을 읽습니다. 저장 인터페이스와 로컬/개인 서버 어댑터의 책임을 구별합니다.
- 원문·ID·namespace·저장 키·초안·수정 이력·사용자 설정·충돌 사본을 보존합니다. 기존 자료를 자동 업로드·새 형식으로 덮어쓰지 않습니다. 키/형식 변경과 복구는 격리된 자료에서 먼저 확인합니다.
- 저장 성공·서버 반영·다른 기기 수신을 구별합니다. 재시도·중복 요청·버전 충돌·응답 유실의 처리는 해당 변경에 연결된 범위에서 확인합니다. 브라우저 검사나 Web Lock을 서버 권한 보장으로 표현하지 않습니다.
