# 서버와 API

[코드 지침](../AGENTS.md)을 상속합니다.

- [책임 분리](../../docs/architecture.md#프론트엔드백엔드-책임-분리)와 [데이터 계약](../../docs/data-contract.md)의 해당 API·소유권·원자성·버전·중복 요청 계약을 적용합니다. 클라이언트가 보낸 userId만으로 권한을 인정하지 않습니다.
- 인증·관계·소유권·조건부 쓰기와 원문/수정 이력의 반영은 서버에서 강제합니다. 실패를 성공 응답으로 바꾸거나 오류 때문에 사용자의 입력을 폐기하지 않습니다.
- 개인 원문·토큰·비밀키를 코드·로그·보고에 포함하지 않습니다. 변경과 직접 관련된 허용/거부·원자적 쓰기·재시도를 격리된 자료로 확인합니다. 로컬 검사와 실제 서버 적용은 따로 보고합니다.
