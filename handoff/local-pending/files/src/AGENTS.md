# 웹앱 코드 작업

[웹앱 지침](../AGENTS.md)을 상속합니다. 작업 디렉터리 밖의 파일을 수정할 때도 해당 경로의 AGENTS.md를 확인합니다. 루트에서 시작한 세션이 모든 하위 지침을 자동으로 읽는다고 가정하지 않습니다.

- TypeScript·React·현재 모듈의 명명과 구현 패턴을 사용합니다. 화면·학습 규칙·저장·서버 경계를 바꾸면 [책임 분리](../docs/architecture.md#프론트엔드백엔드-책임-분리)를 확인합니다. UI는 저장 인터페이스를 사용하고, 저장 어댑터·서버 SDK를 화면에 직접 붙이지 않습니다.
- 변경 파일 가까이의 기존 검사를 먼저 사용합니다. 실행 명령의 기준은 [package.json](../package.json)입니다. 코드 변경의 타입 확인은 `npm run typecheck`, 사용·배포용 산출물은 `npm run build`로 확인합니다. 동작 변경은 해당 경로의 기존 Vitest 검사를 선택합니다. 작은 표현 수정마다 새 검사를 만들지 않습니다.
- 검사 범위·시점·종료는 [공통 정책](../../docs/작업%20진행과%20검증%20정책.md)이 담당합니다. 실패·공통 영향·새 변경 없이 전체 검사를 반복하지 않습니다. 자동검사·실제 브라우저·물리 기기·서버 반영을 구별해 보고합니다.
