# 학습 규칙

[코드 지침](../AGENTS.md)을 상속합니다.

- [TRACE](../../../docs/TRACE%20학습법.md)와 [데이터 계약](../../docs/data-contract.md)의 바꾸는 의미만 확인합니다. 체크·시도·반복·독립 해결·정확성을 혼합하지 않습니다. 미기록·미응답·불확실을 실패나 0점으로 바꾸지 않습니다.
- 학습 규칙은 React·브라우저 저장소·Supabase SDK에 의존하지 않도록 유지합니다. 입력에 없는 문제 번호·개념·혼동 관계를 이미 수집된 값으로 가정하지 않습니다.
- 규칙을 바꾸면 실제 경계값·부분 수행·예외의 결과를 기존 검사로 확인합니다. 제안·가정·추정을 관측이나 사용자 응답으로 저장하지 않습니다.

- 수학 인터랙티브의 계산·조건·판정은 [수학 인터랙티브 설계·검증 기준](../../../docs/수학%20인터랙티브%20설계·검증%20기준.md)의 MI07·MI08·MI12와 관련 규칙을 따릅니다. 적용 조건 실패/미확인/결론을 구분하고 유한 표본·근사와 증명을 혼합하지 않으며 허용된 계산/내용 계약과 실제 경계 검사를 유지합니다.
