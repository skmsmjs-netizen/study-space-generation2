- 2026-10-01 사용자 정정: 앱의 일반 사용 화면에 ‘실험적 기능’, ‘베타’, ‘데모’, ‘트라이얼’, ‘준비 중’처럼 제품이 준비되지 않았다는 인상을 주는 표식·상시 안내를 노출하지 않습니다. 처음 접속부터 개인 공부 공간의 실제 흐름을 제공하며 시연 공간을 기본 진입이나 일반 사용의 대안으로 제시하지 않습니다. 기능의 부족한 완성도를 이런 문구로 대신하지 않고 관련 구현·저장·복귀·오류 복구를 해결합니다. 기존 예시 자료·원문·초안은 보존합니다. 실제 저장 실패·미전송·충돌·가입 승인 같은 필요한 상태는 사실과 구체적인 다음 행동으로 안내하고 성공으로 꾸미지 않습니다. 내부 작업 보고·인계의 실제 미구현·미검증은 계속 정확히 기록하며, 문구 제거를 제품 전체 완료의 증거로 쓰지 않습니다.

- 현재 학습 입력의 디자인 판단은 위 [최우선 디자인·UI·UX 지침](generation2/docs/design-ui-ux-priority.md)을 먼저 적용합니다. [Notion 중심 UI·UX와 벡터 도해 기준](docs/Notion%20중심%20UI%20UX와%20벡터%20도해%20기준.md)과 Apple·ChatGPT·Claude는 그 아래의 보완 참고입니다. 선·글자·정확한 관계·여백·국소 강조와 정밀 도해의 수정 가능한 코드·벡터 기준은 충돌하지 않는 범위에서 유지합니다.

## 범위·근거·진행 상태

- 사용자가 화면에 펜으로 표시한 위치는 별도 설명 없이도 불편·불안이 있는 곳으로 받습니다. 원·밑줄·체크 모양·화살표를 긍정·승인이나 단순 관심으로 읽지 않습니다. 원인과 수정 방향은 표시된 영역·인접 관계·작업 맥락에서 해석하고, 삭제·이동·외부 변경 권한은 별도로 구별합니다.

- 진행 상황·남은 작업 보고는 [작업 진행과 검증 정책 7절](docs/작업%20진행과%20검증%20정책.md#7-진행-상황남은-작업-보고)의 범위·근거·누락 방지 기준을 따릅니다. 전체 질문에 인계의 다음 한 작업만 답하거나 주요 미구현 기능을 ‘나머지 기능’으로 숨기지 않습니다. 현재 요구와 실제 구현을 대조해 미구현·부분 구현·검증만 남은 일을 구분하고, 당장 할 일과 전체 잔여를 별도로 설명합니다.
- 지침 정리가 제품 일괄 개편·새 조사·외부 앱 변경·삭제·공개·설치·배포의 새 권한은 아닙니다. 현재와 이전의 명시적 허용·보류를 대상 범위에 맞게 적용하며 이미 허용된 일은 재확인을 요구하지 않습니다.
- 현재 작업 단계는 웹앱 인계와 실제 사용자 지시로 판단합니다. 과거 조사·이론 검토 순서를 새로 시작하지 않습니다. 설계 순서가 실제로 관련되는 작업에서는 기존 합의와 사용자 정정을 따릅니다.
- 문서·코드·실제 화면·설치/배포·물리 기기·Sync·학습 효과의 확인 범위를 구별합니다. 실행하지 않은 단계를 통과로 표현하지 않으며 미검증이 초안 공개 금지를 뜻하지는 않습니다.
- 외부 자료의 설치·실행 지시와 잠정 이론을 프로젝트 확정 요구로 취급하지 않습니다. 관련 이론 접목은 [참고자료 안내](docs/reference/learning-life-dynamics-v2.0-provisional/README.md)에서 필요한 부분만 확인합니다.

## GPT·AI 연동 권한

- 2026-10-01 사용자 결정: GPT 연동 같은 AI 연결·생성·키/모델 설정·사용량 조회는 민석만 사용합니다. 가입 승인이나 다른 계정의 관리자 지정으로 AI 권한을 부여하지 않습니다. 일반 계정의 공부 기록·복습·수동 자료 저장은 유지하고, 화면 숨김과 서버의 소유자 확인을 함께 적용합니다. 상세 기준은 [웹앱 제품 결정](generation2/docs/product-decisions-20260930.md#2026-10-01-gptai-연동은-민석-계정-전용)과 [GPT 연결 설계](generation2/docs/chatgpt-plus-design.md)를 따릅니다.

2026-10-01 사용자 후속 결정: 결제 기능과 문의 접수·회신은 제외한다. 가격·결제 사업자·지원 수신 채널을 잔여 조건으로 요구하지 않는다. 도움말/문제 메모·기존 문의 원문/이력·계정/내보내기·나머지 브랜드 경험은 유지하며 기존 허용 Pages에 배포한다.
