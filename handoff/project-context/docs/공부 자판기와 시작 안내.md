# 공부 자판기와 시작 안내

기준 시안의 기존 구성과 요소를 유지합니다. 이번에 타이머를 새로 추가하지 않는다는 선택을 기존 시간·일시정지·중단 요소의 삭제로 확대하지 않습니다. 현재 기준 시안에는 해당 조작이 없었으며, 원래 상단 메뉴·네 구역·CSS를 유지한 채 룰렛 영역 안에 공부 시작·안내·기록 복귀를 연결했습니다. 실제 앱의 전체 메뉴 통합은 별도 작업의 설치 근거를 따릅니다.

무엇부터 공부해야 할지, 준비가 부족한 부분이 어디인지 모르는 사람도 작은 공부를 시작하고 시험 준비에 필요한 보완점을 찾아갈 수 있게 합니다. 무작위 추첨은 시작과 재발견을 돕고, 실제 공부·수행 결과를 다음 제안에 연결합니다. 이 목적과 실제 성적 향상의 입증은 구별합니다.

## 사용 흐름

1. Home의 흐르는 주제를 직접 고르거나 `하나 뽑기`를 누릅니다.
2. 선택한 주제의 경로와 지금 해볼 행동을 확인하고 `공부 시작`을 누릅니다.
3. `공부하고 오세요` 화면이 나타납니다. 이때 공부 기록이나 활동 체크는 생성되지 않습니다.
4. 공부 후 `다 하셨으면 기록하세요`를 누르면 같은 주제의 기존 기록 화면으로 들어갑니다.
5. 공부함이나 실제로 해본 TRACE 활동을 남깁니다. 일부만 했거나 막힌 경우도 기록할 수 있습니다. 메모·결과는 기존 선택 입력을 사용합니다.

이미 공부한 내용은 `이미 공부했어요 · 기록하기`로 바로 기록합니다. 여러 주제 선택과 이전 기록 수정은 기존 방식대로 유지합니다.

사용자가 같은 발화 안에서 시간 측정을 철회했으므로 새 타이머·일시정지·중단 시간·소요시간 자동 기록은 추가하지 않았습니다. 기존 사용자가 직접 입력하는 공부 날짜·시각 기능은 유지합니다.

## 시작 안내와 추첨

- 기존 다음 공부 계산에서 유효한 수행 재확인 후보, TRACE 다음 행동·부족함, 이어 할 내용을 재사용합니다. 충돌·자료 변경·수행 조건 등 기존 근거 구별을 유지합니다.
- 수행 재확인 후보가 있으면 그 항목의 행동과 당시 조건을 안내합니다. TRACE에 다음 행동을 남겼으면 원문을 사용합니다. 부족함만 있으면 그 부분을 확인하고 다시 설명하거나 풀어보도록 안내합니다.
- 근거가 없으면 자료 없이 핵심 내용·사용 조건을 설명하고, 처음 보는 내용이거나 막히면 설명·예제를 본 뒤 다시 해보는 일반적인 공부 방법을 제안합니다. 기록 없음이나 체크 수로 능력을 판정하지 않습니다.
- `하나 뽑기`는 화면에서 보고 있는 과목의 허용된 말단 주제를 대상으로 합니다. 기존 공부 횟수 역수 가중치에, 유효한 다음 행동·부족함·수행 재확인 후보가 있는 주제는 2배 노출 가중치를 적용합니다. 이는 초기 운영 규칙이며 능력 점수나 검증된 최적 계수가 아닙니다.
- 다른 후보가 있으면 직전 `하나 뽑기` 결과를 이번 추첨에서 제외합니다. 후보가 하나라면 그 후보를 유지합니다. 기존 과목 무작위 선택·15칸 후보 흐름의 추첨 규칙과 직접 선택은 보존했습니다.
- 제외한 과목은 자동 뽑기에 포함하지 않습니다. 실제 시험 범위·출제 여부를 새로 추정하거나 기존 출제 표시를 변경하지 않습니다.

## 복귀와 보존

공부 시작 시 주제 ID와 학기 범위만 `study-record-trial:study-launch:v1`에 기기 내부 복귀 위치로 남깁니다. 시작 시각·공부 시간·완료 여부는 저장하지 않습니다. 화면을 닫거나 앱을 다시 열어도 Home에서 같은 주제의 기록 버튼을 사용할 수 있습니다. 이 복귀 위치의 기기 간 Sync는 이번 기능의 보장 범위가 아닙니다.

`다른 내용 고르기`는 복귀 위치만 해제합니다. 기존 기록·메모·입력은 삭제하지 않습니다. 작성 중인 글은 원래 입력으로 이어 열도록 보호합니다. 목차 이동·삭제로 복귀 대상을 찾지 못하면 기록을 생성하지 않고 다시 선택하도록 안내합니다. 복귀 위치를 저장하지 못하면 공부 시작을 성공으로 표시하지 않습니다.

기록 진입 뒤에만 선택한 주제를 기존 Home·Anki·Kanban·Canvas 연결에 반영합니다. 뽑기·안내 열람·공부 시작은 실제 공부나 독립 수행으로 세지 않습니다.
