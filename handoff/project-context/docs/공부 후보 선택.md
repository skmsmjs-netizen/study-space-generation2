# 공부 기록에 들어가기 전 후보 선택

## 2026-09-23 공부 기록창의 좌우 룰렛

공부 기록창은 같은 폭의 두 영역으로 나눕니다. 왼쪽 카드의 중앙에는 회색 단원명, 하단에는 과목명을 작게 표시하고, 오른쪽 카드의 중앙에는 노란색 주제명, 하단에는 파란색 목차명을 작게 표시합니다. 과목 형광펜은 테마의 `--text-normal`을 22%로 옅게 사용합니다. 어두운 테마에서는 흰빛, 밝은 테마에서는 짙은 중립색이며 별도 고정 흰색을 쓰지 않습니다. 두 영역은 기존 정사각형·질감·조명·호버·누름 스타일을 공유하고 왼쪽 카드만 과목·단원의 중립색 계열을 사용합니다.

사용자의 움직임 선택에 따라 **양쪽 목록 모두 위에서 아래로 독립적으로 흐릅니다.** 첫 진입은 중간 위치에서 시작하며, 과목을 무작위로 정해 첫 단원의 주제를 보여 줍니다. 왼쪽에서 단원을 누르면 오른쪽 목록만 해당 단원의 주제로 바뀝니다. 각 목록에 마우스를 올리거나 키보드 초점을 두면 그 목록만 멈춥니다. 각 영역에서 빨리감기와 흐름 조절이 가능하며 동작 줄이기를 켜면 둘 다 정지합니다.

기록할 내용을 놓치지 않도록 각 적격 단원과 그 아래 주제는 한 순환에 한 번씩 모두 표시합니다. 단원 선택·움직임은 공부 기록이나 연결된 보드 범위를 바꾸지 않습니다. 오른쪽 주제를 누르면 기존 기록 입력으로 바로 연결하고, 작성 중 글이 있으면 명시적으로 이어 열도록 안내합니다. 선택 직전에 학기·단원 소속·삭제 상태를 다시 확인합니다. 완전한 네 단계가 없는 경로는 룰렛에서 제외하며, 기존 얕은 항목과 후보에서 숨긴 과목의 기록 접근은 `전체 항목에서 직접 고르기`에 유지합니다.

## 2026-09-23 룰렛 후보의 네 단계 위계

룰렛은 **과목 → 단원(회색) → 목차(파랑) → 주제(노랑)**가 연결된 경로의 말단 주제만 표시합니다. 하위 항목이 없어도 과목 바로 아래는 단원, 그 아래는 목차이며 주제로 승격하지 않습니다. 중간 목차가 더 깊어지는 기존 구조는 유지하고, 그 아래 말단 주제도 포함합니다.

정사각형 중앙에는 노란색 주제명, 하단에는 그 주제의 바로 위 파란색 목차명을 작게 표시합니다. 판정은 형광펜과 같은 저장된 ID·부모 관계를 사용합니다. 이름이나 글자 색을 추측해 분류하지 않습니다. 주제까지 연결된 경로가 하나도 없는 과목은 과목 추첨에서도 제외합니다. 완성된 경로와 미완성 경로가 한 과목에 섞여 있으면 완성된 경로의 주제만 나옵니다.

홈 룰렛·공부 후보 창·하나 뽑기에 동일하게 적용합니다. 과목별 제외·시험 유무·학기 범위와 공부 횟수 가중치를 유지합니다. 기존 기록·초안·직접 기록 선택은 보존하며 저장된 목차를 자동 이동·추가하지 않습니다. 후보가 전혀 없으면 `과목 → 단원 → 목차 → 주제까지 입력하면 공부 후보가 나타납니다.`를 표시합니다. 아래 이전 설명의 '하위 항목이 없으면 후보' 규칙은 이 기준으로 대체됩니다.

## 2026-09-23 공부 시작과 기록 분리 — 0.31.29

현재 동작은 **주제 선택 → 공부 시작 → 공부하고 오세요 → 다 하셨으면 기록하세요 → 기존 기록 입력**입니다. 이미 공부한 경우 바로 기록할 수 있습니다. Home과 후보 선택에 `하나 뽑기`를 추가했고, 유효한 다음 행동·부족함·수행 재확인 후보를 반영합니다. 아래의 이전 ‘확인 후 입력’ 설명은 이 새 흐름으로 변경되며, 기존 정사각형·후보 범위·과목 제외·단원명·형광펜·질감은 유지합니다. 상세 규칙은 [공부 자판기와 시작 안내](공부%20자판기와%20시작%20안내.md)를 따릅니다.

2026-09-23 사용자의 요청에 따른 구현입니다. Home과 공부 기록 입구에 목록 위에 `현재 공부할 수 있는 주제들인데요 ~`를 안내하고, 연결된 단원명과 주제명을 담은 정사각형 버튼을 3열로 보여 줍니다. 각 후보의 `공부하기` 문구는 제거했습니다. 칸 사이의 여백에 얇은 가로·세로 구분선을 표시합니다. 버튼 묶음이 위에서 아래로 흐르며, 커서를 올려 멈추고 하나를 선택하면 공부 시작 안내를 확인한 뒤 기존 기록 입력으로 이어집니다. 선택 후보는 하위 항목이 없는 주제만 사용합니다. 단원이나 과목 자체는 자동 후보와 직접 선택 정사각형에서 제외합니다.

- Home으로 돌아오거나 새 기록 입력 창에 진입할 때마다 현재 보고 있는 학기 범위에서 삭제하지 않았고 공부 후보로 포함한 과목 중 하나를 같은 확률로 뽑습니다. 같은 과목이 연속으로 나올 수도 있습니다.
- Home 또는 기록 선택창의 `공부 후보 설정`에서 과목별 후보 표시를 켜거나 끌 수 있습니다. AI리터러시는 사용자의 요청에 따라 자동 후보에서 제외했습니다. 다른 온라인 과목을 이름으로 추측해 일괄 제외하지 않습니다. 제외는 과목 ID로 저장해 이름 변경에도 유지하며, 다시 체크하고 적용하면 복구됩니다. 목차·기록·강의·출석·일정과 직접 선택은 보존합니다.
- 해당 과목의 주제는 공부 기록 횟수가 적을수록 더 자주 추첨합니다. 주제가 없는 과목을 과목·단원 카드로 대신 표시하지 않습니다. 다른 과목을 다시 뽑을 수 있습니다.
- 후보에는 노란색 주제명을 가운데에 표시하고, 바로 연결된 파란색 목차명은 사각형 하단에 작은 글씨로 표시합니다. 과목명·전체 경로·횟수·추가 버튼은 넣지 않습니다. 두 이름은 저장된 ID로 기존 `node-highlight` 형광펜 기능을 적용합니다. 단원은 회색, 목차는 파랑, 네 단계 이상 경로의 말단 주제는 노랑입니다. 과목에 바로 속한 항목이나 목차에서 끝난 항목은 룰렛 후보가 아닙니다.
- 후보를 누르면 과목·단원·주제의 전체 경로와 `이 주제를 공부하시겠습니까?` 안내가 나타납니다. 다시 고르기·닫기는 공부 기록을 만들지 않습니다.
- 주제를 확인하면 해당 주제의 기존 활동 입력으로 연결합니다. 여러 주제 선택과 기존 입력은 유지합니다. 기존 명령·연결에서 특정 과목·단원 범위로 진입한 경우는 후보 카드 대신 `선택한 범위로 입력` 동작을 유지합니다.
- 이미 열린 기록 안에서 주제를 바꾸는 동안에는 선택 안내를 반복하지 않습니다. 과거 기록 열기·수정은 원래 기록을 직접 엽니다.
- 작성 중인 글이 있으면 원래 입력 이어 열기로 돌아갈 수 있습니다. 글이 있는 상태에서 다른 새 대상을 고르면 원래 입력을 먼저 마치도록 안내하며 글을 지우지 않습니다.
- 처음 진입하거나 후보를 다시 뽑으면 순환 목록의 중간 위치에서 시작합니다. 숨겨진 입력 선택창도 실제로 열리고 크기가 정해진 뒤 중간 위치를 잡습니다. 이후 정지·재생은 그 자리에서 이어집니다.
- 자동 흐름은 마우스 올림·누름·키보드 초점·확인창·문서가 보이지 않는 상태에서 멈춥니다. 흐름 멈추기·재생하기, 이전 줄·다음 줄, 전체 과목·목차의 직접 선택을 제공합니다. 동작 줄이기에서는 자동 흐름을 끕니다.

자동 흐름, 과목·목차에서 직접 고르기, 특정 주제로 들어온 선택 후보 모두 같은 정사각형을 사용합니다. 주제명은 중앙, 연결된 단원명은 하단의 작은 보조 글씨로 표시하며, 설정·닫기·입력 이어 열기 같은 일반 동작 버튼은 기존 형태를 유지합니다.

정사각형에는 잔잔한 표면 결, 위쪽 가장자리의 빛, 얕은 그림자를 넣었습니다. 커서를 올리면 기존 강조색으로 테두리와 표면이 밝아지며 글자가 1px 올라갑니다. 누르면 안쪽 그림자와 1px 내려간 글자로 눌림을 표현합니다. 칸 자체와 여백의 구분선은 움직이거나 줄어들지 않습니다. 밝음·어두움에 맞춰 질감 농도를 조절하며, 동작 줄이기에서는 글자 이동과 전환을 제거합니다. 강제 색상 모드에서는 질감·그림자를 없애고 시스템 버튼·초점 색을 사용합니다. 추가 이미지나 플러그인 설치 없이 기존 선택 화면의 스타일로 적용합니다.

버튼 전체가 한 선택 영역입니다. Home에서 선택하면 확인 안내를 바로 엽니다. 후보 안의 `이 범위 보기` 버튼은 제거했으며, 수동 범위 선택은 후보 밖의 `범위 변경`에 남겨 두었습니다. 클릭 후 확인할 때 기존 세 창 연결이 반영됩니다. 자동 이동·호버·추첨만으로 범위나 공부 횟수가 바뀌지 않습니다. 화면이 좁아도 3열과 가로·세로 1:1 비율을 유지합니다. 긴 이름은 버튼 안에서 줄바꿈하고 공간을 넘는 부분은 말줄임합니다. 전체 이름은 접근성 이름과 선택 후 확인 안내에 보존합니다. 커서를 올렸을 때 뜨는 기본 툴팁은 표시하지 않습니다.

## 추첨 기준

한 후보의 가중치는 `1 / (1 + 저장된 공부 횟수)`입니다. 같은 과목에서 각 후보의 가중치를 합한 값으로 나누어 매 추첨의 확률을 계산합니다. 따라서 0회 후보는 1회 후보의 2배, 9회 후보의 10배 가중치를 가집니다. 어느 후보도 횟수가 많다는 이유만으로 제외하지 않습니다.

주제가 둘 이상이면 복원 추출로 15개의 후보 자리를 채워 순환합니다. 후보가 적어도 적게 기록한 내용이 여러 자리에 나올 확률이 커집니다. 높이가 짧은 버튼 묶음도 끊김 없이 흐르도록 화면을 채울 만큼의 시각적 반복본을 붙이며, 반복본은 키보드·스크린 리더의 중복 선택 순서에서 제외합니다. 한 번의 추첨에서 모든 항목이 보장되지는 않으므로 전체 목차의 직접 선택을 함께 제공합니다. 한 후보뿐이면 그 후보만 표시합니다.

공부 횟수는 기존 `model.aggregate`의 공부 사건 집계를 재사용합니다. 공부함 또는 TRACE 활동 체크가 있는 같은 공부는 주제별·상위 단원별로 한 번만 셉니다. 후보 추첨에는 주제별 횟수만 사용하며 상위 단원 집계는 기존 현황에 보존합니다. 같은 저장 ID의 중복, 한 회차 안의 여러 활동을 여러 번 세지 않습니다. 메모만 있는 기록·후보 선택·안내 확인은 공부 횟수를 늘리지 않습니다. 저장 충돌·형식 확인이 필요한 기록은 기존 집계처럼 제외하고 후보 화면에 안내합니다. 범위가 불분명한 기록도 별도로 표시합니다.

이 수치는 기록 기반 노출 조정입니다. 기록 없음은 실제로 공부하지 않았다는 판정이 아니며, 기록 횟수는 숙련·성취·완료의 점수가 아닙니다.

## 적용 경로와 보존

홈의 공부 기록·입력 이어 열기, 바로 하기·기록 명령, 과목 목차의 선택한 내용 기록, 주제·공부 페이지, Canvas의 공부 기록 진입, 다음 공부의 기록·시작 경로가 공통 진입 기능을 사용합니다. 특정 주제로 진입한 경우 그 항목을 따로 선택할 수 있는 버튼도 남겨 목적지를 잃지 않게 합니다. 다음 공부의 방법·이어 공부 연결은 확인 후에만 실행합니다.

과목 제외는 기존 설정의 `studyCandidates.excludedSubjectIds`에 저장하며, 최신 설정을 읽은 뒤 사용자가 바꾼 과목만 합칩니다. 저장 실패 시 기존 표시 설정을 유지하고 같은 창에서 재시도합니다. 과목을 모두 제외해도 안내와 설정 진입을 남깁니다.

기존 공부·TRACE·자유 글·초안·주제 ID·개인 배치와 저장 방식은 그대로 사용합니다. 이 변경은 과제·온라인 강의 등록, 기존 Anki 회상 평가, 문제별 수행 판정의 의미를 바꾸지 않습니다. 자료 열기·안내 확인·공부 수행·입력 저장은 구별합니다.
