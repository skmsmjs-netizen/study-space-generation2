# 과목·단원·주제 표 입력

2026-09-23 최신 사용자 정정을 반영한 입력 방식입니다.

- 과목명을 한 번 적고, 표의 왼쪽에는 단원, 오른쪽에는 각 주제를 적습니다.
- 주제마다 테두리가 있는 개별 입력칸을 사용합니다. 여러 줄짜리 본문 입력칸은 사용하지 않습니다.
- 단원 칸은 해당 주제 행들을 묶어 표시합니다. 생성 구조는 **과목 → 단원 → 주제** 세 단계입니다.
- 하위 목차 추가와 표 붙여넣기 기능은 제공하지 않습니다. 일반 입력칸의 기본 글자 복사·붙여넣기는 가능합니다.

## 입력과 생성

1. `첫 과목 추가`, `과목 추가` 또는 `표로 한 번에 만들기`를 엽니다.
2. 등록할 학기를 확인하고 과목명과 단원명을 적습니다.
3. 주제 칸을 채웁니다. `주제 추가`를 누르면 같은 단원에 빈 주제 칸이 추가됩니다.
4. `단원 추가`, `과목 추가`로 표를 확장합니다.
5. 같은 화면의 생성 개수를 확인하고 `한 번에 생성`을 누릅니다. 상세 구조는 `생성할 구조 보기`에서 펼칩니다.

키보드의 Enter는 다음 입력칸으로 이동합니다. 마지막 주제 칸에서는 새 주제 칸을 추가합니다. 한글 조합 중 Enter는 칸을 추가하거나 저장하지 않습니다. 빈 주제 칸은 건너뛰며, 같은 과목·단원·주제 경로가 반복되면 한 번만 만듭니다. 주제를 입력했다면 소속 단원명도 적어야 합니다. 과목만 또는 단원까지만 등록하는 것은 가능합니다.

등록된 항목과 이름·경로가 같으면, 기존 항목에 연결할지 같은 이름으로 새로 만들지 사용자가 선택합니다. 확인 중 등록된 목차가 변경되면 구조를 다시 확인해야 합니다.

## 삭제와 되돌리기

- 과목명 옆 `⋯ → 과목 삭제`: 작성 중인 해당 과목과 포함된 단원·주제 입력을 삭제합니다.
- 단원명 아래 `⋯ → 단원 삭제`: 해당 단원과 그 안의 주제 입력을 삭제합니다.
- 주제 칸 옆 `⋯ → 주제 삭제`: 해당 주제 입력칸을 삭제합니다.
- `삭제 되돌리기`: 최근 삭제부터 복원합니다. 최대 20회 삭제를 보관하며, 생성 전 창을 닫았다 다시 열어도 복원할 수 있습니다. 다른 칸에서 나중에 수정한 글은 덮어쓰지 않습니다.

입력 표의 삭제는 아직 생성하지 않은 입력에 적용됩니다. 이미 생성한 항목은 `등록한 항목 관리`에서 기존 삭제·복원 기능을 사용합니다. 기존 항목을 참조하는 공부 기록과 원문 보존은 기존 목차 저장 규칙을 따릅니다.

## 입력 보존

각 칸의 원문과 삭제 복원 정보를 초안으로 보관합니다. 저장 실패 시 표를 유지하며, 저장 재시도는 같은 생성 ID를 사용해 중복 생성을 막습니다.

이전 세 열 초안은 과목·단원·주제 칸으로 복원하며 원본도 함께 보존합니다. 이전 초안이 더 깊거나 미완성이라 자동 변환할 수 없으면 원문을 보여 주고, 사용자가 새 표 작성을 선택하기 전까지 생성을 막습니다. 기존 자료의 계층을 자동으로 줄이거나 삭제하지 않습니다.

항목 이름은 최대 180자, 단원과 주제의 입력 행은 합계 500개까지 지원합니다. 새 표에서 생성한 항목은 기존 과목 선택, 공부 기록, Kanban·Canvas 연결 경로를 사용하며 공부 횟수나 성취를 자동 생성하지 않습니다.
