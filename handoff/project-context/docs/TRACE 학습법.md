# TRACE 학습법

2026-09-21 최신 정정 · 다섯 활동 아래의 15개 하위 항목을 각각 입력합니다. T·R·A·C·E는 설명이 붙은 묶음이며, 큰 활동 자체를 체크하지 않습니다. 이전 14항목과 이후 다섯 활동·C2 기준, 원기록은 당시 의미와 ID로 보존합니다. 사용자가 직접 조정한 기준은 유지합니다.

> **조금 해보았다면, 체크해 보세요.** 일부만 했거나 막혔어도 괜찮아요. 메모는 필요할 때만 남기세요. 순서는 자유롭습니다.

## 체크가 뜻하는 것

TRACE는 한 주제를 공부할 때 활용하는 다섯 활동입니다. 과목 → 단원 → 주제를 따라 기록하며, 과목마다 같은 목차 깊이를 강제하지 않습니다. 과목·단원·주제 이름은 선택한 목차에서 가져오므로 매번 다시 쓰지 않습니다.

체크는 **그 활동을 해보았다는 기록**입니다. 일부만 수행했거나 중간에 막혔어도 체크할 수 있습니다. 모든 내용을 이해하거나 도움말의 예시를 전부 수행할 필요는 없습니다. 평소 활동 체크는 별도 글 없이 저장됩니다. 다만 C2 안의 **시험 전 서술 점검**을 체크할 때는 자기 문장으로 쓴 내용이 필요합니다. 이미 체크한 활동도 다시 할 수 있고, 필요한 경우 체크를 되돌리거나 보류할 수 있습니다.

활동 사이에 고정된 순서나 선행 완료 조건은 없습니다. 문제를 먼저 풀거나, 풀이 중 의미를 탐색하거나, 기억을 확인한 뒤 필요한 내용을 다시 정리할 수 있습니다. 체크와 주제의 목표 달성, 실제 독립 수행은 따로 봅니다.

## 의인화 문답 · 개념과 대화해보기

개념·기호·공식·정리를 하나의 인물처럼 대하며 공부해볼 수 있습니다. “너는 누구니?”, “여기서 무슨 일을 하니?”, “언제 너를 불러야 하지?”처럼 질문하고 답하면서 의미를 알아가거나 문제의 해결 방법을 찾아볼 수 있습니다. 친근한 표현으로 생각하되, 설명이 원래 정의와 조건에 맞는지 확인해볼 수 있습니다.

의인화 문답은 여러 활동에서 골라 쓰는 공통 기법입니다. 새로운 단계나 선행 완료 조건을 만들지 않으며, 사용 여부를 따로 기록하거나 평가하지 않습니다. 의미를 알아보며 대화했다면 E, 해결 방법을 찾았다면 A, 혼자 답할 수 있는지 확인하거나 내용을 재구성했다면 C로 남길 수 있습니다. 하나의 공부가 여러 활동에 걸쳤다면 해당 활동들을 함께 체크해도 됩니다. 안내된 모든 방법을 수행할 필요는 없습니다.

## 주제별 다섯 활동과 체크

2026-09-23 정정: 입력 화면에는 쉬운 한글 행동명과 짧은 설명을 표시합니다. TRACE 이름·영문 원어·약어는 별도로 펼쳐 보는 공부 방법 안내에서 확인합니다. 이 문서의 영문 번호는 공부법 설명과 이전 기준 대응용이며 입력자가 알아야 할 용어가 아닙니다. 하위 항목별 체크·상태·메모·추가 반복을 각각 받습니다. 번호는 표시용이며 저장 ID와는 별개입니다. 기준을 조정하면 같은 활동 안에서 번호가 이어집니다.

| 공부법의 묶음 | 안내용 대응 번호 | 한글 입력 이름과 설명 |
|---|---|---|
| T · Trace · 흐름 조망 | T1, T2 | 흐름 살펴보기 · 전체 흐름과 앞뒤 내용의 연결을 살펴봅니다. |
| R · Reduce · 실효 정립 | R1, R2 | 핵심 정리하기 · 기억하고 사용할 핵심과 조건을 정합니다. |
| A · Apply · 해결 연습 | A1, A2 | 풀어 본 문제 다시풀기 · 방법을 골라 문제를 풀고, 막힌 부분을 다시 시도합니다. |
| C · Check · 수행 검증 | C1~C5 | 안 풀어본 문제 풀기 · 도움 없이 기억·설명·해결할 수 있는 범위를 확인합니다. |
| E · Explore · 본질 해석 | E1~E4 | 의미 이해하기 · 개념이 필요한 이유와 의미·관계를 자기 말로 해석합니다. |

### T — Trace · 흐름 조망

- [ ] **T1. 이 주제에서 답하려는 질문을 한 문장으로 적어보았다.**
- [ ] **T2. 설명의 흐름을 따라가고 필요한 선행 개념을 짚어보았다.**

무엇을 배우며 앞뒤 내용이 어떻게 이어지는지 살펴보는 활동입니다. 강의자료를 훑으며 중심 질문, 내용의 전개, 필요한 선행 개념을 짚어볼 수 있습니다.

### R — Reduce · 실효 정립

- [ ] **R1. 기억하고 사용할 정의·공식·핵심 결론을 정리해보았다.**
- [ ] **R2. 기호의 뜻과 적용 조건을 확인하고 원문과 대조해보았다.**

정의·공식·조건·결론에서 “우선 이렇게 기억하고 사용하자”라는 기준을 정하는 활동입니다. 핵심에 표시하거나 짧게 적으면서 기호의 뜻과 적용 조건을 함께 확인할 수 있습니다. 여기서 실효는 실제로 기억하고 꺼내 쓸 내용을 뜻합니다.

### A — Apply · 해결 연습

- [ ] **A1. 대표 문제를 직접 풀고 방법을 선택한 이유를 설명해보았다.**
- [ ] **A2. 틀리거나 막힌 부분을 보완하고 다시 풀어보았다.**

배운 내용을 사용하여 해결 방법을 선택하고 실행해보는 활동입니다. 대표예제나 연습문제를 시도하고, 막힌 부분은 해설을 참고하거나 필요한 내용을 보완하여 다시 풀어볼 수 있습니다. 도움을 받았거나 일부만 풀었어도 체크할 수 있습니다. 이것을 도움 없는 독립 해결로 자동 기록하지는 않습니다.

문제를 풀면서 “지금 누구의 도움이 필요하지?”, “이 정리를 모셔오면 무엇을 해결할 수 있지?”, “이분을 부를 조건은 갖춰졌나?”라고 생각해볼 수 있습니다. 후보 개념이나 공식을 비교하고, 필요한 방법을 선택하여 풀이를 이어갈 수 있습니다. 해결 방법을 찾지 못했더라도 선택과 적용을 시도했다면 A로 체크할 수 있습니다.

### C — Check · 수행 검증

- [ ] **C1. 자료 없이 핵심을 떠올리고 정확성을 확인해보았다.**
- [ ] **C2. 자기화 재구성: 공부한 내용을 나만의 언어와 방식으로 표현하고 연결해보았다.** · 선택
- [ ] **C3. 변형·혼합·새 문제에서 목표 수행을 확인해보았다.**
- [ ] **C4. 핵심 정의·공식·조건·결론을 백지에 서술하고 원문과 대조해보았다.** · 선택
- [ ] **C5. 검증 결과를 살피고 부족함과 다음 행동을 정해보았다.**

현재 기억하고 설명하고 해결할 수 있는 범위를 직접 확인하는 활동입니다. 자료 없이 핵심을 떠올리거나 문제를 풀어보고, 필요하면 시간과 허용 도구를 실제 평가에 맞출 수 있습니다. 검증 중 막혔어도 C를 체크할 수 있습니다.

자료를 덮고 “너는 어떤 역할을 하지?”, “언제 사용할 수 있지?”, “이 상황에서도 불러도 될까?”라고 질문한 뒤 스스로 답해볼 수 있습니다. 막히거나 조건이 떠오르지 않으면 그 부분을 확인해 다음 공부에 활용할 수 있습니다.

기존에 요청한 **백지 서술**은 C의 선택 검증 방법으로 유지합니다. C4 안의 ‘백지 서술’을 펼쳐 R에서 정리한 핵심 정의·공식·조건·결론과 기호의 뜻을 자료 없이 써 보고 원문과 대조합니다. 빠진 조건과 부정확한 부분을 찾았다면 필요한 메모만 남깁니다. 종이나 다른 앱에서 쓴 답을 다시 타이핑할 필요는 없습니다.

백지 서술 결과는 `충분히 서술함 / 일부 서술함 / 보완 필요`, 주제의 목표 수행 결과는 `목표 달성 / 일부 달성 / 보완 필요`로 따로 남길 수 있습니다. 입력하지 않은 결과는 미입력입니다. 백지 서술이나 결과 입력을 C 체크의 필수 조건으로 삼지 않습니다. 과거 C4와 그 결과·메모는 당시 항목으로 남으며 새 하위 항목에 자동으로 합치지 않습니다.

#### C2 — 자기화 재구성 · 선택

- [ ] **C2. 자기화 재구성: 공부한 내용을 나만의 언어와 방식으로 표현하고 연결해보았다.**

공부한 내용을 나만의 언어와 방식으로 바꾸고, 주제 사이의 관계를 연결하여 다시 구성하는 활동입니다. C 수행 검증에서 활용할 수 있으며, 일부 주제만 다루었거나 구성을 마치지 못했더라도 시도했다면 체크할 수 있습니다.

공부한 범위의 각 주제를 자기 문장으로 설명해 보세요. 나만의 풀이 방법·암기법·판단 팁·예시·암기꼬리·약어·그림·움직이는 장면·동영상 중 내용에 잘 맞는 방식을 골라 표현할 수 있습니다. 모든 방식을 사용할 필요는 없습니다. 이를 연결하며 전체 내용을 나에게 익숙한 설명 체계로 만들어볼 수 있습니다.

먼저 자료 없이 시도한 뒤 원문과 대조하면, 무엇을 기억하고 어디에서 설명이 끊기는지 확인할 수 있습니다. 자신만의 표현으로 바꾸더라도 정의의 의미와 성립 조건은 유지합니다. 이미 만든 필기·그림·동영상을 다시 옮기지 않아도 됩니다. 필요한 내용이나 자료 위치·링크, 막힌 부분만 메모에 남길 수 있습니다.

평소 C2는 체크만 저장할 수 있으며 메모와 추가 반복도 선택입니다. 입력한 메모는 해당 주제의 자기화 재구성 의문 아래에 연결됩니다. C2를 체크해도 C1의 체크·백지 서술 결과·주제 목표 달성은 자동으로 바뀌지 않습니다. 통계에서는 C 수행 검증의 체크·반복에 포함하며, 실제 성취 정도는 별도 결과로 판단합니다.

공부한 개념들을 등장인물처럼 놓고, 각자의 역할과 관계를 대화나 이야기로 다시 구성해볼 수 있습니다. 자기 문장·풀이 방법·암기법·판단 팁·예시·암기꼬리·약어·그림·움직이는 장면·동영상과 함께 자신에게 익숙한 설명 방식으로 활용해볼 수 있습니다.

#### C2 안의 시험 전 서술 점검

시험 직전에는 **기억한 내용을 자기 문장으로 남긴 뒤 점검을 체크합니다.** C2의 ‘시험 전 서술 점검 · 서술 필수’를 펼쳐 설명을 적고 ‘서술을 남기고 시험 전 점검을 해보았다’를 체크합니다. 역할·사용 조건·개념 사이의 관계를 연결해볼 수 있으며, 대화·이야기 형식도 사용할 수 있습니다. 먼저 자료 없이 시도한 뒤 원문과 대조하고, 막힌 부분과 고친 내용을 함께 남겨 보세요.

평소의 시도 체크와 구별되는 시험 전 점검입니다. 빈칸이나 공백만으로는 점검을 체크할 수 없습니다. 안내 예시를 전부 답하도록 요구하거나 글의 분량·정답 여부를 자동 판정하지는 않습니다. 아직 설명하지 못한 부분도 명시하여 남길 수 있습니다. 점검 체크는 서술해보았다는 기록이며 실제 목표 달성·정확성·백지 서술 결과는 별도로 판단합니다.

- **서술 저장**은 글만 저장합니다. 글을 수정하면 점검 체크는 다시 확인하도록 해제됩니다. 평소 C2의 시도 체크는 유지합니다.
- **점검 체크**는 현재 서술과 체크를 함께 저장하며 C2 시도도 기록합니다. 다른 활동·목표·백지 결과는 자동 입력하지 않습니다.
- 점검 체크나 C2 체크를 해제해도 서술은 보존합니다. 수정 이력·되돌리기·다시 실행·미저장 초안 복원을 지원합니다.
- 새 공부의 점검은 비어 있는 상태에서 시작합니다. 지난 서술을 새 수행으로 자동 복사하지 않습니다. 같은 공부의 수정·체크 재조작은 횟수를 늘리지 않습니다.
- 서술은 **주제 → C2 의문 → 시험 전 서술 메모**로 연결합니다. 기존 선택 메모·추가 반복 메모를 덮어쓰지 않습니다. 선택 기간의 점검 체크와 남긴 서술을 따로 집계합니다.

C3나 새로운 TRACE 기준 ID는 추가하지 않습니다. 현재 항목 번호와 사용자가 조정한 기준은 유지합니다. 사용자가 기준에서 제외한 항목의 이전 서술도 이력에서 확인할 수 있습니다.

### E — Explore · 본질 해석

- [ ] **E1. 어떤 문제나 필요를 다루기 위해 도입되는지 설명해보았다.**
- [ ] **E2. 도입 사례에서 주어진 것과 구하려는 것을 풀어 말해보았다.**
- [ ] **E3. 뜻을 자기 말과 예시로 설명하고 원문과 대조해보았다.**
- [ ] **E4. 다른 적용 상황·조건 변화·더 알 수 있는 결론을 생각해보았다.**

개념·정리·공식이 왜 필요하며 어떤 상황과 관계를 표현하는지 자기 언어로 해석하는 활동입니다. 도입 예시를 풀어 읽고, 수식과 그림을 대응시키거나, 조건이 달라질 때의 변화와 추가적인 함의를 생각해볼 수 있습니다.

개념·기호·정리·공식에 “너는 누구니?”, “왜 등장했니?”, “무엇을 설명해주니?”, “이 친구와는 무슨 관계니?”라고 질문해볼 수 있습니다. 개념의 입장에서 답하거나 개념끼리 대화하도록 구성하면서 도입 상황·역할·조건·의미를 자기 언어로 풀어볼 수 있습니다. 처음 의미를 익힐 때도 그림·상황·예시와 함께 사용할 수 있습니다.

## RAE ‘레이’와 시험 대비

내용을 익힐 때는 **RAE, ‘레이’**를 중심으로 운영합니다. R에서 기억할 기준을 정하고, A에서 사용하며, E에서 의미와 상황을 연결합니다. 세 활동을 묶어 기억하되 수행 순서는 자유롭습니다.

T는 내용의 맥락을 잡아줍니다. C는 실제로 떠올리고 사용할 수 있는 범위를 확인합니다. C에서도 기억을 꺼내는 연습이 이루어지므로 암기가 완성될 때까지 미루지 않고 중간중간 활용할 수 있습니다.

시험 대비에서는 필요한 수준의 T·R·A·E를 확보하면서 C에서 목표 수행을 달성하는 것을 지향합니다. C를 체크했다는 것은 검증을 해보았다는 뜻입니다. 시험 준비가 충분한지는 실제로 무엇을 기억하고 해결했는지에 따라 따로 판단합니다.

시험이 가까워지면 해결하지 못하는 문제와 검증에서 드러난 부족함을 먼저 보완합니다. 문제 해결에 필요한 E는 바로 다루고, 현재 평가 목표를 넘어서는 탐구는 질문을 남겨두고 나중에 이어갈 수 있습니다.

학습의 완료 기준은 과목·주제·현재 수준·평가 목표에 따라 상대적이며 가변적입니다. 입문에서는 기본 의미와 대표 문제, 시험 대비에서는 변형 문제와 시간 내 수행, 심화에서는 유도·증명·새로운 함의까지 목표로 삼을 수 있습니다. 모든 체크칸을 채워야 목표 달성이 되는 것은 아닙니다.

## RA와 E를 구분하는 예시

### 외적과 돌림힘

R에서는 외적의 계산식, 크기와 방향의 규칙, 순서를 바꾸면 부호가 바뀐다는 성질을 기억할 내용으로 정합니다.

A에서는 주어진 벡터의 외적을 구하거나 τ = r × F를 사용하여 돌림힘을 계산합니다.

E에서는 문을 여는 상황에 위치벡터와 힘을 놓고 작용 위치와 힘의 방향이 회전 효과에 어떻게 연결되는지 생각합니다. 외적의 순서를 바꿀 때 입력 벡터 자체의 방향은 그대로이고 결과의 부호가 바뀐다는 점도 그림으로 해석할 수 있습니다.

‘평행사변형의 넓이’라는 결론을 기억하고 계산하는 것은 RA이며, 밑변·높이·방향이 왜 그 식과 연결되는지 설명하는 것은 E입니다. 돌림힘은 외적의 의미를 이해하는 사례로 활용하되, 이를 외적의 실제 역사적 탄생 배경으로 단정하지 않습니다.

### 임계점

R에서는 정의역 내부에서 함수가 정의되어 있고 도함수가 0이거나 존재하지 않는 점을 살핀다는 기준을 기억합니다. 이 예시는 정의역 내부를 기준으로 하며 실제 교재의 정의와 적용 범위를 함께 확인합니다.

A에서는 함수를 미분하여 도함수가 0인 곳을 찾고, 미분이 불가능한 곳도 확인합니다.

E에서는 각 조건을 수평 접선·모서리·첨점 등의 그림으로 해석합니다. y = x²와 y = x³는 모두 원점에서 기울기가 0이지만 x²에는 극솟값이 있고 x³에는 극값이 없다는 것을 비교할 수 있습니다.

또한 y = |x|의 원점처럼 함수는 존재하지만 미분이 불가능한 경우와, y = 1/x의 x = 0처럼 함수 자체가 정의되지 않는 경우를 구분합니다. 정의를 식으로 기억하고 후보를 계산하는 것은 RA이며, 조건의 의미와 한계를 그림으로 설명하는 것은 E입니다.

## 프로그램에서 기록하는 방법

기존 필기·풀이·코드·보고서·말로 한 설명을 바탕으로 해본 활동을 체크합니다. 공부 후 책을 정리한 상태라면 기록을 위해 책을 다시 펴도록 요구하지 않습니다. 과목에 따라 ‘문제 풀기’는 증명 작성, 코드 구현, 실험 수행, 자료 분석, 서술형 답안 작성으로 바꿔 적용합니다.

평소 메모는 필요할 때만 남깁니다. 시험 전 C2 서술 점검을 체크할 때는 실제 설명을 남깁니다. 입력 안내는 **막힌 부분 / 다음에 할 일 / 더 생각해볼 질문**입니다. 학습 목표·자료·검증 조건·결과·남은 부족함·다음 행동도 선택 입력입니다.

선택 메모의 연결 구조는 **주제 → 체크 내용에 대응하는 Canvas 의문 → 작성한 메모**입니다. 예를 들어 R1의 의문은 “우선 무엇을 기억하고 사용하면 될까요?”이며 작성한 내용은 그 의문 아래에 연결됩니다. 체크만 했다면 빈 메모를 만들지 않습니다. 메모 원문·줄바꿈은 그대로 보존하고, Canvas 카드는 원기록을 참조합니다. 수정·저장 재시도에 중복 생성하지 않으며 개인 배치·연결·색과 삭제한 카드 상태를 지킵니다.

각 활동은 추가 반복으로 다시 기록할 수 있습니다. `한 번 더 함` 또는 `정확한 횟수 / 최소 이만큼 / 횟수 모름`을 사용하며, 반복 메모는 선택입니다. 일부만 반복하거나 막혔어도 기록할 수 있습니다. 체크를 껐다 켜는 조작 자체는 반복으로 세지 않습니다. 같은 공부에서 여러 활동을 체크해도 공부 기록은 한 건입니다.

상태는 `미체크 / 체크함 / 해당 없음 / 보류`를 유지합니다. 해당 없음과 제외 항목은 체크 비율의 분모에서 빼고 보류는 남겨 둡니다. 기록 전·미정·저장 충돌을 실패나 0점으로 바꾸지 않습니다. 통계는 현재 활동 체크, 선택 기간의 체크·반복·메모, 목표 달성과 백지 서술 결과를 구분합니다. 이전 기준의 체크는 기간 이력에 별도 표시하며 새 활동의 현재 체크로 환산하지 않습니다.

다음 공부는 빈 체크칸을 순서대로 채우도록 요구하지 않습니다. 남겨 둔 다음 행동·부족함과 수행 확인에서 드러난 보완점을 먼저 보여 주고, 필요한 활동을 선택할 수 있게 합니다. RAE는 내용 익히기의 선택지이며 필수 진행 순서가 아닙니다. 이미 체크한 활동도 다시 고를 수 있습니다.

## 기준 조정과 이전 기록 보존

현재 공부·성취 기준은 TRACE로 통일하며 기준 조정 기능을 유지합니다. 주제·과목과 새 주제·모든 과목과 새 주제를 선택하여 항목 문구·활동·기본/선택/제외를 조정하거나 항목을 추가할 수 있습니다.

0.30.0에서 수정하지 않은 이전 기본 14항목을 다섯 활동으로 바꿨습니다. 0.30.1에서는 기존 다섯 활동의 ID·체크·메모·반복을 유지하고 C2 자기화 재구성만 별도 ID로 추가합니다. 이전 14항목과의 구분도 유지합니다. 사용자가 직접 조정한 기준은 그대로 둡니다. 이전 기준 정의·항목 ID·실제 공부·수정 이력·초안·반복·메모·목표 결과를 보존하며, 새 활동에는 별도 ID를 사용합니다. 이전 항목의 입력은 ‘이전 기준의 체크·메모·반복’에서 열고 기존 Canvas 의문·메모도 유지합니다. 저장된 이전 초안은 당시 항목으로 이어서 저장할 수 있습니다.

0.30.2는 의인화 문답을 공통 및 A·C·E 도움말에 반영하고, C2 안에 서술이 필요한 시험 전 점검을 추가합니다. 기존 여섯 항목의 ID·정의·사용자 입력·기준 연결은 바꾸지 않습니다. 신규 서술은 별도 입력으로 저장하여 선택 메모를 보존합니다.

체크 수와 반복 횟수는 공부 시간·이해도·실력 점수·시험 성적이 아닙니다. 이 체크리스트는 공부의 흔적을 남기고 다음 행동을 떠올리는 도구입니다.


## 과목 안에서 보는 TRACE 현황

각 과목의 ‘TRACE 학습 현황’에서 기록한 주제, 부족함을 직접 남긴 주제, 시험 전 서술 점검을 한 주제를 확인합니다. 주제별 ‘활동·메모’를 열면 하위 항목의 현재 체크, 원문 메모·반복 메모·시험 전 서술, 다음 행동을 함께 볼 수 있습니다. ‘원기록’과 ‘주제 열기’로 이어집니다. 활동 분포는 필요할 때 펼칩니다. 전체 ‘변화’ 화면에 같은 TRACE 통계를 중복해서 놓지 않습니다.

## 교수님 출제 안내의 표시

출제 가능성은 기존 디자인의 `--color-orange`, 출제 확정은 `--color-red`를 그대로 사용합니다. 별도 강조 팔레트를 만들지 않습니다. 같은 주제 ID의 Canvas·Obsidian Kanban·프로그램 목차 보드가 같은 라벨과 테두리로 연결되며, 특정 세부내용의 표시에는 ‘일부 내용’을 붙입니다. 입력창·시험 목록·오늘의 출제 우선 표시도 같은 색상 역할을 따릅니다. 시험 준비 기간·표시 끔·해제 상태를 존중하고, 개인 카드 색상·위치·연결선을 덮어쓰지 않습니다.
