## 3. 실제 적용 순서와 완료 제한

1. 관련 작업을 시작할 때 이 담당 기준과 실제 변경 경로를 확인한다. 근거가 이미 유효하면 같은 외부 조사를 반복하지 않는다.
2. 새 틀/큰 변경에서는 MI01–MI12의 적용 여부를 각각 적는다. 해당하지 않으면 대상과 이유를 적으며 “나머지 동일”로 숨기지 않는다. 작은 수정은 영향을 받는 규칙과 연결된 기존 과업을 선택한다.
3. 의미 있는 첫 결과를 만든 뒤, 바뀐 경로에서 수식·분기·표현 대응·조작·복귀·보존·좁은 화면의 필요한 확인을 실행한다. 적용되지 않은 규칙과 실제 결함은 같은 허용 범위에서 보완한다.
4. **충족된 것으로 보고할 항목은 실제 구현과 관측 근거를 가져야 한다.** 실행되지 않은 검사, 자동 검사만으로 확인할 수 없는 조작, 접근 불가 조건은 미검증으로 남긴다. 검사 코드를 썼다는 사실이나 지침을 저장했다는 사실만으로 완료 보고하지 않는다.
5. 필수 결함이 있으면 해당 과업을 실사용 완료로 보고하지 않는다. 이를 첫 초안 공개 금지, 반복 사용자 승인, 관련 없는 전수 QA의 선행조건으로 확대하지 않는다.
6. 작업 보고에는 기준 정의/구현/직접 확인/미검증을 구별한다. 자동 검사와 독립적인 수학 검토, 물리 기기, 장기 사용, 학습 효과는 서로 대신하지 않는다.

**강제할 수 있는 것과 없는 것을 구별한다.** 유효한 내용 구조·허용 범위·분기 보호·저장 복귀·자동 접근성·렌더링은 검사 명령으로 반복 확인한다. 표현의 적합성, 원문 해석, 새 증명의 정당성, 학습 효과는 자동 검사로 완전 보장하지 않는다. 모델이 같은 오류를 설명과 테스트에 함께 넣을 가능성도 검토 범위에 남긴다.

## 4. 공통 틀의 구조

2026-10-02 사용자 후속 요청으로 [공통 관찰틀의 위치·조작·보존 기준](../generation2/docs/observation-frames.md)을 채택한다. 질문/관찰/조절/현재값/근거/참고의 역할별 자리, 반응형 읽기 순서, 시야·개념 초기화 범위, 비수학 읽기 예외, 대표 적용·전수 대응 전환 조건은 그 문서가 담당한다. MI01–MI12와 원문/학습 의미/저장 계약은 유지하며 기준 채택과 실제 검증을 구별한다.

화면 방식은 **관계 탐색 / 단계 전개 / 조건 판단**으로 조합한다. 수학 표현은 함수·공간·근사·누적·변화·분해·확률·기호연산·논증 후보와 연결하며 실제 교재에서 충분성을 확인한다. 세 화면 방식이나 아홉 후보를 공인 표준·교재 전체 포괄의 증거로 부르지 않는다.

개념 내용은 안정 ID, 한글·영문명, 핵심 질문, 정의역/적용 조건, 출처, 표현의 역할/대응, 조절값 범위·기본값, 단계·분기, 허용 계산 종류를 가진다. 공통 화면은 기존 디자인 토큰, LaTeX 렌더러, 조작·접근성·복귀를 담당한다. 공통 계산은 허용된 식/알고리즘, 특이점·오차·정확/근사 구별을 담당한다. 실제 사용자 저장은 기존 계정·소유권·서버 계약에 연결한다.

## 6. 그래프 확대와 물리 개념의 필수 확장

2026-10-01 사용자 “그래프는 무조건 확대해서 볼 수 있게, 물리도 구조” 요청을 적용한다. MI05/06/09/10/11/12의 구체적인 실행 요구다.

- **모든 개념 그래프는 확대·축소·전체 보기와 크게 보기를 제공한다. 2026-10-01 최종 후속 정정에 따라 현재 1D/2D에서 마우스/한 손가락 드래그는 위치 이동만, 두 손가락/트랙패드 핀치는 확대·축소로 통일한다. 영역 확대·방향 이동 버튼·드래그 방식 선택기를 두지 않는다. 일반 스크롤을 확대 입력으로 처리하지 않는다.** 명칭이 있는 ＋/−·전체 보기 버튼과 키보드 대체 조작을 함께 둔다. 크게 보기에서 복귀할 수 있어야 한다. 2D 수학 그래프의 축을 임의 회전해 의미를 바꾸지 않는다. 향후 3D 공간 표현은 실제 3D 렌더러의 카메라 회전·확대·이동·기본 시점 복귀와 카메라 상태 보존을 구현하고 별도로 확인한다. 현재 틀에는 3D 렌더러가 없다.
- 확대는 보기 범위를 바꾸는 조작이다. 정의역·모델의 유효 범위·계산한 구간을 자동으로 늘리지 않는다. 보이지 않는 곡선의 범위와 곡선이 실제로 없는 상태를 구별한다. 공간의 길이·각도 비교는 같은 축척을 유지하고, 서로 다른 단위의 물리량을 하나의 동일 세로축으로 겹치지 않는다.
- 수동 확대 범위는 개념별, 단위가 다른 그래프는 물리량별로 보존한다. 조절값 갱신·단계 전환·화면 폭 변화가 수동 시점을 지우지 않는다. 수동 시점이 없으면 현재 모델의 자료 범위에서 기본 축을 정한다. 원래 범위 버튼은 현재 개념/물리량의 기본 범위만 복구하고 다른 조절값·개념의 시점을 지우지 않는다.
- **물리 레코드는 계, 좌표·기준계·양의 방향, 물리량의 기호/이름/단위/차원, 법칙의 이름과 LaTeX, 모델의 가정과 적용 조건을 갖는다.** 누락한 물리 레코드는 실행 검사에서 거부한다. 단위 문자열의 존재 확인을 모든 물리 식의 차원 일치 자동 증명으로 표현하지 않는다.
- 물리의 공간 그림·시간 그래프·양 사이 그래프·수식은 각각 무엇을 나타내는지 표시하고 같은 상태/시각의 대응을 연결한다. 위치와 시간, 속도와 속력, 벡터의 부호와 크기, 역학적 에너지와 전체 에너지를 혼동하지 않는다. 적용 조건의 충족/위반/미확인을 분리하고, 미충족 법칙을 전제로 하는 곡선·수치 결론도 보류한다.
- 물리 풀이의 공통 순서는 **구하는 양 → 계·축 → 가정·조건 → 법칙 → 계산 → 단위·부호·경계와 원래 질문**이다. 관계 탐색·단계 전개·조건 판단 화면을 재사용하며 개념별 새 화면을 남발하지 않는다. 이 조합은 프로젝트의 구현 선택이지 물리학 전체를 포괄하는 공인 분류가 아니다.

실행 구조와 예제별 한계는 [물리·그래프 확장 기록](../outputs/20261001-math-template-kit/물리·그래프%20구조.md)을 따른다. 내용 구조를 만들거나 두 역학 사례를 확인한 결과를 전자기·파동·열·회로 전체의 구현/검증으로 확대하지 않는다.

### 6.1. 숫자와 수학 기호의 화면 표시

2026-10-01 사용자 정정: 숫자는 소수점 아래 최대 두 자리로 표시하고 의미 없는 끝자리 0을 붙이지 않는다. 계산과 저장 원값을 표시 정밀도로 반올림해 덮어쓰지 않는다. 결과·범위·축 눈금·hover·숫자 입력의 표시를 같은 규칙으로 연결한다. 작은 양의 오차를 반올림하여 정확한 0으로 오인시키지 않도록 필요한 경우 0.01 미만임을 표시한다.

한 글자의 물리량·수학 변수와 영어 기호/약어도 실제 KaTeX로 렌더한다. 본문 수식에만 적용하고 축·범례·조절부·결과·정의/조건의 기호를 일반 글꼴로 남기지 않는다. 변수는 수학 기호, 단위는 `\mathrm{...}`, 연산자/의미를 가진 첨자는 `\operatorname{...}`/`\mathrm{...}` 등 의미에 맞는 LaTeX를 사용한다. native 선택기 안에는 한글 명칭을 쓰고 인접 표현에 수식·단위를 연결한다. 기호를 렌더하더라도 입력의 접근 가능한 이름·숫자 값·키보드 조작은 유지한다.

### 6.2. 그래프 이동·핀치·읽기·복구

긴 조작 설명과 현재 범위는 필요할 때 펼쳐 보는 곳에 둔다. 기본 화면에는 드래그 이동/두 손가락 확대라는 짧은 안내와 조작부만 둔다. 수식이 여러 개면 식 하나당 한 줄로 나누며 cases·행렬 내부 구조는 보존한다.

최대 소수 두 자리 표시에서 눈금이 중복되지 않게 눈금 간격은 최소 0.01로 고른다. 현재 틀은 어느 축의 범위도 0.05 미만으로 새로 확대하지 않으며, 기존에 저장된 작은 범위는 자동으로 덮어쓰지 않고 축소·전체 보기로 복구한다. 표본 곡선이 없는 범위에는 전체 곡선 보기 버튼을 제시하며 이동을 막지 않는다. 채워진 영역을 잘못 빈 화면으로 판정하지 않는다. 0.05는 현재 예제의 구현값이며 새 단위/모델에는 규모와 표시 정밀도의 적합성을 다시 확인한다.

핀치는 손가락 사이의 지점을 중심으로 확대한다. 두 손가락에서 한 손가락으로 바뀌면 기준점을 다시 잡아 점프를 막는다. touchcancel·개념 전환에서 이전 제스처를 해제한다. 반복 입력은 프레임 단위로 합쳐 마지막 입력까지 반영한다. 전체 보기·개념별 범위 저장·같은 축척의 계약은 입력 방식과 무관하게 유지한다. 그래프 내부의 터치는 그래프를 조작하고 주변 영역에서는 기존 페이지 스크롤·브라우저 확대를 유지한다.

선정 근거: 기존 Plotly의 마우스 이동은 재사용한다. 현재 요구에 맞는 2D 핀치는 [MDN의 다중 터치 이벤트 처리](https://developer.mozilla.org/en-US/docs/Web/API/Touch_events/Multi-touch_interaction)와 [wheel 이벤트의 ctrlKey 확대 구분](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)에 따라 공통 어댑터를 추가했다. Safari GestureEvent 경로도 보완한다. 합성 이벤트·브라우저 모사 통과는 실물 트랙패드/터치 기기 확인과 구별한다.

### 6.3. 실제 앱 연결 기록

2026-10-01 공통 kit의 다섯 개념과 그래프 조작을 실제 웹앱의 `수식 탐색 → 수학·물리 개념`에 연결했다. 소유자별 디바이스 보기 저장, 앱 토큰/테마, 한 식당 한 줄의 공통 KaTeX, 다른 개념/메뉴와 재접속 복귀, 손상 원문 보호와 오류 복구의 실제 경로 및 MI01–MI12 적용은 [실제 앱 연결 기록](../generation2/docs/concept-interactives-integration-20261001.md)에 남긴다. 이번 연결은 공개 배포하지 않았으며 교재 전체의 구현·물리 기기·서버 동기화 검증으로 확대하지 않는다.

후속 사용자 명칭 확정으로 현재 도구 표시 이름은 **개념 탐구실**이다. 명칭의 적용 범위와 기존 경로/저장 보존은 [제품 명칭 결정](../generation2/docs/product-decisions-20260930.md#2026-10-01-교재-기반-인터랙티브-도구-명칭--개념-탐구실)에 따른다.
