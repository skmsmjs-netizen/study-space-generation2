# 학습 입력 웹앱 — 활성 문서 안내

2026-10-02 최종 레이아웃의 담당 원본은 [OS 레이아웃 확정 기준](../generation2/docs/layout-standard.md)·[선택 계약](../generation2/docs/layout-standard-contract.json)입니다. 현재·앞으로의 웹앱 화면/과업을 등록 패턴에 연결하며 [전체111대응](../generation2/docs/layout-standard/entity-layouts.md), 미래24요소, 조건 있는 크기/증가/전환/복귀와 [Figma 실제 결과](../generation2/docs/layout-standard/README.md)를 관리합니다. 기준 등록과 실제 UI 준수/배포를 구별합니다.

2026-10-02 사용자 첨부 철학의 담당 원본은 [지식 표현과 천문대 경험 기준](../generation2/docs/knowledge-structure-standard.md)입니다. 두 PDF의 슬라이드1–70 대응, 모듈/대응/관계/순서·전체→원문/조건·질문 복귀·개인 구조 수정과 실제 소비 범위를 연결합니다. 본문 양쪽 정렬은 천문대 기준값 `metrics.paper.bodyAlignment`와 기존 CSS 생성기가 소유합니다.

2026-10-01 사용자 결정으로 [최우선 디자인·UI·UX 지침](../generation2/docs/design-ui-ux-priority.md)을 디자인 판단의 첫 담당 문서로 적용합니다. Instagram 자료31개+디자인 개념8개 전체를 대조하며 기존 Notion/Apple/ChatGPT/Claude 미감과 개별 디자인 참고는 그 아래에 둡니다. 현재 사용자 요청·보존·권한 계약을 유지하고 관련 절만 읽습니다.

브랜드와 반복 사용 경험은 [manseeksong 지침](../generation2/docs/manseeksong-brand.md), 요구 전체와 실제 구현/확인/운영 의존의 대조는 [구현 대조표](../generation2/docs/brand-implementation-20261001.md)에서 관리합니다. 2026-10-01 직전 제안의 1–14절 모두 채택했으며 기존 보존·품질·권한·검증 정책을 상속합니다.

현재 기준: 2026-09-30 사용자 정정. 작업 대상은 `generation2/`의 웹앱입니다. 종료한 구현·지침·보관본은 이 안내의 읽기 대상에 포함하지 않습니다.

## 1. 위계와 시작 순서

1. 시스템·개발자 지침의 범위 안에서 현재 사용자 요청·정정과 변경되지 않은 합의를 적용합니다.
2. [루트 AGENTS.md](../AGENTS.md)의 공통 원칙을 [웹앱 AGENTS.md](../generation2/AGENTS.md)가 상속합니다. 하위에는 구현 차이만 둡니다.
3. [웹앱 인계](../generation2/docs/resume-handoff.md)의 최신 부분과 실제 변경 파일을 확인합니다. 이미 읽은 기준이 바뀌지 않았으면 전체 재독하지 않습니다.
4. 아래 표에서 필요한 문서의 관련 절만 이어 읽습니다. 모든 지침·사전·QA를 순회하지 않습니다.

## 3. 갱신과 읽기 제외

- 요구·동작은 담당 문서에, 실제 변경·남은 조건은 웹앱 인계와 해당 원장 항목에 남깁니다. 같은 기준을 다른 파일에 복사하지 않습니다.
- 원문·기록·ID·초안·설정·이력·개인 배치를 보존합니다. 문서·코드·실제 화면·배포·물리 기기·Sync·학습 효과를 각각 확인한 범위로 보고합니다.
- 종료한 구현·과거 지침·백업·보관본을 시작 맥락·조사·검색·이유 확인 자료로 자동 읽지 않습니다. 이 제외는 과거 보관본에서 기준을 되살리려는 경로에도 적용합니다. 현재 자료가 부족하면 현재 웹앱의 파일·계약과 사용자 요청 범위에서 판단합니다.


## 수학 인터랙티브

공통 관찰틀의 역할별 위치·조작·보존·대표 적용·전수 대응 전환은 [공통 관찰틀 기준](../generation2/docs/observation-frames.md)을 따릅니다. 수식과 개념의 실제 화면에서 적용·검증한 범위는 그 문서의 담당 실행 기록으로 확인합니다.

수학·과학 인터랙티브의 연구/공통 틀/개념별 표현/구현/검증은 [수학 인터랙티브 설계·검증 기준](수학%20인터랙티브%20설계·검증%20기준.md)을 담당 기준으로 읽습니다. PhET·DeFT·NCTM·WCAG/APG의 채택 범위와 MI01–MI12, 실제 적용·완료 제한을 한 곳에서 관리합니다.
