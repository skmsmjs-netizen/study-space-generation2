# 스킬 개정의 적용 평가

이 문서는 스킬을 만들거나 크게 개정할 때 사용하는 평가 자료다. 일상 답변마다 실행하지 않는다. 규칙 문구의 존재보다 스킬을 적용한 실제 산출물을 본다.

## 실행 방식

응답 생성자와 채점자를 구분한다. 스킬 경로와 아래 입력·원자료만 독립 응답 생성자에게 준다. 응답 생성자에게 이 문서의 통과 기준, 의심한 결함, 수정 의도, 이전 답을 주지 않는다. 각 사례는 독립 대화로 다룬다. 외부 쓰기나 실제 제품 수정 없이 격리 위치에 응답·변경안을 만든다. 연결·실기기가 필요한 추가 평가는 해당 권한과 환경이 있을 때만 별도 수행한다.

응답 생성자는 자기 답을 설명하기보다 요청된 결과를 만든다. 채점자는 결과의 요구 대응과 의미·상태·기능 보존을 보고 아래 기준으로 판정한다. 자연스러운 여러 답을 허용하며 예문과 글자 그대로 같은지를 테스트하지 않는다. 판단 근거·실제 출력·버전을 기록한다. 사례를 설계한 것과 실행해 통과한 것을 구별한다.

## 회귀를 판정한다

각 사례를 `통과 / 실패 / 검증 불가`로 판정하고 실제 출력 위치를 남긴다. 조건 변형·사실 발명·범위 확장·완료 과장은 다른 사례의 장점으로 상쇄하지 않는다. 실패가 있으면 원인을 고친 뒤 해당 사례와 인접한 다른 맥락으로 재평가한다. 동일 예문의 암기만으로 통과하지 않게 새로운 수치·매체·조건에서도 판단이 유지되는지 본다.

위 13개는 쓰기와 설계 판단의 기본 회귀 사례다. 실제 화면 구현, 호스트 앱, VoiceOver, 물리 기기의 성공을 증명하지 않는다. 사례 통과만으로 모든 미래 작업에서 최고 품질을 보장한다고 쓰지 않는다.
