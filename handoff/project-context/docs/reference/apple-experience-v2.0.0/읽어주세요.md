# Apple 경험 언어 v2.0.0

2026-09-11에 확인한 현재 적용 지침 전달본입니다.

- 전체를 읽거나 복사하려면 `Apple 경험 언어 v2.0.0 - 전체 지침.txt`를 엽니다.
- 원본 파일 구조는 `apple-experience-system/`에 있습니다. 스킬 본문과 참고 문서 5개를 그대로 담았습니다.
- `프로젝트 우선 적용 규칙.md`는 현재 AGENTS.md의 관련 3개 섹션입니다. 스킬의 일반 기본값보다 우선합니다.
- 한국어 설명·안내는 자연스러운 존댓말(~합니다/~입니다/~됩니다)을 기본으로 합니다. 쓰기 기준 원문의 일반 말투보다 이 규칙이 우선합니다.
- 사용자 지정 형식·편집 범위·전문 규약을 함께 따릅니다. 이 묶음은 표현 지침이며, 별도 프로젝트 규약의 전체 사본은 아닙니다.
- 출처 문서의 확인일·검증 범위는 당시 기록을 그대로 보존했습니다. 이번 전달에서 외부 출처를 새로 검증하지 않았습니다.
- `원문 대조.json`에는 포함된 원문 파일 및 프로젝트 발췌의 SHA-256을 기록했습니다.
