## 0. 이 문서가 완성하는 것

이 이론의 목적은 **필요한 생활을 먼저 보호하고, 그 안에서 공부를 시작·지속·중단·재개할 수 있도록 돕는 것**입니다. 깨어 있는 시간이나 공부 시간을 무한히 늘리는 것이 목적은 아닙니다.

이번에는 수면·기상, 시간 배분, 작업부하·휴식, 집중 여유의 예상, 이탈, 식사·충동 대응, 실천 점수·누적 보상, 최근 학습 양상까지 하나의 체계로 연결합니다. 필요한 가정과 계수는 질문 없이 잠정 선택했습니다. 선택한 값이 민석님의 실제 생활이나 개인 생리상수라는 뜻은 아닙니다.

완성의 의미는 “모든 현상이 증명됐다”가 아니라 **각 입력에 대해 무엇을 계산하고, 무엇을 보류하며, 어떤 행동 후보를 제시하는지가 정해졌다**는 뜻입니다. 과학적 타당성은 이 명세를 대상으로 별도로 검증합니다.

### 먼저 보는 전체 구조

| 층 | 받는 것 | 만드는 것 | 지켜야 할 경계 |
|---|---|---|---|
| 기록 | 자기보고, 시각, 실행·확인 사건 | 확인된 생활·학습 원장 | 기록된 시간이 실제 집중시간은 아닙니다. |
| 제약 | 채택한 수면·생활·일정 계획 | 공부에 배정할 수 있는 시간과 현재 선택 범위 | 잠·식사를 줄여 여유를 늘리지 않습니다. |
| 예상 | 수면 이력, 등록된 작업·휴식, 공개된 고정 가정 | 수면압·작업부하·집중 여유의 시나리오 | 가정이 만든 값을 측정값으로 바꾸지 않습니다. |
| 안내 | 현재 요청, 제약, 기록, 예상의 적용 상태 | 지금 가능한 행동과 검토 시점 | 현재 필요와 선택권이 점수보다 우선합니다. |
| 보상·요약 | 확인된 행동과 당시 목표 | 생활실천 점수, 누적 포인트, 최근 양상 | 예측값·낙관적 보고 자체에는 보상을 주지 않습니다. |

관측이 들어오면 원장과 계산 결과는 바뀝니다. 그러나 결과를 맞추기 위해 사람별 계수를 자동 학습하지 않습니다.

$$
\theta_n=\theta_0,\qquad
X(t_{n+1}^{+})
=\mathcal J_{\theta_0}\!\left(
\Phi_{\theta_0}(X(t_n^{+}),t_{n+1}-t_n),e_{n+1}
\right),\qquad
O_n=\mathcal G_{\theta_0}(X(t_n^{+})).
\tag{1}
$$

\(\Phi\)는 사건 사이의 시간 변화, \(\mathcal J\)는 새 입력·정정에 따른 전이, \(\mathcal G\)는 결과를 만드는 함수입니다. 아래에서 각각을 정의합니다. 계획 변경은 새 계획 버전이며, 자동 파라미터 추정과 구별합니다.

## 1. 개념과 주장의 종류

### 1.1 반드시 구별할 개념

| 개념 | 이 명세의 정의 | 이 정의에 포함하지 않는 것 |

| 학습 활동 | 사용자가 학습으로 확인한 시간 구간 | 실제 주의 배분, 이해, 기억, 성적 |
| 집중 | 특정 과제에 주의를 유지하는 실제 과정 | 타이머 작동 그 자체 |
| 몰입 | 과제와 자아·시간 경험에 관한 심리 상태 | 긴 세션이나 높은 점수만으로 하는 판정 |

| 현재 졸림 \(z\) | 응답 시점의 졸림에 대한 순서형 자기보고 | 객관적 수행검사나 진단 |
| 집중 여유 \(R\) | \(S,F,C_a\)를 결합한 시나리오 지표 | 집중률, 공부 성공 확률, 건강 점수 |
| 비계획 중단 | 원래 의도한 진행보다 먼저 멈췄다고 보고한 사건 | 도덕적 실패, 모든 일시정지 |
| 회복 | 명시적 휴식의 기록, 또는 그 조건에서의 모형상 \(F\) 감소 | 실제 회복 효과가 확인됐다는 주장 |
| 최근 양상 | 같은 규칙 아래 최근 관측된 종료 이유 등의 분포 | 본질적 성격·고정 학습 스타일 |
| 생활실천 점수 \(D\) | 채택한 목표를 확인된 행동이 충족한 정도 | 삶·성실성·사람의 가치 |
| 누적 포인트 \(XP\) | 확인된 충족분의 날짜별 적립 원장 합 | 저축한 생리 에너지, 능력 성장량 |

주관적으로 느낀 졸림과 객관적 수행이 항상 함께 변하는 것은 아닙니다. 수면 제한 실험에서도 두 결과의 변화 양상이 달랐습니다. 따라서 자기보고 하나나 수면압 하나를 학업 수행 전체의 대리값으로 사용하지 않습니다. [Van Dongen 등, 2003](https://www.med.upenn.edu/uep/assets/user-content/documents/VanDongen2003CumulativeCost.pdf)

### 1.2 모든 식과 계수의 귀속

- **정의**: 이 프로젝트가 무엇을 기록·계산하기로 했는지 정하는 규약입니다.
- **도출**: 정의와 가정으로부터 수학적으로 따라오는 결과입니다.
- **문헌 모형**: 확인한 연구에서 가져온 관계·계수입니다. 개인에게 검증됐다는 뜻은 아닙니다.
- **정책**: 배점·문턱·질문 빈도·안내 우선순위처럼 목적에 맞춰 선택한 규칙입니다.
- **가설**: 실제 사람의 상태·중단·조치 효과와 대응할 가능성을 검증해야 하는 부분입니다.

같은 관측값을 만드는 서로 다른 실제 집중 과정이 존재할 수 있습니다. 자료 \(H(z)\)로 실제 양 \(\varphi(z)\)를 유일하게 알아내려면 최소한 다음 조건이 필요합니다.

$$
H(z_1)=H(z_2)\ \Longrightarrow\ \varphi(z_1)=\varphi(z_2).
\tag{2}
$$

타이머 40분으로는 그중 40분 집중한 경우와 20분 집중한 경우를 구별하지 못합니다. 따라서 예상층의 유일한 계산 결과는 **주어진 가정 아래의 유일성**이며 실제 집중의 식별이 아닙니다. 이 한계를 이유로 수학을 없애지도 않고, 수학이 있다는 이유로 한계를 없애지도 않습니다.

## 2. 입력 계약과 입력부담

### 2.1 기본 일일 입력

연속시간 \(t\)의 단위는 분입니다. 시각에는 날짜와 시간대를 함께 보관합니다. \(\bot\)는 미확인, \(0\)은 확인된 영, \(\mathrm{NA}\)는 규칙상 적용 제외입니다.

$$
\mathbf y_d=(h_d,w_d,m_d,c_d,r_d,v_d),\qquad
\bot\ne0,\quad \bot\ne\mathrm{NA}.
\tag{3}
$$

| 입력 | 질문의 뜻 | 값 | 직접 쓰이는 곳 |
|---|---|---|---|
| \(h_d\) | 주수면에서 실제로 잤다고 추정하는 시간 | 0–1440분, 미확인 | 수면 목표 충족, 수면 시나리오 |
| \(w_d\) | 그 수면 뒤 침대에서 실제로 일어난 시각 | 날짜·시각, 미확인 | 기상 계획 편차, 수면 시나리오의 가정 앵커 |
| \(m_d\) | 미리 정한 필요한 식사를 실제로 챙겼는지 | 모두 챙김 1, 일부 이상 놓침 0, 미확인 | 식사 실천 |
| \(c_d\) | 충동 상황에서 정해 둔 선택 절차를 사용했는지 | 상황 없음 N, 모두 사용 1, 일부 이상 미사용 0, 미확인 | 충동 대응 실천 |
| \(r_d\) | 미리 고른 한 가지 돌봄 행동을 했는지 | 완료 1, 미완료 0, 미확인 | 움직임 또는 회복 실천 |
| \(v_d\) | 표시된 학습 구간이 맞는지 | 확인, 정정, 오늘 학습 없음, 미확인 | 활동 원장 확정 |

수면시간은 침대에 머문 시간이 아닙니다. \(w_d\)도 마지막으로 잠에서 깬 시각과 반드시 같지는 않습니다. 원래 필드의 뜻을 바꾸지 않습니다.

\(m_d=0\)이면 \(c_d\)가 달라도 기본 식사 점수는 0입니다. 따라서 이 경우 일일 점수를 위한 \(c_d\) 질문은 생략할 수 있습니다. \(m_d\)가 미확인인 경우에도 \(c_d\)만으로 식사 점수를 확정할 수 없으므로 기본 후속 질문을 생략합니다. 생략을 N이나 성공으로 저장하지 않습니다. 필요한 도움·선택적 기록은 계속 사용할 수 있습니다.

### 2.2 전체 기능을 위해 추가하는 두 종류의 입력

**현재 상태에는 현재 입력이 필요하고, 중단 양상에는 종료 이유가 필요합니다.** 아침 수면 기록과 타이머만으로 두 결과를 만들어 내지 않겠습니다.

| 추가 입력 | 정의 | 제시 시점 | 건너뛴 경우 |
|---|---|---|---|
| \(z(t_z)\) | 0: 졸리지 않음 / 1: 조금 졸림 / 2: 졸려서 지속이 어려움 / 3: 깨어 있기 어려움 | 공부하는 날 첫 시작에 최대 1회 제시. 이후 사용자가 상태 도움을 요청할 때 | 현재 졸림 판단만 보류합니다. |
| \(e_j^{\rm end}\) | 예정대로 마침 / 예정보다 일찍 피로·졸림으로 마침 / 예정보다 일찍 내용 막힘으로 마침 / 외부 방해 / 선택·일정 변경 / 잘 모르겠음 | 학습 시도 종료 시 1회 | 종료 이유는 미확인입니다. |

\(z\)는 이 프로젝트의 **미검증 단일 문항**입니다. 기존 표준 척도의 점수·검사명·진단 문턱을 가져오지 않습니다. 순서 정보만 사용하며 3이 1의 세 배 피로라는 식으로 계산하지 않습니다. 보고의 유효기간은 60분, 명시적 상태 변경·도움 종료·새 보고가 있으면 그 전이라도 종료하는 정책입니다.

종료 이유는 타이머 일시정지마다 묻지 않습니다. 휴식 후 같은 시도를 재개할 때에는 하나의 시도로 이어집니다. “피로·졸림”이라는 이유 선택은 사용자의 귀속이며 실제 원인이 확정됐다는 뜻은 아닙니다.

시작 때 이미 선택한 시도 종료계획(시간 또는 사용자가 정한 완료 조건)의 버전을 연결합니다. 예정 시간이 끝난 뒤 피로를 느끼는 것과, 피로 때문에 예정보다 일찍 끝내는 것을 구별합니다. 계획 없이 시작할 수는 있지만 그런 시도의 비계획 종료 여부는 미확인입니다. 최초 주의이탈이나 중간의 모든 막힘을 측정하는 문항은 아닙니다.

### 2.3 부하를 숨기지 않는 집계

학습 시도 \(N_d\ge1\)개를 모두 종료하고 응답한 날의 기본 응답 수는 다음과 같습니다.

$$
Q_d^{\rm answer}=(5\text{ 또는 }6)+1+N_d.
\tag{4}
$$

생활 입력 5–6개, 첫 시작의 졸림 1개, 종료 이유 \(N_d\)개입니다. 시작·종료 조작 약 \(2N_d\), 휴식·재개, 정정, 처음 설정, 추가 도움, 분할수면의 선택적 상세 기록은 별도입니다. 한 화면에 합쳐도 독립적인 판단 수를 줄였다고 계산하지 않습니다. 공부하지 않는 날에는 졸림·종료 이유 질문을 자동 추가하지 않습니다.

모든 응답은 건너뛸 수 있습니다. 이 경우 해당 지표를 보류하며 사용 자체를 막지 않습니다. 이 수가 입증된 최솟값이라는 주장도 하지 않습니다. 긴 반복 설문의 부담·자료 품질 문제는 연구 근거가 있지만, 그 연구가 이 앱의 5–6개 또는 식 (4)를 최적이라고 입증한 것은 아닙니다. [Eisele 등, 2022](https://cris.maastrichtuniversity.nl/en/publications/the-effects-of-sampling-frequency-and-questionnaire-length-on-per/)

| 한 블록 상한 \(L\) | 25분 초안 | 편의 정책. 최적 집중시간 아님 |
| 고정일정 \(C_d\), 필수생활 \(N_d\), 여유 \(B_d\) | 미설정 | 직업·수업·식사 소요를 임의로 지어내지 않음 |
| 식사 기준 | 본인에게 필요한 식사를 챙김 | 정해진 3끼·열량·체중 기준 강제 안 함 |
| 충동 대응 절차 | 현재 필요 확인 → 먹기를 포함해 선택 → 선택 실행 | 참기·굶기를 정답으로 삼지 않음 |
| 돌봄 행동 | 회복을 위한 5분의 조용한 휴식 초안. 다른 가능한 행동으로 교체 가능 | 건강 효과량이나 충분한 운동량 아님 |

적용 전인 초안으로 과거 실천을 채점하지 않습니다. 일정 예산이 없으면 정확한 하루 가용량은 보류하지만 기록·생활 도움·시나리오 설명은 사용할 수 있습니다. 실제 수면 목표와 기상 계획을 채택하지 않았다면 관련 목표 점수는 보류합니다.

수면에 충분한 시간을 배정하고 규칙성을 유지하는 방향은 일반 수면 지침과 연결됩니다. 다만 위 480·510분·07:00은 이 문서가 정한 초안입니다. [NHLBI, Healthy Sleep Habits](https://www.nhlbi.nih.gov/health/sleep-deprivation/healthy-sleep-habits)

## 3. 생활시간을 보존하는 제약

### 3.1 날짜와 수면 보호

$$
I_d=[\tau_d,\tau_{d+1}),\qquad
\Delta_d=\mu(I_d),\qquad
\mu(A)=\int\mathbf1_A(t)\,dt.
\tag{5}
$$

서울의 보통 하루는 1440분입니다. 시간대·일광절약시간이 있는 경우 실제 경과시간을 사용합니다. 과거 날짜를 새 시간대에 맞춰 조용히 재분류하지 않습니다.

날짜가 붙은 기상계획 \(W_j\)와 수면기회 \(s_j\)를 이용해:

$$
\mathcal S_d=I_d\cap\bigcup_j[W_j-s_j,W_j).
\tag{6}
$$

전날부터 이어지는 구간과 **오늘 밤부터 내일 기상까지의 구간**을 모두 포함합니다. 다음날 계획이 없어 오늘 밤 보호를 정할 수 없으면 해당 예산 계산은 보류합니다.

수면을 제외한 고정일정·필수생활·여유의 비중복 예산을 \(C_d,N_d,B_d\ge0\)로 두면:

$$
A_d^{raw}=\Delta_d-\mu(\mathcal S_d)-C_d-N_d-B_d,\qquad
A_d=\max(0,A_d^{raw}),\qquad
Q_d=\max(0,-A_d^{raw}).
\tag{7}
$$

각 값은 유한한 분 단위여야 합니다. 정확한 일정 구간이 있으면 구간 합집합의 길이를 한 번만 빼며, 같은 시간을 합계 예산에서도 다시 빼지 않습니다. 합계 모드는 비중복 배정의 확인이 있어야 유효합니다.

\(Q_d>0\)이면 계획 충돌입니다. 이때 \(A_d=0\)은 산술적 절단값일 뿐 정상 휴무를 뜻하지 않습니다.

$$
G_d^{ref}=
\begin{cases}
\min(G_d^{req},A_d),&\text{예산이 완전·유효하고 }Q_d=0,\\
\bot,&\text{그 밖}.
\end{cases}
\tag{8}
$$

### 3.2 과거 기준과 지금의 계획

당일 점수 기준은 적용 시각 \(\eta_d\)와 함께 고정합니다.

$$
\Theta_d^{ref}=
(H_d,W_d,\delta,\eta_w,\mathcal S_d,A_d,G_d^{ref},
\eta_d,\beta_d,\text{policyVersion}).
\tag{9}
$$

\(\beta_d\)는 식사·충동 대응·돌봄의 사전 기준입니다. 현재 행동계획 \(P^{now}(t)\)은 변경할 수 있지만 \(\Theta_d^{ref}\)를 뒤늦게 완화해 이미 관측한 결과에 가점을 주지 않습니다.

짧게 잤거나 식사를 놓쳐도 보호예산은 자동으로 줄지 않습니다. 현재 일정이 바뀌어 더 할 수 있는 시간이 10분이면, 원래 목표에서 90분이 남아 있어도 현재 안내는 10분 또는 종료를 따릅니다.

## 4. 실행·확인·정정의 이산 동역학

### 4.1 실행 상태

\(s(t)\)는 준비, 실행, 일반 일시정지, 명시적 휴식, 종료, 기록 복구 중 하나입니다. 일반 일시정지와 휴식을 분리합니다.

$$
\dot\ell(t)=\mathbf1\{s(t)=\text{실행}\},\qquad
\ell(t_0)=0.
\tag{10}
$$

\(\ell\)은 등록 시계입니다. 집중도나 학습량으로 이름을 바꾸지 않습니다.

| 사건 | 허용 전이 | 기록 처리 |
|---|---|---|
| 시작 | 준비·종료·복구 → 실행 | 새 시도. \(\ell=0\), 열린 미확인 구간 생성 |
| 일시정지 | 실행 → 일반 일시정지 | 실행 구간 닫기. 휴식으로 간주하지 않음 |
| 휴식 시작 | 실행·일시정지 → 명시적 휴식 | 휴식 구간 시작. 실제 효과가 아니라 행동 기록 |
| 재개 | 일시정지·휴식 → 실행 | 같은 시도와 누적 시계 유지 |
| 종료 | 실행·일시정지·휴식 → 종료 | 열린 구간 닫기, 종료 이유 선택 가능 |
| 비정상 종료·불확실한 시계 | 해당 상태 → 기록 복구 | 경과분을 임의 확정하지 않음 |
| 복구 중 새 시작 | 기록 복구 → 실행 | 옛 미확인 기록 유지, 새로운 시도 시작 |

불가능한 전이는 오류로 남깁니다. 같은 사건 ID·버전을 다시 받아도 중복 적용하지 않습니다. 세션 버튼으로 예상 부하 \(F\)나 수면압 \(S\)를 0으로 만들지 않습니다.

### 4.2 활동 원장

각 기록은 ID, 버전, 시간구간 \(J_i\), 확인 상태, 시도 ID를 갖습니다. 현재 버전의 확인된 활동 구간과 미확인 집합을:

$$
K_d=\bigcup_{i:\,confirmed}(J_i\cap I_d),\qquad
U_d=\{\text{열림·미확인·정정 대기 기록}\},\qquad
b_d=\mathbf1\{\chi_d=1,\ U_d=\varnothing\}
\tag{11}
$$

로 정의합니다. \(\chi_d\)는 **현재 목록 버전**의 명시적 확인입니다. 기록이 없다는 사실만으로 학습 0분을 확정하지 않습니다.

새 미확인 기록은 \(K_d\)를 지우지 않고 \(U_d\)에 추가합니다. 기존 기록 \(j\)의 정정 때는 다른 확인 기록들을 다시 합집합으로 계산합니다.

$$
K_d^{(-j)}=\bigcup_{i\ne j:\,confirmed}(J_i\cap I_d).
\tag{12}
$$

\(K_d\setminus J_j\)로 처리하면 겹친 다른 기록의 근거까지 지워지므로 사용하지 않습니다. “오늘 학습 없음”은 명시적 날짜·목록 정정으로만 처리합니다. 해당 날짜와 겹친 부분을 현재 버전에서 제외하고, 다른 날짜 부분과 원본 이력은 보존합니다.

### 4.3 보상 가능한 시간

$$
T_d^{known}=\mu(K_d),\qquad
T_d^{eligible}
=\min\!\left(
A_d^{ref},
\mu\left((K_d\cap[\eta_d,\infty))\setminus\mathcal S_d^{ref}\right)
\right).
\tag{13}
$$

유효한 기준이 있을 때만 계산합니다. 수면 보호구간에서의 공부는 활동 사실로 남지만 추가 실천 적립에는 포함하지 않습니다. 기준 채택 전 활동에 소급 가점하지 않습니다. 총시간만 입력하고 실제 구간을 모르면 보호구간과의 겹침을 판단할 수 없어 해당 적립은 보류합니다.

필수생활 예산은 상한을 보호하지만, 상세 구간이 없으면 실제 식사시간을 침범했는지는 모릅니다. 식사 누락 신호를 별도로 남기는 이유입니다.

## 5. 수면·각성 동역학

### 5.1 문헌에서 가져오는 최소 부분

수면항상성 모형은 각성 중 증가하고 수면 중 감소하는 \(S\)를 둡니다. 다음 시정수는 원모형 저자들의 1999년 논문 부록에서 확인한 값을 분 단위로 변환한 것입니다. 개인의 보편적 생리상수로 취급하지 않습니다. [Borbély & Achermann, 1999, Appendix](https://journals.sagepub.com/doi/pdf/10.1177/074873099129000894)

$$
\dot S(t)=
\begin{cases}
(1-S(t))/1092,&\text{각성 시나리오},\\
-S(t)/252,&\text{수면 시나리오},
\end{cases}
\qquad 0\le S\le1.
\tag{14}
$$

같은 상태가 \(\Delta\)분 지속되는 정확해는:

$$
\Phi_W(s,\Delta)=1-(1-s)e^{-\Delta/1092},\qquad
\Phi_S(s,\Delta)=s\,e^{-\Delta/252}.
\tag{15}
$$

따라서 1분마다 수치적분해야만 구현할 수 있는 이론은 아닙니다. 수면·각성 경계별로 식 (15)를 합성하면 됩니다. 여기서는 원논문의 자동 입면·기상 문턱과 잡음을 사용하지 않습니다. 실제로 잠들 시각을 이 모형이 알아서 결정한다고 주장하지 않습니다.

### 5.2 두 입력으로 만드는 등가 수면 시나리오

기본 입력에는 실제 입면·마지막 각성·중간 각성·낮잠이 없습니다. 추가 상세 기록 없이 다음 계산 구간을 만듭니다.

$$
\widetilde I_d=[w_d-h_d,w_d).
\tag{16}
$$

이는 **보고한 실제 수면시간을 침대에서 일어나기 직전의 연속수면으로 배치한 시나리오**입니다. 실제 잠든 시각의 역산값이 아니며 관측 원장에 수면시작 사실로 저장하지 않습니다. 그 사이에 다른 수면이 없었다는 가정도 포함합니다.

연속 보고가 유효하고 \(a_d=w_d-h_d-w_{d-1}\ge0\)이면:

$$
S(w_d)
=\Phi_S\!\left(\Phi_W(S(w_{d-1}),a_d),h_d\right).
\tag{17}
$$

겹침이나 음의 각성시간을 0으로 잘라 계산하지 않습니다. 잘못 연결되는 구간은 보류합니다. \(h=0\)은 확인된 무수면으로 처리할 수 있지만 개인에게 장시간 각성을 권하는 근거로 사용하지 않습니다.

선택적 상세 수면 구간이 있으면 등가 구간을 대신합니다. 두 자료를 중복 합산하지 않습니다. 분할수면이 확인됐는데 상세 구간이 없으면 단일수면 예상은 부적합으로 표시하고, 수면 기록·생활 계획 기능은 유지합니다.

### 5.3 처음 사용하는 날과 기록 공백

기준 수면목표 \(0<H_0<1440\)가 있는 대표 시나리오에서는 매일 \(1440-H_0\)분 각성·\(H_0\)분 수면을 반복하는 가상 정상주기를 계산한 뒤, 첫 보고 수면의 시작 직전을 그 주기의 취침 직전 상태로 초기화합니다.

$$
a=e^{-(1440-H_0)/1092},\quad b=e^{-H_0/252},\qquad
S^*_{wake}=\frac{b(1-a)}{1-ab},\qquad
S^*_{bed}=1-(1-S^*_{wake})a.
\tag{18}
$$

이는 \(s=b[1-(1-s)a]\)를 풀어 얻습니다. 첫 보고 수면의 **시작 직전**에 \(S^*_{bed}\)를 놓고 실제 보고 \(h\)만큼 식 (15)를 적용합니다. 이후에는 이력을 이어가며 매일 정상값으로 초기화하지 않습니다.

이 가정이 개인에게 맞는다는 보장은 없으므로 첫 구간의 가능한 \(S\) 범위 \([0,1]\)도 함께 전파합니다. 기준 목표가 없어도 이 범위는 계산할 수 있지만 대표 초기값은 보류합니다.

수면·각성 여부가 미확인인 공백 \(\Delta\)에는:

$$
[S^-,S^+]\ \mapsto\
\left[S^-e^{-\Delta/252},\
1-(1-S^+)e^{-\Delta/1092}\right].
\tag{19}
$$

전부 수면인 극단과 전부 각성인 극단으로 가능한 경로를 감쌉니다. 공백을 “평소처럼 잤음”으로 채우지 않습니다. 공백 이후 대표 경로는 보류하고 범위만 이어가며, 새 대표 초기 가정을 명시적으로 채택한 경우에만 새 분석 구간을 시작합니다.

범위는 **해당 방정식·입력 가정 안에서의 범위**이지 신뢰구간이나 실제 생리상태의 보장 구간이 아닙니다.

### 5.4 일주기 성분

최소 입력에서는 개인의 실제 일주기 위상을 추정할 수 없습니다. 잠정적인 시점 성분만:

$$
C_a(t;\phi)=\frac{1+\cos(2\pi(t-\phi)/1440)}2,\qquad 0\le C_a\le1
\tag{20}
$$

로 둡니다. \(\phi\)는 분석 기준일의 현지 16:00에 대응하는 절대시각을 \(t\)와 같은 분 단위·시간 원점으로 표현한 값입니다. 모형상 각성 지원이 가장 큰 기준점이며, 주기적으로 반복됩니다. 이 단순 사인파와 16:00은 **프로젝트 가설**입니다. 원논문 전체 일주기 함수의 재현이나 측정한 개인 위상이 아닙니다. 시간대 변경 시에는 기본 위상을 이어 붙이지 않고 새 분석 구간 또는 보류 상태로 처리합니다.

한 분석 구간에서 \(\phi\)를 고정합니다. 늦게 일어났다는 이유로 그날 즉시 생체시계가 같은 만큼 이동했다고 계산하지 않습니다. 낮 중심 생활의 민감도 시나리오는 \(\phi\in[14{:}00,18{:}00]\)로 둡니다. 교대근무·시차 이동·불규칙 수면에는 기본 위상 사용을 중단하고 전체 위상 또는 보류 상태를 사용합니다.

### 5.5 누적 수면 결손은 별도로 남깁니다

최근 7일 중 동일한 목표·정의 아래 확인된 날짜 집합을 \(\mathcal D_7\)로 놓습니다.

$$
B_7=\sum_{d\in\mathcal D_7}\max(0,H_d-h_d),\qquad
\bar q_{S,7}
=\frac1{|\mathcal D_7|}
\sum_{d\in\mathcal D_7}\min(1,h_d/H_d).
\tag{21}
$$

\(B_7\)은 **기록된 날짜의 목표 미달분 합**이지 생리적 수면부채의 측정값이 아닙니다. 반드시 관측일수와 함께 표시합니다. 0일이면 평균은 \(\bot\)입니다. 오래 잔 날로 지난 미달분을 자동 상쇄하지 않습니다. 그렇다고 \(B_7\)만큼 더 자야 한다고 처방하지도 않습니다.

단기 \(S\)가 낮아졌다고 장기 수면 제한의 수행 영향까지 사라졌다고 표시하지 않습니다.

## 6. 작업부하·휴식의 동역학

### 6.1 왜 이 형태를 선택하는가

작업 지속 중 부하가 쌓이고 명시적 휴식 중 줄어드는 가장 작은 유계 모형을 선택합니다. 주의 과제에서 짧은 목표 전환이나 휴식이 영향을 줄 수 있다는 근거는 있지만, 아래 지수식·90분·20분이 증명됐다는 근거는 아닙니다. 또한 피로 증가와 수행 감소가 항상 일치하지 않으므로 \(F\)를 실제 성과로 바꾸지 않습니다. [Ariga & Lleras, 2011](https://pubmed.ncbi.nlm.nih.gov/21211793/), [Herlambang 등, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6764012/)

작업 노출 \(u(t)=1\)은 등록된 실행 구간, 휴식 노출 \(v(t)=1\)은 명시적으로 선택한 휴식 구간입니다. 동시에 1일 수 없습니다.

$$
\dot F(t)=\frac{u(t)}{\tau_L}(1-F(t))
-\frac{v(t)}{\tau_R}F(t),\qquad
\tau_L=90,\ \tau_R=20\ {\rm min},\quad 0\le F\le1.
\tag{22}
$$

작업 부하가 클수록 남은 증가 여지는 작아지고, 휴식에서의 절대 감소량은 현재 부하에 비례한다는 **가설**입니다. 난도·흥미·질병·정서·수업·신체활동의 개인별 효과는 포함하지 않습니다.

$$
\Psi_L(f,\Delta)=1-(1-f)e^{-\Delta/\tau_L},\qquad
\Psi_R(f,\Delta)=f\,e^{-\Delta/\tau_R}.
\tag{23}
$$

### 6.2 모르는 시간을 휴식으로 만들지 않습니다

일반 일시정지·앱 종료·타이머 밖의 시간은 미확인입니다. 대표 경로는 그 구간에서 \(F\)를 유지한다는 **중립적 계산 약속**을 두며, 가능한 경로는:

$$
[F^-,F^+]\ \mapsto\
\left[F^-e^{-\Delta/\tau_R},\
1-(1-F^+)e^{-\Delta/\tau_L}\right]
\tag{24}
$$

로 넓힙니다. 대표값 유지가 실제 피로가 일정하다는 뜻은 아닙니다. 미확인 시간이 길면 실제 작업량·회복을 모른다는 사실이 범위에 드러납니다.

최초 사용 시 대표 \(F=0\)은 “등록된 작업 이력을 아직 누적하지 않은 기준점”입니다. 실제로 충분히 회복했다는 추정이 아닙니다. 초기 범위는 \([0,1]\)입니다. 명시적 수면 시나리오에서는 식 (23)의 휴식 분기를 적용하되, 이는 \(F\)만의 가설적 완화이며 \(S\)는 식 (14)를 따릅니다.

새 세션·자정·성공적인 종료 이유만으로 \(F\)를 초기화하지 않습니다. 작업·휴식이 겹치면 구간이 정정되기 전까지 해당 예상은 보류합니다. 종료 누락·동기화 충돌은 휴식이 아니라 미확인 입력입니다.

## 7. 현재 상태와 집중 여유의 출력

### 7.1 현재 졸림은 직접적인 안내 입력입니다

유효한 \(z=2\) 또는 3이면 쉬기·마치기·수면 여건 검토를 우선 제시합니다. 모형 \(R\)가 높다고 자기보고를 틀렸다고 판단하지 않습니다. \(z=0\)도 객관적 수행이 충분하다는 보증이 아닙니다.

현재 졸림 보고는 \(S,F\)나 계수를 강제 보정하지 않습니다. 기록된 수면이 정정되면 그 자료를 입력으로 시나리오를 다시 계산할 뿐입니다. 따라서 관측과 모형의 차이를 “메타인지 부족”으로 채점하는 기능은 없습니다.

### 7.2 집중 여유의 시나리오

$$
R(t)=100(1-S(t))(1-F(t))
\left[(1-\gamma)+\gamma C_a(t)\right],\qquad
\gamma=0.2.
\tag{25}
$$

곱셈은 한 조건의 불리함을 다른 조건의 큰 값으로 무제한 상쇄하지 않도록 선택한 가설입니다. \(1-S\)와 \(1-F\)가 실제 집중력을 선형으로 표현한다는 입증은 없습니다. \(\gamma=0.2\)도 문헌에서 추정한 효과 크기가 아닙니다.

\(R\)는 **“이 가정에서의 집중 여유”**입니다. 80은 집중 80%, 20은 학업 수행 불가를 뜻하지 않습니다. 실제 능력·학습 성취·건강의 등급을 붙이지 않습니다. 사용자 기본 정보의 우선순위는 현재 보고 → 지금의 제약 → 가능한 다음 행동이며 \(R\)는 설명을 펼쳤을 때 보이는 잠정 예상입니다.

고정 \(\gamma\)와 상태·위상 범위가 있을 때 보수적인 범위는:

$$
R^-=100(1-S^+)(1-F^+)[1-\gamma+\gamma C_a^-],\qquad
R^+=100(1-S^-)(1-F^-)[1-\gamma+\gamma C_a^+].
\tag{26}
$$

정확한 \(\min/\max\)를 구하기 어려운 의존성이 있으면 가능한 경로 집합을 감싸는 외측 범위로 해석합니다. \(\gamma\)도 바꾸는 민감도 분석에서는 식 (25)를 다시 평가해 범위를 구합니다.

\(R^+-R^->20\)이면 숫자 중심의 안내를 하지 않고 “가정에 따른 차이가 커 현재 여유를 좁혀 말하기 어렵습니다”로 표시하는 정책입니다. 이 20은 정확도 기준이나 임상 문턱이 아닙니다.

### 7.3 학습량을 자동 생성하지 않습니다

$$
T_d^{known}=\mu(K_d)
\quad\not\equiv\quad
\int_{I_d}R(t)/100\,dt
\quad\not\equiv\quad
\text{지식 증가량}.
\tag{27}
$$

적분값을 만들 수 있다는 것과 그것이 실제 학습량이라는 것은 다릅니다. 이해도·문제 해결력·몰입·기억률은 별도 관측 없이 생성하지 않습니다. 과목을 입력하지 않는 이론은 과목 간 운영에 공통으로 쓸 수 있지만, 모든 과목의 학업 성과를 같은 척도로 측정하는 이론은 아닙니다.

## 8. 중단 검토 시점과 이탈 가설

### 8.1 실사용 안내: 부하 문턱의 첫 통과

앞으로 계속 작업한다고 가정했을 때 \(F_\star=0.5\)에 처음 도달하는 남은 시간을:

$$
b_F(f)=
\begin{cases}
0,&f\ge F_\star,\\
\tau_L\log\!\dfrac{1-f}{1-F_\star},&0\le f<F_\star
\end{cases}
\tag{28}
$$

로 둡니다. 식 (23)에 \(F_\star\)를 대입해 풉니다. 이것은 **규칙상 휴식 검토 시점**이지 실제 이탈이 발생할 시각이 아닙니다. \(F_\star\)는 가설적 정책 문턱입니다.

이미 \(F\ge F_\star\)라고 모델링될 때 \(F_{reset}=0.25\)까지 감소시키는 가정 속 휴식시간은:

$$
r_F(f)=
\begin{cases}
0,&f\le F_{reset},\\
\tau_R\log(f/F_{reset}),&f>F_{reset}.
\end{cases}
\tag{29}
$$

이는 “이 식에서는 그만큼 쉰다고 가정하면 해당 값이 된다”는 해입니다. 실제 휴식 효과·충분한 회복을 보장하지 않습니다. 쉬고도 졸리거나 계속하기 어렵다면 시간표의 계산값보다 현재 보고를 우선합니다.

### 8.2 연구 시나리오: 확률을 쓰려면 필요한 수식

이탈 가능성을 수학적으로 정의하려면 위험률과 관측 사건을 연결해야 합니다. 검증 전 개인 확률로 제시하지 않는 **연구 전용 잠정 모형**을 다음과 같이 완결합니다.

학습 시도 중 등록된 실행시간을 \(u\)로 놓고:

$$
\lambda(u)=\lambda_0
\exp\{\beta_S S(t(u))+\beta_F F(t(u))
+\beta_C[1-C_a(t(u))]\},
\quad
(\lambda_0,\beta_S,\beta_F,\beta_C)=(0.002,1,2,0.5).
\tag{30}
$$

\(\lambda\)의 단위는 분당 위험률입니다. 목표 사건은 **피로·졸림을 이유로 보고한 비계획 종료**입니다. 외부 방해·내용 막힘·모든 종료를 한 사건으로 섞지 않습니다.

여기서 0.002와 각 계수는 **계산 가능한 연구 초안을 만들기 위한 가설값**입니다. 0.002는 모든 공변량이 0일 때 지수모형 평균 대기시간을 500분으로 두는 기준점일 뿐, 실제 이탈 빈도의 근거가 없습니다. 기본값을 뒀다는 이유로 개인 확률을 공개하지 않습니다.

$$
\Lambda(u)=\int_0^u\lambda(v)\,dv,\qquad
Q(u)=e^{-\Lambda(u)},\qquad
P_{\rm scen}(u)=1-Q(u),\qquad
\dot Q=-\lambda Q,\quad Q(0)=1.
\tag{31}
$$

\(P_{\rm scen}\)은 외부 사건 없이 해당 작업 경로가 계속된다는 가정 아래의 **시나리오 누적확률**입니다. 실제 생활에서 경쟁하는 종료 원인을 모두 고려한 개인 발생확률이 아닙니다.

실행시간 \(u(t)\)는 해당 시도의 실행구간 길이만 누적합니다. \(t(u)\)는 누적 실행시간을 각 실행구간의 실제 시각으로 되돌리는 구간별 역매핑입니다. 휴식·일시정지 중에는 역매핑을 정의하지 않으며, 재개 경계는 다음 실행구간의 시작값을 사용합니다. 실행구간 오른쪽 끝에서 직접 종료한 사건의 위험률은 그 구간의 왼쪽 극한을 사용합니다. 휴식·일시정지 도중 최종 종료한 경우는 이 실행시간 위험모형의 관심 사건으로 넣지 않고 별도 종료 경로로 표시합니다.

수치 계산은 실행시간 축에서 중점법으로 적분합니다. 구간을 1분 이하로 나누고, 경계·휴식·재개·사건 시점에서 분할합니다. 0.5분 격자로 다시 계산해 누적확률 차이가 \(10^{-3}\)보다 큰 경우 더 세분합니다. 이 허용차는 수치 오차 기준이며 모형 정확도가 아닙니다.

### 8.3 종료·검열·경쟁 원인

| 기록 | 연구용 사건 처리 | 사용자의 의미 |
|---|---|---|
| 피로·졸림으로 비계획 종료 | 관심 사건 \(\delta=1\) | 실패 점수 없음 |
| 예정대로 종료 | 예정 관측 종료. 지속 가능시간 전체는 모름 | 정상 완료 |
| 외부 방해·내용 막힘·선택 변경 | 다른 원인의 종료 | 피로 사건으로 합치지 않음 |
| 종료 이유 미확인·타이머 유실 | 결과 누락 또는 불확실한 노출 | 조용히 정상 완료로 바꾸지 않음 |
| 잠깐 쉬고 같은 시도 재개 | 같은 시도의 노출 이어가기 | 쉬었다고 이탈 판정하지 않음 |

완전한 사건·노출 자료가 있고 해당 원인별 위험 모형을 평가할 때의 기여는:

$$
\mathcal L_j
=\lambda(u_j)^{\delta_j}
\exp\left[-\int_0^{u_j}\lambda(v)\,dv\right].
\tag{32}
$$

이는 모형 평가의 정의이지 자동 계수 갱신 명령이 아닙니다. 식 (32)은 시작 계획·실행 노출·관측 종료가 확인된 시도에 한해 적용합니다. 계획이 없거나 종료 원인·노출이 불확실하면 해당 기여는 미확인입니다. 다른 종료 원인을 관측 끝으로 두는 원인별 분석만으로 실제 누적발생률을 계산할 수는 없습니다. 실생활 확률을 주장하려면 경쟁 원인, 누락, 반복측정, 정책으로 정해진 종료 시점까지 별도로 다뤄야 합니다.

실사용 기본 경로는 식 (28)과 현재 입력을 사용합니다. 식 (30)–(32)의 확률은 연구 시나리오로만 남기며 검증 전에는 “30분 뒤 이탈확률 42%”와 같은 개인 진술을 제공하지 않습니다.

## 9. 지금 할 수 있는 행동을 고르는 규칙

### 9.1 가능한 선택을 먼저 계산합니다

현재 알려진 연속 가용구간을 \(\mathcal F^{now}\), 앞으로 하기로 선택한 양을 \(G^{now}_{remain}\), 사용자 블록 상한을 \(L\)로 둡니다.

$$
c(t)=\sup\{b\ge0:[t,t+b)\subseteq\mathcal F^{now}\},\qquad
b_{\max}=\min\{c(t),G^{now}_{remain},L\}.
\tag{33}
$$

구간들은 유한한 반열린 구간의 합집합으로 표현합니다. 합계 예산만으로는 \(c(t)\)를 알 수 없습니다. 정확한 연속 구간을 모르면 구체적인 “지금 25분 가능”은 보류하고 직접 선택한 짧은 시작·종료 같은 비확정적 선택을 제공합니다.

부하 예상이 적용 가능하고 아래의 상태범위·민감도 검사를 통과한 경우:

$$
b^{review}
=\left\lfloor\min\{b_{\max},b_F(F)\}\right\rfloor.
\tag{34}
$$

각 계수 대안에서 전파한 부하 범위를 \(\mathcal B_F(\theta)\)로 놓고, 모든 \(\theta\in\Theta_{sens}\), \(f\in\mathcal B_F(\theta)\)에 대해 식 (34)의 후보 집합 \(\mathcal B_{review}\)를 만듭니다. \(b_F\)는 \(f\)에 대해 감소하므로 각 범위의 양끝으로 최솟값·최댓값을 계산할 수 있습니다. 후보 최댓값−최솟값이 10분 이하이고, 모든 후보의 안내 범주(0분: 지금 검토 / 양수: 계속 후 검토)가 같을 때만 대표값을 표시합니다. 조건을 통과하더라도 가정 범위를 함께 제공합니다.

그 외에는 \(b_{\max}\)만 계획상 상한으로 사용합니다. 예를 들어 초기 부하 범위가 \([0,1]\)이면 지금 검토와 나중 검토가 함께 가능하므로 단일 모형 권장시간을 보류합니다. 어느 경우에도 “최적 학습시간”으로 이름 붙이지 않습니다. 1분 미만이면 억지로 1분을 권하지 않고 현재 구간을 종료하거나 다른 선택을 안내합니다.

### 9.2 우선순위와 종료 조건

안내 \(\pi(X)\)는 아래 첫 적용 규칙을 주요 안내로 제시하고, 다른 필요한 선택을 숨기지 않습니다.

| 우선 | 조건 | 주요 행동 후보 | 안내 종료·재검토 |
|---|---|---|---|
| 1 | 현재 식사·수면·회복 필요 또는 사용자 종료 요청 | 필요한 생활을 하거나 마치기 | 사용자가 해결·종료·다른 선택을 보고 |
| 2 | 수면 보호 진입·현재 일정 충돌·연속 여유 없음 | 멈추기, 일정 재배정 | 최신 계획에서 충돌 해소 |
| 3 | 유효한 \(z=2,3\) | 쉬기·마치기·수면 여건 검토 | 새 상태 보고 또는 60분 경과 |
| 4 | 현재 내용 막힘 | 문제·개념을 작게 나누기, 해설·도움 확인 | 사용자가 재개·전환·종료 선택 |
| 5 | 현재 외부 방해 | 방해원 줄이기, 장소·시간 변경 | 방해 해결 또는 계획 변경 |
| 6 | 시작이 어려움 | 자료 열기 등 한 행동, 최대 5분의 작은 시작 초안 | 시작·중단·다른 계획 선택 |
| 7 | 모든 허용 상태범위·계수 시나리오에서 부하 문턱에 도달하고 §9.1의 적용 검사를 통과 | 휴식 또는 종료 검토 | 실제 선택에 따른 기록 |
| 8 | 그 밖 | 허용 범위 안에서 계속·짧게 시작·종료 | 새 입력·제약·검토 시점 |

5분은 행동 단위를 작게 만드는 정책이지 효과가 입증된 보편적 최소시간이 아닙니다. 식사·빛·움직임·환경 정리가 \(S,F,R\)를 즉시 특정 수치만큼 올린다고 계산하지 않습니다. 명시적 휴식만 \(F\) 시나리오의 휴식 분기에 연결합니다.

안내의 유효성은 조건의 유효성과 함께 끝납니다. 대표 부하만 높고 허용 범위에 낮은 부하도 포함되면 우선 7을 모형 근거로 활성화하지 않습니다. 현재 졸림·명시적 휴식 요청에 의한 도움은 이 예상 검사와 무관하게 유지합니다. 어제 식사를 놓쳤다는 기록만으로 오늘 계속 식사 알림을 만들지 않습니다. 높은 생활 점수가 현재 졸림을 무효화하지도 않습니다.

현재 심한 졸림이 있으면 점수 확보를 위해 버티도록 유도하지 않습니다. 지속되는 수면 문제 등은 앱 점수로 진단·치료하지 않고 전문적인 상담을 고려하도록 안내하는 범위에 머뭅니다.

## 10. 식사·충동·일상 관리의 이론

### 10.1 상태를 모르면 절차를 설계합니다

열량·혈당·배고픔 강도·정신적 충동 에너지를 기본 입력으로 추정하지 않습니다. 이 영역은 생리 ODE를 덧붙이는 대신 **상황–선택–실행의 유한 상태 규칙**으로 완결합니다.

$$
\text{상황 인지}
\longrightarrow\text{현재 필요 확인}
\longrightarrow\text{선택}
\longrightarrow\text{실행}
\longrightarrow\text{닫힘}.
\tag{35}
$$

현재 필요 확인은 선택적 도움 경로에서만 합니다. “지금 필요한 식사·간식인가”, “먹기로 할 것인가”, “다른 행동을 먼저 할 것인가”를 사용자가 고릅니다. 배고픔을 ‘가짜’라고 판정하지 않습니다. 식사 필요가 확인되면 먹기를 포함하는 선택이 먼저입니다.

충동 대응에서의 성공은 **미리 정한 선택 절차를 사용한 것**이지 먹지 않은 결과가 아닙니다. 야식 시각만으로 실패를 판정하지 않습니다. 일반 수면 지침도 취침 전 큰 식사와 가벼운 간식을 구별합니다. [NHLBI, Healthy Sleep Habits](https://www.nhlbi.nih.gov/health/sleep-deprivation/healthy-sleep-habits)

### 10.2 실행 의도를 규칙으로 사용합니다

사전 계획은 다음 구조를 갖습니다.

$$
\mathcal I_k=(\text{단서}_k,\text{가능한 행동}_k,\text{대안}_k,\text{종료조건}_k).
\tag{36}
$$

예를 들면 “공부를 마치고 음식을 찾게 되면, 현재 식사 필요를 확인하고 먹기 또는 다른 행동을 선택합니다”입니다. 본인의 맥락에 맞지 않는 절차는 바꿀 수 있으며 다음 적용 시점부터 새 버전으로 기록합니다.

상황과 행동을 연결하는 실행 의도 연구는 이 형식의 근거입니다. 다만 본 명세의 식사 절차와 개인 효과까지 검증한 연구는 아닙니다. [Gollwitzer & Brandstätter, 1997](https://www.socmot.uni-konstanz.de/publications/implementation-intentions-and-effective-goal-pursuit)

### 10.3 다른 생활관리 요소의 위치

움직임, 조용한 회복, 내일 준비, 학습 환경 정리 중 **현재 필요한 하나**를 돌봄 행동으로 선택합니다. 전부를 매일 의무 입력으로 추가하지 않습니다. 구체적인 완료 기준과 가능한 대안을 사전에 정합니다.

장기적으로 같은 시각에 일어나기 위해서는 다음날 기상 \(W_{d+1}\)과 확보할 수면기회 \(s_{d+1}\)에서 오늘 밤 보호 시작 \(W_{d+1}-s_{d+1}\)를 도출합니다. 오늘 남은 공부를 그 뒤로 밀어 넣지 않습니다. 늦게 끝났다면 최신 계획에서 잠·일정·학습을 재배치하며, 이미 부족한 잠을 더 줄여 기상 점수를 얻도록 안내하지 않습니다.

기분·스트레스·카페인·운동량·음식 상세 같은 추가 변수는 관련성이 없어서 제외하는 것이 아닙니다. 기본 의사결정에 비해 입력 비용·추정 불확실성이 커서 이번 핵심 모델에서 제외합니다. 필요할 때 맥락 기록으로 추가하더라도 사전에 정의한 소비처가 없으면 점수·ODE에 몰래 연결하지 않습니다.

## 11. 생활실천 점수와 누적 보상

### 11.1 점수의 성격과 이번 버전 변경

생활실천 점수는 네 영역을 각 25점으로 둡니다. 동일 배점은 건강 효과가 동일하다는 뜻이 아니라 특정 한 영역이 보상을 독점하지 않도록 선택한 정책입니다. 합성지표의 가중치는 가치판단과 민감도 검토를 필요로 합니다. [OECD/JRC, 2008, §1.6–1.7](https://www.oecd.org/content/dam/oecd/en/publications/reports/2008/08/handbook-on-constructing-composite-indicators-methodology-and-user-guide_g1gh9301/9789264043466-en.pdf)

v1.2와 달리 수면 영역 25점 안에서 **수면 20점 + 수면 목표를 충족한 경우에만 열리는 기상 5점**을 둡니다. 잠을 줄여 기상 가점을 얻는 선택을 막기 위한 비보상적 정책입니다. 이 변경은 새로운 정책 버전에만 적용하며 과거 점수는 다시 채점하지 않습니다.

### 11.2 수면·기상

목표·입력이 유효할 때:

$$
q_s=\min(1,h_d/H_d),\qquad
\epsilon_w=|w_d-W_d|,\qquad
q_w=\max\left(0,1-\frac{\max(0,\epsilon_w-\delta)}{\eta_w}\right).
\tag{37}
$$

\(w_d,W_d\)는 같은 수면 사건에 연결된 날짜 포함 시각입니다. 자정을 기준으로 단순 시계 차이를 빼지 않습니다. 허용폭 안에서는 모두 1이며 더 일찍 일어나는 추가 보상은 없습니다.

$$
\kappa_w=
\begin{cases}
0,&q_s\text{가 확인되고 }q_s<1,\\
q_w,&q_s=1,\ q_w\text{가 확인됨},\\
\bot,&\text{그 밖},
\end{cases}
\qquad q_H=\frac{20q_s+5\kappa_w}{25}.
\tag{38}
$$

따라서 \(q_H\le q_s\)이고, 목표 미달 수면은 기상시각과 무관하게 20점 미만, 목표 충족 수면은 기상시각과 무관하게 최소 20점입니다. 목표 이상 수면이 가능한 상황에서 목표 미만으로 줄여 기상 가점을 얻는 선택이 더 높은 점수를 만들 수 없습니다. 너무 이르거나 늦은 기상은 채택한 일정과의 편차이며 사람의 성실성 평가가 아닙니다.

이 정책은 목표 경계에서 불연속입니다. 목표 직전 수면을 목표 충족으로 과장 보고할 유인이 생길 수 있으므로 입력 정밀도·과장 보고·압박을 연구에서 검토합니다. 자기보고의 진실성이나 수면 목표의 의학적 적정성을 보장하지는 않습니다. 문제가 크면 기상 5점을 제거하고 기상 편차를 보상 없는 기술지표로 남기는 대안과 비교합니다.

주수면으로 표현하기 어려운 분할수면의 수면 점수는 기본 모드에서 보류합니다. 상세 수면 모드를 채택하면 중복 없는 실제 수면 구간 합계와 사전 정의한 평가 주기를 별도로 설정해야 하며, 그 모드의 점수를 주수면 점수와 자동 비교하지 않습니다.

### 11.3 식사와 돌봄

식사 기준이 사전에 정의돼 있어야 다음을 계산합니다.

$$
q_M=
\begin{cases}
0,&m=0,\\
1,&m=1,\ c=\mathsf N,\\
1,&m=1,\ c=1,\ \text{절차 기준 있음},\\
1/2,&m=1,\ c=0,\ \text{절차 기준 있음},\\
\bot,&\text{그 밖},
\end{cases}
\qquad
q_R=
\begin{cases}
r,&\text{돌봄 기준과 보고 있음},\\
\bot,&\text{그 밖}.
\end{cases}
\tag{39}
$$

식사 기준이 없거나 \(m=\bot\)이면 전체 \(q_M=\bot\)입니다. 상황 없음은 충동을 견뎌낸 사건이 아니므로 관련 능력 증가로 해석하지 않습니다. \(q_M=0\)도 현재 굶고 있으라는 뜻이 아니며 필요한 식사 도움은 즉시 제공합니다.

### 11.4 학습 실천

유효한 \(G_d^{ref}>0\)이면:

$$
q_L^{known}=\min(1,T_d^{eligible}/G_d^{ref}).
\tag{40}
$$

이는 이미 확인된 시간으로 확보한 충족분입니다. 현재 전체 목록이 미확인이라도 기존 적립 근거는 남습니다. \(G_d^{ref}=0\)이 유효하게 사전 채택된 휴무·가용량 0인 경우에만 학습 영역을 적용 제외합니다. 미설정·충돌·미실행을 휴무로 바꾸지 않습니다.

### 11.5 부분 적립과 완결 점수

계산 편의를 위해 \([x]_{known}\)은 값이 유효하게 확인됐으면 \(x\), 아니면 **원장의 근거 없음 0**을 반환하는 함수로 둡니다. 원자료의 \(\bot\)를 실제 실패 0으로 바꾸는 함수가 아닙니다.

$$
p_H=20[q_s]_{known}+5[\kappa_w]_{known},\quad
p_M=25[q_M]_{known},\quad
p_R=25[q_R]_{known},\quad
p_L=25[q_L^{known}]_{known}.
\tag{41}
$$

수면 목표를 충족했는데 기상만 미확인이면 수면 20점은 적립하고 기상 5점 배점의 충족분만 보류합니다. 수면이 목표 미달로 확인되면 \(\kappa_w=0\)이므로 기상 응답과 무관하게 해당 영역 점수는 확정할 수 있습니다. 이 0은 미확인의 대체값이 아니라 사전 정책의 기상 가점 비적용 결과입니다.

학습을 제외한 세 영역은 적용됩니다. \(a_L=0\)은 유효한 학습목표 0인 경우, 그 외에는 1입니다. 수면 영역의 확정 조건은 \(\operatorname{known}(q_s)\land[q_s<1\lor\operatorname{known}(q_w)]\)입니다. \(f_M,f_R\)는 각 영역 값의 확정 여부, \(f_L\)은 유효한 양의 목표와 현재 전체 활동 확인 \(b_d=1\) 여부입니다. 필요한 기준이 없는 값에 일반 사칙연산을 하지 않으며 해당 합성값을 \(\bot\)로 둡니다.

$$
E_d=p_H+p_M+p_R+a_Lp_L,\qquad
P_d=25(3+a_L),
\tag{42}
$$

$$
D_d=
\begin{cases}
100E_d/P_d,&\text{모든 적용 영역의 }f_k=1,\\
\bot,&\text{그 밖}.
\end{cases}
\tag{43}
$$

미완결 상태에서는 “확보한 점수 \(E_d/P_d\), 미확인 영역”을 함께 표시합니다. 분모를 이미 응답한 영역만으로 축소하지 않습니다. 휴무일 3개 영역을 모두 채우면 \(D=100\), 적립 상한은 75이며 보통 학습일 100과 적용 범위가 다릅니다.

### 11.6 누적 포인트

$$
XP_n=\sum_d E_d(n),\qquad
XP_{n+1}=XP_n+
\sum_{(d,k)\in\mathcal A_n}
\left[p_{dk}(n+1)-p_{dk}(n)\right].
\tag{44}
$$

\(\mathcal A_n\)은 실제로 바뀐 날짜·영역 셀의 집합입니다. 재확인할 때마다 새 점수를 더하지 않습니다. 새 미확인 활동은 기존 포인트를 없애지 않습니다. 실제 기록 정정으로 근거가 줄었다면 포인트도 바로잡되 정정 내역을 설명합니다.

연속일 중단·미응답 때문에 과거 포인트를 벌금처럼 지우지 않습니다. 목표 초과·세션 쪼개기·앱 접속·긍정적인 현재 졸림 답변에는 추가 보상이 없습니다. 포인트를 숨겨도 기록과 도움은 사용할 수 있습니다.

### 11.7 모든 내부 숫자를 올릴 대상으로 만들지 않습니다

사용자가 확보할 숫자는 확인된 실천 적립 \(E,XP\)입니다. \(R\)는 변하는 시나리오이며 저축할 수 없습니다. 내부 부하 \(F\), 위험률 \(\lambda\), 기록 누락 수를 보상 숫자처럼 전시하지 않습니다.

이 분리는 사용자의 보상 욕구를 버리는 것이 아니라, **높여도 목적을 해치지 않는 수치에만 보상 역할을 맡기는 것**입니다. 포인트가 행동량을 늘릴 수 있다는 연구가 있어도 내적 동기나 질이 함께 좋아진다는 보장은 없습니다. [Mekler 등, 2017](https://research.aalto.fi/en/publications/towards-understanding-the-effects-of-individual-gamification-elem/)

## 12. 최근 학습 양상: 유형은 사람이 아니라 기간에 붙입니다

### 12.1 분석 단위와 충분 조건

최근 14일 안에 시작한 학습 시도들을 기준으로 합니다. 전체 대상 집합은 그 창 안에 시작한 식별 가능한 시도 전부이며 미종료·미확인·양수 노출 미확정 시도도 포함합니다. 분류 집합은 그중 정정·버전 확인이 끝나고 실행 노출이 양수이며 종료 이유가 분류 가능한 시도입니다. 자정 이후에 끝나도 하나의 시도를 중복 집계하지 않습니다.

종료 이유를 모른다는 응답과 미응답은 분류 가능한 이유가 아닙니다. 분류 가능한 시도 수 \(N\), 전체 대상 시도 수 \(N_{all}\), 분류 가능한 \(N\)개 시도의 서로 다른 시작일 수 \(D_{obs}\)로:

$$
\operatorname{Enough}
=\mathbf1\{N\ge10,\ D_{obs}\ge5,\ N/N_{all}\ge0.7\}.
\tag{45}
$$

\(N_{all}=0\)이면 나눗셈 없이 자료 부족입니다. 10회·5일·70%·14일은 성급한 라벨링을 줄이려는 정책값입니다. 통계적으로 충분한 표본수나 심리유형의 존재를 보장하지 않습니다. 원장 표현상의 분할·중복 정정은 같은 시도 ID로 묶습니다. 실제로 종료·새 시작을 여러 번 하면 시도 수와 유형 분포가 달라질 수 있습니다. 이에 대한 완전한 분할 불변성을 주장하지 않으며, 계획 길이와 하루별 시도 수를 함께 검토합니다. 유형 자체에는 보상이 없습니다.

### 12.2 분류식

분류 가능한 이유 \(k\)는 예정대로, 피로·졸림, 내용 막힘, 외부 방해, 선택·일정 변경입니다.

$$
p_k=\frac{n_k}{N},\quad
k_1=\arg\max_k p_k,\quad p_{(2)}=\text{두 번째로 큰 비율}.
\tag{46}
$$

$$
\operatorname{Profile}=
\begin{cases}
\text{자료 부족},&\operatorname{Enough}=0,\\
\text{이유 }k_1\text{ 우세 양상},
&n_{k_1}\ge3,\ p_{k_1}\ge0.5,\ p_{k_1}-p_{(2)}\ge0.2,\\
\text{혼합 양상},&\text{그 밖}.
\end{cases}
\tag{47}
$$

최상위가 동률이면 혼합입니다. 문턱은 등호를 포함합니다. 정정·날짜 경과로 양상이 바뀔 수 있으며 계산할 때마다 동일한 고정 규칙을 적용합니다. 사람별 분류 계수를 학습하는 것이 아닙니다.

| 표시할 최근 양상 | 뜻 | 연결할 기본 검토 |
|---|---|---|
| 계획 완료가 많은 양상 | 기록한 시도에서 예정대로 마침이 우세 | 현재 계획 유지 여부. 높은 능력으로 해석하지 않음 |
| 피로·졸림 중단이 많은 양상 | 해당 이유의 종료가 우세 | 수면 기록·현재 졸림·작업 길이·회복 선택 |
| 내용 막힘 중단이 많은 양상 | 해당 이유의 종료가 우세 | 내용 분할·선행 개념·자료·도움 |
| 외부 방해 중단이 많은 양상 | 해당 이유의 종료가 우세 | 환경·알림·장소·시간 |
| 선택·일정 변경이 많은 양상 | 그 이유의 종료가 우세 | 계획 유연성·생활 제약. 회피로 단정하지 않음 |
| 혼합 양상 | 한 이유가 충분히 우세하지 않음 | 현재 상황별 선택 |
| 자료 부족 | 사전 조건 미충족 | 사실 기록만 표시 |

이것은 생물학적·심리학적 유형 이론을 발견했다는 주장이 아닙니다. 사용자에게 서로 다른 다음 행동을 연결하기 위해 **관측된 종료 사유로 나눈 운영적 분류**입니다.

### 12.3 어느 시점에 중단됐는가

같은 종료 이유 \(k\)의 확인된 실행시간을 \(\ell_j\)라 하면 \(n_k\ge5\)일 때:

$$
\widetilde\ell_k=\operatorname{median}\{\ell_j:e_j^{end}=k\},\qquad
[\ell_k^{25},\ell_k^{75}]
=\text{해당 표본의 25·75백분위 범위}.
\tag{48}
$$

백분위는 오름차순 표본의 최근접 순위 \(\lceil pn_k\rceil\)로 고정합니다. 표본 수·예정 블록 길이·관측 기간을 함께 표시합니다. “최근 피로로 마친 5회의 가운데 실행시간은 22분입니다”는 가능하지만 “집중 한계는 22분입니다”는 불가능합니다.

완료된 시도만의 중단 시간은 선택된 표본입니다. \(\ell_j\)는 휴식을 제외한 누적 실행시간이며 연속 집중시간이나 첫 주의이탈 시점이 아닙니다. 아직 중단하지 않은 시도, 짧게 계획한 시도, 다른 이유로 마친 시도가 있으므로 이를 개인의 생존곡선·미래 한계로 사용하지 않습니다. 휴식 도중 최종 종료한 시도는 종료 이유 요약에는 포함할 수 있지만 §8의 실행 중 사건 위험률 평가에는 그대로 넣지 않습니다.

### 12.4 기록이 허용하는 생활·복귀 요약

최근 7일의 동일 기준 확정값에 대해 \(a_{kj}^{known}=1\)은 비교 가능한 유효값이 있는 경우입니다. 집계 전용 값 \(\widetilde q_{kj}\)는 그 경우 \(q_{kj}\), 그 외에는 계산 기여 0으로 정의합니다. 원자료의 미확인을 0으로 수정하지 않습니다.

$$
N_{k,d}=\sum_{j=d-6}^d a_{kj}^{known},\qquad
M_{k,d}=
\begin{cases}
\dfrac{\sum_{j=d-6}^d\widetilde q_{kj}}{N_{k,d}},&N_{k,d}>0,\\
\bot,&N_{k,d}=0.
\end{cases}
\tag{49}
$$

계산에서는 미확인 항의 기여를 0으로 두되 원자료와 관측일수를 유지합니다. 기간이 이동하면 새 날짜를 더하고 오래된 날짜를 뺍니다. 기준이 바뀌면 비교 가능한 부분만 다시 선택합니다.

복귀는 “중단·휴식 후 같은 시도 또는 명시적으로 연결된 새 시도를 실제로 다시 시작함”으로 정의합니다. 기본 모드는 확인된 복귀 건수와 중단·휴식 시작부터 재개까지의 시간만 제공합니다. 타이머에 재개가 없다는 이유만으로 실제 미재개를 확정하지 않으므로 복귀 비율은 보류합니다. 연구에서 비율이 필요하면 기준 중단 시점부터 60분 결과를 재개·미재개·미확인으로 별도 확인하고, 앞 두 결과가 확인된 사례를 분모, 재개 사례를 분자로 둡니다. 이 추가 입력은 기본 부담에 숨기지 않으며 실제 회복 효과나 인과관계로 해석하지 않습니다.

\(c_d\)는 \(m_d\)에 따라 선택적으로 수집되므로 전체 충동 빈도·조절 능력을 추정하지 않습니다. “필요한 식사를 챙겼다고 보고한 날 중, 답변한 해당일의 절차 실천”이라는 조건을 유지합니다.

## 13. 전체 상태·초기조건·사건 순서

전체 상태는 다음으로 닫습니다.

$$

(\mathcal R,\mathcal Y,\Theta^{ref},P^{now},
s,\ell,S,F,\phi,\mathcal B_S,\mathcal B_F,

\tag{50}
$$

\(\mathcal R\)은 버전 있는 원장, \(\mathcal Y\)는 자기보고, \(\mathcal B\)는 모형 범위, \(\mathcal H\)는 현재 도움의 조건·종료 상태, \(\mathcal P\)는 날짜별 포인트 원장입니다.

초기 원장은 비어 있고 자기보고·채택 계획은 미확인입니다. 실행 상태는 준비, \(\ell=0\), \(XP=0\)은 적립 원장 초기값입니다. 생활 실패 0점이나 실제 집중 가능 상태를 의미하지 않습니다. 모형 초기값은 §5.3·§6.2의 가정과 별도로 표시합니다.

동일 자료를 같은 규칙으로 재현하기 위한 처리 순서는:

1. 사건 ID·버전·시각·범위를 검사합니다.
2. 실제 기록의 정정과 계획 변경을 구별해 원장을 갱신합니다.
3. 영향을 받는 구간의 합집합·확인 상태를 다시 계산합니다.
4. 수면·작업·휴식 시나리오를 영향을 받은 최초 경계부터 다시 전파합니다.
5. 당시 기준으로 날짜별 적립 셀을 계산하고 차분을 반영합니다.
6. 같은 버전·관측 범위에서 최근 요약과 양상을 계산합니다.
7. 현재 입력·현재 제약으로 안내를 계산합니다.

동일 시각 경계에서는 끝나는 반열린 구간을 닫고 새 구간을 엽니다. 서로 양립할 수 없는 동시 사건·수면과 공부의 사실 충돌은 우선순위를 임의로 만들어 해결하지 않고 충돌 상태로 표시합니다.

현재 시나리오가 바뀌어도 과거에 어떤 안내를 보여줬는지 기록은 덮어쓰지 않습니다. 새 자료로 다시 계산한 값과 당시 가용 자료로 계산한 값을 구별해야 예측을 사후에 유리하게 고치는 일을 막을 수 있습니다.

## 15. 수학적으로 확인할 성질

### 15.1 상태 범위와 존재·유일성

각 구간의 \(S,F\) 미분방정식은 상태에 대해 선형이고 유한한 양의 시정수를 가집니다. 유한 구간별 입력에서 정확해가 존재하며 유일합니다. 경계에서 연속으로 연결하고 유한한 사건 전이를 적용합니다.

\(S=0,F=0\)에서는 해당 상태를 음수로 미는 항이 없고, \(S=1,F=1\)에서는 1보다 크게 미는 항이 없습니다. 따라서 초기값이 \([0,1]\)이면 계속 그 안에 있습니다.

$$
0\le S,F,C_a\le1
\quad\Longrightarrow\quad
0\le R\le100,\quad
\lambda>0,\quad
0\le P_{\rm scen}\le1.
\tag{52}
$$

이는 수학적 범위 증명입니다. 상태의 실제 측정 타당성을 증명하지 않습니다.

### 15.2 점수의 범위·상한

\(q_s,q_w,q_M,q_R,q_L\in[0,1]\)이면 각 적용 영역 \(p_k\in[0,25]\)이고 \(D\in[0,100]\)입니다. 수면을 목표 이상으로 늘려도 추가 가점하지 않으며, 학습도 상한을 넘겨 적립되지 않습니다.

수면·기상 점수는:

$$
20q_s+5\kappa_w\le25q_s,\qquad
q_s<1\Rightarrow p_H<20,\qquad
q_s=1\Rightarrow p_H\ge20
\quad\text{(필요값 확정 시)}.
\tag{53}
$$

따라서 기상시각을 어떻게 바꾸더라도 수면 목표 미달의 점수가 목표 충족의 점수보다 높아질 수 없습니다. 이는 채택한 목표에 관한 유인 성질이며 실제 개인에게 필요한 수면량을 보장하지 않습니다.

### 15.3 분할·중복에 대한 불변성

같은 확인 구간을 더 작은 여러 구간으로 나눠도 합집합은 같습니다.

$$
\bigcup_i J_i=K
\quad\Longrightarrow\quad
T^{known},T^{eligible},p_L
\text{는 동일합니다}.
\tag{54}
$$

등록 작업·휴식 노출도 세션 ID가 아니라 시간구간으로 합성하므로 같은 노출을 쪼갰다는 이유로 \(S,F\)가 달라지지 않습니다. 단순 재시작은 회복이 아닙니다.

### 15.4 미확인 추가와 실제 정정의 차이

기존 확인 기록·계획이 같다면 새 미확인 기록 추가는 기존 적립을 줄이지 않습니다. 새 사실이 확인되면 충족분이 증가하거나 같을 수 있습니다. 그러나 기존 사실 정정은 근거를 바꾸므로 감소할 수 있습니다. 이 두 경우를 같은 “미확인 페널티”로 처리하지 않습니다.

### 15.5 생활 보호와 보상의 한계

수면 보호구간·기준 채택 전의 추가 학습은 적립을 늘리지 않습니다. 다만 어떤 점수 규칙도 자기보고의 진실성·목표의 적정성·실제 건강을 수학적으로 보장할 수는 없습니다. 작은 목표를 채택해 높은 점수를 얻는 경우도 있으므로 점수 옆에 목표와 실제 시간을 함께 표시하고 사람 간 순위를 만들지 않습니다.

## 16. 끝까지 계산하는 가상 사례

아래 숫자는 모두 **검산을 위한 가상 사례**이며 민석님의 생활 기록이 아닙니다.

### 16.1 생활시간과 점수

하루 1440분, 수면 보호 510분, 고정일정 450분, 필수생활 180분, 여유 60분이면:

$$
A=1440-510-450-180-60=240,\qquad
G^{req}=120\Rightarrow G^{ref}=120.
\tag{55}
$$

수면 360분/목표 480분, 기상목표 07:00·실제 08:00, 허용 30분·감소폭 60분, 식사 \(m=1,c=0\), 돌봄 \(r=1\), 적립 가능 학습 30분이 모두 확정됐다고 하겠습니다.

$$
q_s=0.75,\quad q_w=0.5,\quad
p_H=20(0.75)+5(0)=15,
\tag{56}
$$

$$
p_M=12.5,\quad p_R=25,\quad p_L=25(30/120)=6.25,\qquad
D=E=58.75.
\tag{57}
$$

미확인 학습 10분이 추가되면 확보분 58.75는 유지하되 최종 \(D\)는 보류합니다. 그 10분이 보호구간 밖의 새 활동으로 확인되면 \(p_L=25/3\), \(D=60.833\ldots\), 추가 적립은 \(25/12=2.0833\ldots\)입니다.

이 사례의 수면은 목표 미달이므로 기상만 미확인이어도 수면·기상 영역 15점은 확정할 수 있습니다. 별도 사례로 수면 480분이 확인되고 기상만 미확인이면 20점을 확보하고 기상 부분을 보류합니다. 이때 실제 기상 08:00이 확인되면 2.5점이 추가됩니다.

유인 반례도 검토합니다. 같은 00:00 입면에서 07:30 기상·450분 수면은 18.75점이고, 08:00 기상·480분 수면은 22.5점입니다. 단순히 수면 충족값과 기상 충족값의 최솟값을 가점으로 사용하던 초안에서는 이 순서가 뒤집혔으므로, 식 (38)의 수면 충족 문턱으로 교정했습니다.

### 16.2 수면·집중 여유

\(H_0=480\)분의 가상 정상주기에서 \(S^*_{bed}=0.623376\), \(S^*_{wake}=0.092795\)입니다. 첫 실제 보고 수면을 360분으로 넣으면 08:00의 \(S=0.149393\), 이후 120분 각성 뒤 10:00의 \(S=0.237913\)입니다. \(\phi\)를 같은 기준일 16:00으로 두고 \(F=0.35\)를 가정하면 \(C_a=0.5\), 대표 \(R=44.5821\)입니다. 모두 가정의 계산값이며 실제 준비도 측정이 아닙니다.

작업부하 대표값 \(F=0.35\)일 때 문턱까지:

$$
b_F=90\log(0.65/0.5)=23.6128\ldots\ {\rm min}.
\tag{58}
$$

현재 연속 여유 40분, 앞으로 선택한 양 30분, 블록 상한 25분이면 계획상 상한은 25분입니다. 모형은 약 23분 뒤 검토를 계산하지만, \(\tau_L=45,180\)분 대안에서는 약 11.8,47.2분으로 달라집니다. 계획 상한을 적용해도 약 11–25분으로 10분 이상 차이가 나므로 **단일 모형 권장시간을 보류**합니다. 사용자는 계획상 25분 이내에서 선택할 수 있습니다.

즉, 계수를 정했다고 근거가 충분해진 것은 아닙니다. 이 사례는 수학적 완성과 개인 권장시간의 확정을 분리해야 하는 이유입니다.

### 16.3 휴식과 재개

\(F=0.5\)에서 명시적으로 10분 쉬는 시나리오라면:

$$
F_{after}=0.5e^{-10/20}=0.303265\ldots,\qquad
r_F(0.5)=20\log2=13.8629\ldots\ {\rm min}.
\tag{59}
$$

실제로는 회복 효과를 측정하지 않았습니다. “10분의 휴식을 기록했습니다”와 “이 가정에서는 부하가 이렇게 감소합니다”를 구분합니다. 현재 졸림이 계속되면 추가 학습을 자동 권하지 않습니다.

### 16.4 이탈확률의 가정 의존

상태가 잠시 \(S=0.4,F=0.3,C_a=0.75\)에 고정돼 있다고 단순화하면:

$$
\lambda=0.002e^{0.4+2(0.3)+0.5(0.25)},\qquad
P_{\rm scen}(25)=1-e^{-25\lambda}.
\tag{60}
$$

이 계산은 실제 시간 변화까지 포함한 전체 예측이 아니라 상수상태 검산입니다. 기준 가설의 \(P_{\rm scen}(25)\)는 약 0.142737입니다. \(\lambda_0\)를 4분의 1 또는 4배로 바꾸면 약 0.037771, 0.459923으로 달라집니다. 관측 자료로 평가하기 전에는 어느 값이 개인에게 맞는지 알 수 없으므로 이 확률을 사용자 예언처럼 제시하지 않습니다.

### 16.5 최근 양상

최근 14일, 서로 다른 6일에 분류 가능한 12개 시도가 있고 전체 대상이 14개라면 관측률은 \(12/14\)입니다. 피로·졸림 7개, 계획 완료 3개, 외부 방해 2개라면:

$$
p_{\rm fatigue}=7/12,\quad
p_{\rm planned}=3/12,\quad
p_{\rm fatigue}-p_{\rm planned}=1/3.
\tag{61}
$$

정책 문턱을 만족하므로 “최근에는 피로·졸림으로 마친 기록이 많습니다: 7/12회, 14일 중 6일 관측”으로 표시합니다. “피로형 인간”이나 “집중력이 낮은 유형”이라고 하지 않습니다.

자료가 4일에만 몰려 있거나, 분류 가능 이유가 전체의 70% 미만이면 같은 비율이어도 양상 판정을 보류합니다.

## 18. 논문급 연구로 만들기 위한 명제와 설계

### 18.1 학술적 기여를 좁고 분명하게 잡습니다

잠정 논문 제목은 **“최소 자기보고와 고정계수 동역학을 결합한 학습·생활 자기조절 지원 모형의 설계 및 평가”**입니다.

기여 후보는 새로운 인간 본성의 법칙이 아니라 다음 세 가지입니다.

1. 관측·시나리오·보상을 분리하면서도 하나의 실행 체계로 연결하는 수학적 명세입니다.
2. 수면·생활 보호, 결측, 정정, 목표 변경에서도 보상이 목적을 해치지 않도록 하는 제약과 성질입니다.
3. 추가 입력·상태 예상이 실제로 단순 기록보다 유용한지를 검증할 수 있는 평가 설계입니다.

기존 수면식에 생활 점수를 붙였다는 사실만으로 독창성이 충분해지지는 않습니다. 가장 중요한 연구 질문은 **복잡한 예상층이 최소 기록·단순 규칙보다 무엇을 더 잘하는가**입니다.

### 18.2 반증 가능한 주장

| 연구 질문·가설 | 필요한 관측 | 틀렸다고 판단할 근거 |
|---|---|---|
| 추가 문항은 판단 개선 대비 수용 가능한 부담인가 | 설정·응답·정정 소요, 건너뜀, 중도 이탈, 이해 인터뷰 | 실익 없이 부담·누락·오해 증가 |
| \(R\)가 다음 시도의 어려움과 관련되는가 | 당시 고정 예측, 이후 독립적인 상태·과제 수행 자료 | 시간대·직전 수면·현재 졸림만 쓴 단순 기준보다 개선 없음 |
| 위험 모형이 피로·졸림 종료를 설명하는가 | 당시 예측, 실행 노출, 종료 이유, 경쟁 원인·누락 | 보정 불량, 단순 경과시간 기준보다 평가 손실 큼 |
| 제약 기반 안내가 생활 침범을 줄이는가 | 기록 외 표본일의 시간 재구성, 실제 수면·식사 누락 | 점수만 높고 생활 침범은 같거나 증가 |
| 점수·포인트가 지속 가능한 실행에 도움이 되는가 | 동일 계획 아래 실행·재개, 자율성·압박·부작용 | 과장 보고·수면 축소·식사 억제·불필요한 앱 사용 증가 |
| 최근 양상이 실제로 다른 도움 선택에 유용한가 | 다음 기간의 선택·상황 대응, 라벨 이해 | 문턱에 매우 불안정하거나 사람의 능력으로 오해 |

점수로 보상한 자기보고와 그 점수만으로 효과를 증명하면 순환논증이 됩니다. 연구용 보조 측정은 사전 동의를 받아 표본일·일부 세션에서만 별도로 수집하고, 기본 앱 입력에 자동으로 상시 추가하지 않습니다.

### 18.3 단계별 연구

**1단계 — 수학·명세 검증.** 경계값, 구간·버전, 불변성, 해석 오류를 검토합니다. 가상 사례는 여기의 자료이며 사용성·효과 자료가 아닙니다.

**2단계 — 형성 평가.** 사용자가 점수와 상태를 구별하는지, 미확인을 실패로 오해하는지, 입력을 지속할 수 있는지 관찰합니다. 문항 이해·소요시간·건너뜀·압박을 함께 봅니다.

**3단계 — 고정 예측 평가.** 입력 시점의 예측을 잠그고 이후 결과와 비교합니다. 사용자별 자료가 훈련·평가에 섞이지 않도록 구분하고, 반복측정은 참가자·날짜 수준에서 다룹니다. 계수를 연구 중 탐색적으로 바꾸면 새 버전으로 구분하고 같은 자료의 맞춤 결과를 검증 결과로 부르지 않습니다.

**4단계 — 지원 효과 비교.** 기록만 제공하는 조건과 기록+안내+보상을 제공하는 조건을 비교합니다. 학습된 생활습관은 쉽게 사라지지 않으므로 단순 교차설계의 잔류효과를 경계하고, 잠정 기본안은 참가자 단위 무작위 병렬 비교로 둡니다. 보상만의 효과를 주장하려면 안내·보상을 분리한 추가 설계가 필요합니다.

이 두 조건만의 차이는 전체 지원 묶음의 효과입니다. **예상층의 추가 가치**를 검증할 별도 비교에서는 입력·보상·생활 보호를 같게 유지하고, 현재 졸림+고정 블록 안내 조건과 동역학 추가 안내 조건을 비교합니다. 예측 평가에서의 개선이 실제 선택 개선까지 입증하는 것도 아니므로, 이 비교 없이 예상층의 실사용 효과를 주장하지 않습니다.

연구 참여자 모집·민감 정보 수집·실험은 적절한 윤리 검토와 동의 절차 이후에 수행합니다. 이번 문서는 실제 모집·승인·연구 수행을 의미하지 않습니다.

### 18.4 주 결과·분석·표본수

실사용 평가의 주 결과 후보는 **사전 선택한 실행의 달성 정도와, 그 과정에서 수면·필요 식사가 침범되지 않았는지**입니다. 점수 상승 자체를 주 효과로 삼지 않습니다. 핵심 결과 하나를 사전 지정하고 나머지는 보조·안전 결과로 둡니다.

예측 평가는 고정 모형의 시간의존 평가 손실·보정, 현재 졸림만 또는 경과시간만 사용하는 단순 기준과의 차이를 봅니다. 반복 관측을 독립 표본처럼 세지 않습니다. 현재 단일 졸림 문항은 설명변수·상태 보고이지 객관적 집중의 정답이 아닙니다.

효과크기·참가자 수는 현재 자료가 없으므로 만들어 내지 않습니다. 독립적인 두 집단 연속 결과의 매우 단순한 출발식은:

$$
n_{\rm arm}\approx
\frac{2(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2}{\Delta_{\min}^2}.
\tag{62}
$$

\(\alpha\)는 유의수준, \(1-\beta\)는 검정력, \(z_p\)는 표준정규분포의 \(p\) 분위수, \(\sigma\)는 결과의 표준편차, \(\Delta_{\min}\)은 의미 있다고 사전 정한 최소 차이입니다. 이 절의 \(z_p\)는 현재 졸림 응답 \(z(t_z)\)와 다른 통계 기호입니다. 실제 반복측정·탈락·군집·이분형 결과에는 이 식을 그대로 쓰지 않으며 예비자료와 계획한 분석에 맞춘 모의실험으로 정합니다. 현재는 효과·분산·검정 기준과 상관 구조가 미확정이므로 표본수 숫자는 보류합니다.

이는 이론의 빈 수식을 남긴 것이 아니라, **실제 연구 규모는 실제 분산·목표 효과·설계를 알아야 정할 수 있다**는 연구 계약입니다.

### 18.5 예상층을 제거할 기준

단순 기록·현재 졸림·고정 블록 정책에 비해 \(S,F,R,\lambda\)를 추가한 이득이 없거나 오해·부담이 커지면 해당 예상층을 제거합니다. 보호시간·원장·실천 보상은 독립적으로 남길 수 있습니다.

이 삭제 가능성이 중요합니다. 어느 이론 이름이 멋있다는 이유로 유지하는 것이 아니라, 실제 질문에 필요한 설명·예측·선택 개선을 제공하는지로 남길 부분을 결정합니다.

## 19. 구현으로 넘길 때의 계산 계약

이번에는 코드를 쓰지 않습니다. 다만 이후 구현자가 심리 가정이나 분모를 새로 발명하지 않도록 의존 순서를 정합니다.

| 6. 현재 출력 | 현재 보고·위상·모형 범위 | \(R\), 적용 상태 | 자기보고와 혼합 측정값 생성 안 함 |

엑셀에서도 시간구간 표, 보고 표, 계획 버전 표, 날짜별 적립 표로 분리할 수 있습니다. 식 (15)·(23)은 지수함수, 식 (28)·(29)는 로그함수, 점수는 조건·최솟값·합계, 유형은 고정 창의 집계입니다. 구간 겹침 제거·버전·결측 처리는 단순 셀 평균으로 대체하지 않습니다.

반올림은 표시 마지막에만 합니다. 시간·적립 내부 계산은 충분한 정밀도로 유지하고, 점수는 소수 첫째 자리, 모형 시나리오는 정수와 범위를 우선 표시하는 정책입니다. 확정 상태·단위·당시 기준을 숫자 옆에 보존합니다.

## 22. 잠정 완성 판정

이론 구성요소, 입력의 쓰임, 초기조건, 연속·이산 상태방정식, 점수·보상, 이탈 가설, 최근 양상, 안내, 결측·정정·범위 밖 경로, 계수 원장, 수학적 성질, 검산 사례, 연구 실패 기준까지 명시했습니다.

남은 것은 사용자에게 빈 선택을 떠넘기는 작업이 아니라 **이 잠정 이론이 실제로 유용하고 타당한지를 확인하는 작업**입니다. 모형이 개인에게 맞는지, 어떤 계수가 필요한지, 보상이 생활을 개선하는지, 입력부담이 감당 가능한지는 아직 검증하지 않았습니다. 그 구분을 유지한 상태에서 이론 초안을 완결합니다.
