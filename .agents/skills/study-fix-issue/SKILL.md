# 학습 입력 오류 수정

현재 작업 위치에서 `generation2`를 찾고 그 AGENTS.md와 대상 경로 지침을 적용합니다. 최신 인계·현재 파일·사용자의 재현 조건으로 작업 범위를 좁힙니다. 종료한 구현을 비교 자료로 읽지 않습니다.

- 오류 조건과 실제 호출/저장 경로를 확인합니다. 먼저 작동하는 수정 결과를 만들고 직접 관련된 확인을 이어갑니다. 원인 가설을 사용자 경험으로 단정하지 않습니다.
- 기존 원문·초안·ID·저장 키·설정·병행 변경을 보존하며 원인을 해결하는 최소 범위를 수정합니다. 자료 손실·권한·이관 위험은 실제 기록 적용 전에 격리된 자료로 확인합니다.
- 가까운 기존 검사를 재사용합니다. 새 회귀 검사는 반복 가치가 있는 동작 결함에만 추가합니다. 실행 명령은 현재 package.json을 확인합니다. 같은 확인을 새 변경 없이 반복하지 않습니다.
- 결과에는 해결한 행동, 볼 위치, 실제 확인과 남은 직접 조건을 남깁니다. 사용자 허용 범위의 다음 수정이 있으면 이어갑니다. commit·공개배포·DB 적용은 각각 기존 허용 범위를 따릅니다.

호출 예: `$study-fix-issue`를 사용해 메모를 저장한 뒤 다시 열면 사라지는 문제를 수정해 주세요.
