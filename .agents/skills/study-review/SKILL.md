# 학습 입력 변경 리뷰

현재 작업 위치에서 `generation2`를 찾고 그 AGENTS.md 및 대상 경로 지침을 적용합니다. 상위 공통 지침은 웹앱 AGENTS.md의 링크로 확인합니다. 최신 인계와 대상 diff/실제 호출 경로만 읽고 종료한 보관본은 조사하지 않습니다.

- 사용자가 지정한 리뷰 범위를 우선합니다. 병행·미커밋 파일을 되돌리거나 리뷰를 임의 수정·배포로 확대하지 않습니다.
- 실행 경로에서 발생 가능한 결함을 확인합니다. UI 변경이면 입력/복귀, 저장 변경이면 원문·ID·초안·실패 복구, API 변경이면 소유권·버전·원자성의 관련 조건을 선택합니다.
- 지적에는 대상 파일/위치, 발생 조건, 사용자 영향, 근거와 필요한 수정 방향을 포함합니다. 추측과 재현한 실패를 구별합니다. 근거 없는 스타일 지적과 검사 수 늘리기를 피합니다.
- 결과는 심각한 결함부터 보고하고 확인 범위·미확인 조건을 짧게 남깁니다. 결함이 없으면 확인한 범위에서 없다고 말합니다. 자동검사 통과를 실제 기기/Sync/학습 효과로 확대하지 않습니다.

호출 예: `$study-review`를 사용해 `src/data`의 이번 변경을 리뷰해 주세요.
별도 에이전트 실행은 현재 세션의 위임 허용에 따릅니다. 이 스킬 사용 자체로 위임을 요구하거나 허용하지 않습니다.
