# 학습 입력 웹앱 배포

현재 작업 위치에서 `generation2`를 찾고 AGENTS.md, 최신 인계, `docs/deployment.md`의 해당 부분을 읽습니다. 명령·원격·환경은 현재 파일과 실제 상태에서 확인합니다. 과거 포트·임시 실행파일·배포 ID를 현재 값으로 사용하지 않습니다.

- 이미 받은 배포 권한을 대상 범위에 맞게 적용합니다. 허용된 작업의 승인을 반복 요청하지 않습니다. 새로운 외부 대상의 승인이 필요하면 먼저 빌드와 review 가능한 변경을 준비하고 대상·변경을 구체적으로 제시합니다.
- 병행 변경과 이번 배포 범위를 구별합니다. 포함 범위가 불명확하면 다른 작업의 변경을 자동 포함·되돌리지 않습니다. 실제 기록·초안·설정·비밀키를 배포 산출물에 넣지 않습니다.
- 현재 package.json과 배포 정의가 요구하는 build/type/CI 및 변경 관련 저장·복구 확인을 수행합니다. 새 실패·영향 없이 전체 QA를 추가하지 않습니다.
- 실제 배포 URL·실행 결과·배포된 산출물과 해당 핵심 경로를 확인합니다. 빌드만 끝나면 배포 완료라고 보고하지 않습니다. 서버 적용·브라우저 동작·물리 기기·Sync를 구별합니다.
- 인계에는 이번 적용과 남은 직접 조건만 추가하고 기존 이력·미검증을 유지합니다. PR을 생성했다면 Codex 작업에 연결합니다.

호출 예: `$study-deploy`를 사용해 현재 허용된 웹앱 배포를 진행해 주세요.
